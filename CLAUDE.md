# CLAUDE.md

Репозиторий сайта «Будет на ЕГЭ»: статический сайт в корне и приложение
Next.js в папке `app/`. Правила проекта лежат в документах, которые надо
читать перед работой:

- `app/README.md` — запуск, команды, правила дизайн-системы
  (только семантические токены, три брейкпоинта, шаг сетки 4px).
- `docs/razdel-pravila.md` — обязательные правила для всех разделов
  (заданий): липкая лента вкладок, липкое «Содержание» в теории, текст
  с формулами через `Tex`/`typeset`, карточки опорных задач без формул,
  автопроверки сырого TeX.
- `docs/zadanie-11/metodika.md` — методика раздела «Текстовые задачи».

## Дизайн-скиллы

В `.claude/skills/` лежат скиллы для работы с интерфейсом:
`impeccable`, `design-taste-frontend`, `ui-ux-pro-max`, `frontend-design`,
`awesome-design`, `playwright-cli`.

**При любой работе с интерфейсом сайта** (новые страницы, правки вёрстки,
аудиты) эти скиллы использовать обязательно, в таком порядке:

1. `impeccable` — сначала: аудит и критика существующего экрана
   (иерархия, типографика, ритм отступов, состояния, доступность).
2. `design-taste-frontend` и `ui-ux-pro-max` — решения по типографике,
   цвету, отступам и иерархии.
3. `frontend-design` — при создании новых блоков и страниц.
4. `awesome-design` — если нужен ориентир по стилю; читать 1–2 файла из
   `references/`, брать цвета, шрифты и отступы, но не логотипы и бренды.
5. `playwright-cli` — скриншоты страниц до и после правок (десктоп и
   мобильный около 390 px).

**Скиллы отвечают только за визуальную часть.** Математическое содержание,
формулировки задач и решений, порядок решений и колонок в таблицах,
обозначения, KaTeX-разметка, структура меню и все правила, уже записанные
в этом файле и в документах выше (`app/README.md`, `docs/razdel-pravila.md`),
имеют приоритет над рекомендациями скиллов. Если скилл предлагает другой
шрифт, палитру или библиотеку компонентов — остаёмся на токенах проекта
(`app/src/styles/tokens.css`) и общих компонентах.

**В отчёте и описании PR** указывать, какие скиллы применялись и что
именно они изменили (какие решения приняты по их рекомендациям).

Примечания по скриптам скиллов: `impeccable/scripts/impeccable` при первом
запуске скачивает бинарный движок из GitHub Releases (проверка sha256);
`ui-ux-pro-max/scripts/*.py` только читают локальные CSV из `data/`.
Оба запускать не обязательно — инструкции в SKILL.md работают и без них.
