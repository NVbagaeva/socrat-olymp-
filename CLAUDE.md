# CLAUDE.md

Сайт — Next.js со статическим экспортом в `app/` (`output: 'export'`,
`trailingSlash: true`), хостинг — Apache (`app/public/.htaccess`).

## Перенос и переименование страниц

- Перенёс или переименовал страницу — **сразу** обнови все внутренние
  ссылки на новый адрес: меню, вкладки, карточки, оглавления, данные
  задач, пропсы вроде `listHref`, адреса, собираемые в коде. Хвосты
  адресов бери из общих констант (`content/opornye.ts` → `OPORNYE.tail`,
  `lib/paths.ts`), а не пиши строкой.
- Заглушки «Страница переехала» (`components/layout/Redirect.tsx`,
  `RedirectPage`) — только для старых внешних ссылок и закладок.
  Внутри сайта на них не ссылаться никогда.
- Каждой заглушке — серверный 301 в `app/public/.htaccess` (раздел
  «Переехавшие страницы») на тот же адрес, что у неё самой.
- Перед коммитом собрать сайт и запустить проверку ссылок:

  ```bash
  cd app && LEGAL_DRAFT=1 pnpm build && pnpm test:links
  ```

  `scripts/check-links.mjs` падает, если внутренняя ссылка ведёт на
  заглушку или в 404, если у заглушки нет 301 в `.htaccess` или её новый
  адрес не существует. Список проблем должен быть пустым.
