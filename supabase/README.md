# Supabase: база и вход

- `migrations/` — миграции для `supabase db push` и `supabase start`.
  Сейчас там миграция согласий (PR #170, `docs/legal/README.md`): путь
  «настоящей» регистрации сессии С-3, где пользователя создаёт сервер
  сайта.
- `trial/auth_trial.sql` — пробный личный кабинет (`docs/AUTH.md`):
  таблицы `profiles` и `kits`, правила доступа, удаление аккаунта и хук
  регистрации по списку адресов. Применяется **вручную** в SQL Editor
  пробного облачного проекта. В `migrations/` не кладётся: с миграцией
  согласий он несовместим (её триггер не пускает регистрацию без
  галочек), а проверка `pnpm test:soglasiya-sql` прогоняет всю папку
  `migrations/`.
- `tests/` — проверки миграции согласий на голом PostgreSQL.
- `templates/` — тексты писем; вставляются в панель, см. README там.
- `config.toml` — настройки локального `supabase start`.

Секретов в этой папке нет и быть не должно: список разрешённых адресов
живёт в Vault проекта, ключи — в переменных GitHub Actions.
