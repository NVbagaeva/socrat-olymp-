# Supabase: база и вход

Что здесь лежит и куда это применяется — в `docs/AUTH.md`.

- `migrations/` — SQL для базы проекта: таблицы `profiles` и `kits`,
  правила доступа (RLS), функция удаления аккаунта и хук регистрации
  по списку адресов. Применяется один раз в SQL Editor панели или
  командой `supabase db push`.
- `templates/` — тексты писем; вставляются в панель, см. README там.
- `config.toml` — настройки для локального запуска `supabase start`
  (нужен Docker): повторяют настройки облачного проекта, письма ловит
  локальный ящик Mailpit.

Секретов в этой папке нет и быть не должно: список разрешённых адресов
живёт в Vault проекта, ключи — в переменных GitHub Actions.
