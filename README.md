# Сайт учителя математики Н. В. Багаевой

Статический сайт без сборки: HTML, CSS и обычный JavaScript. Работает на GitHub Pages,
Node.js и npm не нужны. Весь изменяемый контент лежит в JSON-файлах в папке `data/`.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Главная: направления, результаты, отзывы, вопросы, контакты |
| `about.html` | Обо мне: опыт, образование, подход, динамика качества знаний |
| `materials.html` | База методических материалов с поиском и фильтрами |
| `essay.html` | Эссе «Моя педагогическая философия» |
| `data/site.json` | Имя, контакты, направления и цены, вопросы-ответы, цифры для шапки |
| `data/about.json` | Опыт, образование, приёмы преподавания, данные для графика |
| `data/results.json` | Баллы ЕГЭ и результаты олимпиад со ссылками на протоколы |
| `data/materials.json` | Карточки методических материалов |
| `data/reviews.json` | Отзывы |
| `assets/files/` | Сюда кладутся PDF-материалы |
| `assets/img/` | Иконка сайта и картинка для соцсетей |

## Что нужно заменить в первую очередь

Незаполненные места помечены в JSON словом `TODO`, а на сайте показываются жёлтой плашкой.

1. **Контакты** — `data/site.json`, блок `contacts`. У каждого контакта два поля:
   `value` (что видно на странице) и `href` (куда ведёт ссылка: `https://t.me/username`,
   `mailto:...`, `tel:+7...`). Пока `href` пустой, значение показывается просто текстом.
2. **Кнопка «Записаться»** — `data/site.json`, блок `cta`. Если указать `href`,
   все кнопки «Записаться» начнут вести туда напрямую, а не в раздел контактов.
3. **Цены и форматы** — `data/site.json`, массив `services`, поле `price` у каждого направления.
4. **Отзывы** — `data/reviews.json`. Замените текст и уберите строку `"placeholder": true`,
   тогда пропадёт плашка «пример». Отзывов может быть сколько угодно — карусель подстроится.
5. **Фото** — положите файл в `assets/img/` и укажите путь в `data/site.json`, поле `person.photo`.

## Как добавить методический материал

1. Положите PDF в `assets/files/` (или возьмите ссылку на внешний ресурс).
2. Добавьте объект в `data/materials.json`:

```json
{
  "id": "m-новый-материал",
  "title": "Название",
  "description": "Одно-два предложения о том, что внутри",
  "track": "olympiad",
  "type": "notes",
  "level": "advanced",
  "grades": [9, 10],
  "topics": ["теория чисел", "остатки"],
  "year": 2025,
  "file": "assets/files/имя-файла.pdf",
  "linkLabel": "Скачать PDF"
}
```

Значения полей:

- `track` — `olympiad`, `ege`, `oge`, `school`, `method` (для коллег);
- `type` — `notes`, `publication`, `lesson`, `masterclass`, `video`, `interactive`;
- `level` — `basic`, `medium`, `advanced`;
- вместо `file` можно указать `href` — тогда карточка ведёт на внешний ресурс.

Фильтры и поиск на странице подхватят материал автоматически.

## Как добавить отзыв

```json
{
  "id": "r-2026-01",
  "name": "Анна К.",
  "role": "мама ученика, 9 класс",
  "rating": 5,
  "date": "2026-01",
  "text": "Текст отзыва.",
  "result": "Призёр регионального этапа ВОШ"
}
```

Поле `result` можно опустить (или поставить `null`), звёзды рисуются по полю `rating`.

## Как посмотреть сайт локально

Страницы читают данные из `data/*.json` через `fetch`, а он не работает по протоколу
`file://`. Нужен локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Как опубликовать на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**.
3. Branch: ветка с сайтом, папка `/ (root)`. Сохранить.

Через минуту сайт будет доступен по адресу вида `https://<логин>.github.io/<репозиторий>/`.
Файл `.nojekyll` в корне нужен, чтобы GitHub Pages отдавал файлы как есть.

## График динамики

График на странице «Обо мне» рисуется из `data/about.json`, блок `quality`.
Там же лежат подписи и годы. Те же числа показываются таблицей — она разворачивается
под графиком, отдельно править её не нужно.
