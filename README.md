# Сайт учителя математики Н. В. Багаевой

Статический сайт без сборки: HTML, CSS и обычный JavaScript. Работает на GitHub Pages,
Node.js и npm не нужны. Весь изменяемый контент лежит в JSON-файлах в папке `data/`.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Главная: направления, результаты, отзывы, вопросы, контакты |
| `about.html` | Обо мне: опыт, образование, подход, динамика качества знаний |
| `materials.html` | База методических материалов с поиском и фильтрами |
| `classes.html` | Витрина разделов для учеников: классы с 5 по 11 |
| `class.html?grade=10` | Раздел одного класса: домашка, теория, рабочие файлы |
| `code.html` | Служебная страница: посчитать отпечаток нового кода доступа |
| `essay.html` | Эссе «Моя педагогическая философия» |
| `data/site.json` | Имя, контакты, направления и цены, вопросы-ответы, цифры для шапки |
| `data/about.json` | Опыт, образование, приёмы преподавания, данные для графика |
| `data/results.json` | Баллы ЕГЭ и результаты олимпиад со ссылками на протоколы |
| `data/materials.json` | Карточки методических материалов |
| `data/reviews.json` | Отзывы |
| `data/classes.json` | Список классов и отпечатки кодов доступа |
| `data/classes/10.json` | Домашка, теория и файлы десятого класса (и так для каждого) |
| `assets/files/classes/10/` | Файлы десятого класса |
| `assets/files/` | Сюда кладутся PDF-материалы |
| `assets/img/` | Иконка сайта и картинка для соцсетей |

## Что нужно заменить в первую очередь

Незаполненные места помечены в JSON словом `TODO`, а на сайте показываются жёлтой плашкой.

1. **Контакты** — `data/site.json`, блок `contacts`. У каждого контакта два поля:
   `value` (что видно на странице) и `href` (куда ведёт ссылка: `https://t.me/username`,
   `mailto:...`, `tel:+7...`). Пока `href` пустой, значение показывается просто текстом.
2. **Кнопка «Записаться»** — `data/site.json`, блок `cta`. Если указать `href`,
   все кнопки «Записаться» начнут вести туда напрямую, а не в раздел контактов.
3. **Цены и форматы** — `data/site.json`, массив `services`, поле `price` у каждого направления.
4. **Отзывы** — `data/reviews.json`. Замените текст и уберите строку `"placeholder": true`,
   тогда пропадёт плашка «пример». Отзывов может быть сколько угодно — карусель подстроится.
5. **Фото** — положите файл в `assets/img/` и укажите путь в `data/site.json`, поле `person.photo`.

## Как добавить методический материал

1. Положите PDF в `assets/files/` (или возьмите ссылку на внешний ресурс).
2. Добавьте объект в `data/materials.json`:

```json
{
  "id": "m-новый-материал",
  "title": "Название",
  "description": "Одно-два предложения о том, что внутри",
  "track": "olympiad",
  "type": "notes",
  "level": "advanced",
  "grades": [9, 10],
  "topics": ["теория чисел", "остатки"],
  "year": 2025,
  "file": "assets/files/имя-файла.pdf",
  "linkLabel": "Скачать PDF"
}
```

Значения полей:

- `track` — `olympiad`, `ege`, `oge`, `school`, `method` (для коллег);
- `type` — `notes`, `publication`, `lesson`, `masterclass`, `video`, `interactive`;
- `level` — `basic`, `medium`, `advanced`;
- вместо `file` можно указать `href` — тогда карточка ведёт на внешний ресурс.

Фильтры и поиск на странице подхватят материал автоматически.

## Как добавить отзыв

```json
{
  "id": "r-2026-01",
  "name": "Анна К.",
  "role": "мама ученика, 9 класс",
  "rating": 5,
  "date": "2026-01",
  "text": "Текст отзыва.",
  "result": "Призёр регионального этапа ВОШ"
}
```

Поле `result` можно опустить (или поставить `null`), звёзды рисуются по полю `rating`.

## Как посмотреть сайт локально

Страницы читают данные из `data/*.json` через `fetch`, а он не работает по протоколу
`file://`. Нужен локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Как опубликовать на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**.
3. Branch: ветка с сайтом, папка `/ (root)`. Сохранить.

Через минуту сайт будет доступен по адресу вида `https://<логин>.github.io/<репозиторий>/`.
Файл `.nojekyll` в корне нужен, чтобы GitHub Pages отдавал файлы как есть.

## График динамики

График на странице «Обо мне» рисуется из `data/about.json`, блок `quality`.
Там же лежат подписи и годы. Те же числа показываются таблицей — она разворачивается
под графиком, отдельно править её не нужно.


## Разделы для учеников

Страница `classes.html` — витрина классов с 5 по 11. Каждый класс открывается по своему коду,
который вы даёте на занятии. Внутри — три блока: домашние задания со сроками, теория по темам
и рабочие файлы.

### Что важно понимать про код доступа

Код закрывает раздел от случайных посетителей, но **не защищает данные**: файлы лежат
в открытом репозитории, и тот, кто знает прямую ссылку на файл, откроет его без кода.
Поэтому в разделах классов не должно быть ничего личного об учениках:

- никаких фамилий, оценок, характеристик и контактов;
- никаких сканов работ конкретного ребёнка;
- только учебные материалы и формулировки заданий.

Отметка «Сделал» у задания хранится в браузере ученика и вам не видна. Сдача решений
идёт прежним путём — через мессенджер, кнопка «Сдать решение» просто открывает диалог.

Если однажды понадобятся настоящие логины, личные оценки и приём файлов, вёрстку менять
не придётся — под неё подключается база данных (например, Supabase), и разделы начинают
работать персонально.

### Как поменять код класса

1. Откройте `code.html` (локально или на сайте) и введите новый код — латиница, цифры и дефисы.
2. Скопируйте получившийся отпечаток.
3. В `data/classes.json` найдите нужный класс и вставьте отпечаток в поле `codeHash`.
4. Сохраните файл. Старый код сразу перестанет пускать, у всех, кто входил по нему, доступ сбросится.
5. Передайте новый код ученикам.

Сам код нигде не хранится — в репозитории лежит только его отпечаток, восстановить код из него нельзя.
Демонстрационные коды сейчас заданы как `sokrat-5`, `sokrat-6` и так далее по классам — **поменяйте их
перед тем, как давать ссылку ученикам**.

### Как добавить домашнее задание

В файле `data/classes/<класс>.json`, массив `homework`:

```json
{
  "id": "hw-2026-09-14",
  "title": "Параметр: графический метод",
  "topic": "Параметр",
  "description": "Что именно нужно сделать.",
  "assigned": "2026-09-07",
  "deadline": "2026-09-14",
  "file": "assets/files/classes/11/parametr.pdf",
  "notes": "На что обратить внимание — показывается отдельной плашкой."
}
```

- `id` — любая уникальная строка, по ней хранится отметка «Сделал». Не меняйте его у уже выданного
  задания, иначе отметки учеников слетят.
- `deadline` — дата в формате `ГГГГ-ММ-ДД`. Статус («Срок сегодня», «Осталось 2 дня», «Просрочено»)
  считается автоматически.
- `file` можно заменить на `href`, если задание лежит по внешней ссылке. Оба поля можно оставить пустыми.
- `notes` необязательно.

### Как добавить теорию или рабочий файл

Там же, массивы `theory` и `files`:

```json
{
  "id": "t-parametr",
  "section": "Параметр",
  "title": "Опорный конспект",
  "description": "Коротко о содержимом.",
  "file": "assets/files/classes/11/parametr-konspekt.pdf",
  "href": null
}
```

`section` — заголовок, под которым материал встанет на странице; материалы с одинаковым `section`
группируются вместе. У файлов в `files` поле `section` не используется.

Куда класть файлы: `assets/files/classes/<класс>/`. Если ни `file`, ни `href` не заданы, на странице
будет написано «Скоро добавлю».

### Как убрать класс со страницы

В `data/classes.json` поставьте классу `"enabled": false` — он пропадёт из витрины.
Поле `"sample": true` показывает внутри класса плашку «Пример наполнения» — уберите её,
когда заполните раздел настоящими материалами.
