# Исходники 3D-рендеров

Здесь лежат оригиналы, как они пришли из генератора: белый фон, полный размер,
без сжатия. Эти файлы **не используются на сайте** — они нужны как архив,
если понадобится перерезать фон иначе или пересобрать картинку под другой размер.

Готовые к вёрстке версии (прозрачный фон, сжатые) лежат в `public/images/`
и `public/icons/`.

| Файл | Что это | Где используется готовая версия |
|---|---|---|
| `caesar-bust-source.png` | Бюст Цезаря, стекло | Hero страницы «О проекте» |
| `caesar-full-source.png` | Цезарь в полный рост, стекло | Блок «Как устроено» |
| `wife-bust-source.png` | Женский бюст, стекло | 404, пустые состояния |
| `caesar-icon-source.png` | Упрощённый бюст Цезаря | Иконки, аватары от 96px |
| `wife-icon-source.png` | Упрощённый женский бюст | Иконки, аватары от 96px |
| `nata-portrait-source.png` | Портрет, студийная обработка | Блок «Кто за этим стоит» |

## Как готовились файлы в `public/`

1. Белый фон вырезан заливкой от краёв кадра — так внутренние белые блики
   на стекле остались нетронутыми.
2. Кромка объекта подъедена на 1 px, чтобы убрать белую кайму.
3. Размер уменьшен до 1400–1600 px по длинной стороне.
4. Палитра сокращена до 255 цветов с дизерингом — объём файла упал
   примерно в шесть раз без видимой потери качества.

## Правила

- Стеклянные версии (`caesar-bust`, `caesar-full`, `wife-bust`) работают
  от 300 px. Ниже этого размера гранёность превращается в шум.
- Для размеров 96–256 px используются упрощённые версии из `public/icons/`.
- Для favicon 16–48 px 3D-рендер не годится вообще — нужен плоский SVG.
- Основной синий во всех объектах соответствует токену `#1F5FD0`.
