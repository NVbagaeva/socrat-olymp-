# Экраны задания №12: окно выбора, тренажёр, генератор

Снимки собранного сайта на ширине 1440, приложены к pull request
ветки генератора. Это не макет, а результат: как экраны выглядят
в продукте после этапов 2–6.

| Файл | Что на снимке |
|---|---|
| `01-okno-vybora-tipa-funkcii.png` | окно «Выберите тип функции»: карточки семейств с миниатюрами движка, счётчик из манифеста, «Готовится» у семейств без данных |
| `02-generator-polnyy-vybor.png` | вкладка «Генератор» с полным выбором: своё название работы, дата, четыре навыка, 20 задач, две колонки, чёрно-белая тема |
| `03-trenazher-konfigurator.png` | вкладка «Тренажёр»: конфигуратор, «Повтор ошибок» неактивен при пустой истории |
| `04-trenazher-zadanie.png` | сессия тренажёра: первое задание со свежими числами, кружки подхода |
| `05-list-uchenika.png` | лист ученика из генератора, первая страница: строка «Ответ: ____», ответов нет |

Полный набор состояний на 1440 / 768 / 360 — в чате сессии;
сюда положены только те пять, на которые ссылается описание PR.
