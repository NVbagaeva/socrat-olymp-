# Спасибо, что ты рядом 🌙❤️

Короткий анимационный мультик (~44 с) про двух пушистиков и маленькую чёрную машинку с пластырем.
Вертикальный формат 1080×1920 — для Telegram.

Файлы:

- `index.html` — сама анимация: SVG-персонажи, шёрстка на `feTurbulence` + `feDisplacementMap`, анимация на GSAP.
  Все реплики, тайминги сцен и финальная надпись вынесены в константы `LINES`, `T`, `FINAL_TEXT` в начале скрипта.
- `render.py` — покадровый рендер в MP4 (H.264, 30 fps) через Playwright + ffmpeg.

## Посмотреть в браузере

Просто откройте `index.html` в Chrome/Edge/Safari (нужен интернет: GSAP грузится с cdnjs, шрифт Nunito — с Google Fonts).
Сцена сама масштабируется под окно; после окончания появляется кнопка «▶ Ещё раз».

## Собрать MP4

Нужны Python 3.10+ и ffmpeg.

```bash
# 1. зависимости
pip install playwright
python -m playwright install chromium

# ffmpeg: любой из вариантов
#   macOS:   brew install ffmpeg
#   Ubuntu:  sudo apt install ffmpeg
#   Windows: winget install ffmpeg   (или скачать с ffmpeg.org и добавить в PATH)
#   без прав администратора: pip install imageio-ffmpeg   (render.py найдёт его сам)

# 2. рендер
python render.py                       # -> out.mp4 рядом со скриптом
python render.py -o love.mp4 --crf 16  # своё имя файла и качество
```

Полезные параметры:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-o`, `--out` | `out.mp4` | имя итогового файла |
| `--fps` | `30` | частота кадров видео |
| `--crf` | `18` | качество H.264, меньше — лучше и тяжелее |
| `--width`, `--height` | `1080`, `1920` | размер кадра |
| `--duration` | из анимации | принудительно обрезать/удлинить, с |
| `--ffmpeg` | из `PATH` | путь к ffmpeg |
| `--chromium` | браузер Playwright | путь к своему Chrome/Chromium |

Рендер идёт покадрово (каждый кадр — `window.__anim.seek(t)` + скриншот), поэтому результат не зависит от
производительности машины: ~1300 кадров занимают 5–8 минут. Готовый файл сразу можно отправлять в Telegram.

## Что поменять под себя

В начале `<script>` в `index.html`:

- `LINES` — текст реплик и время их появления (`at`, секунды);
- `T` — начало каждой сцены и общая длительность `T.end`;
- `FINAL_TEXT` — финальная надпись;
- `TYPE_SPEED` / `HOLD_AFTER` — скорость печати и сколько реплика висит после допечатывания;
- `POS` — где стоят герои и машинка.
