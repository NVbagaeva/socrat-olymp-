## Чем отличаются

| | Стеклянная сцена | Чертёж |
|---|---|---|
| Шрифт | Inter 4 Variable (wght + opsz): на крупном кегле — начертание Display, заголовки 620–640. Номера — тот же Inter, табличные цифры | Onest Variable, веса 400 / 500 / 700. Номера и цифры — JetBrains Mono. Одна рукописная ремарка — Caveat |
| Стекло | Везде: шапка, двери, карточки, панели, лента вкладок, нижнее меню. Одна рецептура: белое 55 %, blur 16 px (10 на телефоне), блик по кромке, двухслойная синяя тень. Позади — дрейфующие свечения: синее, оранжевое, терракотовое | Только шапка, нижнее меню и подписи к кристаллу. Остальное — белое и линия 1 px, теней нет |
| Цвет | Синий — интерактив, номера, свечения. Оранжевый — звёзды, тёплая дверь учителя, ошибки. Терракота — бейдж «структура 2027», свечение | Синий — только то, что нажимается. Терракота — одна точка внимания на экран (точка h на кристалле, ремарка учителя). Оранжевый — только свет внутри рендера. Бейдж — контур navy |
| Кнопки | Primary — глянцевая «таблетка» (градиент, блик, синяя тень). Secondary — стекло. Ghost — синий текст. Радиус 14 | Primary — плоская синяя, на ховере темнее. Secondary — белая с линией. Ghost — синий текст. Радиус 10 |
| Вкладки | Стеклянная дорожка, активная — глянцевая таблетка (фирменный жест) | Строка над линией, активная — синее подчёркивание 2 px |
| Карточки | Стекло, на ховере подъём на 3 px и синяя тень, пиктограмма покачивается | Белые с линией, на ховере синяя линия, пиктограмма сдвигается на 4 px |
| Свои шрифты | **100,1 КБ**: Inter latin 71,2 + cyrillic 28,9 | **57,2 КБ**: Onest latin 33,0 + cyrillic 15,5, JetBrains Mono (только цифры) 8,7. Caveat 44,1 КБ сайт и так грузит везде |

Общее для обеих страниц (от корневого layout сайта, не от направления): Inter 400–700 четырьмя файлами и Caveat — 300 КБ предзагрузки, KaTeX — 41,8 КБ шрифтов. При переходе на новое направление Inter из корня заменился бы его шрифтом, а не добавился к нему.

## Lighthouse, телефон

Lighthouse 12, профиль mobile: эмуляция Moto G Power, медленный 4G, CPU × 4. Сборка `pnpm build` под Apache с gzip, по 5 прогонов на страницу, в таблице — медиана.

| | Стеклянная сцена | Чертёж |
|---|---|---|
| Performance | **66** (60–76) | **80** (77–80) |
| First Contentful Paint | 1,7 с | 1,35 с |
| Largest Contentful Paint | 6,1 с | 5,4 с |
| Total Blocking Time | 446 мс | 78 мс |
| Cumulative Layout Shift | 0 | 0 |
| Speed Index | 2,8 с | 1,35 с |
| Accessibility | 100 | 100 |
| Best Practices | 100 | 100 |
| SEO | 63* | 63* |

\* Демо закрыты от поиска (`noindex`) намеренно — отсюда 63.

- Разница в TBT и Speed Index — цена стекла: размытие поверх анимированных свечений пересчитывается каждый кадр. На слабом телефоне это и есть ощущение «тормозит».
- LCP около 5–6 с у обеих — это кристалл. Отрисовку держат общие для сайта 300 КБ шрифтов и 94 КБ CSS из корневого layout, а не направление.
- three.js в первую загрузку не входит: живая модель кристалла приезжает по первому касанию.

## Что важно знать про кристалл

В покое — готовый рендер (тот же файл, что в герое главной), целиком в кадре. По первому касанию, перетаскиванию или стрелке подгружается живая модель той же фигуры и вращается пальцем (вбок; вертикальный жест остаётся прокрутке) и мышью.

Живая модель проще рендера: стекло без преломлений, поэтому в момент подмены видно, что это другая картинка (`11-kristall-povorot-1440`). Если направление выберем, модель стоит довести (карта окружения под рендер, преломление) или показывать вращение заранее отрендеренными кадрами.
