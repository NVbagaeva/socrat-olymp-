# кнопка «Миграции» применяет новые (bin/migrate.sh).

# Только добавлять в конец. Уже применённый файл не правится: изменение
# оформляется новым файлом, иначе миграции остановятся.
#
# Схема одна — схема кабинета: согласия, роли, классы, домашние задания,

# файлы и в том же порядке проверяет pnpm test:soglasiya-sql.
#
# Каталог банка (supabase/seed/kabinet_katalog.sql) миграцией не
# является: он пересобирается вместе с банком и применяется при каждом
# нажатии «Миграции» (bin/migrate.sh, папка catalog/).
