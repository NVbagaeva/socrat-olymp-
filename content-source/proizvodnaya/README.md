# Открытый банк задания №9 «Производная и первообразная»

Сюда добавляются задачи из открытого банка ФИПИ. Тренажёр умеет
показывать только их (переключатель «Только открытый банк»); пока
файл пуст, этот режим на сайте выключен, а в тренажёре работают
сгенерированные задачи.

## Файл

`content-source/proizvodnaya/otkrytyj-bank.json` — массив записей.
Пустой массив `[]` допустим.

## Формат записи

```json
{
  "id": "fipi-9-001",
  "prototype": "9.2.1",
  "uslovie": "На рисунке изображён график функции $y=f(x)$ и касательная к нему в точке с абсциссой $x_0$. Найдите значение производной функции $f(x)$ в точке $x_0$.",
  "kartinka": "/images/proizvodnaya/bank/fipi-9-001.png",
  "otvet": 0.5,
  "razbor": [
    "Значение производной равно угловому коэффициенту касательной.",
    "$k=\\dfrac{\\Delta y}{\\Delta x}=\\dfrac{1}{2}=0{,}5$.",
    "Ответ: $0{,}5$."
  ],
  "istochnik": "otkrytyj-bank"
}
```

Поля:

- `id` — уникальный код записи: латиница, цифры, точка, дефис,
  подчёркивание. После выхода менять не нужно: по нему тренажёр
  помнит ошибки ученика.
- `prototype` — код прототипа из реестра: `9.1.1` … `9.5.6`. Так
  задача попадает в нужную группу (I–V) и в статистику.
- `uslovie` — текст условия. Формулы только в `$…$` (набирает
  KaTeX); сырой TeX вне долларов не пишите. В JSON обратная
  косая черта удваивается: `\\dfrac`, `\\Delta`. Десятичная
  запятая в формуле — `0{,}5`.
- `kartinka` — необязательно. Путь к рисунку, который лежит в
  `app/public/images/proizvodnaya/bank/`. Пишите путь от `public`,
  со слэшем в начале: `/images/proizvodnaya/bank/<файл>`. Файл
  должен существовать, иначе скрипт остановится с ошибкой.
- `otvet` — число: целое или конечная десятичная дробь (`-3`,
  `0.5`). В готовом файле ответа числом не остаётся, только
  отпечаток.
- `razbor` — необязательно. Массив строк разбора по шагам, формулы
  в `$…$`. Разбор показывается ученику только по его просьбе и
  закрыт отпечатком ответа.
- `istochnik` — всегда `"otkrytyj-bank"`. Эта пометка отличает
  задачу открытого банка от наших сгенерированных.

## Картинки

Положите файл в `app/public/images/proizvodnaya/bank/` (папку
создайте, если её нет). Формат PNG, WebP или SVG; фон светлый,
подписи читаемы. Имя — по `id`, например `fipi-9-001.png`.

## Как пометить прототип

Каждая запись обязана указывать `prototype` — код прототипа, к
которому относится задача (поле `prototype` в файлах
`app/src/lib/proizvodnaya/prototypes/`). Группа определяется по
нему автоматически: `9.1.*` — группа I, `9.2.*` — II и так далее.
Запись с неизвестным кодом скрипт не пропустит.

## Как собрать

Из папки `app/`:

```bash
pnpm build:bank-9-open
```

Скрипт проверяет записи, закрывает ответы и разборы отпечатками и
пишет `app/src/lib/proizvodnaya/otkrytyj-bank.ts`. Этот файл не
правят руками. Результат закоммитьте вместе с JSON и картинками.

После сборки проверьте на сайте: вкладка «Тренажёр» → «Источник
заданий» → «Только открытый банк» должна показать число задач.
