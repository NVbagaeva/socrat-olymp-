## 2. Классификация задач №13

### 2.0. Общая модель, из которой выводятся все четыре типа

Любая задача на кредит или вклад — это цепочка периодов. В каждом периоде происходят ровно два события в фиксированном порядке:

1. **начисление процентов**: долг (вклад) умножается на $k = 1 + \dfrac{r}{100}$;
2. **выплата** (для вклада — пополнение или снятие): долг уменьшается на платёж $z_i$.

Если обозначить долг на начало $i$-го периода $D_{i-1}$, а на конец — $D_i$, то

$$z_i = k\,D_{i-1} - D_i = \underbrace{(D_{i-1} - D_i)}_{\text{изменение долга}} + \underbrace{\frac{r}{100}\,D_{i-1}}_{\text{проценты}}.$$

Сложив все платежи при $D_n = 0$, получаем **универсальную формулу суммы выплат**:

$$Z = \sum z_i = S + \frac{r}{100}\,(D_0 + D_1 + \dots + D_{n-1}),$$

то есть «вернуть банку» = «сумма кредита» + «проценты», а проценты — это ставка, умноженная на сумму долгов на начало каждого периода. Это и есть «три столбца — три правила» рабочей тетради в общем виде. Все формулы ниже — её частные случаи:

| Как задан долг | Что получается из общей формулы | Тип |
|---|---|---|
| убывает равномерно: $D_i = S - i\,\dfrac{S}{n}$ | $\sum D_{i-1} = S\,\dfrac{n+1}{2}$, переплата $П = S\cdot\dfrac{n+1}{2}\cdot\dfrac{r}{100}$ (арифметическая прогрессия) | **А** |
| убывает «известным образом»: таблица, две ставки, фиксированный шаг + остаток, «только проценты» первые годы | та же сумма, но считается по кускам; при двух ставках $Z = S + \tfrac{r_1}{100}\sum_{\text{первые}} D + \tfrac{r_2}{100}\sum_{\text{вторые}} D$ | **Б** |
| долг неизвестен, известны платежи | цепочка $((Sk - X)k - X)k - X = 0$, после раскрытия скобок — геометрическая прогрессия $Sk^n = X(k^{n-1} + \dots + k + 1)$ | **В** |
| та же цепочка «в обратную сторону»: сумма растёт, пополнения прибавляются | $((Sk + x)k + x)k + x$, неравенства «наибольшее / наименьшее целое» | **Г** |

Ключевое методическое следствие: **А и Б решаются «от долга»** (путь долга задан, платежи вычисляются), **В и Г — «от платежа»** (платежи заданы, долг раскручивается цепочкой). Это разделение и определяет, какой формат таблицы естествен для каждого типа (см. § 3).

### 2.1. Тип А — дифференцированный платёж

**Признак в условии:** «долг должен быть на одну и ту же величину меньше долга на 15-е число предыдущего месяца» / «сумма долга уменьшалась равномерно» / «на одну и ту же сумму». Долг убывает по арифметической прогрессии с шагом $d = S/n$.

**Математическая модель (таблица):**

| Период | Долг на начало | Изменение долга | Проценты | Платёж | Долг на конец |
|---|---|---|---|---|---|
| 1 | $S$ | $S/n$ | $S\cdot r/100$ | сумма двух | $S - S/n$ |
| 2 | $S - S/n$ | $S/n$ | $(S - S/n)\cdot r/100$ | … | $S - 2S/n$ |
| … | | | | | |
| $n$ | $S/n$ | $S/n$ | $S/n \cdot r/100$ | | $0$ |

**Ключевые формулы:**
- платёж $z_i = \dfrac{S}{n} + \dfrac{r}{100}\cdot\dfrac{S\,(n - i + 1)}{n}$ — убывающая арифметическая прогрессия с разностью $\dfrac{S\,r}{100\,n}$;
- переплата $П = \dfrac{r}{100}\cdot\dfrac{S}{n}\,(n + (n-1) + \dots + 1) = S\cdot\dfrac{n+1}{2}\cdot\dfrac{r}{100}$ — **выводится**, а не даётся;
- наибольший платёж $z_1 = \dfrac{S}{n}\left(1 + \dfrac{rn}{100}\right)$, наименьший $z_n = \dfrac{S}{n}\left(1 + \dfrac{r}{100}\right)$, их отношение $\dfrac{100 + rn}{100 + r}$;
- выплаты за первый год (12 из $n$ месяцев): $12\cdot\dfrac{S}{n} + \dfrac{r}{100}\cdot\dfrac{S}{n}\,(n + (n-1) + \dots + (n-11))$.

### 2.2. Тип Б — «поломанный» дифференцированный платёж

**Признак:** долг убывает **не одной прогрессией**: меняется ставка, или шаг, или в конце остаётся «хвост», который гасится одним платежом, или первые годы долг вообще не меняется. Приём один и тот же: сумма выплат $= S + \dfrac{r}{100}\sum D_{i-1}$, сумму долгов считаем **по кускам**.

### 2.3. Тип В — аннуитет и «известны платежи»

**Признак:** в условии сказано про **платежи**, а не про долг: «равными платежами», «в первый год выплачено … во второй …», «каждый следующий платёж втрое больше», «если платить по X — за 4 года, по Y — за 2». Долг раскручивается цепочкой $(Sk - X)k - X \dots = 0$.

**Ключевые формулы (все выводятся раскрытием скобок):**
- $n$ равных платежей: $Sk^n = X\,(k^{n-1} + k^{n-2} + \dots + 1)$; для $n = 2$: $X = \dfrac{Sk^2}{k+1}$; $n = 3$: $X = \dfrac{Sk^3}{k^2 + k + 1}$; $n = 4$: $X = \dfrac{Sk^4}{(k^2+1)(k+1)}$ — разложение $k^3 + k^2 + k + 1 = (k^2 + 1)(k + 1)$ обязательно показывать;
- разные платежи: $((Sk - x_1)k - x_2)k - x_3 = 0$ → $Sk^3 = x_1 k^2 + x_2 k + x_3$;
- «4 года по X или 2 по Y»: делим $Sk^4 = X(k^2+1)(k+1)$ на $Sk^2 = Y(k+1)$ → $\dfrac{k^2 + 1}{k^2} = \dfrac{Y}{X}$, замена $q = k^2$;
- минимальный срок при «платёж не более N»: $Sk^n \le N\,\dfrac{k^n - 1}{k - 1}$, перебор $n$ с проверкой.

### 2.5. Признаки для режима «Определи тип» (блок Д зачёта)

## 3. Конвенции раздела (из ваших материалов)

Эти правила вычитаны из зачёта, тетради и конспектов и становятся правилами раздела: по ним проверяются теория, решения опорных задач, подсказки тренажёра и учительский лист генератора.

1. **Коэффициент** $k = 1 + \dfrac{r}{100}$ вводится один раз и объясняется словами: «показывает, во сколько раз вырастет долг после начисления процентов». При двух ставках второй коэффициент — $q$. $k$ записываем обыкновенной дробью, когда это упрощает сокращения ($1{,}25 = \tfrac54$, $1{,}2 = \tfrac65$, $1{,}125 = \tfrac98$).
2. **Оформление задачи**: Дано → Найти → таблица по периодам (математическая модель) → Решение по шагам → «Ответ:» с единицами. Без модели решение не засчитывается (это и критерий ЕГЭ, и правило зачёта: 1 балл за модель, 1 за ответ).
3. **Обозначения**: $S$ — сумма кредита (вклада), $n$ — число периодов, $r$ или $p$ — ставка, $X$ — платёж (пополнение), $Z$ или $B$ — общая сумма выплат, $П$ — переплата, $D_i$ — долг после $i$-й выплаты. В тетради столбец «Сумма изменения долга» и «Переплата» — слово «переплата» там означает проценты за период; в теории называем этот столбец «Проценты», а слово «переплата» оставляем за $П = Z - S$, чтобы не путать два смысла. *(Вопрос 3 в § 5.)*
4. **«Три столбца — три правила»** для А и Б: изменение долга $= S/n$ (или задано); проценты $=$ долг на начало $\cdot\, r/100$; долг на конец $=$ долг на начало $-$ изменение. Платёж $=$ изменение $+$ проценты.
5. **Формула переплаты не даётся готовой**: выводится через арифметическую прогрессию $S + \dfrac{S(n-1)}{n} + \dots + \dfrac{S}{n} = S\cdot\dfrac{n+1}{2}$ (сумма первых $n$ членов). Готовая формула в ответе ЕГЭ без вывода — 1 балл из 2 (конспект 21.12 №2).
6. **Аннуитет** — через раскрытие скобок $((Sk - X)k - X)k - X = 0$ и геометрическую прогрессию; для четырёх платежей — разложение $k^3 + k^2 + k + 1 = (k^2 + 1)(k + 1)$.
7. **Считаем в тысячах или миллионах**, в ответе переводим в единицы условия («Ответ выразите в рублях» → 1 200 000, а не 1200). Тренажёр проверяет единицы.
8. **Проценты через пропорцию с краткой записью**: `100 % — S` / `125 % — ?`, 100 % — то, с чем сравниваем, то, что стоит после «чем». Правило из промпта; в материалах по №13 оно явно не встречается, но нужно в главе 1 теории (джинсы −50 % / +50 %) и в А6 («на сколько процентов больше суммы кредита» — 100 % это $S$).
9. **Умные сокращения** вместо столбика: $\dfrac{910 \cdot 1{,}728}{3{,}64}$ — сначала $1{,}728 = 1{,}2^3$, $3{,}64 = 1{,}44 + 1{,}2 + 1$, потом сокращение на 0,52 и т. д. Признаки делимости — в сворачиваемой панели.
10. **Сюжеты** — путешествия и современные цели (кругосветка, Камчатка, глэмпинг, кемпер, тур в Японию): этот стиль зачёта берём как образец, но в банке на каждый прототип — другой сюжет, имя, город, даты 2026+.
11. **Периоды и даты**: месячные кредиты — «15-го числа … 1-го числа … со 2-го по 14-е»; годовые — «в июле … каждый январь … с февраля по июнь». Формулировки ФИПИ воспроизводятся дословно (это не авторский текст, а стандартная «рамка» условия).

### 3.1. Вопрос о формате таблицы: предложение

В материалах два формата:

| | Тетрадь (А) | Зачёт (А–В) |
|---|---|---|
| Столбцы | Долг на начало · Сумма изменения долга · Переплата (проценты) · Долг на конец | Долг до начисления % · Долг после начисления % · Выплата · Долг после выплаты |
| Что считается «по правилу» | изменение и проценты, платёж — их сумма | долг после начисления ($\times k$), платёж — разность |
| Естественна, когда | задан путь долга (А, Б) | заданы платежи (В, Г) |

**Предлагаю:** не один формат на всё и не «по типу», а **два формата по механизму** решения, с общими крайними столбцами.

- **Формат «от долга»** (типы А и Б): *Долг на начало · Изменение долга · Проценты · Долг на конец*, платёж — сумма столбцов 2 и 3 (показывается отдельной строкой «Платёж» или пятым столбцом). Это тетрадный формат, но столбец назван «Проценты», а не «Переплата» (см. конвенцию 3). Б оставляем в этом же формате, а не переводим в зачётный: Б — это А с «изломом», и ученик должен видеть, что три правила работают по-прежнему, просто сумма долгов считается по кускам. Переключение формата именно на более трудном типе ломает навык там, где он нужнее всего.
- **Формат «от платежа»** (типы В и Г): *Долг на начало · После начисления % · Выплата · Долг на конец*. Это зачётный формат. Для Г третий столбец — «Пополнение (+) / Снятие (−)», а первый и четвёртый — «Вклад на начало / Вклад на конец», как вы и предложили.
- Оба формата начинаются с «на начало» и заканчиваются «на конец» — у ученика одна картинка периода, меняются только два средних столбца, и в теории показан переход между ними: «после начисления» $=$ «на начало» $+$ «проценты».
- **В движке** `tableModel` хранит для каждого периода все пять величин (`start, afterInterest, interest, change, payment, end`), а какие два средних столбца показать, решает тип задачи (настройка в конфиге раздела). Поэтому зачёт, если захотите, можно печатать в едином зачётном формате для всех блоков, ничего не пересчитывая.

Если вы предпочитаете ваш вариант по умолчанию (тетрадь для А, зачёт для Б и В) — движок это тоже умеет, нужно лишь выставить формат для Б. Решение — за вами (вопрос 2 в § 5).
