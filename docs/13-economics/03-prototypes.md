# Задание №13. Список прототипов на утверждение

Этап 3, PR 1. После вашего «ок» на каждый прототип генерируется 10 вариантов с новыми числами и сюжетами; каждый вариант проверяется независимым солвером (прямой пересчёт таблицы по периодам).

**Итого: 66 прототипов** (дифференцированный — 19, «поломанный» — 19, аннуитет — 15, вклады — 13) **и 3 подготовительных** («таблица руками»). Банк — около 690 задач. Режим «Определи тип» берёт условия из всего банка и 10 условий блока «Определи тип» вашего зачёта, своих прототипов у него нет.

Что изменилось по сравнению с инвентарём этапа 1 (`01-analysis.md`, приложение Б):

- **A-18 разделён на два**: платёж $k$-го месяца (A-18) и сумма кредита по первому платежу (A-19). Задание 13 — краткий ответ, у задачи должен быть один ответ-число.
- **Добавлен B-19** — двухфазный кредит из демоверсии 2026 и ЕГЭ-2023: долг в середине срока задан, найти ставку.
- **A-02 и D-04 переформулированы** под один ответ-число: «на сколько процентов от кредита переплата меньше в выгодном банке» и «в ответ запишите $n + m$».

## Общие правила для всех прототипов

- **Ответ** — целое число или конечная десятичная дробь, в единицах, которые требует условие (рубли / тыс. / млн / проценты / месяцы / годы). Единицы ответа указаны в каждой строке.
- **Ставки**: месячные 1–5 %, годовые 5–30 %; у задач Ларина — до 50 %. $k$ подбирается так, чтобы записывался дробью с малым знаменателем ($1{,}1$; $1{,}2 = \frac65$; $1{,}25 = \frac54$; $1{,}125 = \frac98$).
- **Платежи положительные, долг кредита убывает**; в задачах «наибольшее / наименьшее целое» соседнее значение действительно не подходит, а ограничение отсекает ровно одно значение.
- **Числа источников в банк не попадают**: тройки «сумма — ставка — срок» из всех задач инвентаря записаны в список запрещённых, генератор их пропускает.
- **Сюжет** — имя, цель кредита или вклада, город, даты 2026+ из восьми тем: путешествия, учёба и курсы, техника и гаджеты, спорт, стартап и бизнес, дом и ремонт, творчество, питомцы. Формулировки условий ФИПИ («1-го числа каждого месяца долг возрастает…») не меняются, меняются сюжет и числа.
- **Источник**: «ФИПИ» — прототип открытого банка; «ЕГЭ-20xx» — задача реального экзамена (тоже банк ФИПИ); «авторская» — ваши задачи (лист, тетрадь, зачёт) и задачи по А. Малковой, на сайте с пометкой «не из открытого банка»; «Ларин» — повышенный уровень, тоже «не из открытого банка».
- **Уровень**: базовый / повышенный. Повышенный — Ларин, задачи с перебором, условия на целое $S$, неизвестный срок у «поломанного» платежа (решения этапа 1).

## Рамки условий

Длинные стандартные формулировки ФИПИ ниже обозначены рамками, чтобы таблицы читались.

- **Рамка «15-е число»** (месячный дифференцированный): «15-го {месяца} {кто} берёт кредит в банке на {n} месяцев. Условия его возврата таковы: — 1-го числа каждого месяца долг возрастает на {r} % по сравнению с концом предыдущего месяца; — со 2-го по 14-е число каждого месяца необходимо выплатить часть долга; — 15-го числа каждого месяца долг должен быть на одну и ту же величину меньше долга на 15-е число предыдущего месяца.»
- **Рамка «июль»** (годовой дифференцированный): «В июле {год} года планируется взять кредит в банке на сумму {S} на {n} лет. Условия: — каждый январь долг возрастает на {r} % по сравнению с концом предыдущего года; — с февраля по июнь каждого года необходимо выплатить часть долга; — в июле каждого года долг должен быть на одну и ту же величину меньше долга на июль предыдущего года.»
- **Рамка «январь»** (годовой с платежами): «В июле {год} года планируется взять кредит в банке на сумму {S}. Условия: — каждый январь долг увеличивается на {r} % по сравнению с концом предыдущего года; — с февраля по июнь каждого года необходимо выплатить одним платежом часть долга.»
- **Рамка «конец периода»** (короткая): «{Кто} взял(а) кредит {S} на {n} месяцев (лет). В конце каждого периода банк начисляет {r} % на оставшуюся сумму долга, затем {кто} вносит платёж» + «долг уменьшается на одну и ту же величину» (дифференцированный) или «платежи равные» (аннуитет).
- **Рамка «вклад»**: «В конце каждого года вклад увеличивается на {r} % по сравнению с его размером в начале года».
