# Плашки банка заданий — устройство и стиль

Документ для дизайнера: всё, что нужно, чтобы нарисовать новые плашки
(карточки заданий) в точности в стиле сайта. Значения взяты из кода
приложения `app/` (Next.js), а не из макета; размеры на разных ширинах
замерены в собранной странице.

## 2. Откуда берутся данные

Всё, что видно на плашке, — из массива `tasks` в `app/src/content/tasks.ts`.
В разметке текстов нет.

```ts
{ no: '14', name: 'Уравнение', slug: '14', status: 'dev', part: 2, illustration: 'placeholder' }
```

| Поле | На плашке |
|---|---|
| `no` | крупный номер «14» (две цифры, с ведущим нулём: «01») |
| `name` | название |
| `shortTitle` | на плашке **не используется** — только в узком сайдбаре |
| `slug` | адрес: клик ведёт на `/zadaniya/{slug}/` |
| `status` | состояние: `active` / `dev` / `soon` (см. §5) |
| `part` | в какой блок попадает: 1 (по умолчанию) или 2 |
| `badge` | доп. бейдж голубого тона, сейчас только «структура 2027» у №06 и №13 |
| `illustration` | формат миниатюры: не задан → `task-NN.webp`; `'svg'` → `task-NN.svg`; `'placeholder'` → временный линейный значок |

Подписи блоков — массив `taskParts` там же:

```ts
{ part: 1, title: 'Часть 1', lead: 'краткий ответ' },
{ part: 2, title: 'Часть 2', lead: 'развёрнутое решение' },
```

**Сменить статус задания — одна строка:** `status: 'dev'` → `status: 'active'`.

## 3. HTML-структура

### Страница целиком

```html
<main class="app-main">
  <header class="bank-head">…заголовок «Банк заданий ЕГЭ» и цитата…</header>
  <div class="bank-filters"><div class="bank-search">…поиск…</div></div>

  <div class="task-parts">
    <section class="task-part" aria-labelledby="task-part-1">
      <div class="task-part__head">
        <h2 id="task-part-1" class="t-h4 task-part__title">Часть 1</h2>
        <p class="task-part__lead">Задания 01–13 · краткий ответ</p>
      </div>
      <ul class="tasks-grid">
        <li>…плашка…</li>
        …
      </ul>
    </section>

    <section class="task-part" aria-labelledby="task-part-2">…Часть 2, №14–20…</section>
  </div>

  <section class="bank-start">…«Не знаете, с чего начать?»…</section>
</main>
```

### Плашка

Внутренняя разметка одна на все состояния — меняется только внешний тег:
`<a>` (ссылка), `<button>` (открывает окно, у №12) или `<span>` (раздел закрыт).

```html
<a class="task-card task-card--bank [task-card--dev]" href="/zadaniya/14">
  <span class="task-card__no" aria-hidden="true">14</span>
  <span class="task-card__body">
    <span class="task-card__title">
      <span class="sr-only">Задание 14. </span>Уравнение
    </span>
    <span class="task-card__meta">
      <!-- 0–2 бейджа: -->
      <span class="badge">Скоро</span>                       <!-- status: soon -->
      <span class="badge badge--dev">В разработке</span>     <!-- status: dev -->
      <span class="badge badge--info">структура 2027</span>  <!-- поле badge -->
    </span>
  </span>
  <span class="task-card__ill" aria-hidden="true">
    <img class="ill-photo" src="/images/task-14.webp" width="96" height="96" alt="">
  </span>
  <!-- только у кликабельных плашек: -->
  <span class="task-card__go" aria-hidden="true"><svg viewBox="0 0 24 24">…стрелка…</svg></span>
</a>

<!-- раздел закрыт («Скоро»): -->
<span class="task-card task-card--bank task-card--soon" aria-disabled="true">…</span>
```

### Раскладка внутри плашки (CSS grid 2 колонки × 3 строки)

```
┌──────────────────────────────────────────────┐
│ 14                         │                 │  строка 1: номер      | миниатюра
│ Уравнение                  │   [миниатюра]   │  строка 2: название + | (строки 1–2,
│ (• В разработке)           │                 │            бейджи     |  по центру)
│                            │       (→)       │  строка 3: —          | круглая стрелка
└──────────────────────────────────────────────┘
  колонка 1: 1fr (текст)      колонка 2: auto (= --card-ill)
```

- `grid-template-columns: minmax(0, 1fr) auto`
- `grid-template-rows: auto 1fr calc(32px + 8px)` — третья строка
  зарезервирована под стрелку **у всех** плашек, даже у закрытых: так
  миниатюры стоят на одной линии.
- зазоры: между колонками 16px, между строками 4px.
- плашки одного ряда одной высоты (`grid-auto-rows: 1fr`), высота — по самой высокой.

### Тени и скругления

| Токен | Значение | Где |
|---|---|---|
| `--radius-lg` | 12px | скругление плашки |
| `--radius-pill` | 999px | бейдж |

### Шрифт

Семейство — **Inter** (`--font-sans`: Inter, system-ui, -apple-system, sans-serif).

| Элемент | Кегль / интерлиньяж | Жирность | Прочее |
|---|---|---|---|
| Номер `.task-card__no` | по ярусу, см. таблицу ниже | 600 | `letter-spacing: -0.02em`, цвет `#1F5FD0` |
| Название `.task-card__title` | по ярусу | 500 | цвет `#101728`; 2 строки (3 на ≥1440), дальше многоточие |
| Бейдж `.badge` | 13px (на плашке банка; базово 12px) | 500 | высота 24px, поля 0 10px, pill |
| Заголовок части `.t-h4` | 20/28px | 600 | `letter-spacing: -0.01em`, цвет `#0B1F45` |
| Подпись части | 14/20px | 400 | цвет `#667389` |

### Размеры плашки по ярусам

Размеры задают токены `--card-*` (`tokens.css`). Кроме ярусов экрана есть
**компактная шкала по ширине самой плашки**: если плашка уже 360px,
включается она (container query), независимо от ширины окна.

| | Компактная (плашка < 360px) | Базовая (до 1439) | ≥ 1440 | ≥ 1920 |
|---|---|---|---|---|
| Внутренний отступ `--card-pad` | 16px | 24px | 28px | 32px |
| Номер `--card-no` / lh | 24 / 30px | 30 / 36px | 32 / 38px | 36 / 42px |
| Название `--card-title` / lh | 15 / 20px | 16 / 22px | 17 / 24px | 18 / 26px |
| Миниатюра `--card-ill` | 72×72 | 96×96 | 36% ширины плашки, 72…160px | то же |
| Строк названия | 2 | 2 | 3 | 3 |
| Мин. высота | 100px | 150px | 150px | 150px |

Отступы внутри: номер → название 4px; название → бейджи 8px; между бейджами 12px.

Замер на странице банка (с сайдбаром 240px):

| Ширина окна | Колонок | Плашка (Ш×В) | Отступ | Миниатюра |
|---|---|---|---|---|
| 1920 | 4 | 392 × 258 | 32 | 141 |
| 1440 | 3 | 368 × 240 | 28 | 132 |
| 1280 | 3 | 315 × 176 | 16 | 72 |
| 1024 | 2 | 352 × 150 | 16 | 72 |
| 768 | 2 | 320 × 150 | 16 | 72 |
| 390 | 1 | 350 × 150 | 16 | 72 |
| 360 | 1 | 320 × 150 | 16 | 72 |

**Для отрисовки берите эталон 1440: плашка 368×240, отступ 28, номер 32/38,
название 17/24, миниатюра ~132×132.**

### Миниатюра

- Растровая `task-NN.webp`, квадрат, **прозрачный фон**, без подложки
  (у самих картинок светлые заливки). Стиль — «стекло»: синее
  полупрозрачное + лёгкие блики (см. корневой `README.md` и `tools/glass_style.py`).
- Вписывается в квадрат `--card-ill` (`object-fit: contain`), по
  вертикали — по центру строк 1–2, по горизонтали — по центру колонки.
- Исходник — ≥ 192×192 (на 1920 показывается до 160px).
- Для №14–20 картинок пока нет: стоит временный линейный значок
  (кружок-подложка `#1F5FD0` с прозрачностью 6% + линии 1.5px тем же
  синим). **Нужны 7 картинок `task-14.webp` … `task-20.webp`** в стиле
  остальных; после этого у задания убирается `illustration: 'placeholder'`.

## 5. Состояния

| Состояние | Когда | Тег | Вид |
|---|---|---|---|
| **Открыт** | `status: 'active'` | `<a>` (у №12 — `<button>`) | белая плашка, рамка `#E4EBF3` |
| ↳ hover / focus | наведение мышью или фокус с клавиатуры | | рамка `#9BC0F2`, тень `--shadow-sm`; внизу справа проявляется кружок 32×32 `#1F5FD0` с белой стрелкой 16px (из прозрачности 0 и сдвига −4px влево в 1 и 0). Переход 120ms, `cubic-bezier(0.2, 0, 0, 1)`. На тач-устройствах стрелки нет |
| ↳ focus-visible | Tab | | общая обводка фокуса сайта (`base.css`) + та же стрелка |
| ↳ active (нажатие) | | | отдельного стиля нет |
| **Скоро** (disabled) | `status: 'soon'` | `<span aria-disabled>` | фон `#F7F9FC` вместо белого; номер (`#1F5FD0`) и название (`#101728`) на плашке банка остаются прежнего цвета — правила `.task-card--bank` перекрывают приглушённый `#97A1B0` базовой карточки; миниатюра webp не приглушается; бейдж «Скоро» нейтральный, но с белым фоном. Наведение не реагирует, курсор обычный, стрелки нет, в Tab не попадает |
| **В разработке** (новое) | `status: 'dev'` | `<a>` | как «Открыт» (белая, наведение и стрелка работают — ведёт на заглушку), плюс бейдж «В разработке» и миниатюра с прозрачностью 60% |

### Бейджи

| Класс | Фон | Текст | Пример |
|---|---|---|---|
| `.badge` | `#F7F9FC` (на закрытой плашке — `#FFFFFF`) | `#667389` | «Скоро» |
| `.badge.badge--dev` | `#F7F9FC` | `#667389`, перед текстом точка 6×6 `#E07A2F`, зазор 6px | «В разработке» |
| `.badge--info` | `#E8F0FC` | `#1F5FD0` | «структура 2027» |

Почему «В разработке» сделан так: в системе было только «Скоро», и оно
означает «нажать нельзя». Плашки второй части нажимаются (ведут на
заглушку), поэтому им нужно отдельное состояние. Янтарный тон
(`--color-warning`) занят смыслом «предупреждение», поэтому бейдж
нейтральный, а отличает его точка акцентного терракотового цвета —
того же, что у акцентов чертежей.

## 6. Блоки «Часть 1» / «Часть 2»

- Каждая часть — `<section class="task-part">` с заголовком и своей сеткой.
- Заголовок: «Часть N» (20/28, 600, `#0B1F45`) и в той же строке по базовой
  линии подпись «Задания 01–13 · краткий ответ» (14/20, `#667389`), зазор 12px.
  На узком экране подпись переносится под заголовок (зазор 4px).
- От заголовка до сетки 16px; между частями 40px (на телефоне 32px).
- Диапазон номеров в подписи считается из конфига.
- При поиске пустая часть скрывается целиком.
- Часть 1 — №01–13, Часть 2 — №14–20.

## 7. Адаптивность

Сетка: `grid-template-columns: repeat(var(--grid-cols), minmax(min(300px, 100%), 1fr))`,
зазор 16px (на телефоне < 768 — 12px).

| Экран | Колонок на странице банка | Как задано |
|---|---|---|
| ≥ 1920 | 4 | `--grid-cols: 4` |
| 1440–1919 | 3 | `--grid-cols: 3` |
| 1024–1439 (десктоп/ноутбук) | 2–3 по ширине (1280 → 3, 1024 → 2) | `auto-fill`, минимум 300px |
| 768–1023 (планшет) | 2 | `auto-fill`; сайдбар сворачивается до 72px |
| < 768 (телефон) | 1 | сайдбар скрыт, снизу панель навигации; портрет в шапке и декор снизу скрыты |

Последний неполный ряд прижат влево, плашки не растягиваются на пустые места.
На главной (без сайдбара) колонок при той же ширине окна больше.

## 8. Куда ведёт клик

| Плашка | Переход |
|---|---|
| Открытый раздел | `/zadaniya/{slug}/` (например `/zadaniya/3/`) |
| №12 «Графики функций» на странице банка | не переход, а окно выбора подтемы (`SubtopicDialog`); на главной — переход `/zadaniya/12/` |
| «Скоро» | никуда |
| «В разработке» (№14–20) | `/zadaniya/14/` … `/zadaniya/20/` — страница-заглушка |

Плашка кликабельна целиком (ссылка — весь прямоугольник).

### Страница-заглушка

Та же оболочка кабинета, что у банка: тёмный сайдбар со списком заданий
(в нём №14–20 тоже есть и активны), верхнее меню «Главная · Задания · …»
с подсвеченным пунктом «Задания», на телефоне — нижняя панель. Дальше:
крошки «Главная / Банк заданий / №14», заголовок `t-h1`
«Задание №14. Уравнение», пустое состояние «Раздел в разработке» с
пояснением и кнопкой «Вернуться в банк заданий».
