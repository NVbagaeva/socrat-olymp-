приложения `app/` (Next.js), а не из макета; размеры на разных ширинах

## 2. Откуда берутся данные

Всё, что видно на плашке и в сайдбаре, — из массива `tasks` в
`app/src/content/tasks.ts`. В разметке текстов нет.

```ts
{ no: '06', name: 'Случайные величины и распределения', shortTitle: 'Случайные величины',
  slug: '6', part: 1, status: 'soon', badges: ['структура 2027'] },
{ no: '14', name: 'Уравнение', slug: '14', part: 2, status: 'soon', stub: true, icon: 'svg' },
```

| Поле | Что задаёт |
|---|---|
| `no` | крупный номер «14» (две цифры, с ведущим нулём: «01») |
| `name` | название на плашке и в заголовке заглушки |
| `shortTitle` | короткое название для сайдбара; на плашке не используется |
| `slug` | адрес: `/zadaniya/{slug}/` |
| `part` | часть экзамена: 1 или 2 |
| `status` | `ready` — раздел открыт; `soon` — «Скоро» (см. §5) |
| `stub` | у неоткрытого задания есть страница-заглушка: плашка и пункт сайдбара остаются приглушёнными, но ведут на неё |
| `badges` | голубые бейджи, сейчас «структура 2027» у №06 и №13 |
| `icon` | формат иконки: не задан → `task-NN.webp`; `'svg'` → `task-NN.svg` |

Подписи частей — массив `taskParts` там же (заголовок сегмента, подпись
сегмента, заголовок над сеткой). Тексты заглушки — `tasksPage.stub`.

**Открыть задание — одна строка:** `status: 'soon'` → `status: 'ready'`
(и завести раздел; `stub` после этого не нужен).

### Плашка

Внутренняя разметка одна на все состояния — меняется только внешний тег:
`<a>` (ссылка), `<button>` (открывает окно, у №12) или `<span>` (раздел закрыт).

```html
<a class="task-card task-card--bank" href="/zadaniya/2/">
  <span class="task-card__no" aria-hidden="true">14</span>
  <span class="task-card__body">
    <span class="task-card__title">
      <span class="sr-only">Задание 02. </span>Векторы
    </span>
    <span class="task-card__meta">
      <!-- 0–2 бейджа: -->
      <span class="badge">Скоро</span>                       <!-- status: soon -->
      <span class="badge badge--info">структура 2027</span>  <!-- поле badges -->
    </span>
  </span>
  <span class="task-card__ill" aria-hidden="true">
    <img class="ill-photo" src="/images/task-02.webp" width="96" height="96" alt="">
  </span>
  <!-- только у кликабельных плашек: -->
  <span class="task-card__go" aria-hidden="true"><svg viewBox="0 0 24 24">…стрелка…</svg></span>
</a>

<!-- «Скоро» без страницы (№01, 07…): -->
<span class="task-card task-card--bank task-card--soon" aria-disabled="true">…</span>

<!-- «Скоро» со страницей-заглушкой (№14–20): тот же вид, но ссылка и стрелка -->
<a class="task-card task-card--bank task-card--soon" href="/zadaniya/14/">…</a>
```

### Раскладка внутри плашки (CSS grid 2 колонки × 3 строки)

```
┌──────────────────────────────────────────────┐
│ 02                         │                 │  строка 1: номер      | миниатюра
│ Векторы                    │   [миниатюра]   │  строка 2: название + | (строки 1–2,
│ (Скоро)                    │                 │            бейджи     |  по центру)
│                            │       (→)       │  строка 3: —          | круглая стрелка
└──────────────────────────────────────────────┘
  колонка 1: 1fr (текст)      колонка 2: auto (= --card-ill)
```

- `grid-template-columns: minmax(0, 1fr) auto`
- `grid-template-rows: auto 1fr calc(32px + 8px)` — третья строка
  зарезервирована под стрелку **у всех** плашек, даже у закрытых: так
  миниатюры стоят на одной линии.
- зазоры: между колонками 16px, между строками 4px.
- плашки одного ряда одной высоты (`grid-auto-rows: 1fr`), высота — по самой высокой.

### Тени и скругления

| Токен | Значение | Где |
|---|---|---|
| `--radius-lg` | 12px | скругление плашки |

### Шрифт

Семейство — **Inter** (`--font-sans`: Inter, system-ui, -apple-system, sans-serif).

| Элемент | Кегль / интерлиньяж | Жирность | Прочее |
|---|---|---|---|
| Номер `.task-card__no` | по ярусу, см. таблицу ниже | 600 | `letter-spacing: -0.02em`, цвет `#1F5FD0` |
| Название `.task-card__title` | по ярусу | 500 | цвет `#101728`; 2 строки (3 на ≥1440), дальше многоточие |
| Бейдж `.badge` | 13px (на плашке банка; базово 12px) | 500 | высота 24px, поля 0 10px, pill |
| Заголовок над сеткой `.t-h4` | 20/28px | 600 | `letter-spacing: -0.01em`, цвет `#0B1F45` |
| Счётчик «13 заданий» | 14/20px | 400 | цвет `#97A1B0` |

### Размеры плашки по ярусам

Размеры задают токены `--card-*` (`tokens.css`). Кроме ярусов экрана есть
**компактная шкала по ширине самой плашки**: если плашка уже 360px,
включается она (container query), независимо от ширины окна.

| | Компактная (плашка < 360px) | Базовая (до 1439) | ≥ 1440 | ≥ 1920 |
|---|---|---|---|---|
| Внутренний отступ `--card-pad` | 16px | 24px | 28px | 32px |
| Номер `--card-no` / lh | 24 / 30px | 30 / 36px | 32 / 38px | 36 / 42px |
| Название `--card-title` / lh | 15 / 20px | 16 / 22px | 17 / 24px | 18 / 26px |
| Миниатюра `--card-ill` | 72×72 | 96×96 | 36% ширины плашки, 72…160px | то же |
| Строк названия | 2 | 2 | 3 | 3 |
| Мин. высота | 100px | 150px | 150px | 150px |

Отступы внутри: номер → название 4px; название → бейджи 8px; между бейджами 12px.

Замер на странице банка (с сайдбаром 240px):

| Ширина окна | Колонок | Плашка (Ш×В) | Отступ | Миниатюра |
|---|---|---|---|---|
| 1920 | 4 | 392 × 258 | 32 | 141 |
| 1440 | 3 | 368 × 240 | 28 | 132 |
| 1280 | 3 | 315 × 176 | 16 | 72 |
| 1024 | 2 | 352 × 150 | 16 | 72 |
| 768 | 2 | 320 × 150 | 16 | 72 |
| 390 | 1 | 350 × 150 | 16 | 72 |
| 360 | 1 | 320 × 150 | 16 | 72 |

**Для отрисовки берите эталон 1440: плашка 368×240, отступ 28, номер 32/38,
название 17/24, миниатюра ~132×132.**

### Миниатюра

- Растровая `task-NN.webp`, квадрат, **прозрачный фон**, без подложки
  (у самих картинок светлые заливки). Стиль — «стекло»: синее
  полупрозрачное + лёгкие блики (см. корневой `README.md` и `tools/glass_style.py`).
- Вписывается в квадрат `--card-ill` (`object-fit: contain`), по
  вертикали — по центру строк 1–2, по горизонтали — по центру колонки.
- Исходник — ≥ 192×192 (на 1920 показывается до 160px).
- У №14–20 иконки векторные: `app/public/images/task-14.svg` … `task-20.svg`,
  в стиле `task-01.svg` — поле 270×270, линии `#0C3EBC` 1.5–2.5px,
  заливка фигур `#C3DFFA`, лёгкая заливка `#7FAEEA` с прозрачностью 0.12,
  точки-узлы r 4–6, пунктир `6 5`. Сюжеты: 14 — тригонометрическая
  окружность, 15 — куб с треугольным сечением, 16 — метод интервалов
  (+ − +), 17 — график с максимумом, 18 — разносторонний треугольник с
  вписанной окружностью, 19 — параллельные прямые и окружность,
  20 — кубок со звездой. Если художник нарисует растровые версии в
  «стеклянном» стиле, файл кладётся как `task-NN.webp`, а у задания
  убирается `icon: 'svg'`.

## 5. Состояния

| Состояние | Когда | Тег | Вид |
|---|---|---|---|
| **Открыт** | `status: 'ready'` | `<a>` (у №12 — `<button>`) | белая плашка, рамка `#E4EBF3` |
| ↳ hover / focus | наведение мышью или фокус с клавиатуры | | рамка `#9BC0F2`, тень `--shadow-sm`; внизу справа проявляется кружок 32×32 `#1F5FD0` с белой стрелкой 16px (из прозрачности 0 и сдвига −4px влево в 1 и 0). Переход 120ms, `cubic-bezier(0.2, 0, 0, 1)`. На тач-устройствах стрелки нет |
| ↳ focus-visible | Tab | | общая обводка фокуса сайта (`base.css`) + та же стрелка |
| ↳ active (нажатие) | | | отдельного стиля нет |
| **Скоро** (disabled) | `status: 'soon'` | `<span aria-disabled>` | фон `#F7F9FC` вместо белого; номер (`#1F5FD0`) и название (`#101728`) на плашке банка остаются прежнего цвета — правила `.task-card--bank` перекрывают приглушённый `#97A1B0` базовой карточки; иконка не приглушается; бейдж «Скоро» нейтральный, но с белым фоном. Наведение не реагирует, курсор обычный, стрелки нет, в Tab не попадает |
| **Скоро + заглушка** | `status: 'soon'`, `stub: true` (№14–20) | `<a>` | вид как у «Скоро» (фон `#F7F9FC`, бейдж «Скоро»), но это ссылка: на наведение — рамка `#9BC0F2`, тень и стрелка, как у открытой |

## 6. Части экзамена: переключатель

- Над сеткой — переключатель из двух сегментов: «01–13 · Часть 1 · Задания с
  кратким ответом» и «14–20 · Часть 2 · Задания с развёрнутым ответом».
- Контейнер `.part-switch`: белый, рамка `#D7E5FA`, скругление 16px,
  поле 8px, между сегментами 8px, во всю ширину контента, снизу 32px.
- Сегмент: высота от 64px, скругление 12px, поля 12/20px, по центру:
  диапазон на плашке-таблетке (20/28, 500; фон `#E8F0FC`, текст `#1F5FD0`),
  справа «Часть N» (15/20, 600) и подпись (12/16, `#667389`).
  Наведение — фон `#F2F7FE`.
- Активный сегмент: градиент `#3D79E0` → `#163F8C` сверху вниз, белый текст,
  таблетка диапазона — белая с прозрачностью 15%, подпись — белая 72%,
  тень `--shadow-sm`.
- Телефон (< 768): переключатель во всю ширину, поле 4px, в сегменте всё
  в столбик по центру: диапазон 13px без таблетки, «Часть N» 14px, подпись 11px.
- Под переключателем — строка: слева «Часть 1 · задания с кратким ответом»
  (`t-h4`, `#0B1F45`), справа счётчик «13 заданий» (14px, `#97A1B0`).
  Отступ до сетки 16px.
- Часть живёт в адресе: `/zadaniya/?part=2` открывает вторую. Сегменты —
  ссылки (их можно открыть в новой вкладке); щелчок меняет адрес без
  перезагрузки.
- Поиск ищет по обеим частям: пока строка не пуста, сетка показывает
  найденное во всём банке, заголовок — «Результаты поиска» и число найденных.

## 7. Адаптивность

Сетка: `grid-template-columns: repeat(var(--grid-cols), minmax(min(300px, 100%), 1fr))`,
зазор 16px (на телефоне < 768 — 12px).

| Экран | Колонок на странице банка | Как задано |
|---|---|---|
| ≥ 1920 | 4 | `--grid-cols: 4` |
| 1440–1919 | 3 | `--grid-cols: 3` |
| 1024–1439 (десктоп/ноутбук) | 2–3 по ширине (1280 → 3, 1024 → 2) | `auto-fill`, минимум 300px |
| 768–1023 (планшет) | 2 | `auto-fill`; сайдбар сворачивается до 72px |
| < 768 (телефон) | 1 | сайдбар скрыт, снизу панель навигации; портрет в шапке и декор снизу скрыты |

Последний неполный ряд прижат влево, плашки не растягиваются на пустые места.
На главной (без сайдбара) колонок при той же ширине окна больше.

### Сайдбар

Список заданий разбит на группы: подпись «ЧАСТЬ 1» (11/16, 600, капитель,
разрядка 0.12em, белый 62%), пункты 01–13, тонкий разделитель (белый 10%,
отступы 12px), «ЧАСТЬ 2», пункты 14–20 с короткими названиями. Неоткрытые
пункты приглушены (прозрачность 0.55); у №14–20 это ссылки на заглушки.
Если список выше экрана, сайдбар прокручивается сам, а горы с подписью
уходят вниз, под список. На планшете (72px) подписи групп скрыты, остаются
номера и разделитель.

## 8. Куда ведёт клик

| Плашка | Переход |

### Страница-заглушка

Та же оболочка кабинета, что у банка: тёмный сайдбар, верхнее меню
«Главная · Задания · …», на телефоне — нижняя панель. Дальше по образцу
открытых разделов:

- крошки «Банк заданий ЕГЭ / Часть 2 / Задание №15»; «Часть 2» ведёт на
  `/zadaniya/?part=2`;
- заголовок `t-h1` «Задание №15. Стереометрия» и бейдж «Скоро» (нейтральный,
  на белом с тонкой рамкой `#E4EBF3`, 13px);
- липкая лента вкладок-таблеток «О задании · Теория · Опорные задачи ·
  Тренажёр · Генератор · Для репетиторов» — общий компонент `RazdelTabs`,
  как у №2; все вкладки пока ведут на ту же заглушку, активна «О задании»;
- карточка «Раздел в разработке»: белая, рамка `#E4EBF3`, скругление 16px,
  поле 32px; слева иконка задания крупно в квадрате 280×280 на `#F2F7FE`
  со скруглением 12px, справа заголовок (`t-h4`), текст (16/24, `#667389`)
  и кнопка «К банку заданий» (`btn--primary`, ведёт на вторую часть).
  На телефоне — столбиком.
