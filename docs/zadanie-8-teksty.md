## Типы по группам

## Степени

#### Степень в степени и деление степеней (8.A)

*Работаем с показателями, а не с огромными числами*

**Где теряют балл.** Путают $(a^{m})^{n}$ и $a^{m} \cdot a^{n}$: в первом показатели перемножают, во втором складывают.

**Подтип 1** (базовый)

Условие: Найдите значение выражения $(3^{2})^{4} : 3^{7}$.

1. Степень возводим в степень — показатели перемножаются: $(a^{m})^{n} = a^{m \cdot n}$
   $(3^{2})^{4} = 3^{2 \cdot 4} = 3^{8}$
2. Основания одинаковые, поэтому при делении показатели вычитаются: $a^{x} : a^{y} = a^{x - y}$. Большую степень считать не нужно
   $3^{8} : 3^{7} = 3^{8 - 7} = 3^{1}$
3. Считаем степень
   $3^{1} = 3$

Ответ: **3**

Подсказка до ответа: _Что происходит с показателями, когда степень возводят в степень?_

**Подтип 2** (повышенный)

Условие: Найдите значение выражения $(4^{2})^{4} : 4^{9}$.

1. Степень возводим в степень — показатели перемножаются: $(a^{m})^{n} = a^{m \cdot n}$
   $(4^{2})^{4} = 4^{2 \cdot 4} = 4^{8}$
2. Основания одинаковые, поэтому при делении показатели вычитаются: $a^{x} : a^{y} = a^{x - y}$. Большую степень считать не нужно
   $4^{8} : 4^{9} = 4^{8 - 9} = 4^{-1}$
3. Показатель $-1$ означает обратное число: $a^{-1} = \dfrac{1}{a}$
   $4^{-1} = \dfrac{1}{4} = 0{,}25$

Ответ: **0,25**

Подсказка до ответа: _Что происходит с показателями, когда степень возводят в степень?_

#### Дробные показатели: одно основание (8.C)

*Сводим все степени к одному основанию*

**Где теряют балл.** Складывают показатели у разных оснований. Сначала основания делают одинаковыми, только потом работают с показателями.

**Подтип quot** (базовый)

Условие: Найдите значение выражения $\dfrac{125^{2{,}4}}{5^{5{,}2}}$.

1. Записываем $125$ как степень числа $5$: $125 = 5^{3}$. Степень в степени — показатели перемножаются
   $125^{2{,}4} = (5^{3})^{2{,}4} = 5^{3 \cdot 2{,}4} = 5^{7{,}2}$
2. Основания одинаковые — при делении показатели вычитаются: $a^{x} : a^{y} = a^{x - y}$
   $5^{7{,}2} : 5^{5{,}2} = 5^{7{,}2 - 5{,}2} = 5^{2}$
3. Считаем степень
   $5^{2} = 25$

Ответ: **25**

Подсказка до ответа: _Какое из оснований — степень другого? Как записать его через меньшее?_

**Подтип prod** (базовый)

Условие: Найдите значение выражения $2^{3{,}4} \cdot 8^{0{,}2}$.

1. Записываем $8$ как степень числа $2$: $8 = 2^{3}$. Степень в степени — показатели перемножаются
   $8^{0{,}2} = (2^{3})^{0{,}2} = 2^{3 \cdot 0{,}2} = 2^{0{,}6}$
2. Основания одинаковые — при умножении показатели складываются: $a^{x} \cdot a^{y} = a^{x + y}$
   $2^{3{,}4} \cdot 2^{0{,}6} = 2^{3{,}4 + 0{,}6} = 2^{4}$
3. Считаем степень
   $2^{4} = 16$

Ответ: **16**

Подсказка до ответа: _Какое из оснований — степень другого? Как записать его через меньшее?_

**Подтип neg** (повышенный)

Условие: Найдите значение выражения $\dfrac{2^{4{,}6}}{4^{2{,}8}}$.

1. Записываем $4$ как степень числа $2$: $4 = 2^{2}$. Степень в степени — показатели перемножаются
   $4^{2{,}8} = (2^{2})^{2{,}8} = 2^{2 \cdot 2{,}8} = 2^{5{,}6}$
2. Основания одинаковые — при делении показатели вычитаются: $a^{x} : a^{y} = a^{x - y}$
   $2^{4{,}6} : 2^{5{,}6} = 2^{4{,}6 - 5{,}6} = 2^{-1}$
3. Показатель $-1$ означает обратное число: $a^{-1} = \dfrac{1}{a}$
   $2^{-1} = \dfrac{1}{2} = 0{,}5$

Ответ: **0,5**

Подсказка до ответа: _Какое из оснований — степень другого? Как записать его через меньшее?_

**Подтип frac** (повышенный)

Условие: Найдите значение выражения $2^{\frac{2}{3}} \cdot 8^{\frac{1}{9}}$.

1. Записываем $8$ как степень числа $2$: $8 = 2^{3}$. Степень в степени — показатели перемножаются
   $8^{\frac{1}{9}} = (2^{3})^{\frac{1}{9}} = 2^{3 \cdot \frac{1}{9}} = 2^{\frac{1}{3}}$
2. Основания одинаковые — при умножении показатели складываются: $a^{x} \cdot a^{y} = a^{x + y}$
   $2^{\frac{2}{3}} \cdot 2^{\frac{1}{3}} = 2^{\frac{2}{3} + \frac{1}{3}} = 2^{1}$
3. Считаем степень
   $2^{1} = 2$

Ответ: **2**

Подсказка до ответа: _Какое из оснований — степень другого? Как записать его через меньшее?_

**Подтип chain** (повышенный, своя подсказка)

Условие: Найдите значение выражения $(243^{2})^{2} : (81^{2})^{2}$.

1. Записываем $243$ и $81$ как степени числа $3$: $243 = 3^{5}$, $81 = 3^{4}$
   $(243^{2})^{2} : (81^{2})^{2} = ((3^{5})^{2})^{2} : ((3^{4})^{2})^{2}$
2. Степень в степени — показатели перемножаются, сколько бы скобок ни было
   $3^{5 \cdot 2 \cdot 2} : 3^{4 \cdot 2 \cdot 2} = 3^{20} : 3^{16}$
3. Основания одинаковые — при делении показатели вычитаются. Большие степени не считаем
   $3^{20} : 3^{16} = 3^{20 - 16} = 3^{4}$
4. Считаем степень
   $3^{4} = 81$

Ответ: **81**

Подсказка до ответа: _Степенью какого числа являются оба основания?_

#### Степени с разными основаниями (8.D)

*Одинаковые показатели — перемножаем основания*

**Где теряют балл.** Перемножают основания при разных показателях. Собирать под одну степень можно только множители с одинаковым показателем.

**Подтип same** (базовый)

Условие: Найдите значение выражения $\dfrac{5^{5{,}4} \cdot 7^{5{,}4}}{35^{4{,}4}}$.

1. Показатели в числителе одинаковые — перемножаем основания: $a^{x} \cdot b^{x} = (ab)^{x}$
   $5^{5{,}4} \cdot 7^{5{,}4} = (5 \cdot 7)^{5{,}4} = 35^{5{,}4}$
2. Теперь и в числителе, и в знаменателе основание $35$ — при делении показатели вычитаются
   $35^{5{,}4} : 35^{4{,}4} = 35^{5{,}4 - 4{,}4} = 35^{1}$
3. Считаем степень
   $35^{1} = 35$

Ответ: **35**

Подсказка до ответа: _У каких множителей показатели одинаковые? Что даёт $a^{n} \cdot b^{n}$?_

**Подтип split** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{35^{6{,}8} \cdot 5^{-7{,}8}}{7^{4{,}8}}$.

1. Раскладываем основание на простые множители: $35 = 5 \cdot 7$, а степень произведения — произведение степеней
   $35^{6{,}8} = 5^{6{,}8} \cdot 7^{6{,}8}$
2. Собираем степени числа $5$ — при умножении показатели складываются
   $5^{6{,}8} \cdot 5^{-7{,}8} = 5^{6{,}8 + (-7{,}8)} = 5^{-1}$
3. Степени числа $7$ делим — показатели вычитаются
   $7^{6{,}8} : 7^{4{,}8} = 7^{6{,}8 - 4{,}8} = 7^{2}$
4. Остались небольшие степени — считаем их и перемножаем
   $5^{-1} \cdot 7^{2} = \dfrac{1}{5} \cdot 49 = 9{,}8$

Ответ: **9,8**

Подсказка до ответа: _Какое основание можно разложить на множители, чтобы они совпали с остальными?_

**Подтип fracpow** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{\left(5^{\frac{5}{6}} \cdot 7^{\frac{1}{2}}\right)^{6}}{35^{3}}$.

1. Возводим произведение в степень: каждый множитель отдельно, показатели перемножаются
   $\left(5^{\frac{5}{6}} \cdot 7^{\frac{1}{2}}\right)^{6} = 5^{\frac{5}{6} \cdot 6} \cdot 7^{\frac{1}{2} \cdot 6} = 5^{5} \cdot 7^{3}$
2. Знаменатель раскладываем на те же множители: $35 = 5 \cdot 7$
   $35^{3} = (5 \cdot 7)^{3} = 5^{3} \cdot 7^{3}$
3. Сокращаем одинаковые основания — показатели вычитаются, а $7$ сокращается полностью. Так не нужно считать $35^{3}$
   $\dfrac{5^{5} \cdot 7^{3}}{5^{3} \cdot 7^{3}} = 5^{2}$
4. Считаем то, что осталось
   $5^{2} = 25$

Ответ: **25**

Подсказка до ответа: _Что получится, если умножить внешний показатель на каждый дробный показатель в скобке?_

## Корни

#### Квадрат корня и скобки с корнями (8.B)

*Квадрат убирает корень, а произведение корней собираем под один*

**Где теряют балл.** Возводят в квадрат только корень и забывают про множитель перед ним: $(6\sqrt{24})^{2}$ — это $36 \cdot 24$, а не $6 \cdot 24$.

**Подтип sq-int** (базовый)

Условие: Найдите значение выражения $\dfrac{(2\sqrt{40})^2}{2}$.

1. Квадрат произведения — произведение квадратов, а квадрат корня равен подкоренному числу: $(a\sqrt{b})^2 = a^2 \cdot b$
   $(2\sqrt{40})^2 = 2^{2} \cdot (\sqrt{40})^{2} = 4 \cdot 40$
2. Не перемножаем, а сокращаем: $4$ и $2$ — на $2$
   $\dfrac{4 \cdot 40}{2} = 2 \cdot 40 = 80$

Ответ: **80**

Подсказка до ответа: _Чему равен квадрат корня? Что останется от $(k\sqrt{n})^{2}$?_

**Подтип sq-dec** (повышенный)

Условие: Найдите значение выражения $\dfrac{(8\sqrt{44})^2}{25}$.

1. Квадрат произведения — произведение квадратов, а квадрат корня равен подкоренному числу: $(a\sqrt{b})^2 = a^2 \cdot b$
   $(8\sqrt{44})^2 = 8^{2} \cdot (\sqrt{44})^{2} = 64 \cdot 44$
2. Общих множителей у числителя и знаменателя нет — перемножаем числитель и доводим знаменатель до $100$: умножаем числитель и знаменатель на $4$, а деление на $100$ — это перенос запятой на два знака влево
   $\dfrac{64 \cdot 44}{25} = \dfrac{2816}{25} = \dfrac{11264}{100} = 112{,}64$

Ответ: **112,64**

Подсказка до ответа: _Чему равен квадрат корня? Что останется от $(k\sqrt{n})^{2}$?_

**Подтип brackets** (повышенный, своя подсказка)

Условие: Найдите значение выражения $(\sqrt{48} + \sqrt{12}) \cdot \sqrt{48}$.

1. Выносим множитель из-под корня: $\sqrt{a^2 b} = a\sqrt{b}$. Здесь $48 = 16 \cdot 3$, $12 = 4 \cdot 3$
   $(\sqrt{48} + \sqrt{12}) \cdot \sqrt{48} = (4\sqrt{3} + 2\sqrt{3}) \cdot 4\sqrt{3}$
2. В скобках подобные слагаемые с одним и тем же корнем $\sqrt{3}$ — складываем коэффициенты
   $(4\sqrt{3} + 2\sqrt{3}) \cdot 4\sqrt{3} = 6\sqrt{3} \cdot 4\sqrt{3}$
3. Квадрат корня равен подкоренному числу: $\sqrt{3} \cdot \sqrt{3} = 3$
   $6\sqrt{3} \cdot 4\sqrt{3} = 6 \cdot 4 \cdot 3 = 72$

Ответ: **72**

Подсказка до ответа: _Умножьте корень на каждое слагаемое в скобке. Что получится под корнем?_

#### Произведение и частное корней (8.E)

*Корни одной степени собираем под один знак корня*

**Где теряют балл.** Перемножают подкоренные числа «в лоб» и получают большое число. Сначала сокращаем: $\dfrac{72 \cdot 96}{27}$ — делим 72 на 9 и 27 на 9.

**Подтип same-index** (базовый)

Условие: Найдите значение выражения $\dfrac{\sqrt[4]{31} \cdot \sqrt[4]{48}}{\sqrt[4]{93}}$.

1. Корни одной степени собираем под один корень: $\sqrt[n]{a} \cdot \sqrt[n]{b} = \sqrt[n]{ab}$ и $\dfrac{\sqrt[n]{a}}{\sqrt[n]{b}} = \sqrt[n]{\dfrac{a}{b}}$
   $\dfrac{\sqrt[4]{31} \cdot \sqrt[4]{48}}{\sqrt[4]{93}} = \sqrt[4]{\dfrac{31 \cdot 48}{93}}$
2. Не перемножаем, а сокращаем: $31$ и $93$ — на $31$, затем $48$ и $3$ — на $3$
   $\sqrt[4]{\dfrac{31 \cdot 48}{93}} = \sqrt[4]{\dfrac{48}{3}} = \sqrt[4]{16}$
3. Узнаём под корнем степень: $16 = 2^{4}$. Корень и степень с одинаковым показателем снимают друг друга: $\sqrt[n]{a^{n}} = a$
   $\sqrt[4]{16} = \sqrt[4]{2^{4}} = 2$

Ответ: **2**

Подсказка до ответа: _Степени корней одинаковые. Что будет, если собрать всё под один корень?_

**Подтип mixed-index** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{\sqrt[12]{7} \cdot \sqrt[4]{7}}{\sqrt[3]{7}}$.

1. Записываем корни как степени с дробным показателем: $\sqrt[n]{a} = a^{\frac{1}{n}}$
   $\dfrac{\sqrt[12]{7} \cdot \sqrt[4]{7}}{\sqrt[3]{7}} = \dfrac{7^{\frac{1}{12}} \cdot 7^{\frac{1}{4}}}{7^{\frac{1}{3}}}$
2. Основание одно, поэтому при умножении показатели складываются, а при делении вычитаются. Дроби приводим к общему знаменателю $12$
   $\dfrac{7^{\frac{1}{12}} \cdot 7^{\frac{1}{4}}}{7^{\frac{1}{3}}} = 7^{\frac{1}{12} + \frac{1}{4} - \frac{1}{3}} = 7^{\frac{1 + 3 - 4}{12}} = 7^{0}$
3. Любое число, кроме нуля, в нулевой степени равно единице
   $7^{0} = 1$

Ответ: **1**

Подсказка до ответа: _Как записать корень $n$-й степени показателем? Что сделать с показателями при умножении?_

**Подтип with-factor** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{\sqrt[30]{7} \cdot 7 \cdot \sqrt[60]{7}}{\sqrt[20]{7}}$.

1. Корни из одного числа перемножаем как степени: $\sqrt[n]{a} = a^{\frac{1}{n}}$, а при умножении показатели складываются
   $\sqrt[30]{7} \cdot \sqrt[60]{7} = 7^{\frac{1}{30} + \frac{1}{60}} = 7^{\frac{2 + 1}{60}} = 7^{\frac{3}{60}} = 7^{\frac{1}{20}} = \sqrt[20]{7}$
2. Получился ровно корень из знаменателя: одинаковые множители $\sqrt[20]{7}$ в числителе и знаменателе сокращаются
   $\dfrac{\sqrt[20]{7} \cdot 7}{\sqrt[20]{7}} = 7$

Ответ: **7**

Подсказка до ответа: _Сложите дробные показатели двух корней. Что получится?_

#### Квадрат разности корней в дроби (8.F)

*Раскрываем квадрат и видим тот же знаменатель*

**Где теряют балл.** Теряют удвоенное произведение: $(\sqrt{2} - \sqrt{15})^{2} \ne 2 - 15$. Квадрат разности — три слагаемых.

**Подтип 1** (повышенный)

Условие: Найдите значение выражения $\dfrac{3(\sqrt{2} + \sqrt{11})^2}{26 + 4\sqrt{22}}$.

1. Раскрываем квадрат суммы: $(x + y)^2 = x^2 + 2xy + y^2$, а квадрат корня равен подкоренному числу
   $(\sqrt{2} + \sqrt{11})^2 = 2 + 2\sqrt{2} \cdot \sqrt{11} + 11 = 13 + 2\sqrt{22}$
2. Ищем ту же скобку в знаменателе: при корне стоит $4 = 2 \cdot 2$, и $26 = 2 \cdot 13$ — выносим $2$ за скобку
   $26 + 4\sqrt{22} = 2(13 + 2\sqrt{22})$
3. Одинаковые скобки в числителе и знаменателе сокращаются — остаются множители перед ними
   $\dfrac{3(13 + 2\sqrt{22})}{2(13 + 2\sqrt{22})} = \dfrac{3}{2} = 1{,}5$

Ответ: **1,5**

Подсказка до ответа: _Раскройте квадрат разности. На что похож знаменатель после этого?_

#### Корни из десятичных дробей (8.G)

*Под одним корнем десятичные дроби сокращаются*

**Где теряют балл.** Извлекают корни из каждой дроби по отдельности — их нет в таблице. Сначала собираем под один корень, потом сокращаем.

**Подтип 1** (базовый)

Условие: Найдите значение выражения $\dfrac{\sqrt{3{,}2} \cdot \sqrt{2{,}1}}{\sqrt{0{,}42}}$.

1. Произведение и частное корней — корень из произведения и частного: $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$, $\dfrac{\sqrt{a}}{\sqrt{b}} = \sqrt{\dfrac{a}{b}}$
   $\dfrac{\sqrt{3{,}2} \cdot \sqrt{2{,}1}}{\sqrt{0{,}42}} = \sqrt{\dfrac{3{,}2 \cdot 2{,}1}{0{,}42}}$
2. Избавляемся от запятых: умножаем числитель и знаменатель на $100$ — каждый множитель числителя на $10$, знаменатель на $100$
   $\sqrt{\dfrac{3{,}2 \cdot 2{,}1}{0{,}42}} = \sqrt{\dfrac{32 \cdot 21}{42}}$
3. Не перемножаем, а сокращаем: $21$ и $42$ — на $21$, затем $32$ и $2$ — на $2$
   $\sqrt{\dfrac{32 \cdot 21}{42}} = \sqrt{\dfrac{32}{2}} = \sqrt{16}$
4. Под корнем полный квадрат: $16 = 4^{2}$, а корень из квадрата положительного числа равен самому числу
   $\sqrt{16} = 4$

Ответ: **4**

Подсказка до ответа: _Все корни квадратные. Что получится под одним корнем, если сначала сократить?_

## Логарифмы

#### Сумма и разность логарифмов (8.H)

*Одинаковые основания — собираем в один логарифм*

**Где теряют балл.** Применяют свойство к сумме под логарифмом: $\log_{a}(x + y)$ не раскладывается. Свойство работает только для суммы логарифмов.

**Подтип int** (базовый)

Условие: Найдите значение выражения $\log_{3} 39 - \log_{3} 13$.

1. Разность логарифмов с одинаковым основанием — логарифм частного: $\log_a x - \log_a y = \log_a \dfrac{x}{y}$
   $\log_{3} 39 - \log_{3} 13 = \log_{3} \dfrac{39}{13} = \log_{3} 3$
2. Под логарифмом получилось само основание, а $\log_a a = 1$
   $\log_{3} 3 = 1$

Ответ: **1**

Подсказка до ответа: _Основания одинаковые. Во что превращается разность (или сумма) двух логарифмов?_

**Подтип dec-args** (повышенный)

Условие: Найдите значение выражения $\log_{6} 30 - \log_{6} 5$.

1. Разность логарифмов с одинаковым основанием — логарифм частного: $\log_a x - \log_a y = \log_a \dfrac{x}{y}$
   $\log_{6} 30 - \log_{6} 5 = \log_{6} \dfrac{30}{5} = \log_{6} 6$
2. Под логарифмом получилось само основание, а $\log_a a = 1$
   $\log_{6} 6 = 1$

Ответ: **1**

Подсказка до ответа: _Основания одинаковые. Во что превращается разность (или сумма) двух логарифмов?_

**Подтип dec-base** (повышенный)

Условие: Найдите значение выражения $\log_{0{,}2} 1{,}36 - \log_{0{,}2} 6{,}8$.

1. Разность логарифмов с одинаковым основанием — логарифм частного: $\log_a x - \log_a y = \log_a \dfrac{x}{y}$
   $\log_{0{,}2} 1{,}36 - \log_{0{,}2} 6{,}8 = \log_{0{,}2} \dfrac{1{,}36}{6{,}8}$
2. Знаменатель ровно в $5$ раз больше числителя: $6{,}8 = 5 \cdot 1{,}36$. Сокращаем на $1{,}36$ — делить столбиком не нужно
   $\dfrac{1{,}36}{6{,}8} = \dfrac{1{,}36}{5 \cdot 1{,}36} = \dfrac{1}{5}$
3. Под логарифмом получилось само основание: $\dfrac{1}{5} = 0{,}2$, а $\log_a a = 1$
   $\log_{0{,}2} \dfrac{1}{5} = \log_{0{,}2} 0{,}2 = 1$

Ответ: **1**

Подсказка до ответа: _Основания одинаковые. Во что превращается разность (или сумма) двух логарифмов?_

#### Частное логарифмов (8.J)

*Переход к новому основанию без лишних шагов*

**Где теряют балл.** Сокращают логарифмы как обычные дроби. $\log$ — не множитель, сокращать можно только по формуле перехода.

**Подтип same-base** (базовый)

Условие: Найдите значение выражения $\dfrac{\log_{3} 625}{\log_{3} 5}$.

1. Числитель и знаменатель — логарифмы по одному основанию $3$, поэтому дробь сворачивается в один логарифм по формуле перехода: $\dfrac{\log_c x}{\log_c y} = \log_y x$. Формула верна при любом основании $c$ — значит, и при $c = 3$
   $\dfrac{\log_{3} 625}{\log_{3} 5} = \log_{5} 625$
2. Узнаём степень основания: $625 = 5^{4}$. Логарифм степени основания равен показателю: $\log_a a^{c} = c$
   $\log_{5} 625 = \log_{5} 5^{4} = 4$

Ответ: **4**

Подсказка до ответа: _Во что сворачивается дробь из двух логарифмов с одинаковым основанием?_

**Подтип same-arg** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{\log_{4} 14}{\log_{2} 14}$.

1. Основание $4$ — степень числа $2$: $4 = 2^{2}$. Показатель основания выносим вперёд обратным числом: $\log_{a^{k}} x = \dfrac{1}{k}\log_a x$
   $\dfrac{\log_{4} 14}{\log_{2} 14} = \dfrac{\log_{2^{2}} 14}{\log_{2} 14} = \dfrac{\frac{1}{2}\log_{2} 14}{\log_{2} 14}$
2. Сокращаем $\log_{2} 14$ — он стоит и в числителе, и в знаменателе и не равен нулю, так как $14 \ne 1$. Остаётся коэффициент числителя
   $\dfrac{\frac{1}{2}\log_{2} 14}{\log_{2} 14} = \dfrac{1}{2} = 0{,}5$

Ответ: **0,5**

Подсказка до ответа: _Числа под логарифмами одинаковые, а основания — степени одного числа. Как вынести показатель из основания?_

#### Частное логарифмов плюс логарифм (8.I)

*Частное логарифмов — это логарифм по новому основанию*

**Где теряют балл.** Делят числа под логарифмами: $\dfrac{\log_{3} 32}{\log_{3} 4} \ne \log_{3} 8$. Частное логарифмов — переход к новому основанию.

**Подтип 1** (повышенный)

Условие: Найдите значение выражения $\dfrac{\log_{3} 28}{\log_{3} 14} + \log_{14} 0{,}5$.

1. Числитель и знаменатель — логарифмы по одному основанию $3$, поэтому дробь сворачивается в один логарифм по формуле перехода: $\dfrac{\log_c x}{\log_c y} = \log_y x$. Формула верна при любом основании $c$ — значит, и при $c = 3$
   $\dfrac{\log_{3} 28}{\log_{3} 14} = \log_{14} 28$
2. Теперь оба логарифма по основанию $14$, а сумма логарифмов — логарифм произведения: $\log_a x + \log_a y = \log_a (xy)$
   $\log_{14} 28 + \log_{14} 0{,}5 = \log_{14} (28 \cdot 0{,}5)$
3. Записываем $0{,}5$ обыкновенной дробью и сокращаем $28$ со знаменателем $2$
   $28 \cdot 0{,}5 = 28 \cdot \dfrac{1}{2} = \dfrac{28}{2} = 14$
4. Под логарифмом получилось само основание, а $\log_a a = 1$
   $\log_{14} 14 = 1$

Ответ: **1**

Подсказка до ответа: _Во что сворачивается дробь из двух логарифмов с одинаковым основанием?_

#### Произведение логарифмов (8.K)

*Цепочка: основание одного — число под другим*

**Где теряют балл.** Перемножают числа под логарифмами. В произведении логарифмов «среднее» число сокращается, а не умножается.

**Подтип int** (базовый)

Условие: Найдите значение выражения $\log_{7} 11 \cdot \log_{11} 49$.

1. Во втором логарифме переходим к основанию $7$: $\log_{11} 49 = \dfrac{\log_{7} 49}{\log_{7} 11}$ — формула перехода верна для любого нового основания. Тогда $\log_{7} 11$ сокращается: он не равен нулю, так как $11 \ne 1$
   $\log_{7} 11 \cdot \log_{11} 49 = \log_{7} 11 \cdot \dfrac{\log_{7} 49}{\log_{7} 11} = \log_{7} 49$
2. Узнаём степень основания: $49 = 7^{2}$. Логарифм степени основания равен показателю: $\log_a a^{c} = c$
   $\log_{7} 49 = \log_{7} 7^{2} = 2$

Ответ: **2**

Подсказка до ответа: _Что общего у числа под первым логарифмом и основания второго?_

**Подтип dec** (повышенный)

Условие: Найдите значение выражения $6\log_{2{,}5} 3 \cdot \log_{3} 0{,}4$.

1. Во втором логарифме переходим к основанию $2{,}5$: $\log_{3} 0{,}4 = \dfrac{\log_{2{,}5} 0{,}4}{\log_{2{,}5} 3}$ — формула перехода верна для любого нового основания. Тогда $\log_{2{,}5} 3$ сокращается: он не равен нулю, так как $3 \ne 1$
   $6\log_{2{,}5} 3 \cdot \log_{3} 0{,}4 = 6\log_{2{,}5} 3 \cdot \dfrac{\log_{2{,}5} 0{,}4}{\log_{2{,}5} 3} = 6\log_{2{,}5} 0{,}4$
2. Числа взаимно обратные: $2{,}5 \cdot 0{,}4 = 1$, поэтому $0{,}4 = 2{,}5^{-1}$. Логарифм степени основания равен показателю, остаётся умножить на $6$
   $6\log_{2{,}5} 0{,}4 = 6\log_{2{,}5} 2{,}5^{-1} = 6 \cdot (-1) = -6$

Ответ: **-6**

Подсказка до ответа: _Что общего у числа под первым логарифмом и основания второго?_

#### Логарифм, где есть корень (8.L)

*Корень — дробный показатель, его выносим вперёд*

**Где теряют балл.** Путают, куда идёт показатель: из-под логарифма — множителем ($\log_{a} b^{k} = k\log_{a} b$), из основания — делителем ($\log_{a^{k}} b = \tfrac{1}{k}\log_{a} b$).

**Подтип root-base** (базовый, своя подсказка)

Условие: Найдите значение выражения $7\log_{\sqrt[4]{5}} 5$.

1. Записываем $5$ как степень основания: корень $n$-й степени, возведённый в $n$-ю степень, равен подкоренному числу — $(\sqrt[n]{a})^{n} = a$
   $5 = \left(\sqrt[4]{5}\right)^{4}$
2. Логарифм степени основания равен показателю: $\log_a a^{c} = c$. Остаётся умножить на $7$
   $7\log_{\sqrt[4]{5}} 5 = 7\log_{\sqrt[4]{5}} \left(\sqrt[4]{5}\right)^{4} = 7 \cdot 4 = 28$

Ответ: **28**

Подсказка до ответа: _Как записать корень в основании степенью? Что делает показатель, стоящий в основании логарифма?_

**Подтип root-base-pow** (повышенный, своя подсказка)

Условие: Найдите значение выражения $4\log_{\sqrt[4]{5}} 125$.

1. Записываем $125$ как степень основания: $5 = \left(\sqrt[4]{5}\right)^{4}$, потому что $(\sqrt[n]{a})^{n} = a$. Степень в степени — показатели перемножаются
   $125 = 5^{3} = \left(\left(\sqrt[4]{5}\right)^{4}\right)^{3} = \left(\sqrt[4]{5}\right)^{12}$
2. Логарифм степени основания равен показателю: $\log_a a^{c} = c$. Остаётся умножить на $4$
   $4\log_{\sqrt[4]{5}} 125 = 4\log_{\sqrt[4]{5}} \left(\sqrt[4]{5}\right)^{12} = 4 \cdot 12 = 48$

Ответ: **48**

Подсказка до ответа: _Запишите и основание, и число под логарифмом степенями одного числа. Что останется?_

**Подтип root-arg** (базовый)

Условие: Найдите значение выражения $7\log_{5} \sqrt[4]{5}$.

1. Корень — степень с дробным показателем: $\sqrt[n]{a} = a^{\frac{1}{n}}$
   $\sqrt[4]{5} = 5^{\frac{1}{4}}$
2. Логарифм степени основания равен показателю: $\log_a a^{c} = c$. Сокращать нечего — умножаем числитель на $7$ и записываем дробь десятичной
   $7\log_{5} \sqrt[4]{5} = 7\log_{5} 5^{\frac{1}{4}} = 7 \cdot \dfrac{1}{4} = \dfrac{7}{4} = 1{,}75$

Ответ: **1,75**

Подсказка до ответа: _Как записать корень степенью? Куда уходит показатель из-под логарифма?_

**Подтип root-arg-pow** (повышенный)

Условие: Найдите значение выражения $5\log_{5} \sqrt[4]{125}$.

1. Записываем $125$ как степень основания: $125 = 5^{3}$. Корень — степень с дробным показателем: $\sqrt[n]{a^{m}} = a^{\frac{m}{n}}$
   $\sqrt[4]{125} = \sqrt[4]{5^{3}} = 5^{\frac{3}{4}}$
2. Логарифм степени основания равен показателю: $\log_a a^{c} = c$. Сокращать нечего — умножаем числитель на $5$ и записываем дробь десятичной
   $5\log_{5} \sqrt[4]{125} = 5\log_{5} 5^{\frac{3}{4}} = 5 \cdot \dfrac{3}{4} = \dfrac{15}{4} = 3{,}75$

Ответ: **3,75**

Подсказка до ответа: _Как записать корень степенью? Куда уходит показатель из-под логарифма?_

## Тригонометрия

### Значение по известной функции

#### Синус по косинусу и четверти (8.M)

*Квадрат из тождества, знак — по четверти*

**Где теряют балл.** Забывают про четверть и пишут ответ с плюсом. Квадрат ничего не знает о знаке, знак даёт только четверть.

**Подтип base** (базовый)

Условие: Найдите $\sin\alpha$, если $\cos\alpha = \dfrac{\sqrt{21}}{5}$ и $\alpha \in \left(0; \frac{\pi}{2}\right)$.

1. Возводим $\cos\alpha$ в квадрат: в квадрат возводятся и числитель, и знаменатель, $(\sqrt{21})^2 = 21$
   $\cos^2\alpha = \left(\dfrac{\sqrt{21}}{5}\right)^2 = \dfrac{21}{25}$
2. Из основного тригонометрического тождества $\sin^2\alpha + \cos^2\alpha = 1$ выражаем $\sin^2\alpha$. Единицу записываем как $\dfrac{25}{25}$
   $\sin^2\alpha = 1 - \cos^2\alpha = 1 - \dfrac{21}{25} = \dfrac{25 - 21}{25} = \dfrac{4}{25}$
3. Угол $\alpha$ из промежутка $\left(0; \frac{\pi}{2}\right)$ — это I четверть. Синус — ордината точки единичной окружности, а в I четверти эта точка лежит выше оси $Ox$. Поэтому $\sin\alpha > 0$ и берём корень со знаком плюс. Корень из дроби извлекаем из числителя и знаменателя отдельно, затем переводим в десятичную дробь, домножив числитель и знаменатель на $2$
   $\sin\alpha = \sqrt{\dfrac{4}{25}} = \dfrac{2}{5} = \dfrac{4}{10} = 0{,}4$

Ответ: **0,4**

Подсказка до ответа: _В какой четверти лежит угол $\alpha$? Какой знак у синуса в этой четверти?_

**Подтип adv** (повышенный)

Условие: Найдите $\sin\alpha$, если $\cos\alpha = -\dfrac{\sqrt{15}}{4}$ и $\alpha \in \left(\pi; \frac{3\pi}{2}\right)$.

1. Возводим $\cos\alpha$ в квадрат: в квадрат возводятся и числитель, и знаменатель, $(\sqrt{15})^2 = 15$, а минус пропадает
   $\cos^2\alpha = \left(-\dfrac{\sqrt{15}}{4}\right)^2 = \dfrac{15}{16}$
2. Из основного тригонометрического тождества $\sin^2\alpha + \cos^2\alpha = 1$ выражаем $\sin^2\alpha$. Единицу записываем как $\dfrac{16}{16}$
   $\sin^2\alpha = 1 - \cos^2\alpha = 1 - \dfrac{15}{16} = \dfrac{16 - 15}{16} = \dfrac{1}{16}$
3. Угол $\alpha$ из промежутка $\left(\pi; \frac{3\pi}{2}\right)$ — это III четверть. Синус — ордината точки единичной окружности, а в III четверти эта точка лежит ниже оси $Ox$. Поэтому $\sin\alpha < 0$ и перед корнем ставим минус. Корень из дроби извлекаем из числителя и знаменателя отдельно, затем переводим в десятичную дробь, домножив числитель и знаменатель на $25$
   $\sin\alpha = -\sqrt{\dfrac{1}{16}} = -\dfrac{1}{4} = -\dfrac{25}{100} = -0{,}25$

Ответ: **-0,25**

Подсказка до ответа: _В какой четверти лежит угол $\alpha$? Какой знак у синуса в этой четверти?_

#### Косинус по синусу и четверти (8.N)

*Квадрат из тождества, знак — по четверти*

**Где теряют балл.** Косинус отрицателен во II и III четвертях, синус — в III и IV. Знак определяет четверть, а не «минус из условия».

**Подтип base** (базовый)

Условие: Найдите $\cos\alpha$, если $\sin\alpha = 0{,}8$ и $\alpha \in \left(0; \frac{\pi}{2}\right)$.

1. Из основного тригонометрического тождества $\sin^2\alpha + \cos^2\alpha = 1$ выражаем $\cos^2\alpha$
   $\cos^2\alpha = 1 - \sin^2\alpha = 1 - 0{,}8^2 = 1 - 0{,}64 = 0{,}36$
2. Угол $\alpha$ из промежутка $\left(0; \frac{\pi}{2}\right)$ — это I четверть. Косинус — абсцисса точки единичной окружности, а в I четверти эта точка лежит правее оси $Oy$. Поэтому $\cos\alpha > 0$ и берём корень со знаком плюс
   $\cos\alpha = \sqrt{0{,}36} = 0{,}6$

Ответ: **0,6**

Подсказка до ответа: _В какой четверти лежит угол $\alpha$? Какой знак у косинуса в этой четверти?_

**Подтип adv** (повышенный)

Условие: Найдите $\cos\alpha$, если $\sin\alpha = -\dfrac{\sqrt{51}}{10}$ и $\alpha \in \left(\pi; \frac{3\pi}{2}\right)$.

1. Возводим $\sin\alpha$ в квадрат: в квадрат возводятся и числитель, и знаменатель, $(\sqrt{51})^2 = 51$, а минус пропадает
   $\sin^2\alpha = \left(-\dfrac{\sqrt{51}}{10}\right)^2 = \dfrac{51}{100}$
2. Из основного тригонометрического тождества $\sin^2\alpha + \cos^2\alpha = 1$ выражаем $\cos^2\alpha$. Единицу записываем как $\dfrac{100}{100}$
   $\cos^2\alpha = 1 - \sin^2\alpha = 1 - \dfrac{51}{100} = \dfrac{100 - 51}{100} = \dfrac{49}{100}$
3. Угол $\alpha$ из промежутка $\left(\pi; \frac{3\pi}{2}\right)$ — это III четверть. Косинус — абсцисса точки единичной окружности, а в III четверти эта точка лежит левее оси $Oy$. Поэтому $\cos\alpha < 0$ и перед корнем ставим минус. Корень из дроби извлекаем из числителя и знаменателя отдельно, затем записываем дробь со знаменателем $10$ десятичной
   $\cos\alpha = -\sqrt{\dfrac{49}{100}} = -\dfrac{7}{10} = -0{,}7$

Ответ: **-0,7**

Подсказка до ответа: _В какой четверти лежит угол $\alpha$? Какой знак у косинуса в этой четверти?_

#### Тангенс по синусу или косинусу (8.O)

*Сначала вторая функция по четверти, потом делим*

**Где теряют балл.** Делят в другом порядке: $\operatorname{tg}\alpha = \dfrac{\sin\alpha}{\cos\alpha}$, а не наоборот. И теряют знак второй функции.

**Подтип triple** (базовый)

Условие: Найдите $\operatorname{tg}\alpha$, если $\sin\alpha = -0{,}6$ и $\alpha \in \left(\frac{3\pi}{2}; 2\pi\right)$.

1. Из основного тригонометрического тождества $\sin^2\alpha + \cos^2\alpha = 1$ выражаем $\cos^2\alpha$. При возведении в квадрат минус пропадает
   $\cos^2\alpha = 1 - \sin^2\alpha = 1 - (-0{,}6)^2 = 1 - 0{,}36 = 0{,}64$
2. Угол $\alpha$ из промежутка $\left(\frac{3\pi}{2}; 2\pi\right)$ — это IV четверть. Косинус — абсцисса точки единичной окружности, а в IV четверти эта точка лежит правее оси $Oy$. Поэтому $\cos\alpha > 0$ и берём корень со знаком плюс
   $\cos\alpha = \sqrt{0{,}64} = 0{,}8$
3. Тангенс — отношение синуса к косинусу. Синус и косинус разных знаков, поэтому тангенс отрицателен. Чтобы убрать запятые, домножаем числитель и знаменатель на $10$, затем сокращаем на $2$ и записываем ответ десятичной дробью
   $\operatorname{tg}\alpha = \dfrac{\sin\alpha}{\cos\alpha} = \dfrac{-0{,}6}{0{,}8} = -\dfrac{6}{8} = -\dfrac{3}{4} = -\dfrac{75}{100} = -0{,}75$

Ответ: **-0,75**

Подсказка до ответа: _Тангенс — это отношение чего к чему? Какую функцию нужно сначала найти по четверти?_

**Подтип root-int** (базовый)

Условие: Найдите $\operatorname{tg}\alpha$, если $\cos\alpha = -\dfrac{\sqrt{82}}{82}$ и $\alpha \in \left(\frac{\pi}{2}; \pi\right)$.

1. Возводим $\cos\alpha$ в квадрат, минус пропадает: $(\sqrt{82})^2 = 82$. Дробь сразу сокращаем на $82$ — считать $82^2$ не нужно
   $\cos^2\alpha = \left(-\dfrac{\sqrt{82}}{82}\right)^2 = \dfrac{82}{82 \cdot 82} = \dfrac{1}{82}$
2. Из основного тригонометрического тождества $\sin^2\alpha + \cos^2\alpha = 1$ выражаем $\sin^2\alpha$. Единицу записываем как $\dfrac{82}{82}$
   $\sin^2\alpha = 1 - \cos^2\alpha = 1 - \dfrac{1}{82} = \dfrac{82 - 1}{82} = \dfrac{81}{82}$
3. Угол $\alpha$ из промежутка $\left(\frac{\pi}{2}; \pi\right)$ — это II четверть. Синус — ордината точки единичной окружности, а во II четверти эта точка лежит выше оси $Ox$. Поэтому $\sin\alpha > 0$ и берём корень со знаком плюс. Корень из дроби извлекаем из числителя и знаменателя отдельно; $\sqrt{82}$ оставляем как есть — он потом сократится
   $\sin\alpha = \sqrt{\dfrac{81}{82}} = \dfrac{9}{\sqrt{82}}$
4. Тангенс — отношение синуса к косинусу. Синус и косинус разных знаков, поэтому тангенс отрицателен. Делим на дробь — значит умножаем на перевёрнутую; $\sqrt{82} \cdot \sqrt{82} = 82$, и $82$ сокращается ещё до умножения
   $\operatorname{tg}\alpha = \dfrac{\sin\alpha}{\cos\alpha} = \dfrac{9}{\sqrt{82}} : \left(-\dfrac{\sqrt{82}}{82}\right) = -\dfrac{9 \cdot 82}{\sqrt{82} \cdot \sqrt{82}} = -\dfrac{9 \cdot 82}{82} = -9$

Ответ: **-9**

Подсказка до ответа: _Тангенс — это отношение чего к чему? Какую функцию нужно сначала найти по четверти?_

**Подтип root** (повышенный)

### Формулы двойного угла

#### Косинус двойного угла по известному синусу (8.P)

*Формула двойного угла через ту функцию, которая дана*

**Где теряют балл.** Пытаются найти $\cos\alpha$ по синусу и теряются в знаке. Не нужно: в $1 - 2\sin^{2}\alpha$ синус стоит в квадрате.

**Подтип int** (базовый)

Условие: Найдите $24\cos 2\alpha$, если $\cos\alpha = -0{,}5$.

   $\cos 2\alpha = 2\cos^2\alpha - 1 = 2 \cdot (-0{,}5)^2 - 1 = 2 \cdot 0{,}25 - 1 = 0{,}5 - 1 = -0{,}5$
2. Умножить на $0{,}5$ — значит разделить пополам: $0{,}5 = \dfrac{1}{2}$
   $24 \cdot (-0{,}5) = -\dfrac{24}{2} = -12$

**Подтип dec** (повышенный, своя подсказка)

#### Синус двойного угла (8.R)

*Произведение синуса и косинуса одного угла — половина синуса двойного*

**Где теряют балл.** Теряют двойку: $\sin\alpha\cos\alpha = \tfrac{1}{2}\sin 2\alpha$. Половина, а не весь синус двойного угла.

**Подтип table** (повышенный)

Условие: Найдите значение выражения $10\sqrt{2}\sin\frac{9\pi}{8} \cdot \cos\frac{9\pi}{8}$.

1. Произведение $\sin\alpha\cos\alpha$ — половина синуса двойного угла: $2\sin\alpha\cos\alpha = \sin 2\alpha$. Выделяем двойку из коэффициента: $10\sqrt{2} = 5\sqrt{2} \cdot 2$. Угол удваивается: $2 \cdot \frac{9\pi}{8} = \frac{9\pi}{4}$
   $10\sqrt{2}\sin\frac{9\pi}{8} \cdot \cos\frac{9\pi}{8} = 5\sqrt{2} \cdot 2\sin\frac{9\pi}{8}\cos\frac{9\pi}{8} = 5\sqrt{2}\sin\frac{9\pi}{4}$
2. Синус повторяется через $2\pi$ — это его период, поэтому вычитаем $2\pi$
   $\sin\frac{9\pi}{4} = \sin\left(\frac{9\pi}{4} - 2\pi\right) = \sin\frac{\pi}{4} = \frac{\sqrt{2}}{2}$
3. Подставляем найденное значение. Корень, умноженный на такой же корень, даёт число под корнем: $\sqrt{2} \cdot \sqrt{2} = 2$
   $5\sqrt{2}\sin\frac{9\pi}{4} = 5\sqrt{2} \cdot \frac{\sqrt{2}}{2} = \dfrac{5 \cdot 2}{2}$
4. Сокращаем $2$ в числителе и знаменателе
   $\dfrac{5 \cdot 2}{2} = 5$

Ответ: **5**

Подсказка до ответа: _Есть синус и косинус одного угла. Какая формула их соединяет?_

**Подтип cancel** (базовый)

Условие: Найдите значение выражения $\dfrac{18\sin85^\circ \cdot \cos85^\circ}{\sin170^\circ}$.

1. В числителе — синус двойного угла: $2\sin\alpha\cos\alpha = \sin 2\alpha$. Выделяем двойку: $18 = 9 \cdot 2$. Угол удваивается: $2 \cdot 85^\circ = 170^\circ$ — это как раз угол знаменателя
   $\dfrac{18\sin85^\circ \cdot \cos85^\circ}{\sin170^\circ} = \dfrac{9 \cdot 2\sin85^\circ\cos85^\circ}{\sin170^\circ} = \dfrac{9\sin170^\circ}{\sin170^\circ}$
2. Сокращаем $\sin170^\circ$ — он не равен нулю, и остаётся $9$
   $\dfrac{9\sin170^\circ}{\sin170^\circ} = 9$

Ответ: **9**

**Подтип reduce** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{12\sin20^\circ}{\cos80^\circ \cdot \cos10^\circ}$.

1. Знаменатель приводим к одному углу: $10^\circ = 90^\circ - 80^\circ$, а по формуле приведения $\cos(90^\circ - \alpha) = \sin\alpha$

Затем раскладываем по формуле синуса двойного угла $\sin 2\alpha = 2\sin\alpha\cos\alpha$

3. Подставляем и сокращаем $\sin80^\circ\cos80^\circ$ — остаётся $12 \cdot 2$

#### Косинус двойного угла через табличный угол (8.S)

*Разность квадратов косинуса и синуса — косинус двойного угла*

**Где теряют балл.** Путают порядок: $\cos 2\alpha = \cos^{2}\alpha - \sin^{2}\alpha$. Если в условии $\sin^{2} - \cos^{2}$ — это минус косинус двойного угла.

**Подтип diff** (базовый)

Условие: Найдите значение выражения $12\sqrt{2}\cos^2\frac{3\pi}{8} - 12\sqrt{2}\sin^2\frac{3\pi}{8}$.

1. Выносим общий множитель $12\sqrt{2}$ за скобки — в скобках косинус двойного угла: $\cos^2\alpha - \sin^2\alpha = \cos 2\alpha$. Угол удваивается: $2 \cdot \frac{3\pi}{8} = \frac{3\pi}{4}$
   $12\sqrt{2}\cos^2\frac{3\pi}{8} - 12\sqrt{2}\sin^2\frac{3\pi}{8} = 12\sqrt{2}\left(\cos^2\frac{3\pi}{8} - \sin^2\frac{3\pi}{8}\right) = 12\sqrt{2}\cos\frac{3\pi}{4}$
2. По формуле приведения $\cos(\pi - \alpha) = -\cos\alpha$: $\frac{3\pi}{4} = \pi - \frac{\pi}{4}$ — угол II четверти, косинус там отрицателен
   $\cos\frac{3\pi}{4} = \cos\left(\pi - \frac{\pi}{4}\right) = -\cos\frac{\pi}{4} = -\frac{\sqrt{2}}{2}$
3. Подставляем найденное значение. Значение отрицательное — результат со знаком минус. Корень, умноженный на такой же корень, даёт число под корнем: $\sqrt{2} \cdot \sqrt{2} = 2$
   $12\sqrt{2}\cos\frac{3\pi}{4} = 12\sqrt{2} \cdot \left(-\frac{\sqrt{2}}{2}\right) = -\dfrac{12 \cdot 2}{2}$
4. Сокращаем $2$ в числителе и знаменателе
   $-\dfrac{12 \cdot 2}{2} = -12$

Ответ: **-12**

#### Формулы приведения (8.T)

*Лишние обороты и дополнение до 90° и 180°*

**Где теряют балл.** При дополнении до $180^\circ$ у косинуса меняется знак: $\cos(180^\circ - \alpha) = -\cos\alpha$, а у синуса — нет.

**Подтип co** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{11\sin76^\circ}{\cos14^\circ} + 8$.

1. Углы $76^\circ$ и $14^\circ$ в сумме дают $90^\circ$, поэтому работает формула приведения $\sin(90^\circ - \alpha) = \cos\alpha$
   $\sin76^\circ = \sin(90^\circ - 14^\circ) = \cos14^\circ$
2. Подставляем: в числителе и знаменателе одно и то же $\cos14^\circ$ — сокращаем, и дробь равна $11$
   $\dfrac{11\cos14^\circ}{\cos14^\circ} + 8 = 11 + 8 = 19$

Ответ: **19**

Подсказка до ответа: _Сколько в сумме дают два угла? Как связаны косинус и синус таких углов?_

**Подтип period** (базовый)

Условие: Найдите значение выражения $-\dfrac{11\sin747^\circ}{\sin27^\circ}$.

1. Синус повторяется через $360^\circ$ — это его период. Раскладываем $747^\circ = 27^\circ + 2 \cdot 360^\circ$ и отбрасываем полные обороты
   $\sin747^\circ = \sin(27^\circ + 2 \cdot 360^\circ) = \sin27^\circ$
2. Подставляем: в числителе и знаменателе $\sin27^\circ$ — сокращаем, он не равен нулю
   $-\dfrac{11\sin27^\circ}{\sin27^\circ} = -11$

Ответ: **-11**

Подсказка до ответа: _Как связаны угол в числителе и угол в знаменателе? Сколько полных оборотов лишние?_

**Подтип pi** (базовый, своя подсказка)

Условие: Найдите значение выражения $\dfrac{30\sin194^\circ}{\sin14^\circ}$.

1. По формуле приведения $\sin(180^\circ + \alpha) = -\sin\alpha$: угол $194^\circ$ лежит в III четверти, синус там отрицателен
   $\sin194^\circ = \sin(180^\circ + 14^\circ) = -\sin14^\circ$
2. Подставляем и сокращаем $\sin14^\circ$ — он не равен нулю, а минус остаётся
   $\dfrac{30 \cdot (-\sin14^\circ)}{\sin14^\circ} = -30$

Ответ: **-30**

Подсказка до ответа: _Сколько в сумме дают два угла? Меняет ли знак эта функция при дополнении до $180^\circ$?_

#### Тангенсы углов, дающих в сумме 90° (8.U)

*Тангенс дополнительного угла — котангенс*

**Где теряют балл.** Ищут тангенсы в таблице — там их нет. Нужно заметить сумму углов $90^\circ$ (или $\tfrac{\pi}{2}$ в радианах).

**Подтип deg** (базовый)

Условие: Найдите значение выражения $37\operatorname{tg}11^\circ \cdot \operatorname{tg}79^\circ - 20$.

1. Углы $11^\circ$ и $79^\circ$ в сумме дают $90^\circ$, поэтому работает формула приведения $\operatorname{tg}(90^\circ - \alpha) = \operatorname{ctg}\alpha$
   $\operatorname{tg}79^\circ = \operatorname{tg}(90^\circ - 11^\circ) = \operatorname{ctg}11^\circ$
2. Тангенс и котангенс одного угла — взаимно обратные числа: $\operatorname{tg}\alpha \cdot \operatorname{ctg}\alpha = 1$
   $37\operatorname{tg}11^\circ \cdot \operatorname{ctg}11^\circ - 20 = 37 \cdot 1 - 20 = 17$

Ответ: **17**

Подсказка до ответа: _Сколько в сумме дают два угла? Что такое тангенс дополнительного угла?_

**Подтип rad** (повышенный, своя подсказка)

Условие: Найдите значение выражения $23\operatorname{tg}\frac{\pi}{22} \cdot \operatorname{tg}\frac{5\pi}{11} - 60$.

1. Проверяем, что углы в сумме дают прямой угол $\dfrac{\pi}{2}$: приводим дроби к знаменателю $22$
   $\frac{\pi}{22} + \frac{5\pi}{11} = \frac{\pi}{22} + \frac{10\pi}{22} = \frac{11\pi}{22} = \frac{\pi}{2}$
2. Значит, $\frac{5\pi}{11} = \dfrac{\pi}{2} - \frac{\pi}{22}$, и по формуле приведения $\operatorname{tg}\left(\dfrac{\pi}{2} - \alpha\right) = \operatorname{ctg}\alpha$
   $\operatorname{tg}\frac{5\pi}{11} = \operatorname{tg}\left(\frac{\pi}{2} - \frac{\pi}{22}\right) = \operatorname{ctg}\frac{\pi}{22}$
3. Тангенс и котангенс одного угла — взаимно обратные числа: $\operatorname{tg}\alpha \cdot \operatorname{ctg}\alpha = 1$
   $23\operatorname{tg}\frac{\pi}{22} \cdot \operatorname{ctg}\frac{\pi}{22} - 60 = 23 \cdot 1 - 60 = -37$

Ответ: **-37**

Подсказка до ответа: _Сложите два угла. Сколько получилось?_

#### Сумма квадратов синуса и косинуса (8.V)

*Приведение превращает сумму в основное тождество*

**Где теряют балл.** Складывают квадраты синусов как есть. Сначала приводим один из углов — и получаем $\sin^{2}\alpha + \cos^{2}\alpha = 1$.

**Подтип 90** (базовый)

Условие: Найдите значение выражения $\dfrac{80}{\sin^279^\circ + 15 + \sin^211^\circ}$.

1. По формуле приведения $\sin(90^\circ - \alpha) = \cos\alpha$: от $90^\circ$ синус меняется на косинус
   $\sin^211^\circ = \sin^2(90^\circ - 79^\circ) = \cos^279^\circ$
2. В знаменателе квадраты синуса и косинуса одного угла, а их сумма по основному тригонометрическому тождеству равна единице: $\sin^2\alpha + \cos^2\alpha = 1$
   $\dfrac{80}{\sin^279^\circ + 15 + \cos^279^\circ} = \dfrac{80}{1 + 15} = \dfrac{80}{16}$
3. Делим нацело, ведь $80 = 16 \cdot 5$
   $\dfrac{80}{16} = 5$

Ответ: **5**

Подсказка до ответа: _Как связаны два угла под синусами? Во что превращается $\sin^{2}$ второго угла?_

**Подтип 270** (повышенный)

Условие: Найдите значение выражения $\dfrac{76}{\sin^299^\circ + 1 + \sin^2189^\circ}$.

1. По формуле приведения $\sin(90^\circ + \alpha) = \cos\alpha$: от $90^\circ$ синус меняется на косинус
   $\sin^2189^\circ = \sin^2(90^\circ + 99^\circ) = \cos^299^\circ$
2. В знаменателе квадраты синуса и косинуса одного угла, а их сумма по основному тригонометрическому тождеству равна единице: $\sin^2\alpha + \cos^2\alpha = 1$
   $\dfrac{76}{\sin^299^\circ + 1 + \cos^299^\circ} = \dfrac{76}{1 + 1} = \dfrac{76}{2}$
3. Делим нацело, ведь $76 = 2 \cdot 38$
   $\dfrac{76}{2} = 38$

Ответ: **38**

Подсказка до ответа: _Как связаны два угла под синусами? Во что превращается $\sin^{2}$ второго угла?_

## Буквенные выражения

#### Дробь с буквами: сократить и подставить (8.W)

*Разность квадратов раскладываем и сокращаем до подстановки*

**Где теряют балл.** Подставляют числа сразу и считают большие квадраты. Сначала сокращаем, подставляем в одну строчку.

**Подтип squares-int** (базовый)

Условие: Найдите значение выражения $\dfrac{16a^2 - b^2}{4a + b}$ при $a = 4,\ b = -7$.

1. Числитель — разность квадратов: $16a^2 = (4a)^2$, а $x^2 - y^2 = (x - y)(x + y)$
   $16a^2 - b^2 = (4a)^2 - b^2 = (4a - b)(4a + b)$
2. Одна из скобок совпадает со знаменателем — сокращаем дробь на $4a + b$, и квадраты считать не нужно
   $\dfrac{(4a - b)(4a + b)}{4a + b} = 4a - b$
3. Подставляем $a = 4$, $b = -7$ в упрощённое выражение
   $4a - b = 4 \cdot 4 - (-7) = 16 + 7 = 23$

Ответ: **23**

Подсказка до ответа: _На что похож числитель? Какой множитель после разложения совпадёт со знаменателем?_

**Подтип squares-dec** (повышенный)

1. Числитель — разность квадратов: $16a^2 = (4a)^2$, а $x^2 - y^2 = (x - y)(x + y)$
   $16a^2 - b^2 = (4a)^2 - b^2 = (4a - b)(4a + b)$
2. Одна из скобок совпадает со знаменателем — сокращаем дробь на $4a + b$, и квадраты считать не нужно

3. Подставляем $a = 1{,}8$, $b = -3{,}2$ в упрощённое выражение
   $4a - b = 4 \cdot 1{,}8 - (-3{,}2) = 7{,}2 + 3{,}2 = 10{,}4$

Ответ: **10,4**

Подсказка до ответа: _На что похож числитель? Какой множитель после разложения совпадёт со знаменателем?_

**Подтип sum-diff** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{(a + b)^2 - (a - b)^2}{5ab}$ при $a = -3{,}4,\ b = -7$.

1. Числитель — разность квадратов: $x^2 - y^2 = (x - y)(x + y)$ при $x = a + b$, $y = a - b$. В разности скобок $a$ уходит, в сумме — $b$
   $(a + b)^2 - (a - b)^2 = \bigl((a + b) - (a - b)\bigr)\bigl((a + b) + (a - b)\bigr) = 2b \cdot 2a = 4ab$
2. Сокращаем дробь на $ab$ — буквы уходят совсем, поэтому значения $a = -3{,}4$, $b = -7$ не понадобились
   $\dfrac{4ab}{5ab} = \dfrac{4}{5} = 0{,}8$

Ответ: **0,8**

Подсказка до ответа: _Раскройте оба квадрата. Что останется после вычитания?_

**Подтип common** (базовый, своя подсказка)

Условие: Найдите значение выражения $\dfrac{a^2}{a - b} - \dfrac{b^2}{a - b}$ при $a = -8,\ b = 4$.

1. Знаменатели одинаковые — вычитаем числители, знаменатель оставляем
   $\dfrac{a^2}{a - b} - \dfrac{b^2}{a - b} = \dfrac{a^2 - b^2}{a - b}$
2. Числитель — разность квадратов: $a^2 - b^2 = (a - b)(a + b)$, поэтому дробь сокращается на $a - b$
   $\dfrac{a^2 - b^2}{a - b} = \dfrac{(a - b)(a + b)}{a - b} = a + b$
3. Подставляем $a = -8$, $b = 4$ в упрощённое выражение
   $a + b = -8 + 4 = -4$

Ответ: **-4**

Подсказка до ответа: _Знаменатели одинаковые. Что получится в числителе, если собрать всё в одну дробь?_

#### Корни с буквами (8.X)

*Формулы сокращённого умножения для корней*

**Где теряют балл.** $\sqrt{a^{2}} = \lvert a \rvert$, а не $a$: при отрицательном $a$ ответ со знаком минус будет неверным.

**Подтип conjugate** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{a - b}{\sqrt{a} - \sqrt{b}}$ при $a = 10{,}24,\ b = 0{,}09$.

1. Числитель — разность квадратов корней: $a = (\sqrt{a})^2$, $b = (\sqrt{b})^2$, поэтому $a - b = (\sqrt{a} - \sqrt{b})(\sqrt{a} + \sqrt{b})$
   $\dfrac{a - b}{\sqrt{a} - \sqrt{b}} = \dfrac{(\sqrt{a} - \sqrt{b})(\sqrt{a} + \sqrt{b})}{\sqrt{a} - \sqrt{b}}$
2. Сокращаем дробь на общий множитель $\sqrt{a} - \sqrt{b}$: он не равен нулю, потому что $a \ne b$
   $\dfrac{(\sqrt{a} - \sqrt{b})(\sqrt{a} + \sqrt{b})}{\sqrt{a} - \sqrt{b}} = \sqrt{a} + \sqrt{b}$
3. Подставляем $a = 10{,}24$, $b = 0{,}09$ и извлекаем корни: $10{,}24 = 3{,}2^2$, $0{,}09 = 0{,}3^2$
   $\sqrt{a} + \sqrt{b} = \sqrt{10{,}24} + \sqrt{0{,}09} = 3{,}2 + 0{,}3 = 3{,}5$

Ответ: **3,5**

Подсказка до ответа: _Как разложить $a - b$, если $a = (\sqrt{a})^{2}$?_

**Подтип modulus** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\sqrt{a^2 b}$ при $a = -7,\ b = 36$.

1. Корень из произведения — произведение корней, а $\sqrt{a^2} = \lvert a \rvert$: арифметический корень не бывает отрицательным
   $\sqrt{a^2 b} = \sqrt{a^2} \cdot \sqrt{b} = \lvert a \rvert \cdot \sqrt{b}$
2. Подставляем $a = -7$, $b = 36$. Число $a$ отрицательное, поэтому $\lvert a \rvert = -a = 7$, а $36 = 6^2$
   $\lvert a \rvert \cdot \sqrt{b} = \lvert -7 \rvert \cdot \sqrt{36} = 7 \cdot 6 = 42$

Ответ: **42**

Подсказка до ответа: _Чему равен $\sqrt{a^{2}}$, если $a$ отрицательно?_

**Подтип square** (базовый)

Условие: Найдите значение выражения $(\sqrt{a} - \sqrt{b})^2 + 2\sqrt{ab}$ при $a = 0{,}8,\ b = 2{,}9$.

1. Раскрываем квадрат разности: $(x - y)^2 = x^2 - 2xy + y^2$, где $(\sqrt{a})^2 = a$, $(\sqrt{b})^2 = b$ и $\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}$
   $(\sqrt{a} - \sqrt{b})^2 = a - 2\sqrt{ab} + b$
2. Слагаемые $-2\sqrt{ab}$ и $2\sqrt{ab}$ взаимно уничтожаются — корни считать не придётся
   $a - 2\sqrt{ab} + b + 2\sqrt{ab} = a + b$
3. Подставляем $a = 0{,}8$, $b = 2{,}9$
   $a + b = 0{,}8 + 2{,}9 = 3{,}7$

Ответ: **3,7**

Подсказка до ответа: _Какая формула сокращённого умножения здесь спрятана, если $\sqrt{a}$ считать за букву?_

**Подтип product** (базовый, своя подсказка)

Условие: Найдите значение выражения $(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b})$ при $a = 7{,}8,\ b = 0{,}3$.

1. Произведение суммы и разности — разность квадратов: $(x + y)(x - y) = x^2 - y^2$, а квадрат корня — подкоренное число: $(\sqrt{a})^2 = a$
   $(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b}) = (\sqrt{a})^2 - (\sqrt{b})^2 = a - b$
2. Подставляем $a = 7{,}8$, $b = 0{,}3$ — корни из них извлекать не нужно
   $a - b = 7{,}8 - 0{,}3 = 7{,}5$

Ответ: **7,5**

Подсказка до ответа: _Какая формула даёт произведение суммы на разность?_

#### Степени с буквами (8.Y)

*Свойства степеней упрощают выражение до подстановки*

**Где теряют балл.** Забывают возвести в степень числовой коэффициент: $(5a)^{3} = 125a^{3}$, а не $5a^{3}$.

**Подтип int-pos** (базовый)

Условие: Найдите значение выражения $\dfrac{(a b^{2})^{3}}{a^{4} b^{4}}$ при $a = 4,\ b = 10$.

1. Возводим произведение в степень: каждый множитель отдельно, показатели перемножаются — $(x^{m} y^{n})^{k} = x^{mk} y^{nk}$
   $(a b^{2})^{3} = a^{3} b^{2 \cdot 3} = a^{3} b^{6}$
2. Делим степени с одинаковым основанием — показатели вычитаются: $\dfrac{x^{m}}{x^{n}} = x^{m - n}$. Отрицательный показатель переносим в знаменатель: $x^{-n} = \dfrac{1}{x^{n}}$
   $\dfrac{a^{3} b^{6}}{a^{4} b^{4}} = a^{3 - 4} b^{6 - 4} = a^{-1} b^{2} = \dfrac{b^{2}}{a}$
3. Подставляем $a = 4$, $b = 10$
   $\dfrac{b^{2}}{a} = \dfrac{10^{2}}{4} = \dfrac{100}{4} = 25$

Ответ: **25**

Подсказка до ответа: _Что останется, если раскрыть скобку по свойству $(ab)^{n} = a^{n}b^{n}$ и сократить?_

**Подтип int-neg** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{(a b^{3})^{-2}}{b^{-4}}$ при $a = 0{,}25,\ b = 5$.

1. Возводим произведение в степень: каждый множитель отдельно, показатели перемножаются — $(x^{m} y^{n})^{k} = x^{mk} y^{nk}$
   $(a b^{3})^{-2} = a^{-2} b^{3 \cdot (-2)} = a^{-2} b^{-6}$
2. Делим степени с одинаковым основанием — показатели вычитаются: $\dfrac{x^{m}}{x^{n}} = x^{m - n}$. Отрицательный показатель переносим в знаменатель: $x^{-n} = \dfrac{1}{x^{n}}$
   $\dfrac{a^{-2} b^{-6}}{b^{-4}} = a^{-2} b^{-6 - (-4)} = a^{-2} b^{-2} = \dfrac{1}{a^{2} b^{2}}$
3. Подставляем $a = 0{,}25$, $b = 5$
   $\dfrac{1}{a^{2} b^{2}} = \dfrac{1}{0{,}25^{2} \cdot 5^{2}} = \dfrac{1}{1{,}5625} = 0{,}64$

Ответ: **0,64**

Подсказка до ответа: _Что получится с показателями, если возвести $a^{-2}b^{2}$ в степень $-2$?_

**Подтип decimal** (повышенный, своя подсказка)

Условие: Найдите значение выражения $\dfrac{a^{0{,}9} \cdot a^{1}}{a^{1{,}4}}$ при $a = 4$.

1. Основания одинаковые: при умножении показатели складываются, при делении вычитаются — $\dfrac{a^{x} \cdot a^{y}}{a^{z}} = a^{x + y - z}$
   $\dfrac{a^{0{,}9} \cdot a^{1}}{a^{1{,}4}} = a^{0{,}9 + 1 - 1{,}4} = a^{0{,}5}$
2. Показатель $0{,}5 = \dfrac{1}{2}$ — это квадратный корень: $a^{\frac{1}{2}} = \sqrt{a}$
   $a^{0{,}5} = a^{\frac{1}{2}} = \sqrt{a}$
3. Подставляем $a = 4$: это точный квадрат, $4 = 2^2$
   $\sqrt{a} = \sqrt{4} = 2$

Ответ: **2**

Подсказка до ответа: _Какие показатели сократятся, если сложить и вычесть их по порядку?_

**Подтип numeric** (базовый)

Условие: Найдите значение выражения $\dfrac{(5a)^{2}}{a^{2}}$ при $a = 0{,}5$.

1. Возводим произведение в степень — каждый множитель отдельно: $(xy)^{n} = x^{n} y^{n}$

2. В числителе и в знаменателе одна и та же степень $a^{2}$ — сокращаем её полностью, поэтому значение $a = 0{,}5$ не понадобится
   $\dfrac{25a^{2}}{a^{2}} = 25$

#### Логарифмы с буквами (8.Z)

*Свойства логарифмов убирают буквы из ответа*

**Где теряют балл.** $\log_{a}(a^{5}b)$ — это $5 + \log_{a} b$, а не $5\log_{a} b$: степень только у $a$, а $b$ — отдельный множитель.

**Подтип product** (базовый)

Условие: Найдите значение выражения $\log_{a} (a^{2} b) - \log_{a} b$ при $a = 7,\ b = 11$.

1. Разность логарифмов с одним основанием — логарифм частного: $\log_{a} x - \log_{a} y = \log_{a} \dfrac{x}{y}$
   $\log_{a} (a^{2} b) - \log_{a} b = \log_{a} \dfrac{a^{2} b}{b}$
2. Сокращаем дробь на $b$, а логарифм степени основания равен показателю: $\log_{a} a^{k} = k$. Значения $a = 7$, $b = 11$ не понадобились
   $\log_{a} \dfrac{a^{2} b}{b} = \log_{a} a^{2} = 2$

Ответ: **2**

Подсказка до ответа: _Какое свойство логарифма разложит выражение так, чтобы одинаковые части сократились?_

**Подтип chain** (базовый, своя подсказка)

Условие: Найдите значение выражения $\log_{a} b \cdot \log_{b} a^{2}$ при $a = 10,\ b = 11$.

1. Выносим показатель степени за знак логарифма: $\log_{b} a^{k} = k \log_{b} a$
   $\log_{a} b \cdot \log_{b} a^{2} = 2 \cdot \log_{a} b \cdot \log_{b} a$
2. Логарифмы $\log_{a} b$ и $\log_{b} a$ взаимно обратны: $\log_{b} a = \dfrac{1}{\log_{a} b}$, поэтому их произведение равно $1$. Значения $a = 10$, $b = 11$ не понадобились
   $2 \cdot \log_{a} b \cdot \log_{b} a = 2 \cdot 1 = 2$

Ответ: **2**

Подсказка до ответа: _Что общего у числа под первым логарифмом и основания второго?_

**Подтип identity** (повышенный, своя подсказка)

Условие: Найдите значение выражения $2^{\log_{4} b}$ при $b = 121$.

1. Основание логарифма — квадрат: $4 = 2^{2}$, поэтому выносим множитель $\dfrac{1}{2}$: $\log_{c^{2}} x = \dfrac{1}{2}\log_{c} x$. Его возвращаем под логарифм как квадратный корень — теперь у логарифма то же основание $2$, что и у степени
   $\log_{4} b = \log_{2^{2}} b = \dfrac{1}{2}\log_{2} b = \log_{2} \sqrt{b}$
2. Основное логарифмическое тождество: $c^{\log_{c} x} = x$ — степень и логарифм с одним основанием взаимно уничтожаются
   $2^{\log_{4} b} = 2^{\log_{2} \sqrt{b}} = \sqrt{b}$
3. Подставляем $b = 121$: это точный квадрат, $121 = 11^{2}$
   $\sqrt{b} = \sqrt{121} = 11$

Ответ: **11**

## Что нужно знать

### Степени

- $a^{m} \cdot a^{n} = a^{m+n}$ — например $2^{3} \cdot 2^{4} = 2^{7}$
- $a^{m} : a^{n} = a^{m-n}$ — например $5^{7} : 5^{5} = 5^{2} = 25$
- $(a^{m})^{n} = a^{mn}$ — например $(5^{2})^{3} = 5^{6}$
- $a^{n} \cdot b^{n} = (ab)^{n}$ — например $2^{5} \cdot 5^{5} = 10^{5}$
- $a^{-n} = \dfrac{1}{a^{n}}$ — например $2^{-3} = \dfrac{1}{8} = 0{,}125$

### Корни

- $\sqrt[n]{a} \cdot \sqrt[n]{b} = \sqrt[n]{ab}$ — например $\sqrt{2} \cdot \sqrt{8} = \sqrt{16} = 4$
- $(\sqrt{a})^{2} = a$ — например $(3\sqrt{5})^{2} = 9 \cdot 5 = 45$
- $\sqrt[n]{a} = a^{\frac{1}{n}}$ — например $\sqrt[3]{8} = 8^{\frac{1}{3}} = 2$
- $\sqrt{a^{2}} = \lvert a \rvert$ — например $\sqrt{(-7)^{2}} = 7$
- $(\sqrt{a} - \sqrt{b})^{2} = a - 2\sqrt{ab} + b$ — например $(\sqrt{3} - \sqrt{2})^{2} = 5 - 2\sqrt{6}$

### Логарифмы

- $\log_{a} x + \log_{a} y = \log_{a} xy$ — например $\log_{6} 4 + \log_{6} 9 = \log_{6} 36 = 2$
- $\log_{a} x - \log_{a} y = \log_{a} \dfrac{x}{y}$ — например $\log_{2} 60 - \log_{2} 15 = \log_{2} 4 = 2$
- $\log_{a} b^{k} = k\log_{a} b$ — например $\log_{2} \sqrt[5]{2} = \dfrac{1}{5}$
- $\dfrac{\log_{c} b}{\log_{c} a} = \log_{a} b$ — например $\dfrac{\log_{3} 8}{\log_{3} 2} = \log_{2} 8 = 3$
- $\log_{a} b \cdot \log_{b} c = \log_{a} c$ — например $\log_{5} 13 \cdot \log_{13} 625 = \log_{5} 625 = 4$
- $a^{\log_{a} b} = b$ — например $7^{\log_{7} 5} = 5$

### Тригонометрия

- $\sin^{2}\alpha + \cos^{2}\alpha = 1$ — например $\cos\alpha = -0{,}8 \Rightarrow \sin^{2}\alpha = 0{,}36$
- $\operatorname{tg}\alpha = \dfrac{\sin\alpha}{\cos\alpha}$ — например $\dfrac{0{,}6}{-0{,}8} = -0{,}75$
- $\sin 2\alpha = 2\sin\alpha\cos\alpha$ — например $2\sin 15^\circ\cos 15^\circ = \sin 30^\circ = \tfrac{1}{2}$
- $\cos 2\alpha = \cos^{2}\alpha - \sin^{2}\alpha = 1 - 2\sin^{2}\alpha$ — например $\sin\alpha = 0{,}5 \Rightarrow \cos 2\alpha = 0{,}5$
- $\sin(90^\circ - \alpha) = \cos\alpha$ — например $\sin 72^\circ = \cos 18^\circ$
- $\cos(180^\circ - \alpha) = -\cos\alpha$ — например $\cos 172^\circ = -\cos 8^\circ$
- $\operatorname{tg}\alpha \cdot \operatorname{tg}(90^\circ - \alpha) = 1$ — например $\operatorname{tg} 5^\circ \cdot \operatorname{tg} 85^\circ = 1$

### Буквенные выражения

- $a^{2} - b^{2} = (a - b)(a + b)$ — например $\dfrac{a^{2} - 4b^{2}}{a + 2b} = a - 2b$
- $(a \pm b)^{2} = a^{2} \pm 2ab + b^{2}$ — например $(a + b)^{2} - (a - b)^{2} = 4ab$
- $(ab)^{n} = a^{n}b^{n}$ — например $(5a)^{3} = 125a^{3}$
- $\log_{a}(a^{k} b) = k + \log_{a} b$ — например $\log_{a}(a^{5} b) - \log_{a} b = 5$
