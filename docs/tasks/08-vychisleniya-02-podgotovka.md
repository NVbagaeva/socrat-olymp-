# Задание №08. Этап 2 — подготовительные задачи

Документ описывает вкладку подготовки: состав микро-задач по пяти
группам, формат одной задачи и структуру данных. Интерфейса за этим
документом ещё нет.

## Название вкладки

В репозитории у №3, №4, №5 и №12 вкладка называется «Подготовительные
задачи»; следов вкладки «Трудные задачи» нет ни в коде, ни в
`docs/`. Для №8 предлагаю **«Подготовительные задачи»**: задачи ниже —
это ступеньки «одно свойство — одно действие» перед прототипами ЕГЭ,
а не задачи сложнее экзамена. Если план №3 предполагает отдельную
вкладку «Трудные задачи», она у №8 не нужна: сложность закрывает
уровень «Повышенная» в тренажёре.

## Принципы

- Микро-задача = одно свойство или одна формула, один шаг вычисления.
- Задачи параметрические: у каждой микро-задачи есть генератор с
  seed, как у прототипов тренажёра. На вкладке показывается
  зафиксированный вариант (seed из банка), поэтому у всех учеников
  задачи одинаковые и прогресс «решено» по номеру задачи осмыслен.
- Ответ на вкладку не приходит: на сборке считается отпечаток
  (`sealAnswer`), проверка — `answerMatches` в браузере, как в №3.
- Подсказка после ошибки — **точная формула свойства** в записи TeX и
  ничего больше. Никаких «попробуйте подумать», никаких выдуманных
  пояснений. У задач на знак функции подсказка — таблица знаков по
  четвертям (это факт, не текст).
- Плашка «Запомни!» блока (аналог `tip` у №12) — список формул блока
  без комментариев.
- Условие и формулы — в конфиге `lib/vychisleniya/prep/`, компоненты
  получают готовые значения пропсами.

## Состав блоков

Идентификаторы: блок `P8-<группа>`, задача `P8-<группа>-<номер>`.
Номер задачи двузначный.

Итого 40 микро-задач, по 8 в блоке. Каждая — шаблон с генератором;
на вкладке показывается один зафиксированный вариант шаблона
(seed из банка подготовки). Числа в таблицах — примеры формы, не
обязательный вариант банка.

## Формат одной задачи на экране

1. **Условие** — «Найдите значение выражения» + формула KaTeX (или
   «Определите знак …» / «Найдите $x$»).
2. **Поле ответа** — числовое; принимает «0,5», «0.5», «-3», «−3»,
   «3/2». Для задач на знак — два варианта на выбор («плюс»,
   «минус»), как `answerType: 'choice'` у №12.
3. **Проверка** — отпечаток: на сборке `sealAnswer(answer)` (число)
   или `fingerprint('choice:' + номер)` (выбор); в браузере
   `answerMatches(input, seal)`. Число в клиент не уходит.
4. **После ошибки** — плашка «Пока неверно» и подсказка: формула
   свойства. Она хранится открытым текстом (в ней нет ответа) и
   показывается только после неверного ответа или по кнопке
   «Подсказка». Второй попытки без ограничений.
5. **После верного ответа** — отметка «решено» в `localStorage`
   (ключ `budetege:vychisleniya-8:prep:v1`, формат
   `Record<blockId, number[]>` как у `prepProgress.ts`), переход к
   следующей нерешённой (`lib/prepOrder.ts`).
6. **Разбор** — одна строка: та же формула с подставленными числами
   и ответом, закрытая `sealText` тем же отпечатком; раскрывается по
   кнопке «Показать решение». Отдельных многошаговых разборов у
   микро-задач нет: шаг один.

## Структура данных

Файлы в `app/src/lib/vychisleniya/prep/`:

```ts
// prep/types.ts
export type PrepGroup = 'I' | 'II' | 'III' | 'IV' | 'V';

export interface PrepChoice {
  /** Номер варианта: '1', '2'. */
  number: string;
  /** Текст варианта: «плюс», «минус». */
  label: string;
}

/** Результат генератора микро-задачи — ещё с ответом (только сборка). */
export interface PrepGenerated {
  /** Условие: текст с формулами в $…$. */
  uslovie: string;
  /** Ответ числом или номер верного варианта выбора. */
  otvet: number | string;
  /** Одна строка разбора с подставленными числами. */
  razbor: string;
  params: Record<string, number | string>;
}

/** Шаблон микро-задачи — конфиг с генератором. */
export interface PrepMicro {
  /** Идентификатор: P8-1-01. */
  id: string;
  /** Что отрабатывается: «Произведение степеней». */
  nazvanie: string;
  /** Формула-подсказка, TeX без долларов. Показывается после ошибки. */
  formula: string;
  /** Тип ответа. */
  answerType: 'number' | 'choice';
  /** Варианты при answerType 'choice'. */
  choices?: PrepChoice[];
  /** Seed зафиксированного варианта. */
  seed: string;
  /** Детерминированный генератор. */
  generate(rng: Rng): PrepGenerated;
}

export interface PrepBlock {
  /** Идентификатор: P8-1. */
  id: string;
  group: PrepGroup;
  /** Часть адреса: /podgotovka/{slug}. */
  slug: 'stepeni-korni' | 'logarifmy' | 'znaki-chetverti' | 'formuly-trigonometrii' | 'bukvennye';
  /** Название карточки: «Степени и корни». */
  nazvanie: string;
  /** Подзаголовок карточки в одну строку. */
  lead: string;
  /** Формула на карточке блока (TeX). */

  /** Плашка «Запомни!»: список формул блока, TeX. */

  zadachi: PrepMicro[];
```

## Что проверяет самотест подготовки

- у каждого блока ровно 8 задач, идентификаторы по шаблону
  `P8-<группа>-<NN>`, без повторов;
- зафиксированный вариант каждой задачи даёт «хороший» ответ
  (целое или конечная десятичная дробь);
- на 1000 seed каждый генератор даёт «хороший» ответ, не даёт деления
  на ноль, отрицательных подкоренных, аргументов логарифма $\le 0$,
  оснований $1$;
- разбор заканчивается тем же числом, что ответ;
- формула-подсказка не содержит чисел варианта (только буквы и
  константы формулы);
- отпечатки разных ответов внутри блока не совпадают.
