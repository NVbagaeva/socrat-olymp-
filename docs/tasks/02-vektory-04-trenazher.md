# Задание №2 «Векторы»: этап 4 — «Тренажёр», «Генератор», «Для репетиторов», печать

Три вкладки и три страницы печати; карточка раздела в банке заданий
открыта (`content/tasks.ts`, `status: 'active'`).

## Тренажёр

Конфигуратор как у №8: прототип (девятнадцать карточек тремя группами,
миниатюра — рисунок движка по первому варианту банка или формула) →
режим (отработка, смешанная, повтор ошибок, контроль) → количество
(5/10/20/все). Уровней нет: у прототипов векторов их нет.

Сессия собирается в браузере (`lib/vektory/session.ts`): генератор
считает свежие числа по случайному seed, ответ сразу закрывается
отпечатком, разбор (шаги с заголовками и рисунок с катетами) — под тем
же отпечатком. Рисунок условия без катетов.

Экран задания: условие, рисунок (во весь экран по нажатию), поле
ответа (запятая и точка равноправны), «Проверить». Подсказки — шаги
разбора по одному («Подсказка» → «Следующий шаг»); с первой подсказкой
рисунок переключается в режим катетов. «Полное решение» открывает все
шаги. Зачёт: без подсказок — чистое решение; с подсказками — решено с
подсказкой; полное решение до верного ответа — не засчитано. В режиме
«Контроль» подсказок и решения нет. Итог и статистика — как у №8,
по прототипам.

## Генератор

Вид работы и дата, прототипы (мультивыбор, кнопка «Все» у группы),
количество (5/10/15/20), число вариантов (1–4, одной структуры с
другими числами), поле seed (пусто — случайный, кнопка «Новый seed»;
одинаковый seed даёт одинаковый лист, seed стоит в адресе листа),
колонки, тема. Выход: лист ученика и лист с решениями — страницы
печати, открывают окно печати браузера сами, кнопка «Скачать PDF /
Печать» на странице дублирует его.

Лист (`lib/vektory/sheet2.ts`, шаблон `lib/sheet/`): блок на прототип
с плашкой кода, карточка задачи с рисунком (клетка 3,4 мм в одну
колонку, 3,0 мм в две), строка «Ответ: ____» у ученика; у учителя —
разбор по шагам с заголовками в карточке, рисунок с катетами, строка
ответа и сводная таблица «Ответы» с новой страницы (по вариантам).

## Для репетиторов

Банк из десяти зафиксированных вариантов на прототип (`lib/vektory/bank.ts`).
Страница: тема и колонки, «Весь банк» (лист ученика / лист с
решениями на 190 задач), «Ключ ответов» (таблицы «вариант → ответ»
по прототипам, группами A, B, C) и таблица прототипов с листами по
каждому. Все листы собираются в браузере по seed банка (`bank=1` в
адресе); ключ не печатается сам — репетитор нажимает «Скачать PDF /
Печать» и сохраняет PDF. В сборке, в `public/` и в git ответов и PDF
нет.
