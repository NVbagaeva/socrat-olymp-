# Задание №2 «Векторы»: этап 3 — «О задании», «Теория», «Опорные задачи»

Три вкладки раздела `/zadaniya/2/` на общей оболочке: шапка с кольцом
прогресса, лента вкладок (`RazdelTabs`), панель. Вкладки тренажёра и
генератора появятся на этапе 4 вместе со своими страницами.

## Кольцо прогресса

Своё у раздела, по действиям: прочитанный раздел теории (долистан до
конца, `lib/theoryRead`, ключ «2») — шаг, верно решённая микрозадача
тренировок (`lib/vektory/progress.ts`, хранилище
`budetege:vektory-2:opornye:v1`) — шаг. Всего 8 + 30 = 38 шагов;
вкладок, которых ещё нет, в сумме нет. На этапе 4 к сумме добавятся
задачи тренажёра.

## О задании

Что проверяет задание, формат ответа (1 балл; целое или конечная
десятичная дробь, запятая и точка равноправны), три группы прототипов
с карточкой на каждый из девятнадцати: код, название (KaTeX, без
переносов) и мини-рисунок движка в окне `'tight'` по первому варианту
банка — или формула, если прототип по координатам. Четыре типичные
ошибки: конец и начало перепутаны, потерян знак, |a+b| ≠ |a|+|b|, для
косинуса не посчитаны длины. Тексты — `content/vektory.ts`.

## Теория

Оболочка теории №4 (`TeoriyaShell`: разделы подряд, содержание рядом,
шторка на узком экране) с карточками теории №12 (`QuadraticSection`),
в которые вместо чертежа графика ставится рисунок движка векторов по
ключу сцены (`lib/vektory/stseny.ts`). Восемь разделов
(`content/theoryVektory.ts`):

1. Координаты вектора — конец минус начало, пример по точкам, порядок важен.
2. Чтение координат по клеткам — катеты как модули, правило знака
   («из большего вычитаем меньшее или наоборот?»), пример из (4; 9)
   в (1; 5) → (−3; −4).
3. Сложение, вычитание, умножение на число — покоординатно, с рисунками.
4. Длина вектора — формула, пример, длина суммы считается после координат суммы.
5. Скалярное произведение — через длины и угол, через координаты, косинусы 30°, 45°, 60°.
6. Косинус угла — формула, пример в три шага, знак косинуса.
7. Перпендикулярность — произведение равно нулю.
8. Свойства скалярного произведения — (a+b)·c и (ka)·b.

Язык правила знака в теории тот же, что в шагах решений и подсказках.

## Опорные задачи

Сначала тренировки навыков, затем разобранные задачи.

### Тренировки навыков — состав

Пять блоков по шесть задач (`lib/vektory/prep/`), у каждой кнопка
«Ещё вариант» на новом seed, как у подготовки №8. Ответы закрыты
отпечатком (`lib/vektory/secret.ts`), разбор открывается по кнопке и
закрыт вместе с рисунком, на котором есть катеты; на рисунке условия
катетов нет.

| Блок | Навык | Ответ | Задачи |
| --- | --- | --- | --- |
| P2-1 | Координаты вектора по рисунку | выбор из 4 | шесть векторов на сетке; подвохи — «начало минус конец» (−x; −y), перепутаны x и y, потерян один знак |
| P2-2 | Действия с векторами | выбор из 4 | a+b, a−b, 2a, 2a+b, a−2b, 3a−2b по координатам; подвохи — знак при b, коэффициенты наоборот, −результат |
| P2-3 | Длина вектора | число | три по координатам, три по рисунку; длины целые (пифагоровы векторы) |
| P2-4 | Скалярное произведение по координатам | число | шесть пар векторов по координатам |
| P2-5 | Косинус угла | число | шесть пар с косинусом из двухзначных значений |

Исходы пишутся по действиям (верно, неверно, открыл решение);
верное решение снимает прежний исход. Счётчик «N из 30 заданий» и
полосы на карточках блоков — из хранилища браузера.

### Разобранные задачи

По одной на прототип (seed `<id>#opornaya`, `lib/vektory/opornye.ts`),
группами A, B, C: условие, рисунок в режиме подсказки (катеты), решение
по шагам с заголовками под свёрнутым «Решение» (`<details>`). В конце
группы C — «Задачи повышенной сложности: косинус с тремя знаками после
запятой»: пояснение (тройка 44–117–125 против 3–4–5 и 7–24–25) и три
задачи с ответами ±0,936 и ±0,352.

## Проверки

`pnpm test:vektory` дополнен: опорные задачи по прототипам (рисунок с
катетами чист), микрозадачи на зафиксированном и 200 случайных seed
(формат ответа, варианты различны, верный отвечает рисунку, рисунок
условия без катетов), сцены теории, все формулы теории и «О задании»
— KaTeX строго. На 1000 seed: 19 000 задач, 6 030 микрозадач, 0
проблем.

Телефон 360–390 px проверен скриншотами: карточки прототипов и теории
идут столбиком, рисунок во всю ширину карточки, подписи читаются;
рисунок задачи открывается во весь экран по нажатию (`FigureZoom`).
