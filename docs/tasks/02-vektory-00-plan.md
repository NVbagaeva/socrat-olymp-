## 3. Движок рисунков: `renderVectorPlane(config) → SVG`

```ts
interface Vektor { name: 'a'|'b'|'c'; from: [number, number]; to: [number, number] }
interface Risunok {
  vectors: Vektor[];
  window?: { xmin; xmax; ymin; ymax };   // по умолчанию x∈[−1;13], y∈[−2;11];
                                         // расширяется по векторам с запасом в 1 клетку
  grid?: boolean;                        // false — режим «без сетки» (B6, B7)
  hints?: boolean;                       // катеты Δx, Δy пунктиром с «+3», «−2»
  cell?: number;                         // px на клетку, из THEME.geometry.cell
  alt?: string;
}
interface Report { tips: {x,y}[]; labelBoxes: Box[]; ticks: {axis, at}[]; ... }
```

- **Сетка и оси** — геометрия и тема из `THEME` (№12): клетка 34 px,
  сетка `--graph-grid`, оси `--graph-axis` со стрелками-треугольниками,
  курсив *x*, *y*, подписи `0`, `1` по x и `1` по y. В ч/б теме печати
  токены уже дают чёрное и серое.
- **Вектор** — отрезок толщиной `THEME.width.curve` (3.2 px), залитый
  наконечник-многоугольник. Остриё — ровно `sx(x₂), sy(y₂)`; стержень
  укорочен на длину наконечника, чтобы не торчать из-под него. Маркер
  `<marker>` не используется намеренно: с ним положение острия зависит
  от `refX` и `markerUnits`, и проверить его числом в тесте нельзя;
  многоугольник даёт координаты острия в явном виде, тест сверяет их с
  узлом. Проверка визуально — на демо-странице с увеличением.
- **Подпись** — `<text>` жирным курсивом из `--font-math` плюс стрелка
  над буквой (отдельный `<path>`); белое гало, как у всех подписей
  движка. Место — из 8 кандидатов (две стороны по нормали × смещения),
  первым проходит кандидат без пересечений с отрезками, наконечниками,
  осями, подписями осей и другими подписями; при равенстве — ближе к
  середине. Проверка пересечений — прямоугольник подписи против
  отрезка (`geometry.ts`), а не облако точек.
- **Без сетки** — только оси, пунктирные проекции концов на обе оси,
  подписи только нужных значений; значения, отличающиеся меньше чем
  на 1, запрещены уже генератором, движок это проверяет и пишет в
  `report`.
- **Подсказка** — катеты смещений пунктиром с подписями «+3», «−2»
  (`fmt` даёт типографский минус). Включается только явным `hints:
  true`; лист ученика, карточки генератора и тренажёр до подсказки
  вызывают движок без него.

## 4. Структура данных прототипа и задачи

```ts
type Format = 'coords' | 'grid' | 'nogrid' | 'text';   // как задано условие
interface Shag { zagolovok: string; stroki: string[] } // «Шаг 2. Координаты вектора 8a + b»
interface Draft {
  uslovie: string;          // текст с $…$: «Даны векторы $\vec a(6;\,-8)$ …»
  risunok: Risunok | null;  // null у A1–A5, B1–B4, C1
  otvet: number;            // целое или конечная десятичная дробь, ≤ 2 знаков
  proverka: number;         // независимый пересчёт из тех же векторов
  shagi: Shag[];            // последний шаг — «Ответ.»
  params: Params;           // ключ повтора: координаты и коэффициенты
  signature: string;        // «набор векторов» — банк не берёт два с одной
}
interface Prototype { id: 'A1'…'C2'; gruppa: 'A'|'B'|'C'; nazvanie: string;
                      format: Format; generate(r: Rng): Draft | null }
interface Generated extends Draft { prototype: string; seed: string }
```

Генерация: `generate(id, seed)` сеет ГСЧ строкой `${id}|${seed}`, до
400 попыток, пока `generate(r)` не вернёт черновик (null — набор не
подошёл под ограничения). Для рисунков `razmeshchenie.ts` ставит
векторы на поле: не пересекаются и не касаются, расстояние между
отрезками ≥ 1 клетки, не лежат на осях, длина ≥ 2, косые — не меньше
2 из 2 (две горизонтали/вертикали за раз не допускаются, одна —
с вероятностью ~1/6), подписи осей не накрываются.

Математика: длины — из таблицы троек (`troyki.ts`: (3,4,5), (5,12,13),
(8,15,17), (7,24,25), (20,21,29), (9,40,41) и кратные до модуля 30);
сначала результат, потом слагаемые (A2–A5, A7) или перебор
кандидатов по детерминированному списку (A3, A6, A8, где
коэффициенты фиксированы, а делимость ограничивает). A4/A8: ответ
задаётся первым как 0,1·тройка. Косинус: пары троек-кратных с
рациональным |a||b| и десятичным cos (например (9;3)·(2;6) → 0,6),
0 и ±1 исключены, ~1/3 отрицательных — в генераторе, не фильтром.
B1/B2: только пары из списка «хороших» (длины, угол) с конечным ответом.

1. **О задании** — что проверяет, формат ответа, 19 прототипов с

5. **Генератор** — прототипы (мультивыбор), число вариантов, поле seed
   (пусто — случайный; одинаковый seed — одинаковый лист, он лежит в
   адресе листа), колонки, тема. Выход: лист ученика, лист учителя с
   пошаговыми решениями, печать/PDF через `window.print()` как у №8.
6. **Для репетиторов** — таблица прототипов × 10 вариантов: листы

### Уточнения (подтверждены)

- Координаты вектора по рисунку объясняются через катеты. В теории
  (раздел «Координаты вектора»), в подсказках тренажёра и в шагах
  решения (лист учителя, опорные задачи) один и тот же язык:
  - координаты вектора — координаты конца минус координаты начала:
    $(x_2 - x_1;\ y_2 - y_1)$;
  - по рисунку длину катетов считаем в клетках — это модуль
    координаты; на рисунке катеты подписаны длинами без знака;
  - знак определяем вопросом «из большего вычитаем меньшее или
    наоборот?»: конец правее начала ($x_2 > x_1$) — из большего
    вычитаем меньшее, координата $x$ положительная; конец левее —
    из меньшего вычитаем большее, координата отрицательная; так же
    по вертикали: конец выше — $y$ положительная, ниже — отрицательная;
  - пример с рисунком в режиме подсказки: вектор из $(4;\ 9)$ в
    $(1;\ 5)$ — по горизонтали 3 клетки, конец левее, $x = 1 - 4 = -3$;
    по вертикали 4 клетки, конец ниже, $y = 5 - 9 = -4$; итог $(-3;\ -4)$.
  - Шаг решения дословно: «Катет по горизонтали — 3 клетки. Конец
    левее начала: из меньшего вычитаем большее ⇒ $x = -3$. Катет по
    вертикали — 4 клетки. Конец ниже начала ⇒ $y = -4$.
    $\vec a(-3;\ -4)$.» Все формулы — KaTeX.
- Катеты смещений рисуются только в подсказках тренажёра, в опорных
  задачах и в листе учителя (в решениях). В листе ученика, в задачах
  для отработки, в банке для репетиторов и на исходном рисунке
  тренажёра — никогда. Тест: все рисунки, собранные для этих мест,
  не содержат ни одного катета (`report.hints === false`, в SVG нет
  элементов `data-hint`).
- Векторы на рисунке — цветом графика №12 (`lineA`, токен
  `--color-primary`), в ч/б печати чёрные; катеты подсказки —
  акцентным. Линии осей и стержни кончаются у основания наконечника,
  наконечник вектора узкий (16 × 8 px).
- Телефон 360–390 px: поле 15 × 14 клеток — проверяется на
  демо-странице скриншотом; если подписи и цифры мелкие — решение
  предлагается на этапе 1 (кандидаты: поле по векторам без лишних
  клеток, увеличение по нажатию).
- Подписи типов прототипов и всё в карточках — KaTeX, формула не
  рвётся переносом (`white-space: nowrap` у формулы).
- Счётчик прогресса раздела — свой у раздела, считается по
  действиям, пустые вкладки не учитываются (новая логика проекта;
  образец ищется на этапе 3 и используется как есть).
- Опорные задачи: перед 19 разобранными задачами — короткие
  тренировки навыков (микрозадачи с фиксированным seed и кнопкой
  «Ещё вариант», как у №8): «Координаты вектора по рисунку»,
  «Действия с векторами», «Длина вектора», «Скалярное произведение по
  координатам», «Косинус угла». Состав — в документе этапа 3.

- движок: на наборе конфигураций — остриё в узле (координаты из

  нет ни одного катета, нет `NaN/undefined`;
- 1000 seed на каждый из 19 прототипов: формат ответа, `proverka`
  совпадает, ограничения рисунка выполнены (повторная проверка
  геометрией, не доверяя генератору), модули координат ≤ 30,
  последний шаг содержит ответ, все формулы собираются KaTeX строго;
- банк: ровно 10 на прототип, нет повторов ответов и наборов векторов,
  нет коллизий отпечатков.
