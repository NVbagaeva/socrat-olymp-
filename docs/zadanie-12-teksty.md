«≈ 4 минуты» — моя оценка. Поправьте, если даёте другое время.

### Чем опасно

1. Снимают точку не в узле сетки: координаты «на глаз» дают неверный коэффициент.
2. Теряют знак: у убывающей прямой $k<0$, у параболы ветвями вниз $a<0$, сдвиг $f(x+2)$ — влево, а не вправо.
3. Отвечают не на тот вопрос: находят $a$ вместо $f(x_0)$ или абсциссу вместо ординаты.
4. Берут не тот корень: при пересечении графиков один корень — уже отмеченная точка, в ответ идёт второй.

## 2. «Где теряют балл» — свой текст у каждого типа

Показывается под разобранным примером типа на «О задании». Названия типов — прежние (`content/skills12.ts`).

### Линейная функция

| Тип | Где теряют балл |
|---|---|
| Значение функции | Делят горизонтальный катет на вертикальный или забывают минус у убывающей прямой: $k$ — это подъём, делённый на шаг вправо. |
| Аргумент по значению | Верно находят $k$ и $b$, но решают не то уравнение: здесь известно значение функции, нужно найти $x$ из $kx+b=y_0$. |
| Абсцисса пересечения | Ищут $b$ прямой там, где она не пересекает ось $Oy$ в узле: тогда $b$ находят по точке с целыми координатами, подставляя её в $y=kx+b$. |
| Ордината пересечения | Находят абсциссу точки пересечения и на этом останавливаются: спрашивают ординату — подставь найденный $x$ в любую из прямых. |

### Квадратичная функция

| Тип | Где теряют балл |
|---|---|
| Знак коэффициента $a$ | Смотрят на вершину, а не на ветви: знак $a$ показывают ветви — вверх $a>0$, вниз $a<0$. |
| Значение коэффициента $a$ | Считают клетки не от вершины: в системе с началом в вершине $\Delta y=a\cdot\Delta x^2$, и шаг $\Delta x$ возводят в квадрат. |
| Свободный член $c$ | Путают $c$ с ординатой вершины: $c=f(0)$ — точка, где парабола пересекает ось $Oy$. |
| Коэффициент $b$ | Теряют знак в формуле вершины: $x_0=-\dfrac{b}{2a}$, поэтому $b=-2a\cdot x_0$. |
| Значение функции | Находят $a$, $b$, $c$, но ошибаются при подстановке отрицательного $x$: квадрат отрицательного числа положителен. |
| Аргумент по значению | Находят оба корня $f(x)=y_0$ и отвечают не тем: в условии сказано, какой нужен — больший или меньший. |
| Формула по графику | Сверяют только ветви: у вариантов часто совпадает знак $a$, отличает их вершина или $c=f(0)$. |
| Парабола и прямая | В ответ пишут абсциссу отмеченной точки: она уже известна, а спрашивают вторую — второй корень уравнения. |
| Парабола и парабола | Неверно вычитают одну формулу из другой: приравнивают обе параболы и следят за знаками у каждого слагаемого. |

### Дробно-линейная функция

| Тип | Где теряют балл |
|---|---|
| $\frac{k}{x} + a$: значение функции | Путают сдвиги: горизонтальная асимптота $y=a$ поднимает график, вертикальная остаётся $x=0$. |
| $\frac{k}{x} + a$: аргумент по значению | Решают $\dfrac{k}{x}+a=y_0$ без проверки: $x=\dfrac{k}{y_0-a}$, и знак знаменателя решает всё. |
| $\frac{k}{x + a}$: значение функции | Ошибаются со знаком сдвига: у $\dfrac{k}{x+a}$ вертикальная асимптота $x=-a$, сдвиг на $2$ влево — это $x+2$. |
| $\frac{k}{x + a}$: аргумент по значению | Находят $x+a$ и забывают вычесть сдвиг: из $\dfrac{k}{x+a}=y_0$ сначала $x+a=\dfrac{k}{y_0}$, потом $x$. |
| $\frac{kx + a}{x + b}$: коэффициент $k$ | Берут $k$ по одной асимптоте: у $\dfrac{kx+a}{x+b}$ горизонтальная асимптота $y=k$, вертикальная — $x=-b$. |
| $\frac{kx + a}{x + b}$: коэффициент $a$ | Подставляют точку с ошибкой в знаменателе: сначала по асимптотам $k$ и $b$, потом точка даёт $a$. |
| Гипербола и прямая: абсцисса $B$ | Пишут абсциссу точки $A$: она уже отмечена, второй корень уравнения $ax^2+bx-k=0$ — абсцисса $B$. |
| Гипербола и прямая: ордината $B$ | Находят абсциссу $B$ и отвечают ею: спрашивают ординату — подставь $x_B$ в формулу прямой. |
| $\frac{k}{x}$: значение и аргумент | Снимают $k$ по точке не в узле сетки: $k=x\cdot y$ берут по точке с целыми координатами. |
| $\frac{kx + a}{x + b}$: $b$ и значение | Путают знак $b$: вертикальная асимптота $x=-b$, поэтому при асимптоте $x=3$ получается $b=-3$. |

### Иррациональная функция

| Тип | Где теряют балл |
|---|---|
| Значение функции | Берут точку не на целое число клеток правее начала: для $k\sqrt{x}$ удобно $1$, $4$ или $9$ клеток — корень извлекается. |
| Аргумент по значению | Забывают возвести в квадрат: из $k\sqrt{x}=y_0$ получается $\sqrt{x}=\dfrac{y_0}{k}$, и только потом $x$. |
| Корень и прямая: абсцисса $B$ | Не отбрасывают посторонний корень: после возведения в квадрат проверь, что $k\sqrt{x}$ и прямая дают одно число. |
| Корень и прямая: ордината $B$ | Находят абсциссу и отвечают ею: спрашивают ординату — подставь найденный $x$ в формулу прямой. |

### Показательная функция

| Тип | Где теряют балл |
|---|---|
| $a^x$: значение функции | Берут точки не в узлах сетки: для $a^x$ нужны две точки с целыми координатами, $a$ — отношение значений при шаге $1$. |
| $a^x + b$: значение функции | Делят значения, а не вычитают сдвиг: у $a^x+b$ сначала горизонтальная асимптота $y=b$, потом $a$. |
| $a^x + b$: аргумент по значению | Решают показательное уравнение без приведения к одному основанию: $a^x=a^m$ даёт $x=m$. |
| $a^{x+b}$: аргумент по значению | Путают сдвиг: $a^{x+b}$ сдвинут по оси $Ox$ — значение $1$ функция принимает при $x=-b$. |

### Логарифмическая функция

| Тип | Где теряют балл |
|---|---|
| $\log_a x$: значение функции | Ищут основание по точке, где $y=0$: при $x=1$ любой логарифм равен нулю, $a$ даёт другая точка. |
| $b + \log_a x$: значение функции | Путают слагаемое $b$ с основанием: $b$ — значение функции при $x=1$, основание — по второй точке. |
| $b + \log_a x$: аргумент по значению | Неверно переходят к показательной записи: $\log_a t=s \Leftrightarrow a^s=t$, а не $s^a=t$. |
| $\log_a(x + b)$: значение функции | Ошибаются со сдвигом: у $\log_a(x+b)$ ноль функции при $x=1-b$, вертикальная асимптота $x=-b$. |
| $\log_a(x + b)$: аргумент по значению | Находят $x+b$ и забывают вычесть $b$: сначала $x+b=a^{y_0}$, потом $x$. |

### Тригонометрические функции

| Тип | Где теряют балл |
|---|---|
| $a\cos x + b$: найти $a$ | Неверно считают клетку по оси $Ox$: её цена — $\dfrac{\pi}{4}$ или $\dfrac{\pi}{6}$, смотри подпись на оси. |
| $a\cos x + b$: найти $b$ | Путают $b$ с амплитудой: $b$ — середина между наибольшим и наименьшим значениями, $a$ — половина размаха. |
| $a\operatorname{tg} x + b$: найти $a$ | Берут точку, где тангенс не определён: подходят точки, где $\operatorname{tg} x$ равен $0$ или $\pm1$. |
| $a\operatorname{tg} x + b$: найти $b$ | Ищут $b$ не при $x=0$: там $\operatorname{tg} x=0$, и значение функции сразу равно $b$. |
| $a\sin x + b$: найти $a$ | Теряют знак $a$: если при $x=\dfrac{\pi}{2}$ график ниже середины, то $a<0$. |
| $a\sin x + b$: найти $b$ | Ищут $b$ не при $x=0$: там $\sin x=0$, и значение функции сразу равно $b$. |

## 3. «Что нужно знать»

Формула и маленький пример к ней — по видам функций. Примеры посчитаны заново, проверьте числа.

### Линейная функция

| Формула | Пример |
|---|---|
| $k=\dfrac{\Delta y}{\Delta x}$ | $\text{вверх на }3,\ \text{вправо на }2:\ k=1{,}5$ |
| $b=f(0)$ | $\text{прямая пересекает }Oy\text{ в }(0;-1):\ b=-1$ |

### Квадратичная функция

| Формула | Пример |
|---|---|
| $\Delta y=a\cdot\Delta x^2$ | $\text{от вершины: }\Delta x=2,\ \Delta y=4\ \Rightarrow\ a=1$ |
| $x_0=-\dfrac{b}{2a},\quad c=f(0)$ | $a=1,\ x_0=1\ \Rightarrow\ b=-2$ |

### Дробно-линейная функция

| Формула | Пример |
|---|---|
| $y=\dfrac{k}{x+a}+b$ | $\text{асимптоты }x=-a,\ y=b$ |
| $k=(x+a)(y-b)$ | $a=0,\ b=0,\ (2;3):\ k=6$ |

### Иррациональная функция

| Формула | Пример |
|---|---|
| $y=k\sqrt{x}$ | $(4;6):\ 6=k\cdot2\ \Rightarrow\ k=3$ |
| $k\sqrt{x}=y_0\ \Rightarrow\ x=\left(\dfrac{y_0}{k}\right)^2$ | $3\sqrt{x}=12:\ x=16$ |

### Показательная функция

| Формула | Пример |
|---|---|
| $a=\dfrac{f(x+1)}{f(x)}$ | $f(1)=2,\ f(2)=4\ \Rightarrow\ a=2$ |
| $a^x=a^m\ \Rightarrow\ x=m$ | $2^x=8=2^3:\ x=3$ |

### Логарифмическая функция

| Формула | Пример |
|---|---|
| $\log_a 1=0,\quad \log_a a=1$ | $\text{график проходит через }(3;1):\ a=3$ |
| $\log_a t=s\ \Leftrightarrow\ a^s=t$ | $\log_2 x=3:\ x=8$ |

### Тригонометрические функции

| Формула | Пример |
|---|---|
| $b=\dfrac{y_{\max}+y_{\min}}{2}$ | $y_{\max}=3,\ y_{\min}=-1:\ b=1$ |
| $\|a\|=\dfrac{y_{\max}-y_{\min}}{2}$ | $\dfrac{3-(-1)}{2}=2$ |
