## Прокрутка на телефоне

`pnpm test:shapki-site` (scripts/check-shapki-site.mjs) на телефоне 390 px с касаниями для каждого из 19
разделов ведёт пальцем вертикально (касания CDP `Input.dispatchTouchEvent`):

1. по стеклянной картинке — страница прокручивается, картинка при этом не оживает;
2. тап — картинка сменяется живым чертежом;
3. по живому чертежу (и по объёмной фигуре) — страница прокручивается.

Результат на этой сборке: `check-shapki-site: ok (399 проверок, разделов 19)`.
