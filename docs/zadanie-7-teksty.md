## 2. «Где теряют балл» — свой текст у каждого типа

Показывается под разобранным примером типа. Примеры в текстах сверены с задачами банка этого типа.

| Тип | Где теряют балл |
|---|---|
| Единица, делённая на линейное выражение | Переворачивают только левую часть: из $\dfrac{1}{3x-4}=5$ получают $3x-4=5$ вместо $3x-4=\dfrac{1}{5}$. |
| Нечётная степень линейного выражения | У нечётной степени корень один и знак сохраняется: $(x+2)^3=-27$ даёт $x+2=-3$. Ставят «$\pm$», как у квадрата, или теряют минус. |
| Дробный коэффициент и смешанное число | Смешанное число не переводят в неправильную дробь или теряют знак: $-3\dfrac{7}{9}=-\dfrac{34}{9}$. И делят на дробь, не перевернув её. |
| Две дроби с единицей в числителе | Приравнивают знаменатели и не проверяют, что при найденном $x$ они не равны нулю. |
| Равные квадраты | Извлекают корень и пишут только $ax+b=ax+c$ — у этого уравнения корней нет. Корень даёт второй случай: $ax+b=-(ax+c)$. |
| Квадрат суммы равен $bx$ | Раскрывают квадрат суммы без удвоенного произведения: $(x+a)^2=x^2+2ax+a^2$, а не $x^2+a^2$. И считают дискриминант, не перенеся $bx$ влево. |
| Неполное квадратное $kx^2=c$ | Находят только положительный корень. У $x^2=a$ два корня, $\pm\sqrt{a}$, а в ответ нужен тот, что просят: меньший или больший. |
| Дробь с $x$ в числителе и знаменателе | Умножают на знаменатель только часть правой стороны: $c\cdot(rx+s)=crx+cs$. И не проверяют, что знаменатель не равен нулю. |
| $x$ равен дроби с $x$ в знаменателе | После умножения на знаменатель выходит квадратное уравнение с двумя корнями. Не проверяют $x\ne-c$ и записывают не тот корень, что просят. |
| Квадратное уравнение, меньший или больший корень | Ошибаются в знаке $b$ в формуле корней и записывают не тот корень: «меньший» из $-5$ и $8$ — это $-5$. |
| Квадратный корень равен числу | Возводят в квадрат только левую часть: из $\sqrt{x+5}=3$ получают $x+5=3$ вместо $x+5=9$. |
| Кубический корень равен числу | Кубический корень бывает отрицательным: $\sqrt[3]{x-4}=-2$ решается, $x-4=-8$. Пишут «корней нет» или теряют минус у куба. |
| Корень равен $x$: отбор по условию $x\ge0$ | Берут оба корня квадратного уравнения. Отрицательный — посторонний: квадратный корень не может равняться отрицательному числу. |
| Корень из дроби равен числу | После возведения в квадрат неверно выражают знаменатель: из $\dfrac{c}{kx+b}=d^2$ следует $kx+b=\dfrac{c}{d^2}$, а не $c\cdot d^2$. |
| Степень равна степени того же числа | Забывают, что число без показателя — первая степень: $6=6^1$, а $9=3^2$. Показатель приравнивают к самому числу, а не к показателю правой части. |
| Показатель с минусом или коэффициентом | Правую часть записывают степенью неверно ($27=3^3$, $729=9^3$) или теряют минус перед $x$: из $11-x=3$ следует $x=8$. |
| $x$ в показателях обеих частей | При возведении степени в степень показатели перемножают: $(a^k)^{mx}=a^{kmx}$. Их складывают — и уравнение на показатели выходит неверным. |
| Дробь $\dfrac{1}{a}$ в основании или справа | Дробь — это степень с минусом: $\dfrac{1}{16}=2^{-4}$, $\left(\dfrac{1}{a}\right)^{x+b}=a^{-x-b}$. Минус теряют или ставят только перед $x$. |
| $\dfrac{1}{a}$ слева, степень $a$ справа, $x$ в обеих частях | Переходят к основанию $a$ только в одной части. К нему приводят обе: слева $a^{-(x+b)}$, справа $a^{kx}$. |
| Логарифмы с одним основанием равны | Приравнивают выражения под логарифмами и не проверяют, что при найденном $x$ выражение под логарифмом положительно. |
| Логарифм равен числу | Путают основание и показатель: $\log_2(x+1)=3$ значит $x+1=2^3$, а не $3^2$. |
| Логарифм по основанию $\dfrac{1}{a}$ | Основание $\dfrac{1}{a}$ возводят в степень как $a$: $\left(\dfrac{1}{a}\right)^{c}=a^{-c}$ — знак показателя меняется. |
| Множитель перед логарифмом справа | Множитель перед логарифмом не вносят в показатель: $2\log_a c=\log_a c^2$, а не $\log_a 2c$. |
| Основное логарифмическое тождество | Тождество $a^{\log_a b}=b$ применяют, не уравняв основания: у степени основание $a$, у логарифма — $a^k$. Сначала логарифм приводят к основанию $a$. |
| Логарифм степени того же числа | Забывают про степень в основании: $\log_{a^k}a^{n}=\dfrac{n}{k}$, а не $n$. |
| Синус от линейного аргумента | У синуса две серии решений: при $\sin t=\dfrac{1}{2}$ это $t=\dfrac{\pi}{6}+2\pi n$ и $t=\dfrac{5\pi}{6}+2\pi n$. Берут одну — и теряют нужный корень. |
| Косинус от линейного аргумента | У косинуса серии со знаками «плюс» и «минус»: $t=\pm t_0+2\pi n$. Забывают серию с минусом и не находят наибольший отрицательный корень. |
| Тангенс от линейного аргумента | Период тангенса — $\pi$, а не $2\pi$: $t=t_0+\pi n$. С периодом $2\pi$ теряется половина корней, и в ответе оказывается не тот. |
| Дробь-степень слева, $x$ в обоих показателях | $\dfrac{1}{a^m}=a^{-m}$, и $-m$ умножается на весь показатель: $a^{-m(x+b)}$. Скобки раскрывают, не умножив $b$. |
| $x$ в основании логарифма | Берут оба корня из $(x+a)^2=N$. Основание логарифма положительно и не равно единице — отрицательное значение $x+a$ не подходит. |
| Частное степеней с одним основанием | Числитель сначала записывают степенью ($216=6^3$), потом показатель вычитают целиком: $3-(x+1)=3-x-1$. Минус не доносят до второго слагаемого. |
| Показательное уравнение, сводящееся к квадратному | После замены $t=a^x$ берут оба корня квадратного уравнения. Но $t>0$: отрицательный корень отбрасывают, а в ответ пишут $x$, а не $t$. |
| Под логарифмом — степень с $x$ | Пытаются разбить логарифм суммы на сумму логарифмов. Такой формулы нет: сначала по определению $a^{x+p}+b=a^c$. |
| Квадратное уравнение относительно логарифма | Находят $t=\log_a x$ и записывают в ответ $t$. Нужно вернуться к $x=a^t$ и выбрать корень, который просят. |
| Логарифм от логарифма | Снимают логарифмы не с того конца. Идут снаружи внутрь: сначала $\log_b(\log_c x)=a^m$, потом следующий логарифм. |

Значки групп: I — $ax=b$, II — $\sqrt{x}$, III — $a^{x}$, IV — $\log_{a}x$, V — $\sin x$. Названия групп — из банка.

## 4. «Что нужно знать»

Шесть цветных рамок, в каждой — правило и маленький пример. Формулы стандартные, но блок новый —
проверьте, пожалуйста, отбор и формулировки.

**ОДЗ — записываем всегда**

| Правило | Пример |
|---|---|
| $\dfrac{A}{B}:\quad B \ne 0$ | $\dfrac{1}{3x-4}=5:\quad x \ne \dfrac{4}{3}$ |
| $\sqrt{A}:\quad A \ge 0$ | $\sqrt{2x+6}:\quad x \ge -3$ |
| $\log_{a}A:\quad A > 0$ | $\log_{2}(x-5):\quad x > 5$ |

**Линейные и квадратные**

| Правило | Пример |
|---|---|
| $ax = b \iff x = \dfrac{b}{a}$ | $4x = 10 \iff x = 2{,}5$ |
| $\dfrac{a}{b}=\dfrac{c}{d} \iff ad = bc$ | $\dfrac{1}{x+2}=\dfrac{1}{5} \iff x+2 = 5$ |
| $x^{2} = a,\ a > 0 \iff x = \pm\sqrt{a}$ | $x^{2} = 49 \iff x = \pm 7$ |
| $D = b^{2}-4ac,\quad x = \dfrac{-b \pm \sqrt{D}}{2a}$ | $x^{2}-3x-40=0:\ D = 169,\ x = -5;\ 8$ |

**Иррациональные**

| Правило | Пример |
|---|---|
| $\sqrt{A} = b,\ b \ge 0 \iff A = b^{2}$ | $\sqrt{x+5} = 3 \iff x+5 = 9$ |
| $\sqrt{A} = B \iff A = B^{2}$ и $B \ge 0$ (системой) | $\sqrt{40+3x} = x \Rightarrow x = 8$ |
| $\sqrt[3]{A} = b \iff A = b^{3}$ | $\sqrt[3]{x-4} = -2 \iff x-4 = -8$ |

**Показательные**

| Правило | Пример |
|---|---|
| $a^{f(x)} = a^{g(x)} \iff f(x) = g(x)$ | $2^{x-3} = 2^{-4} \iff x-3 = -4$ |
| $\dfrac{1}{a^{n}} = a^{-n}$ | $\dfrac{1}{16} = 2^{-4}$ |
| $(a^{m})^{n} = a^{mn}$ | $9^{x} = (3^{2})^{x} = 3^{2x}$ |

**Логарифмические**

| Правило | Пример |
|---|---|
| $\log_{a}f(x) = c \iff f(x) = a^{c}$ | $\log_{2}(x+1) = 3 \iff x+1 = 8$ |
| $\log_{a}f = \log_{a}g \iff f = g > 0$ | $\log_{5}(x+3) = \log_{5}7 \iff x+3 = 7$ |
| $n\log_{a}b = \log_{a}b^{n}$ | $2\log_{3}4 = \log_{3}16$ |

**Тригонометрические**

| Правило | Пример |
|---|---|
| $\sin t = \dfrac{1}{2} \iff t = \dfrac{\pi}{6}+2\pi n,\ t = \dfrac{5\pi}{6}+2\pi n$ | $n = 0:\ t = \dfrac{\pi}{6},\ t = \dfrac{5\pi}{6}$ |
| $\cos t = \dfrac{1}{2} \iff t = \pm\dfrac{\pi}{3}+2\pi n$ | $n = 0:\ t = \dfrac{\pi}{3},\ t = -\dfrac{\pi}{3}$ |
| $\operatorname{tg} t = 1 \iff t = \dfrac{\pi}{4}+\pi n$ | $n = -1:\ t = -\dfrac{3\pi}{4}$ |
