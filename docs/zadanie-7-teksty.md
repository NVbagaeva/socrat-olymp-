## 2. Группы: «Где теряют балл»

Текст показывается под разобранным примером каждого типа группы (один на группу, не на тип).

| Группа | Значок | Где теряют балл |
|---|---|---|
| I. Линейные, дробно-рациональные, степенные | $ax=b$ | При переносе слагаемого забывают сменить знак, а в дробном уравнении не проверяют, что знаменатель не обратился в нуль. |
| II. Иррациональные | $\sqrt{x}$ | Возводят в квадрат и не проверяют корни: квадратный корень не бывает отрицательным, поэтому отрицательная правая часть даёт посторонний корень. |
| III. Показательные | $a^{x}$ | Приравнивают показатели, не приведя обе части к одному основанию, и теряют минус у $\dfrac{1}{a}=a^{-1}$. |
| IV. Логарифмические | $\log_{a}x$ | Забывают ОДЗ: выражение под логарифмом положительно, основание положительно и не равно единице. |
| V. Тригонометрические | $\sin x$ | Записывают в ответ серию с $\pi$ или берут не тот корень: нужно перебрать $n$ и выбрать наименьший положительный или наибольший отрицательный. |

Названия групп взяты из банка без изменений. Если нужен свой текст «Где теряют балл» у каждого из 35 типов

## 4. «Что нужно знать»

Шесть цветных рамок, в каждой — правило и маленький пример. Формулы стандартные, но блок новый —
проверьте, пожалуйста, отбор и формулировки.

**ОДЗ — записываем всегда**

| Правило | Пример |
|---|---|
| $\dfrac{A}{B}:\quad B \ne 0$ | $\dfrac{1}{3x-4}=5:\quad x \ne \dfrac{4}{3}$ |
| $\sqrt{A}:\quad A \ge 0$ | $\sqrt{2x+6}:\quad x \ge -3$ |
| $\log_{a}A:\quad A > 0$ | $\log_{2}(x-5):\quad x > 5$ |

**Линейные и квадратные**

| Правило | Пример |
|---|---|
| $ax = b \iff x = \dfrac{b}{a}$ | $4x = 10 \iff x = 2{,}5$ |
| $\dfrac{a}{b}=\dfrac{c}{d} \iff ad = bc$ | $\dfrac{1}{x+2}=\dfrac{1}{5} \iff x+2 = 5$ |
| $x^{2} = a,\ a > 0 \iff x = \pm\sqrt{a}$ | $x^{2} = 49 \iff x = \pm 7$ |
| $D = b^{2}-4ac,\quad x = \dfrac{-b \pm \sqrt{D}}{2a}$ | $x^{2}-3x-40=0:\ D = 169,\ x = -5;\ 8$ |

**Иррациональные**

| Правило | Пример |
|---|---|
| $\sqrt{A} = b,\ b \ge 0 \iff A = b^{2}$ | $\sqrt{x+5} = 3 \iff x+5 = 9$ |
| $\sqrt{A} = B \iff A = B^{2}$ и $B \ge 0$ (системой) | $\sqrt{40+3x} = x \Rightarrow x = 8$ |
| $\sqrt[3]{A} = b \iff A = b^{3}$ | $\sqrt[3]{x-4} = -2 \iff x-4 = -8$ |

**Показательные**

| Правило | Пример |
|---|---|
| $a^{f(x)} = a^{g(x)} \iff f(x) = g(x)$ | $2^{x-3} = 2^{-4} \iff x-3 = -4$ |
| $\dfrac{1}{a^{n}} = a^{-n}$ | $\dfrac{1}{16} = 2^{-4}$ |
| $(a^{m})^{n} = a^{mn}$ | $9^{x} = (3^{2})^{x} = 3^{2x}$ |

**Логарифмические**

| Правило | Пример |
|---|---|
| $\log_{a}f(x) = c \iff f(x) = a^{c}$ | $\log_{2}(x+1) = 3 \iff x+1 = 8$ |
| $\log_{a}f = \log_{a}g \iff f = g > 0$ | $\log_{5}(x+3) = \log_{5}7 \iff x+3 = 7$ |
| $n\log_{a}b = \log_{a}b^{n}$ | $2\log_{3}4 = \log_{3}16$ |

**Тригонометрические**

| Правило | Пример |
|---|---|
| $\sin t = \dfrac{1}{2} \iff t = \dfrac{\pi}{6}+2\pi n,\ t = \dfrac{5\pi}{6}+2\pi n$ | $n = 0:\ t = \dfrac{\pi}{6},\ t = \dfrac{5\pi}{6}$ |
| $\cos t = \dfrac{1}{2} \iff t = \pm\dfrac{\pi}{3}+2\pi n$ | $n = 0:\ t = \dfrac{\pi}{3},\ t = -\dfrac{\pi}{3}$ |
| $\operatorname{tg} t = 1 \iff t = \dfrac{\pi}{4}+\pi n$ | $n = -1:\ t = -\dfrac{3\pi}{4}$ |

Под рамками — блок «Равносильные переходы — цветными схемами» (подпись: «Синим — уравнение, оранжевым —
условие, которое нельзя потерять. Все схемы — в теории»). Сами схемы взяты из теории без изменений.
