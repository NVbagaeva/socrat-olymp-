### Как скрыть

1. `struktura.ts` → `skryty`. Возврат раздела — убрать его оттуда (одна строка).
2. Страницы раздела собираются как обычно, адрес `/zadaniya/sluchainye-velichiny/…` (вариант Б). На каждой —
   `<meta name="robots" content="noindex">` и плашка «Скрыт — нет в ЕГЭ-2027» сверху.
3. Сервер (`.htaccess`, блок генерируется из `struktura.ts`): `/zadaniya/sluchainye-velichiny/…` и старые
   `/zadaniya/6/…` → **404** и `X-Robots-Tag: noindex`, если нет cookie `budetege_skrytye=1`. Нужен
   `ErrorDocument 404 /404.html`: своей страницы 404 в main нет (`not-found.tsx` появляется только в PR 296).
4. Администратор: роль `admin` в базе есть (`app_role`, `is_admin()`, один администратор). Клиент узнаёт её
   только через `loadProfile()` в кабинете (`KabinetScreen.tsx:243` — карточка администратора; лёгкая сессия
   `lib/auth/session.ts:40` роль admin не знает). В карточку администратора добавляется «Скрытые разделы»:
   строка с плашкой и кнопкой «Открыть» — ставит cookie и открывает раздел. Внутри раздела страховка в браузере:
   без cookie — экран 404 (на случай, если служебные `index.txt` отдаёт nginx мимо `.htaccess`,
   см. `docs/DEPLOYMENT.md`).
5. Для превью PR без входа — флаг сборки `SKRYTYE=1` (как `GALEREYA`): скрытые разделы видны всем.

Cookie может поставить любой — это не защита, а скрытие. Секретов в разделе нет; JS-файлы сборки и так
публичны.
