# Журнал решения задач (кабинет-2, этап 1а)

Что и как делал ученик — где бы он ни решал. План целиком —
[docs/plans/cabinet-v2.md](plans/cabinet-v2.md). Экраны учителя — этап 1б.

## Что записывается

Одна показанная задача — одна запись (`task_runs`), каждое действие с ней —
событие (`task_events`).

| Что | Где лежит |
|---|---|
| раздел, тип/прототип, ссылка для генератора («8.A\|42\|1», «прототип:3») | `task_runs.task_no`, `kind`, `task_ref` |
| условие и чертёж, какими их видел ученик | `task_snapshots` (одинаковые задачи — одна строка) |
| каждая попытка: ответ как введён, верно/неверно, номер, время | событие `attempt` (`answer`, `ok`, `seq`, `at`) |
| подсказка открыта, шаги, вопрос подсказки с ошибкой | `hint_open`, `hint_step`, `hint_miss` (`step`) |
| «Показать свойство» (у №8 — «Формула»), «Показать решение», «Пропустить», «Похожая задача» | `property`, `solution`, `skip`, `similar` |
| время общее и активное | `task_runs.total_ms`, `active_ms`; у события — активное время к этому моменту |
| итог задачи | `outcome`: `right`, `hinted`, `wrong`, `revealed`, `skipped`; `open` — не закрыта |
| вариант: дата, первичный и тестовый балл, время | `work_results`; его задачи — `task_runs` с `work_id` |
| итог за день по заданию | `activity_days` (день — по Москве) |

**Активное время** идёт, пока вкладка видна и было действие (клавиша,
касание, мышь, прокрутка) не позже двух минут назад. После двух минут
бездействия счётчик встаёт на паузу до следующего действия. Общее время —
от показа задачи до закрытия.

Неверная **запись** ответа («5 см», «1/4» с верным значением) попыткой не
считается и в журнал не идёт — как и в самих тренажёрах.

## Где подключено

| Место | №5 | №8 | Экран |
|---|---|---|---|
| тренажёр | да | да | `Ekran45.tsx`, `Trenazher8Screen.tsx` |
| опорные задачи | да | да | `Opornye45Blok.tsx`, `Podgotovka8Screen.tsx` |
| карточки | да | колоды нет | `Kartochki.tsx` |
| варианты («Собрать вариант», серии, повышенной сложности, ежемесячные) | целиком, все задания | | `WorkRun.tsx` → `lib/zhurnal/variant.ts` |
| домашнее задание | — | да (ДЗ сейчас только №8) | `HomeworkSolve.tsx` |

Вариант записывается при завершении: по каждой задаче — ответы первой и
второй попытки, подсказка, активное время задачи; верный ответ — в снимке.
Задачи второй части (самопроверка) в журнал пока не идут — см. этап 4 плана.

Экран зовёт запись так:

```ts
const zhurnal = useZhurnal({ klyuch, source: 'trainer', taskNo: 8, kind, ref, statement });
zhurnal().popytka(value, right);
zhurnal().podskazka();
zhurnal().zakryt('right');
```

`klyuch` — ключ показа: тот же после перезагрузки страницы (запись
продолжается), новый — для нового показа задачи.

## Кому пишется

Только вошедшему **ученику**, только в сборке с флагом и только в разделах
из списка. Гостю, репетитору и администратору — нет. Школьнику до согласия
родителя сервер отвечает отказом (`progress_not_allowed`), и браузер
перестаёт писать журнал. Прежние журналы браузера (`lib/progressLog`: карта,
«Мои ошибки», прогресс по типам) работают как раньше, в том числе без входа.

## Флаги

Переменные GitHub (Settings → Variables), читаются при сборке сайта
(`deploy.yml` → `next.config.ts` → `app/src/lib/flags.ts`):

| Переменная | Значение |
|---|---|
| `NEXT_PUBLIC_KAB2_ZHURNAL` | `1` — журнал и страница «Моя статистика» (`/kabinet/statistika/`) |
| `NEXT_PUBLIC_KAB2_RAZDELY` | `5,8` — разделы с журналом; `all` — все подключённые |

Без переменных журнала в сборке нет, страницы `/kabinet/statistika/` нет
(404). Флаг действует только при включённом входе.

Порядок включения: «Сервер: развернуть» → «Сервер: миграции» (появятся
таблицы журнала) → переменные → выкладка сайта.

## Очередь в браузере

Ключ `budetege:zhurnal:ochered:v1`. События копятся и уходят пачками
(`journal_push`): раз в 15 секунд и сразу при закрытии задачи. Сети нет —
пачка ждёт и уходит позже; повтор пачки сервер принимает без дублей.
Снимок условия уходит один раз. При смене аккаунта на устройстве чужая
очередь не отправляется.

## Доступ

Читают: ученик — своё; репетитор — своих учеников, пока ученик у него
(`is_my_student`); администратор — всё. Правило стоит в базе (RLS), а не
в интерфейсе. Верный ответ из снимка прямым чтением не получить.

В тренажёре, опорных задачах и карточках верность ответа считает браузер
ученика: журнал — рассказ устройства, а не проверка. Оценки берутся из ДЗ
и работ кабинета, где ответ проверяет база.
