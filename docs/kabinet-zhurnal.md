# Журнал решения задач (кабинет v2, этап 1)

Что делает журнал, как он устроен и как его включить. План всего этапа —
[plans/cabinet-v2.md](plans/cabinet-v2.md), решения владельца по вопросам
В-1…В-13 — там же.

Этап 1 разбит на два PR:

- **1а — журнал** (этот документ): база, запись из браузера, права, тесты.
  Экранов для учителя ещё нет, ученик ничего нового не видит.
- **1б — экраны**: класс, ученик, задача, вариант, выгрузка в Excel и PDF,
  «Моя статистика».

## Что записывается

Пока ученик вошёл в кабинет, по каждой задаче, где бы её ни решали:

| Что | Подробности |
|---|---|
| раздел | номер хранения (`ege_tasks.no`); на экранах — номер ЕГЭ-2027 |
| тип | прототип или тип задачи раздела («8.H», «5:P03», микротип опорной, подтема карточки) |
| задача | id, по которому собирается та же задача с теми же числами: «прототип\|seed\|уровень» (№8), «прототип:вариант» (банк №5), «микротип@seed» (опорные №8) |
| отпечаток условия | `gen_hash`: учитель собирает задачу заново и сверяет; не совпал — показывается сохранённое условие `uslovie_tex` |
| картинка | путь файла сайта у задач банка с рисунком (№5) |
| каждая попытка | ответ как есть (до 40 знаков), верно или нет, номер, время; неверная запись и верное значение дробью — тоже, с пометкой, что попытка не засчитана |
| подсказки | сколько шагов подсказки открыто, на каких шагах была неверная кнопка; «Показать свойство», «Показать решение», «Пропустить» |
| время | активное и общее (ниже) |
| исход | верно, верно с подсказкой, ошибка, открыто решение, пропущено; пусто — задача не закончена |

По вариантам («Собрать вариант», серии, «Варианты повышенной сложности»,
работа от учителя): дата, первичный и тестовый балл, время, и задачи
варианта — ответ ученика, верный ответ, время, подсказки.

### Время

Активное время идёт, только когда вкладка видна и ученик что-то делает:
нажатие, ввод, прокрутка. Промежуток между действиями засчитывается,
если он не длиннее 2 минут. Длиннее — не засчитывается совсем: после
2 минут бездействия таймер стоит. Общее время — от открытия задачи до
закрытия. Учитель увидит активное, общее — во всплывающей подсказке.

### Где подключено

Пробный период — №5 и №8 (номера хранения; на экзамене это задания 5
и 7):

| Раздел | Тренажёр | Опорные | Карточки | Варианты |
|---|---|---|---|---|
| №5 | да | да | да | задачи №5 в варианте |
| №8 | да | да | карточек у №8 нет | задачи №8 в варианте |

Вариант пишется, если в нём есть задача раздела журнала: баллы —
целиком, разбор по задачам — только разделов журнала. №6 вне
ЕГЭ-2027 и в журнал не попадает никогда: это проверяют и сайт, и база.

## Как устроено

| Что | Где |
|---|---|
| Таблицы, запись, чтение, права | `supabase/migrations/20261122120000_zhurnal.sql` |
| Флаги сборки | `app/src/lib/zhurnal/config.ts`, `app/next.config.ts` |
| Запись в браузере | `app/src/lib/zhurnal/model.ts` (чистые функции), `aktivnoe.ts` (таймер), `ochered.ts` (очередь и отправка), `zapis.ts` (хук `useZapisZadachi`), `variant.ts` |
| Подключение в разделах | `Trenazher8Screen.tsx`, `Podgotovka8Screen.tsx`, `Ekran45.tsx`, `Opornye45Blok.tsx`, `Kartochki.tsx`, `WorkRun.tsx` |
| Чтение для экранов (этап 1б) | `app/src/lib/zhurnal/api.ts` |

Таблицы: `zhurnal_zadachi` (строка на задачу), `zhurnal_popytki`
(попытки), `varianty_resheniya` (варианты), `zhurnal_dni` (свёртка по
дням — для тепловой карты, активности и календаря), `kabinet_flags`.

Браузер копит записи в очереди (`localStorage`, ключ
`budetege:zhurnal:ochered:v1:<ученик>`) и отправляет пачками функцией
`zhurnal_push`: через 3 с после изменения, при скрытии вкладки, при
открытии страницы. Без связи записи ждут (до 600). Повтор той же записи
дополняет строку в базе, а не создаёт новую: id записи строится из места
задачи, поэтому и перезагрузка страницы не плодит дублей.

## Кто что видит

| | ученик | учитель | аноним |
|---|---|---|---|
| пишет | только своё, только функцией `zhurnal_push` | нет | нет |
| читает | своё: таблицы и `moya_statistika`, `moya_lenta`, `moy_variant` — без пометок для учителя | только функциями `uchitel_*` и только своих учеников, с дня связи и пока связь действует | нет |

- Учитель не читает таблицы журнала напрямую — даже своих учеников.
- Связь закончилась — записи ученика учителю закрыты. Ученик вернулся —
  связь начинается заново, прежние записи остаются закрытыми (решение В-3).
- Пометка «очень быстро» (решение В-7) есть только в ответах функций
  учителя.
- Школьник до согласия родителя журнал не пишет.

Проверка — `supabase/tests/zhurnal-prava.test.sql` (набор «Журнал и
права доступа» в `pnpm test:kabinet-sql`).

## Срок хранения

Подробные записи — до конца следующего учебного года: решённое в
2026/27 удаляется 1 сентября 2028 (решение В-2). Свёртка по дням
остаётся. Удаляет `zhurnal_svernut()` каждую ночь после копии базы
(`infra/lite/bin/backup.sh`). Удаление аккаунта удаляет всё сразу.

## Как включить

Variables репозитория (**Settings → Secrets and variables → Actions →
Variables**):

| Variable | Значение |
|---|---|
| `NEXT_PUBLIC_ZHURNAL` | `1` — журнал включён (нужен и включённый вход `NEXT_PUBLIC_AUTH_ENABLED=1`) |
| `NEXT_PUBLIC_ZHURNAL_RAZDELY` | номера хранения через запятую; пусто — `5,8` |

Затем две кнопки: **Actions → Сервер: миграции** (новая таблица и флаг
базы) и **Actions → Deploy** (сайт с журналом). Без флага базы сайт
отправляет записи, а база отвечает «журнал выключен» и ничего не
сохраняет. Выключить — поставить `0` и нажать те же кнопки.

Флаги экранов этапа 1б (`NEXT_PUBLIC_PROGRESS_UCHITEL`,
`NEXT_PUBLIC_PROGRESS_UCHENIK`) появятся с экранами.
