# Задание №18 «Планиметрия» — что сделано и что дальше

## Сделано

- Раздел №18 открыт: шапка, лента вкладок как у №16.
- **«О задании»** — на адресе раздела `/zadaniya/18/`: пункты а) и б),
  критерии ФИПИ 0–3 балла, стратегия «застрял в а) — решай б)», зачем
  ключевые схемы, маршрут по вкладкам (`OZadanii18.tsx`, тексты —
  `O_ZADANII_18` в `content/zadanie18.ts`). Прежний адрес
  `/zadaniya/18/o-zadanii/` переадресует на раздел.
- **«Ключевые схемы»** — на своём адресе `/zadaniya/18/skhemy/`, страницы
  схем — `/zadaniya/18/skhemy/<id>/`. 24 схемы в шести группах:
  треугольник, окружность и вписанные углы, касательные, трапеция,
  отношения отрезков, площади. Список — `app/src/content/zadanie18/spisok.ts`.
- У каждой схемы: суть, «Дано», следствия с подсветкой на чертеже,
  доказательство по шагам, «Как узнать», «Где пригождается», запоминалка,
  «Знаю / Не знаю».
- Движок живых схем `app/src/lib/skhemy` (README там же): поворот,
  отражение, случайное положение, пошаговая сборка, перетаскивание,
  подписи без наложений в пикселях экрана; `svg.ts` — тот же чертёж
  неподвижной строкой SVG (для карточек). Переиспользуется для
  «Опорных задач» и «Тренажёра».
- **Карточки — на общем движке** (`lib/kartochki`, вкладка «Карточки»
  стоит в ленте сразу за «Ключевыми схемами»). Колода
  `app/src/content/kartochki/18-klyuchevye-skhemy.ts` собирается из самих
  схем, у каждой две карточки: «Узнай схему по чертежу» (тип «по
  чертежу»: чертёж в случайном положении без букв, на обороте — с
  буквами) и «Вспомни следствия» (тип «свойство»: название и «Дано»).
  Режимы — подтемы колоды, их выбирают в «По подтемам».
  «Повторить теорию» ведёт на страницу схемы.
- Своя реализация (`Kartochki18.tsx`, коробки в `lib/zadanie18/progress.ts`)
  убрана. `lib/zadanie18/progress.ts` теперь — тонкий слой над общим
  прогрессом `budetege:kartochki:18:v1`: статус схемы по двум её карточкам
  (обе во 2-й коробке и выше — «Знаю»), «Знаю / Не знаю» на странице схемы
  оценивает обе карточки, плитки и плашка читают те же коробки.
- Кнопки вводной плашки «Учить схемы» (на сегодня) и «Только незнакомые»
  открывают вкладку «Карточки» сразу с сессией: `kartochki/?nabor=segodnya`
  и `?nabor=neznakomye`. Для этого общий движок научился режиму «На
  сегодня» (время оценки в записи, повтор через 0, 1, 3, 7, 14 дней) —
  обобщённо, для любой колоды; в списке режимов он не показывается.
- Старый прогресс (`budetege:planimetriya-18:skhemy:v1`, коробка на схему)
  переносится один раз на любой странице №18 (`Perenos18.tsx`): коробка
  и время ответа схемы — в обе её карточки, если у карточки нет своей
  записи; старый ключ удаляется.
- Подписи в тесноте — с выноской (`lib/skhemy/podpisi.ts`, как в движке
  №1): если рядом с точкой нет чистого места, буква отходит на 28–48 px и
  соединяется с точкой тонкой линией; выноска не задевает чужие буквы и
  точки. В прогоне `pnpm test:skhemy-18` тесных подписей стало 5 вместо 168.
- **«Опорные задачи»** — `/zadaniya/18/opornye-zadachi/`, страницы задач —
  `/zadaniya/18/opornye-zadachi/<id>/`. 16 задач, составленных для сайта в
  формате №18 (а) докажите, б) найдите), по темам ключевых схем — по 2–3 на
  тему. Тексты — `app/src/content/zadanie18/opornye/`, чертежи —
  `app/src/lib/zadanie18/opornye/` (те же живые сцены движка `lib/skhemy`:
  исходное положение — данные пункта б), «Случайное положение» — любая
  фигура из условия, у части задач вершины тянутся). На странице: условие,
  «Какие схемы здесь» со ссылками на страницы схем, решения а) и б) по
  шагам (открываются по одному, открытый шаг подсвечивает чертёж), ответ.
  Плитки вкладки — с мини-чертежами. `ZhivoyChertezh18` и `MiniChertezh18`
  принимают свою сцену (`skhema`) вместо схемы из реестра.
- Проверка опорных задач: `pnpm test:opornye-18`
  (`app/scripts/verify_opornye18/`) — ответ б) из TeX против ответа,
  вычисленного по данным заново в координатах (без кода сайта; где ответ не
  должен зависеть от формы — на нескольких формах), исходное положение
  чертежа = данные б), утверждение а) на 1000 своих случайных фигурах и на
  1000 случайных положениях чертежа, экран при подсветке каждого шага,
  группы подсветки шагов есть на чертеже, ссылки на схемы — на собранные.
- **«Тренажёр»** — `/zadaniya/18/trenazher/`, на общей оболочке сессии
  (`TrainerSessionHost`, раздел `18`): выбор темы схем, уровня (разминка /
  уровень ЕГЭ / повышенный) и числа задач (5, 10, все), панель с паузой,
  сохранение в браузере, итоги с «Прорешать ошибки» и «Похожие задачи»
  (другая задача той же темы). Банк — 24 задачи, составленные для сайта (не
  повторяют опорные), по 4 на тему: тексты — `app/src/content/zadanie18/trenazher/`,
  чертежи — `app/src/lib/zadanie18/trenazher/` (живые сцены движка, как у
  опорных: исходное положение — данные б), «Случайное положение» — другая
  фигура условия). Ответ б) проверяется автоматически
  (`lib/zadanie18/otvet.ts` поверх общего разбора чисел `chislo16`: 2√3,
  2sqrt3, 4/3, 1,5, \dfrac…); пункт а) — самопроверка: «Показать
  доказательство» открывает шаги (нажатый шаг подсвечивает чертёж), ученик
  отмечает «Доказал / Не доказал», в итогах — сколько «Доказал». Подсказка —
  наводящая мысль и «Какие схемы здесь» со ссылками на страницы схем;
  решение б) — по шагам после ответа (открытое до верного ответа — задача
  «с открытым решением», как у №19). В каталог кабинета задачи не попадают:
  у второй части (№15, №16, №19) банка прототипов для ДЗ нет
  (`scripts/build-kabinet-catalog.mjs`).
- Проверка тренажёра: `pnpm test:trenazher-18` (`app/scripts/verify_trenazher18/`)
  — ответ б) из TeX против ответа, вычисленного по данным заново в
  координатах без кода сайта (где ответ не должен зависеть от формы — на
  нескольких формах; где данные задают фигуру неявно — подбором параметра),
  поле ответа принимает равносильные записи ответа и не принимает соседние
  числа, исходное положение чертежа = данные б), утверждение а) на 1000 своих
  случайных фигурах и на 1000 случайных положениях чертежа, экран при
  подсветке каждого шага, группы подсветки есть на чертеже, ссылки на схемы
  — на собранные; по банку — 24 задачи, по 4 на тему, в каждой теме все три
  уровня, нет совпадений с опорными. Сохранение тренировки — в
  `pnpm test:trainer-sessions` (№18 в списке тренажёров).
- Проверки: `pnpm test:skhemy-18` — каждое следствие и шаг доказательства
  на 1000 случайных конфигурациях, экранная раскладка, согласованность
  текстов с чертежами, у каждой схемы две карточки в колоде, статусы схем;
  `pnpm test:kartochki` — колода №18 (формулы, чертежи, адреса страниц
  схем) и режим «На сегодня».
