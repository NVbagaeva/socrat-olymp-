# Задание №18 «Планиметрия» — что сделано и что дальше

## Сделано

- Раздел №18 открыт: шапка, лента вкладок как у №16. Наполнена вкладка
  «Ключевые схемы» (адрес раздела), остальные — заглушки «Раздел в разработке».
- 24 ключевые схемы в шести группах: треугольник, окружность и вписанные
  углы, касательные, трапеция, отношения отрезков, площади.
  Список — `app/src/content/zadanie18/spisok.ts`.
- У каждой схемы: суть, «Дано», следствия с подсветкой на чертеже,
  доказательство по шагам, «Как узнать», «Где пригождается», запоминалка,
  «Знаю / Не знаю».
- Движок живых схем `app/src/lib/skhemy` (README там же): поворот,
  отражение, случайное положение, пошаговая сборка, перетаскивание,
  подписи без наложений в пикселях экрана. Переиспользуется для
  «Опорных задач» и «Тренажёра».
- Карточки: два режима, переворот, свайп, коробки Лейтнера с повтором
  через 0, 1, 3, 7, 14 дней, итог сессии, «Повторить только незнакомые»,
  запуск «на сегодня» и «только незнакомые» из вводной плашки.
- Проверка: `pnpm test:skhemy-18` — каждое следствие и шаг доказательства
  на 1000 случайных конфигурациях, экранная раскладка, согласованность
  текстов с чертежами, механика коробок.
