# Задание №9 «Производная и первообразная»

Раздел собран по тем же правилам, что №2 и №8 (`docs/razdel-pravila.md`):
шесть вкладок — о задании, теория, опорные задачи, тренажёр, генератор,
для репетиторов. Маршруты — `app/src/app/zadaniya/9/`.

## Где что лежит

| Путь | Что это |
|---|---|
| `app/src/lib/proizvodnaya/spline.ts` | кубический эрмитов сплайн C¹ по узлам на целой сетке (монотонная интерполяция) |
| `app/src/lib/proizvodnaya/krivye.ts` | заготовки рисунков: волна для графика f / F и для графика f′, окно, касательная |
| `app/src/lib/proizvodnaya/render.ts` | движок: рисунок в трёх режимах — `student` (лист ученика), `hint` (подсказка), `teacher` (лист учителя) |
| `app/src/lib/proizvodnaya/reshit.ts` | независимый пересчёт ответа по узлам рисунка и запросу + проверка читаемости |
| `app/src/lib/proizvodnaya/prototypes/` | 31 прототип: 9.1.1 … 9.5.6 (реестр — `index.ts`) |
| `app/src/lib/proizvodnaya/prep/` | опорные задачи: 6 блоков по 10 микрозадач |
| `app/src/lib/proizvodnaya/bank.ts` | банк: 10 вариантов (seed) на прототип; пишет только `pnpm build:bank-9` |
| `content-source/proizvodnaya/` | исходник открытого банка ФИПИ (пока пустой) и инструкция, как его пополнять |

## Источник задачи

У каждого прототипа поле `istochnik`: `'otkrytyj-bank'` или
`'ne-iz-otkrytogo-banka'`. Все собственные прототипы помечены вторым.
Задачи открытого банка добавляются вручную через
`content-source/proizvodnaya/otkrytyj-bank.json` (см. README рядом) и
`pnpm build:bank-9-open`; тренажёр переключает источник «только открытый
банк» / «только сгенерированные».

## Автотесты

```bash
cd app
pnpm test:proizvodnaya [seeds]   # движок, генераторы, банк, опорные задачи
pnpm test:komplekty              # листы ученика и учителя из одного набора
pnpm test:secrets                # после pnpm build: ответов нет в бандле
pnpm test:math-markup --src      # вся математика только в KaTeX (и --site после сборки)
```

`test:proizvodnaya` для каждого сгенерированного задания заново считает
ответ по узлам рисунка (выборка знаков производной, пересечения оси,
интеграл) и сравнивает с ответом, заложенным в прототип; проверяет
читаемость (нули и экстремумы в целых узлах, пересечение оси поперёк,
отмеченные точки не на нулях, подписи не пересекаются, на рисунке ученика
нет построений), строгую сборку формул KaTeX, подсказки с кнопками.
