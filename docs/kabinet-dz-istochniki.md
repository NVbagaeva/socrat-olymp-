# Домашнее задание из трёх источников

ДЗ собирается из любой смеси карточек, опорных задач и задач тренажёра,
из разных разделов. Пилот — №7 и №8. Этот документ дополняет
`docs/kabinet-dz-8.md` (классы, код класса, ключ и проверка ответа в
базе — без изменений). Миграция — `supabase/migrations/20261113130000_dz_istochniki.sql`.

## Решения владельца (13.11.2026)

| Вопрос | Решение |
|---|---|
| Пилот | №8 + №7 |
| Карточки с проверкой («верно / неверно», «вычисление») | проверяет база, ученик не видит ответ до своего ответа; **одна попытка**, оборот — сразу после ответа |
| Карточки «Знаю / Не знаю» | самооценка без проверки; отметка («Знаю» / «Повторить») — в базе, видна репетитору |
| Набор карточек в пределе 60 | один пункт |
| Опорные в ДЗ | аналог с новым зерном (№8), фиксируется при выдаче; где зерна нет (№6, 7, 10) — сама задача; «Ещё вариант» в ДЗ нет |
| Экран задачи | общий экран тренажёра (`components/tasks/trening/EkranZadachi`) |
| «Без подсказок» | выключает всё: пошаговые подсказки, «Запомни», пример; разбор после ответа — по «когда показывать решения» |
| Счётчик времени | задача тренажёра 3 мин, опорная 2 мин, карточка 20 с — `app/src/lib/dz/vremya.ts` |
| Черновик | в базе, виден с телефона и компьютера |
| Шаблоны | только свои; хранят правила (задачи тренажёра при каждой выдаче — новые) |
| «Каждому свои аналоги» | переключатель у каждого пункта (тренажёр, опорные с зерном) |
| Работа над ошибками | тренажёр — аналоги; опорные — аналог (№8) или та же задача (№7); карточки — с ошибкой и «Повторить»; каждому — его |
| После срока | **только просмотр**: ни ответа, ни отметки, ни сдачи; решения открываются, как после сдачи (прежде ответ после срока принимался) |
| Старый экран выдачи | заменён конструктором по тому же адресу `/kabinet/dz-vydat/`; прежние ссылки из №8 работают |

## Модель

```
homework ─┬─ homework_parts (пункт: источник, раздел, ref, правило с зерном, «каждому свои», комментарий)
          │      └─ homework_tasks (единица: задача или карточка; part_id, answer_kind, view)
          │             ├─ homework_keys (ответ, разбор; у самооценки — нет)
          │             └─ homework_answers (ход решения; state known/repeat — отметки)
          ├─ homework_recipients
homework_drafts (user_id) — черновик репетитора
homework_templates (id, user_id) — шаблоны
```

- **Пункт** — то, что репетитор положил в ДЗ: набор карточек (весь или
  выбранные), блок опорных (весь или выбранные задачи), правило тренажёра
  «типы × сколько» или конкретная задача.
- **Единица** — то, на что отвечает ученик. У набора карточек их
  несколько, у правила — по количеству, у задачи — одна.
- **Снимок.** Условие, подсказки и всё видимое ученику — в
  `homework_tasks.question_html` и `view`; ответ и разбор — в
  `homework_keys`. Изменили или удалили задачу в банке — у выданного ДЗ
  всё остаётся. Ученик, лист ученика и лист учителя берут одни строки.
- **Зерно** ставится при выдаче (`lib/dz/sborka`), одно на выдачу, и
  пишется в `homework_parts.rule`.

### Виды ответа (`homework_tasks.answer_kind`)

| Вид | Где | Ключ | Проверка |
|---|---|---|---|
| `number` | задачи, карточка «вычисление» | нормальная запись ЕГЭ | `check_ege_answer` |
| `choice` | опорные №8 «плюс / минус» | номер варианта | точное совпадение, дробь — формат |
| `verno` | карточка «верно / неверно» | `da` / `net` | `da` / `net`, иначе формат |
| `self` | карточки «формула / свойство / чертёж» | нет | `homework_mark(task, known | repeat)` |

### Функции

| Функция | Кто | Что |
|---|---|---|
| `issue_homework_parts(p)` | репетитор | ДЗ из пунктов одной транзакцией; предел 60 на ученика (набор карточек — один); «Без подсказок» и выключенные «Запомни» / пример вырезаются из `view` |
| `issue_homework_tasks(p)` | репетитор | прежняя выдача этапа 3: та же, каждая позиция — пункт тренажёра |
| `check_ege_answer(ввод, ответ)` | функции | проверка числа и дроби — одна с сайтом и заглушкой |
| `homework_check` | ученик | как прежде + виды ответа; у карточки одна попытка и оборот сразу |
| `homework_mark` | ученик | отметка самооценки |
| `homework_reveal`, `homework_solution` | как прежде | у карточек — нет «Показать решение»; оборот после ответа |
| `submit_homework` | ученик | до срока |

Ученики репетитора решают выданное ДЗ бесплатно при любом тарифе:
функции проверяют только «получатель ли».

индивидуального — общий для позиции k у всех учеников), задачи, ключи,

## Разделы

Каталог раздела для конструктора — `/kabinet/dz-vydat/dannye/zNN.json`
(`lib/dz/katalog/server.ts`, `RAZDELY_DZ`), сборщик — `lib/dz/sborka/rNN.ts`.
Подключить раздел: каталог, сборщик, номер в `RAZDELY_DZ` и
`RAZDELY_DZ_KLIENT`, кнопки «В домашнее задание» на страницах раздела.

Каталог раздела — два файла: `zNN.json` — для просмотра в конструкторе
(карточки, блоки опорных, типы тренажёра) без ответов, разборов и
подсказок опорных; `zNN-r.json` — закрытые ответы, разборы и подсказки
опорных (ключ «блок:id»), конструктор качает его только при выдаче и
при работе над ошибками (`zagruzitDlyaVydachi`). С набранными формулами
это бо́льшая часть веса: у №3 — ≈2,4 МБ из 4,5.

`lib/dz/sborka/spisok.ts` (№3, №4, №5).
