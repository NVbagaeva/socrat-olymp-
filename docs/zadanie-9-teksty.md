## 2. «Где теряют балл» — свой текст у каждого типа

Показывается под разобранным примером типа на «О задании». Названия групп и типов — прежние.

### I. Физический смысл производной (значок $v=x'$)

| Тип | Где теряют балл |
|---|---|
| Скорость в заданный момент по закону движения | Подставляют момент времени в сам закон движения $x(t)$. Скорость — производная: сначала найди $v(t)=x'(t)$, потом подставляй. |
| Момент времени, когда скорость равна заданной | Приравнивают заданной скорости сам закон $x(t)$, а нужно $v(t)=x'(t)$. И забывают отбросить отрицательный корень: время $t\geqslant 0$. |

### II. Касательная (значок $k=\operatorname{tg}\alpha$)

| Тип | Где теряют балл |
|---|---|
| Значение производной по графику функции и касательной | Делят горизонтальный катет на вертикальный или теряют минус. Вертикальный катет — в числителе; касательная идёт вниз — ставь минус. |
| Касательная параллельна оси абсцисс: точка отрезка по графику производной | Берут нуль $f'$ вне отрезка. Касательная горизонтальна там, где $f'(x)=0$: из нулей графика производной бери только те, что лежат на отрезке. |
| Касательная параллельна прямой: абсцисса по графику производной | Ищут пересечение графика $f'$ с самой прямой $y=kx+m$, а нужна горизонталь $y=k$: у параллельных прямых равны угловые коэффициенты, число $m$ не важно. |
| Касательная параллельна прямой: количество точек по графику производной | Проводят прямую $y=kx+m$ вместо горизонтали $y=k$ или пропускают точку пересечения. Считай все пересечения графика $f'$ с прямой $y=k$ на интервале. |
| В какой отмеченной точке производная наибольшая | Выбирают самую высокую точку графика, а не самый крутой подъём. Производная — это наклон касательной, а не высота графика. |
| В какой отмеченной точке производная наименьшая | Выбирают самую низкую точку графика. Наименьшая производная — у самого крутого спуска, а не у точки на дне. |
| Параметр: при каком $c$ прямая является касательной | Проверяют только равенство наклонов $f'(x_0)=k$. Нужна ещё общая точка: $f(x_0)=kx_0+m$ — из этого равенства и находится $c$. |

### III. Исследование по графику функции (значок $f$)

| Тип | Где теряют балл |
|---|---|
| Сколько отмеченных точек, в которых производная положительна | Смотрят, выше ли точка графика оси $Ox$. Знак $f'$ — это направление графика: идёт вверх — $f'>0$, вниз — $f'<0$. |
| Сколько отмеченных точек, в которых производная отрицательна | Путают знак функции и знак производной: «ниже оси» — это $f(x)<0$, а $f'(x)<0$ там, где график идёт вниз. |
| Количество целых точек интервала, в которых производная положительна | Засчитывают вершины «горок» и «ямок»: в них $f'=0$, производная там не положительна. И берут выколотые концы интервала. |
| Количество целых точек интервала, в которых производная отрицательна | Вершины, где $f'=0$, и концы интервала в счёт не идут. Считай целые точки строго внутри промежутков, где график идёт вниз. |
| Количество точек, в которых производная равна нулю | Считают точки, где график пересекает ось $Ox$, — это нули самой функции. $f'(x)=0$ там, где касательная горизонтальна: на вершинах «горок» и «ямок». |
| Точка отрезка, в которой производная равна нулю | Отвечают точкой пересечения графика с осью $Ox$, а нужна вершина графика на отрезке: там касательная горизонтальна. |

### IV. Исследование по графику производной (значок $f'$)

| Тип | Где теряют балл |
|---|---|
| Сколько отмеченных точек принадлежит промежуткам возрастания функции | Читают график $f'$ как график функции и смотрят, растёт ли он. Функция $f$ возрастает там, где график $f'$ выше оси $Ox$. |
| Сколько отмеченных точек принадлежит промежуткам убывания функции | Функция $f$ убывает там, где график $f'$ ниже оси $Ox$, а не там, где сам график $f'$ идёт вниз. |
| Точка максимума функции по графику производной | Ищут вершину графика $f'$. Точка максимума $f$ — нуль $f'$, где знак меняется с $+$ на $-$: график $f'$ пересекает ось сверху вниз. |
| Точка минимума функции по графику производной | Путают направление смены знака. Для минимума $f'$ меняется с $-$ на $+$: график $f'$ пересекает ось снизу вверх. |
| Количество точек максимума на отрезке по графику производной | Считают нули вне отрезка или со сменой знака не в ту сторону. Точка максимума — переход $f'$ с $+$ на $-$, и только на отрезке. |
| Количество точек минимума на отрезке по графику производной | Точка минимума — переход $f'$ с $-$ на $+$. Сначала вычеркни нули вне отрезка, потом отбирай нужные. |
| Количество точек экстремума на отрезке по графику производной | Считают касание оси без смены знака — это не экстремум. Экстремум — нуль $f'$, где знак меняется, и только на отрезке. |
| Точка экстремума на отрезке по графику производной | Берут нуль $f'$ вне отрезка или касание оси без смены знака. В ответ пиши абсциссу точки, а не значение функции. |
| В какой точке отрезка функция принимает наибольшее значение | Ищут самую высокую точку графика $f'$. По знаку $f'$ пойми, как ведёт себя $f$: возрастает — наибольшее значение на правом конце, убывает — на левом, возрастание сменяется убыванием — в точке максимума. |
| В какой точке отрезка функция принимает наименьшее значение | Самая низкая точка графика $f'$ здесь ни при чём. Возрастает $f$ — наименьшее значение на левом конце, убывает — на правом, убывание сменяется возрастанием — в точке минимума. |

### V. Первообразная (значок $F'=f$)

| Тип | Где теряют балл |
|---|---|
| Знак функции $f$ в отмеченных точках по графику первообразной $F$ | Смотрят на высоту графика $F$. Знак $f$ определяется наклоном $F$: там, где $F$ возрастает, $f(x)>0$. |
| Знак функции $f$ в отмеченных точках по графику первообразной $F$ (отрицательна) | $f(x)<0$ там, где $F$ убывает, — а не там, где график $F$ лежит ниже оси. |
| Число решений уравнения $f(x)=0$ на отрезке по графику первообразной | Считают точки, где график $F$ пересекает ось. $f(x)=F'(x)=0$ в вершинах графика $F$ — бери только вершины на отрезке. |
| Приращение первообразной $F(b)-F(a)$ по графику-ломаной функции $f$ | Теряют знак у фигуры под осью или ошибаются в клетках. $F(b)-F(a)$ — площадь со знаком: над осью «+», под осью «−». |
| Площадь фигуры под параболой по первообразной: одна граница по рисунку | Вычитают в обратном порядке или берут не ту границу. Площадь — $F(b)-F(a)$: правая граница минус левая; границу, которой нет в условии, читай по рисунку. |
| Площадь фигуры между параболой и осью по первообразной: обе границы по рисунку | Фигура под осью: разность $F(\beta)-F(\alpha)$ отрицательна, а площадь — нет. Не забудь сменить знак. |

## 3. «Что нужно знать»

Правило и маленький пример к нему. Примеры взяты из разобранных задач типов, проверьте числа.

### Производная и касательная

| Правило | Пример |
|---|---|
| $f'(x_0)=k=\operatorname{tg}\alpha$ | катеты $2$ и $10$, касательная идёт вниз: $k=-\dfrac{2}{10}=-0{,}2$ |
| $\text{касательная}\parallel y=kx+m\ \Leftrightarrow\ f'(x_0)=k$ | прямая $y=2x-2$: ищем точки, где $f'(x)=2$ |

### Знак производной

| Правило | Пример |
|---|---|
| $f'(x)>0\ \Rightarrow\ f\ \text{возрастает}$ | около $x_2$ график идёт вверх — значит, $f'(x_2)>0$ |
| $f'(x)<0\ \Rightarrow\ f\ \text{убывает}$ | на графике $f'$ ниже оси на $(-4;\ 2)$ — там $f$ убывает |

### Экстремумы

| Правило | Пример |
|---|---|
| $f':\ +\to-\ \Rightarrow\ x_{\max}$ | при $x=-4$ знак $f'$ меняется с $+$ на $-$: $x=-4$ — точка максимума |
| $f':\ -\to+\ \Rightarrow\ x_{\min}$ | при $x=0$ знак $f'$ меняется с $-$ на $+$: $x=0$ — точка минимума |

### Физический смысл

| Правило | Пример |
|---|---|
| $v(t)=x'(t)$ | $x(t)=\tfrac12t^2+4t$: $v(t)=t+4$, $v(1)=5$ |
| $(x^n)'=nx^{n-1}$ | $(t^3)'=3t^2$, $(4t)'=4$, $(c)'=0$ |

### Первообразная

| Правило | Пример |
|---|---|
| $F'(x)=f(x)$ | $F$ возрастает на $(1;\ 8)$ — значит, там $f(x)>0$ |
| $F(b)-F(a)=S_{\text{над осью}}-S_{\text{под осью}}$ | площадь над осью $15$, под осью $4$: $F(b)-F(a)=15-4=11$ |
