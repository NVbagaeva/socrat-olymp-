# Аудит: «найдите x, при котором f(x) = …» — читается ли ответ с рисунка

Правило: если ищут x по значению функции, ответ **нельзя** прочитать с рисунка. Искомая точка либо внутри рисунка, но x нецелый, либо за рамкой (не ближе клетки — `lib/graph/hidden.js`).

Ничего не исправлялось, кроме примера 8.2 теории линейной функции (эта работа). Отчёт воспроизводится: `node scripts/audit-find-x.mjs 500`.

## 3. Что нашёл

1. **Ответ в узле сетки не читается нигде** — во всех генераторах 0 из 53 000 задач (после того как в этом PR исправлен пример 8.2).
2. **Гипербола: у 11,3 % задач точка видна на вертикали сетки.** x целый, y — десятичный (например x = 6, y = −3,5; x = −6, y = −0,5): точка не в узле, но между горизонталями, и x читается по вертикальной линии. По правилу «x нецелый» это нарушение; по буквальному «узел сетки» — нет. Решение за автором: запретить целый x при видимой точке у наборов 12R.B, 12R.D, 12R.I и P12R-8.
3. **«Почти за рамкой».** У 0,5–2,5 % задач параболы, гиперболы и корня точка вынесена за рамку меньше чем на клетку (у линейной — 0). Под правило невидимой точки с запасом в клетку (`hidden.js`) это не подходит. Больше всего у корня (2,4 %).
4. Миниатюры и подсказки нарушений не содержат.
