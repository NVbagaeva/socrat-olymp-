# Этап 2, предварительно: таблица title и description до применения

Документ к согласованию. В код ничего не внесено: правила ниже лягут
в одну функцию метаданных раздела (`title`, `description`, `canonical`,
Open Graph) после вашего «да». Длины указаны в символах; цель —
title до ~70 (допускаю до 75 для длинных названий), description
до ~160. Строки с ⚠ длиннее 75 — подрежу при утверждении, если
скажете, что лимит жёсткий.

## Правила шаблонов

| Страница | Title | Description |
|---|---|---|
| Раздел (`/zadaniya/N/`) | `Задание N ЕГЭ профиль 2027: {тема} — теория, прототипы, тренажёр` | лид раздела + «Теория, опорные задачи с решениями, тренажёр и генератор вариантов — бесплатно.» |
| Теория | `Задание N ЕГЭ профиль: {тема} — теория и формулы` | что внутри: определения, формулы, ошибки, разборы |
| Опорные задачи | `Задание N ЕГЭ профиль: {тема} — опорные задачи с решениями` | каждый тип с решением и ответом |
| Тренажёр | `Тренажёр задания N ЕГЭ: {тема} — задачи с ответами онлайн` | ответы, подсказки, новые числа, прогресс |
| Генератор | `Генератор задания N ЕГЭ: {тема} — варианты с ответами` | домашняя/самостоятельная из прототипов ФИПИ, печать |
| Для репетиторов | `Задание N ЕГЭ: {тема} — банк задач для репетитора` | прототипы с аналогами, листы с ответами |
| Карточки | `Задание N ЕГЭ: {тема} — карточки для повторения теории` | «знаю / не знаю», интервальное повторение |
| Блок опорных задач `/opornye-zadachi/{блок}/` | `{Название блока} — задание N ЕГЭ профиль, опорная задача с решением` | первое предложение условия (до 150 символов) + «Решение по шагам и ответ.» |
| Разбор `/razbor/{id}/` | `{Название прототипа} — разбор задания N ЕГЭ профиль` | «Разобранный пример задания N: {первое предложение условия}. Решение и ответ.» |

| Схема №18 `/skhemy/{схема}/` | `{Название схемы} — ключевая схема планиметрии, задание 18 ЕГЭ` | что увидеть на чертеже и какую теорему применить |
| Печатные листы, кабинет, режимы тренажёров | без изменений, `noindex` | — |

«2027» стоит только в title разделов и в главной. Если решите писать без
года (вопрос 4 аудита) — убирается одной правкой шаблона.

**H1.** Один на странице, остаётся названием раздела, но получает номер:
«Задание 13. Экономическая задача» (сейчас — «Финансовая грамотность и
экономические задачи» без номера). Визуально это тот же заголовок
шапки; строка берётся из `content/tasks.ts`. У подразделов №12 H1
становится названием функции на всех семи страницах (сейчас у шести —
общий «Задание №12. Графики функций»).

**Короткие темы для title** (длинные официальные названия остаются в H1
и в тексте): 1 планиметрия · 2 векторы · 3 стереометрия · 4 теория
вероятностей · 5 сложная вероятность · 6 случайные величины ·
7 уравнения · 8 вычисления · 9 производная · 10 физический смысл ·
11 текстовые задачи · 12 графики функций · 13 экономическая задача ·

## Что ещё войдёт в этап 2 (для сверки с заданием)

1. `app/public/robots.txt`: `Disallow` для `/styleguide/`, `/kabinet/`,
   `/voyti/`, `/*/pechat/`, `/*/index.txt$`, `/*?*` (параметры
   генераторов: `?seed=`, `?kit=`, `?nabor=`); `Sitemap:` и, по выбору
   зеркала, `Host` не нужен (Яндекс его больше не читает — зеркало
   задаётся редиректом и в Вебмастере).
2. `sitemap.xml` генерируется скриптом после `next build` из списка
   страниц сборки без `noindex`; `lastmod` — дата последнего коммита,
   затронувшего исходники страницы (git log), а не дата сборки.
3. `metadataBase = https://budetege.ru`, `alternates.canonical` на
   каждой странице (с учётом слеша), 301 `www → без www` и
   `/index.html → /` в `.htaccess`.
4. JSON-LD: `BreadcrumbList` в компоненте крошек; `Person` + `Organization`
   (`/about/`, подвал); `LearningResource` на разделах (name, about,
   educationalLevel «10–11 класс», teaches, isAccessibleForFree,
   inLanguage ru); `FAQPage` — только где есть реальные вопросы-ответы в
   тексте; `Quiz` — на тренажёрах после появления статических примеров.
   Проверка: валидатор Schema.org и Яндекс.Вебмастер «Проверка
   микроразметки» — результаты приложу к PR.
5. Open Graph и Twitter: `og:title`, `og:description`, `og:url`,
   `og:type`, `og:site_name`, `og:locale ru_RU`, `og:image` 1200×630 —
   картинка на раздел генерируется на сборке (`satori` + `sharp`, шрифт
   Inter из `src/fonts`, иконка раздела из `public/images`, фон по
   токенам дизайн-системы). Покажу 2–3 образца до массовой генерации.
6. IndexNow: шаг деплоя сравнивает новый `sitemap.xml` с опубликованным
   и шлёт изменённые адреса в `https://yandex.com/indexnow`. Ключ —
   секрет `INDEXNOW_KEY` в GitHub Actions; файл ключа `/<key>.txt`
   генерируется на сборке. Инструкция — в PR.
7. 404: своя страница в стиле сайта со ссылками на разделы, подключение
   `ErrorDocument 404 /404.html` в `.htaccess`; проверка битых ссылок в
   `check.yml` (обход `app/out` по HTML-ссылкам, падение при 404).
8. Переменные `NEXT_PUBLIC_YANDEX_VERIFICATION`,
   `NEXT_PUBLIC_GOOGLE_VERIFICATION`, `NEXT_PUBLIC_METRIKA_ID`; счётчик
   через `next/script` со стратегией `lazyOnload`; цели `reachGoal`:
   `trenazher_start`, `variant_build`, `blank_download`.
