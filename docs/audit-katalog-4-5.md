## 6. План новых сюжетов

Общие ограничения для каждого сюжета:

- ответ в (0; 1), без 0 и 1; для 5-11а — отношение > 1;
- ответ — конечная дробь не длиннее 4 знаков, иначе в условии явно «округлите до сотых», и ответ после округления тоже не 0 и не 1;
- все счётные величины целые;
- нет повторов параметров в прототипе;
- независимость и несовместность сказаны в условии словами.

Каждый сюжет получает:

- `dopustimo`;
- второй счёт (`perebor`) перебором исходов или количествами из 1000 / 10 000;
- шаги разбора с названием этапа.

Шаги подсказок — вопросы с 2–4 кнопками-ответами; ниже «В:» — вопрос, «О:» — верная кнопка. Числа в примерах проверены скриптом.

### №4

**N4-B «Конверты с купонами: что осталось»** — 4-B → «Классическая»

- **Параметры:** a купонов по 2 балла, b по 5, c по 10 (2…12 каждого); сумма S; порог X = S − t, где t — между номиналами.
- **Условие:** «Наугад вынимают один конверт. Найдите вероятность, что сумма баллов в оставшихся конвертах меньше X».
- **Правило:** вынутый номинал > t; m — число таких конвертов. Допустимых наборов 716.
- **Ограничения:** m/n конечная.
- **Пример:** 5 / 9 / 6, S = 115, X = 108 ⇒ вынут 10-балльный, P = 6/20 = **0,3**.
- **Подсказка:**
  - В: «Когда в оставшихся меньше 108?» — О: «если вынули конверт больше чем на 7 баллов».
  - В: «Какие это конверты?» — О: «по 10».
  - В: «Сколько их из 20?» — О: «6».
  - Формат: «0,3».
- **Иллюстрация:** не нужна (или общая картинка «конверты»).

**N4-C «Одна кость»** — 4-C → «Кубики»

- **События:** чётное / нечётное / простое (m = 3), «не больше k» / «больше k» / «кратно 3» (m ≠ 3).
- **Ограничения:** при m ≠ 3 в условии «округлите до сотых».
- **Примеры:** «простое» → **0,5**; «не больше 4» → 4/6 ≈ **0,67**.
- **Подсказка:**
  - В: «Сколько исходов?» — О: «6».
  - В: «Какие грани подходят?» — О: кнопки с наборами граней.
  - Формат: «нужно округлить? до сотых».
- **Иллюстрация:** не нужна.

**N4-D «Известно, что…»** — 4-D → «Кубики»

- **(1) Две кости, сумма s.**
  - Допустимые s ∈ {3, 5, 6, 8, 9, 11}: исходов 2, 4, 5, 5, 4, 2 — знаменатель конечный.
  - Вопросы: «хотя бы на одной выпало r», «на первой больше, чем на второй».
  - Пример: s = 6, «хотя бы на одной 2» ⇒ 2/5 = **0,4**.
- **(2) Три броска, сумма s.**
  - Допустимые s ∈ {6, 9, 12, 15}: исходов 10, 25, 25, 10.
  - Пример: s = 6, «хотя бы раз выпала 1» ⇒ 9/10 = **0,9**; «все разные» ⇒ **0,6**.
- **(3) «Выпало одинаковое число»:** n = 6. Пример: «сумма больше 7» ⇒ **0,5**.
- **Подсказка:**
  - В: «Какие исходы остаются после слов “известно, что”?» — О: список пар.
  - В: «Сколько их?» — О: «5».
  - В: «Сколько из них подходят?» — О: «2».
- **Иллюстрация:** таблица 6×6 с закрашенной диагональю суммы (существующий рисунок `outcome-table`).

**N4-G «Частота против вероятности»** — 4-G → статистическое / «Противоположные»

- **Параметры:** вероятность p (0,01…0,29, два знака) события «ручка пишет плохо»; проверили N (20…200, шаг 5), плохих k.
- **Режим «дана противоположная»:** в условии вероятность «пишет хорошо» = 1 − p.
- **Вопрос:** «На сколько частота события отличается от его вероятности?»
- **Ограничения:** k/N конечная; разность > 0, не длиннее 4 знаков. Допустимых троек 4972.
- **Пример:** p = 0,05, N = 40, k = 3 ⇒ 0,075 − 0,05 = **0,025**.
- **Подсказка:**
  - В: «Что такое частота?» — О: «k/N».
  - В: «Чему равна вероятность того же события?» — в режиме «противоположная» О: «1 − 0,95».
  - В: «Что вычесть из чего?» — О: «из большего меньшее».

**N4-H «Допуск по размеру»** — 4-H → «Противоположные»

- **Параметры:** номинал (диаметр 20…80 мм, масса 200…1000 г), допуск d (0,01…5); P(«отличается не больше чем на d») = q (0,80…0,99).
- **Вопрос:** «меньше номинал − d или больше номинал + d».
- **Ограничения:** q ∉ {0, 1}.
- **Пример:** q = 0,93 ⇒ **0,07**.
- **Подсказка:**
  - В: «“Меньше 495 или больше 505” — это…» — О: «отличается больше чем на 5».
  - В: «Как связано с данным событием?» — О: «противоположное».
- **Иллюстрация:** числовая прямая (переиспользуемый компонент) с полосой допуска.

**N4-I «Число из промежутка»** — 4-I → «Классическая»

- **Параметры:** промежуток [a; b] (двузначные, от 1 до N, трёхзначные); признак: делится на d, оканчивается на c.
- **Ограничения:** m/n конечная. Например, двузначные «делится на 9» = 1/9 — отбрасывается.
- **Примеры:** двузначное «делится на 5» ⇒ **0,2**; «оканчивается на 7» ⇒ **0,1**; от 1 до 40 «делится на 6» ⇒ **0,15**.
- **Подсказка:**
  - В: «Сколько двузначных чисел?» — О: «90».
  - В: «Сколько из них делится на 5?» — О: «18».

**N4-J «Код замка» (необяз.)** — 4-J → «Классическая»

- Код из k цифр (k = 2…4) или из k цифр без повторов; угадать с первой попытки.
- **Пример:** 3 цифры ⇒ **0,001**.
- **Ограничения:** только варианты с конечной дробью; «без повторов» при k = 3 даёт 1/720 — только с округлением, поэтому в генератор не включать.

### №5

**N5-03б «Три промежутка»** — 5-3(б)

- **Сюжет:** время ожидания, масса, рост.
- **Параметры:** p₁ = P(меньше a), p₂ = P(больше b), по 0,05…0,45, два знака, p₁ + p₂ < 0,95.
- **Ответ:** 1 − p₁ − p₂.
- **Пример:** 0,23 и 0,12 ⇒ **0,65**.
- **Подсказка:**
  - В: «На какие части делят прямую a и b?» — О: «меньше a, между, больше b».
  - В: «Чему равна сумма вероятностей трёх частей?» — О: «1».
- **Иллюстрация:** числовая прямая с тремя подписанными промежутками.

**N5-04 «Два кружка»** — 5-4

- **Параметры:** P(A), P(B) (0,2…0,6), P(AB) < min(P(A), P(B)), два знака.
- **Вопрос:** «хотя бы в одном» = P(A) + P(B) − P(AB) / «ровно в одном» / «ни в одном».
- **Пример:** 0,3; 0,25; 0,1 ⇒ хотя бы одно **0,45**, ровно одно **0,35**.
- **Второй способ:** 100 учеников по областям кругов.
- **Иллюстрация:** круги Эйлера с подписанными областями.

**N5-05а «Таблица признаков»** — 5-5(а)

- **Параметры:** таблица 2×2 (цвет × форма), количества 2…20.
- **Условие:** «вынутая игрушка красная; P(шар)».
- **Ограничения:** доля в строке конечная.
- **Пример:** красные шары 6, красные кубики 10 ⇒ 6/16 = **0,375**.
- **Подсказка:**
  - В: «Какая строка таблицы остаётся после “известно, что красная”?»
  - В: «Сколько в ней всего?» — О: «16».

**N5-05б «Доли в популяции»** — 5-5(б)

- **Параметры:** доля мужчин s, доля пенсионеров среди мужчин u и среди женщин w (по 0,1…0,6).
- **Ответ:** su / (su + (1 − s)w). Если дробь бесконечная — в условии «округлите до сотых».
- **Пример:** 0,4; 0,3; 0,2 ⇒ **0,5**.
- **Второй способ:** метод 1000 — 1000 жителей, 120 мужчин-пенсионеров и 120 женщин-пенсионерок.

**N5-05в «Тест положительный — болен ли»** — 5-5(в)

- **Параметры:** доля больных r (0,01…0,2), чувствительность a (0,8…0,99), ложноположительные f (0,01…0,1).
- **Ответ:** ra / (ra + (1 − r)f). Если бесконечная — «округлите до сотых».
- **Примеры:** 0,1; 0,9; 0,1 ⇒ **0,5**; 0,05; 0,9; 0,05 ⇒ 18/37 ≈ **0,49**.
- **Подсказка (метод 10 000):**
  - В: «Сколько больных из 10 000?»
  - В: «Сколько у них положительных?»
  - В: «Сколько положительных у здоровых?»
  - В: «Какая доля положительных — больные?»
  - Последний шаг: «формат ответа: округли до сотых».
- **Иллюстрация:** дерево с количествами по веткам (компонент «метод 1000»).

**N5-05д «Круги Эйлера»** — 5-5(д)

- **Параметры:** P(B) (0,3…0,8), P(AB) < P(B), два знака.
- **Ответ:** P(AB) / P(B), если конечная. Генератор выбирает P(B) из {0,2; 0,25; 0,4; 0,5; 0,8}.
- **Пример:** 0,3 / 0,5 ⇒ **0,6**.
- **Иллюстрация:** круги Эйлера.

**N5-05г «Готовое дерево»** — 5-5(г)

- Дерево 2×2 с вероятностями на ветвях дано картинкой. Вопрос — условная вероятность первого уровня при известном втором.
- Параметры и ограничения как у N5-05в; картинка — существующий `derevo` (`vizual5.ts`).

**N5-06 «Погода держится»** — 5-6

- **Параметры:** p — погода сохраняется (0,6…0,9, один знак); дней d = 2…3; вопрос — «будет другая погода» / «та же».
- **Ответ:** перебор 2^d цепочек.
- **Пример:** p = 0,7, d = 2, «сменится» ⇒ 2·0,7·0,3 = **0,42**.
- **Иллюстрация:** дерево по дням.

**N5-06к «Все k заняты»** — 5-6

- p (0,3…0,9, один знак), k = 2…4, ответ pᵏ или (1 − p)ᵏ.
- **Пример:** 0,6, k = 3 ⇒ **0,216**.

**N5-07 «Датчики: сколько поставить»** — 5-7 «наименьшее n»

- **Параметры:** q — датчик не сработает (0,1…0,5, один знак); порог P (0,9…0,999).
- **Ответ:** наименьшее n с 1 − qⁿ ≥ P.
- **Ограничения:** n = 2…6; отбрасывать равенство на границе.
- **Пример:** q = 0,3, P = 0,99 ⇒ **4** (1 − 0,3⁴ = 0,9919).

**N5-08 «Монеты по карманам»** — 5-8

- **Параметры:** две особые монеты из N, перекладывают k.
- **Ответ:** 2·C(N−2, k−1) / C(N, k).
- **Ограничения:** конечных вариантов мало — только (N, k) = (6, 3) и (5, 2), ответ 0,6. Генератор либо разрешает «округлите до сотых», либо меняет вопрос: «обе в одном кармане», «обе переложены».
- **Пример:** N = 6, k = 3 ⇒ **0,6**.

**N5-09о «Доля поставщика»** — 5-9, обратная

- **Параметры:** доля первого завода x (0,1…0,9, один знак), брак q₁ ≠ q₂ (0,01…0,1).
- **Условие:** дан общий брак t = xq₁ + (1 − x)q₂, найти x.
- **Ограничения:** t задан не длиннее 4 знаков.
- **Пример:** 2 %, 5 %, 3,2 % ⇒ **0,6**.
- **Подсказка:**
  - В: «Что обозначим через x?»
  - В: «Чему равна доля брака в смеси?» — О: «0,02x + 0,05(1 − x)».
  - В: «Какое уравнение?»

**N5-09к «Два кубика»** — 5-9, прямая

- Наугад берут один из двух кубиков: обычный или с двумя шестёрками.
- **Пример:** P(6) = ½·⅙ + ½·²⁄₆ = **0,25**.
- Генератор варьирует число «шестёрок» и вероятность выбора кубика; отбор по конечной дроби.

**N5-10 «Не больше k попыток»** — 5-10

- **Параметры:** p₁ — первая попытка (0,3…0,8), p — каждая следующая (0,5…0,9), k = 2…4.
- **Ответ:** 1 − (1 − p₁)(1 − p)ᵏ⁻¹.
- **Пример:** 0,6; 0,8; k = 3 ⇒ **0,984**.

**N5-10к «Коллекция»** — 5-10

- **Параметры:** всего N (5…20), уже есть m разных, вопрос «новая появится на r-й или s-й покупке».
- **Ограничения:** конечная дробь.
- **Пример:** N = 10, m = 2, «на 2-й или 3-й» ⇒ **0,192**.

**N5-11а «Во сколько раз вероятнее»** — 5-11

- Монету бросают n раз; найти P(ровно k) / P(ровно k − 1) = (n − k + 1)/k.
- **Ограничения:** отношение — конечная дробь, ≠ 1.
- **Примеры:** n = 10, k = 5 ⇒ **1,2**; n = 8, k = 4 ⇒ **1,25**; n = 10, k = 4 ⇒ **1,75**. Отбрасываются, например, n = 6, k = 3 (4/3).
- **Подсказка:**
  - В: «Сколько последовательностей с ровно k орлами?» — О: «C(n, k)».
  - В: «Что сокращается в отношении?» — О: «2ⁿ и общие множители».

**N5-11б «Ровно k из n»** — 5-11

- p (0,1…0,9, один знак), n = 2…4, k.
- **Ответ:** C(n, k)·pᵏ·(1 − p)ⁿ⁻ᵏ, не длиннее 4 знаков, иначе «округлите до сотых».
- **Пример:** n = 3, p = 0,6, k = 2 ⇒ **0,432**.

**N5-11в «До двух выстрелов на мишень»** — 5-11

- **Ответ:** на одну мишень 1 − (1 − p)²; на m мишеней (1 − (1 − p)²)ᵐ.
- **Примеры:** p = 0,6: одна **0,84**, две **0,7056**, три ≈ **0,59** (с округлением).
