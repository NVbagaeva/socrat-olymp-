# №3: остальные страницы раздела в «Стеклянной сцене» — снимки

Теория, Карточки, Генератор и «Для репетиторов» после перевода в тот же
стиль, что шапка раздела (ветка `redesign-ostalnye-stranitsy`). Снимки
собраны с собранного сайта в Chromium (деталь экрана ×2, затем уменьшены
вдвое); окно «Впервые здесь?» выключено.

- `svodka-<страница>-1280.png` — первый экран на 1280×720: слева main,
  справа ветка.
- `svodka-<страница>-390.png` — то же на телефоне 390×844.
- `svodka-<страница>-soderzhanie.png` — содержание вкладки, прокрученное
  под шапку, на 1280×900: там видно сами стеклянные карточки.

Верхняя панель раздела на всех кадрах одинаковая: её переделали раньше
(`docs/zadanie-3-snimki/shapka/`), здесь меняется только содержание
вкладок.
