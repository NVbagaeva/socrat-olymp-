# Решения задания №8: как их писать

Решение — это шаги. У каждого шага две части:

| Поле | Что это | Пример |
|---|---|---|
| `chto` | Что делаем и **почему** — простыми словами. Можно назвать свойство и записать его формулой в `$…$`. С большой буквы, без точки в конце. | `Основания одинаковые — при делении показатели вычитаются: $a^{x} : a^{y} = a^{x - y}$` |
| `tex` | Выкладка этого шага — формула TeX без долларов. Начинается с того, что получилось на прошлом шаге. | `3^{15} : 3^{16} = 3^{15 - 16} = 3^{-1}` |

Шаг собирается функцией `shag(chto, tex)` из `prototypes/common.ts`.

## Правила

1. **Шагов не меньше двух** у задач тренажёра и банка (у опорной микро-задачи — один или два: свойство одно). Последний шаг кончается ответом: `… = ${d(ans)}`.
2. **Подпись объясняет приём, а не повторяет выкладку.** Плохо: «Вычисляем». Хорошо: «Корень из произведения — произведение корней, поэтому извлекаем корень из каждого множителя».
3. **Умное сокращение вместо «перемножим всё».** Если в выражении есть общие множители, одинаковые основания, $a^2 - b^2$ и $(a - b)$ — сначала сокращаем, и подпись говорит, что на что и почему: «Сокращаем $22^{3}$ не вычисляя: раскладываем $22 = 2 \cdot 11$, и $11^{3}$ уходит полностью».
4. **Признаки делимости.** Если число сокращается на множитель, который не очевиден (на 3 и 9 — по сумме цифр, на 4, на 25), подпись называет признак, а у задачи стоит `delimost: priznakiDlya(g)`. Под решением появляется сворачиваемая панель «Признаки делимости» с правилами и примерами (`priznaki.ts`).
5. **Числа — как в условии.** Десятичная запятая — через `d(x)`, степени — `pw()`, дроби — `frac()`, корни — `root()`, логарифмы — `log()` (`tex.ts`).
6. **Генерацию не трогать.** Решения меняются, условие, ответ, параметры, независимый счёт и порядок вызовов `r.*` — нет: по ним собран банк, и задачи банка должны остаться теми же.
7. **Обращение — «мы»:** «Раскладываем…», «Сокращаем…», «Переходим к основанию 2…».

## Проверка

```bash
cd app
node scripts/check-vychisleniya.mjs 300 --only 8.A,8.C,8.D
```

Самотест (`selftest.ts`) проверяет формат шагов, подписи (с большой буквы, без точки, со словами, без «перемножим всё»), что каждая формула набирается KaTeX и что последний шаг кончается ответом.
