# Открытый банк ФИПИ, Школково, онлайн-школы

## Открытый банк ФИПИ (fipi.ru)

- На fipi.ru есть раздел «Открытый банк заданий ЕГЭ» (**проверено**).
  Сам банк (ege.fipi.ru) из этой среды не открылся.
- По памяти (**требует проверки**): бесплатно, задачи без решений и
  без подсказок, без структуры обучения; интерфейс поиска неудобный.
- Для нас это **эталон**, а не конкурент: ценность «точно как в
  открытом банке» держится на нём.
- Косвенно: на Stepik есть платные курсы с решениями «всех 565 заданий
  1 части из банка ФИПИ», №13 — 58, №15 — 62, №16 — 50
  (stepik.org/249598, /255913, /256478, /257099 — **поиск, проверено по
  выдаче**). Это ориентир объёма банка ФИПИ по части 2.

## Тетрика (tetrika-school.ru)

- Главная открылась, но ключевых фактов в тексте страницы не нашёл.
- По памяти (**требует проверки**): онлайн-школа с индивидуальными
  занятиями; своя доска — внутренний инструмент для своих
  преподавателей, внешним репетиторам не продаётся.
- Прямым конкурентом для нас не является.

## Умскул, Фоксфорд, 100балльный

- umschool.net не открылся, foxford.ru вернул 401, 100ballnik.com
  открылся, но на главной — тренажёры и варианты ОГЭ/ЕГЭ в PDF, а не

  проверки**).
- По памяти (**требует проверки**): это онлайн-школы для ученика,
  контент закрыт подпиской на курс; открытого банка с подсказками нет;
  репетиторам инструментов не продают.
- Для нас это **не конкуренты за репетитора**, а конкуренты за ученика
  и родителя (если пойдём в B2C).
