# Решу ЕГЭ / СдамГИА (math-ege.sdamgia.ru)

Источники: каталог заданий `math-ege.sdamgia.ru/prob_catalog` и
страница задачи `problem?id=26646` (скачаны 13.11.2026, **проверено**).
Остальное помечено отдельно.

## 1. Для кого и кто платит

- Ученик (бесплатно), учитель (бесплатные варианты, классный журнал,
  «ссылка, чтобы записаться к учителю», сертификаты для учителей —
  ссылки в меню, проверено).
- Платные услуги и цены: **неизвестно** (не проверял).

## 2. Функции

Банк задач, варианты, автопроверка ответов, учительский журнал и выдача
работ (проверено по меню). Доски, видео, расписания нет (по памяти,
требует проверки). Кабинет ученика — есть (по памяти).

## 3. Методика

**Объём (проверено, каталог):** №1 — 270, №3 — 315, №11 — 102,
№18 — **457**, №19 — **567** задач. Это самый большой открытый банк
из рассмотренных.

**Структура внутри номера (проверено):** «каталог по типам по темам».
- №11: движение по прямой (30), по окружности (5), по воде (15),
  совместная работа (25), прогрессии (9) и др.
- №18: 10 тем (треугольники — 86, четырёхугольники — 87,
  окружности — 53, вписанные/описанные…).
- №19: 14 рубрик, часть — методы: «использование симметрий» (33),
  «монотонность, оценки» (41), «аналитическое решение» (81),
  «координаты (x, a)» (15), «уравнение окружности» (50),
  «расположение корней квадратного трёхчлена» (17)…
  Это список рубрик, а не учебный путь: нет теории метода, опорных
  задач, порядка «от простого к сложному».

**Соответствие ФИПИ (проверено):** у задачи — «Кодификатор ФИПИ/Решу
ЕГЭ» (элемент содержания) и **список «Аналоги к заданию»** (у задачи
№26646 — 30+ аналогов). Это сильная сторона: «другой сюжет того же
типа» у них уже есть. Помечены ли задачи как «из открытого банка ФИПИ»
на уровне прототипа — не увидел.

**Подсказки (проверено):** нет. Одно решение «Спрятать решение» +
ответ. Решения часто короткие («Последовательно получаем: …»).

**Теория:** справочные материалы есть (по памяти, требует проверки),
к задачам напрямую не привязаны.

## 4. Упаковка

Утилитарный портал без лендинга-оффера: меню предметов, новости,
каталог. Ценность — бесплатность и объём.

## 5. Слабые места → наша ниша

1. Нет пошаговых подсказок — только решение целиком.
2. Нет учебной траектории внутри номера (теория → разбор → опорные →
   тренировка). Рубрики есть, методики нет.
3. Аналоги — числовые двойники; методического комментария «чем этот
   сюжет отличается» нет.
4. Интерфейс устаревший, не для урока на планшете.

**Где Решу ЕГЭ сильнее нас:** объём части 2 (№18: 457 против наших 96,
№19: 567 против 135) и бесплатность. Конкурировать объёмом в части 2
нельзя — только структурой и подсказками.
