# Универсальные доски и платформы для репетиторов

Edvibe, ProgressMe, Ziteboard, Сферум, Miro. Объединены: это
«доска + кабинет», без собственной методики ЕГЭ по математике.

## Edvibe (edvibe.com)

- **Для кого:** «A next-gen language teaching platform for educators and
  schools» — мета-описание сайта (**проверено**). То есть в первую
  очередь — **языковые** преподаватели и школы.
- **Функции:** виртуальный класс с доской, кабинет ученика, ДЗ и их
  проверка, конструктор уроков, тариф PRO (справка Edvibe:
  intercom.help/edvibe — **поиск, проверено по выдаче**).
- **Цены:** не нашёл. Конкурент Kwiga пишет «от $2 за нового студента»
  (kwiga.com/analogs/lms/kwiga-vs-edvibe) — **непроверенное утверждение
  конкурента**.
- **Методика математики / банк ЕГЭ:** нет (по памяти, требует проверки).
- **Слабое место:** математика — не их профиль; формулы, графики,
  задачи ЕГЭ — на плечах репетитора.

## ProgressMe (progressme.ru)

- **Для кого:** «interactive linguistic platform», 140+ языков,
  50 000+ преподавателей языков (teflcourse.net/efl-esl-jobs/progressme —
  **поиск, проверено по выдаче**). Сайт отдаёт капчу, сам не открыл.
- **Функции:** виртуальный класс, конструктор курсов с автопроверкой,
  академия с контентом (там же; отзыв startpack.ru, 29.10.2025).
- **Цены:** не нашёл.
- **Методика ЕГЭ по математике:** нет (по памяти, требует проверки).
- **Слабое место:** тот же — платформа для языков.

## Ziteboard (ziteboard.com) — проверено по сайту

- **Для кого:** универсальная доска, «designed for successful realtime
  tutoring».
- **Цены (проверено):** Free — 3 своих доски; неделя Pro — $5;
  месяц Pro — **$9**; есть командные тарифы и white label / API.
- **Функции:** реальное время, iPad/Android, PDF-импорт, экспорт
  PNG/SVG/PDF, видео- и аудиочат в доске, **Math Tools**: редактор
  формул (LaTeX), построитель графиков, циркуль.
- **Банк задач, ДЗ, прогресс:** нет.
- **Слабое место:** никакого контента, оплата в долларах (для РФ
  неудобно).

## Сферум, Miro (по памяти, требует проверки — сайты не открылись)

- **Сферум** (VK, для школ): бесплатно, чаты, звонки, есть доска;
  ориентирован на школы, не на репетиторов, банка ЕГЭ нет.
- **Miro:** универсальная доска; в РФ ограничена с 2022 года;
  математических инструментов почти нет.

## Вывод

Рынок «доска + кабинет + видео» переполнен, и универсальные игроки
закрывают чек-лист из Threads почти целиком. Конкурировать в этом
сегменте функциями бессмысленно. Слабость у всех одна: **нет
содержания ЕГЭ** — задачи, подсказки и путь по номеру репетитор
приносит сам.
