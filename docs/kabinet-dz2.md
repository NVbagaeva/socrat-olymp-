# Новая выдача домашних заданий (кабинет v2, этап 2)

План — [plans/cabinet-v2.md](plans/cabinet-v2.md), §3.2. Этап разбит на PR:

| PR | Что |
|---|---|
| **2а — база** (этот документ) | таблицы, функции учителя и ученика, права, тесты |
| 2б — выдача | корзина «В домашку» в разделах №5 и №8, мастер выдачи, черновики, шаблоны, «Повторить ДЗ» |
| 2в — ученик | «Мои домашки», решение внутри ДЗ, «Сдать» |
| 2г — итоги учителя | «ученики × элементы» со статусами, ответы и время, комментарий, «Вернуть на доработку» |

Нынешние ДЗ №8 (`homework`, `/kabinet/dz-vydat/`) остаются как были
(решение В-10); новые выдаются через новую выдачу.

## Из чего состоит ДЗ

ДЗ — до 30 элементов из разных разделов. Вид элемента:

| Вид | Что ученик делает | Когда элемент выполнен |
|---|---|---|
| `opornye` | решает задачи блока опорных (весь блок или выбранные) | все задачи закрыты |
| `trenazher` | решает задачи по типам из запаса | цель: все задачи, «решить N» или «K верных подряд» |
| `kartochki` | проходит набор карточек | пройдено столько карточек, сколько в наборе |
| `variant` | решает выданную работу («Собрать вариант» или серия), при желании с таймером | работа завершена |
| `chast2` | решение второй части с фото | **откроется с PR 1в** (фото); до этого публикация отвечает `chast2_not_ready` |
| `teoriya` | читает главу | отметка «прочитано» |

Задачи и ключи собирает браузер учителя тем же генератором, что и
тренажёр, — те же числа, тот же чертёж. При «индивидуальных числах» у
каждого ученика свой набор. Ключ ученик не читает никогда: ответ
проверяет база.

## Настройки

| Колонка | Значения | По умолчанию |
|---|---|---|
| `publish_at` | время публикации; в будущем — отложенная | сразу |
| `due_at` | дедлайн, хранится в UTC, учитель задаёт по Москве | нет |
| `after_due` | `late_ok` — можно сдать «с опозданием»; `closed` — после дедлайна ДЗ закрыто | `late_ok` |
| `hints_allowed` | подсказки (шаги разбора) | да |
| `attempts_limit` | 1, 2, 3 или без ограничения (В-9) | без ограничения |
| `solutions_when` | `instant` — после закрытия задачи; `after_due`; `never` | `instant` |
| `individual` | индивидуальные числа | нет |
| `kontrol` | контрольная: подсказок, «Запомни» и разобранного примера нет | нет |

Кому — классы и отдельные ученики (`homework2_targets`). При публикации
цели раскрываются в получателей: ученики классов, которых учитель ведёт
сейчас, и отмеченные ученики.

## Жизнь ДЗ

`draft` (черновик) → `published` (опубликовано; при `publish_at` в
будущем ученики увидят его в это время) → `closed` (учитель закрыл
приём). `template` — шаблон: не публикуется, копируется в черновик.

Статус ученика (`dz2_status`): `not_started`, `in_progress`,
`submitted`, `late` (сдано с опозданием), `missed` (дедлайн прошёл, не
сдано), `returned` (на доработке).

## Функции

| Функция | Кто | Что |
|---|---|---|
| `dz2_save(p)` | учитель | сохранить черновик или шаблон: настройки, цели, элементы, задачи и ключи (заменяются целиком) |
| `dz2_publish(id)` | учитель | опубликовать черновик: проверки, получатели, событие `published` |
| `dz2_copy(id, status)` | учитель | «Повторить ДЗ» / «ДЗ из шаблона» / «Сохранить как шаблон»: копия без целей и без индивидуальных задач |
| `dz2_edit(id, p)` | учитель | после выдачи: название, пояснение, дедлайн, правило после дедлайна, закрыть/открыть приём; событие `edited` ученикам |
| `dz2_delete(id)` | учитель | удалить черновик или шаблон (выданное — только закрыть) |
| `dz2_spisok()` | учитель | мои ДЗ: черновики, шаблоны, выданные со счётом «сдали N из M» |
| `dz2_itogi(id)` | учитель | ученики × элементы: статусы, прогресс, время |
| `dz2_otvety(id, ученик)` | учитель | задачи ученика: ответы как есть, верный ответ, попытки, подсказки, время |
| `dz2_vernut(id, ученик, комментарий)` | учитель | «Вернуть на доработку»: сдача снимается, событие `returned` |
| `dz2_comment(id, ученик, текст)` | учитель | комментарий ученику, событие `commented` |
| `dz2_moi()` | ученик | «Мои домашки» с прогрессом |
| `dz2_open(id)` | ученик | элементы, задачи без ключей, свой ход решения; решение — когда можно |
| `dz2_check(задача, ответ, секунды)` | ученик | проверка ответа: как у ДЗ №8 (неверная запись и дробь с верным значением попытку не тратят), попытки, решение; запись в журнал (этап 1) с `verified = true` |
| `dz2_hint(задача, шаг)` | ученик | шаг разбора как подсказка, если подсказки разрешены |
| `dz2_mark(элемент, сколько)` | ученик | карточки: сколько пройдено; теория: «прочитано» |
| `dz2_submit(id)` | ученик | «Сдать»; после дедлайна при `late_ok` — с опозданием, событие `submitted` учителю |

Ошибки — код в начале сообщения: `forbidden`, `dz2_off`, `not_draft`,
`not_published`, `bad_task_no`, `bad_answer`, `bad_variant`,
`bad_settings`, `bad_due`, `bad_goal`, `no_items`, `no_tasks`,
`no_recipients`, `chast2_not_ready`, `not_your_student`,
`not_your_homework`, `not_your_task`, `progress_not_allowed`,
`homework_closed`, `already_submitted`, `due_passed`, `not_allowed`,
`not_submitted`, `too_big`, `too_many_tasks`.

События (`homework2_events`) копятся для уведомлений этапа 3:
`published`, `edited`, `submitted`, `returned`, `commented`.

## Права

- Ученик не читает таблиц ДЗ: всё — функциями. Ключи и чужие задачи не
  уходят ему никогда; решение — только когда его можно показать.
- Учитель читает свои ДЗ, элементы и цели; задачи, ключи, ответы и
  получателей — функциями, и только своих ДЗ.
- Аноним не вызывает ничего.
- №6 и разделы вне флага в ДЗ не попадают.
