## Из чего состоит ДЗ

ДЗ — до 30 элементов из разных разделов. Вид элемента:

| Вид | Что ученик делает | Когда элемент выполнен |
|---|---|---|
| `opornye` | решает задачи блока опорных (весь блок или выбранные) | все задачи закрыты |
| `trenazher` | решает задачи по типам из запаса | цель: все задачи, «решить N» или «K верных подряд» |
| `kartochki` | проходит набор карточек | пройдено столько карточек, сколько в наборе |
| `variant` | решает выданную работу («Собрать вариант» или серия), при желании с таймером | работа завершена |
| `chast2` | решение второй части с фото | **откроется с PR 1в** (фото); до этого публикация отвечает `chast2_not_ready` |
| `teoriya` | читает главу | отметка «прочитано» |

Задачи и ключи собирает браузер учителя тем же генератором, что и
тренажёр, — те же числа, тот же чертёж. При «индивидуальных числах» у
каждого ученика свой набор. Ключ ученик не читает никогда: ответ
проверяет база.

## Настройки

| Колонка | Значения | По умолчанию |
|---|---|---|
| `publish_at` | время публикации; в будущем — отложенная | сразу |
| `due_at` | дедлайн, хранится в UTC, учитель задаёт по Москве | нет |
| `after_due` | `late_ok` — можно сдать «с опозданием»; `closed` — после дедлайна ДЗ закрыто | `late_ok` |
| `hints_allowed` | подсказки (шаги разбора) | да |
| `attempts_limit` | 1, 2, 3 или без ограничения (В-9) | без ограничения |
| `solutions_when` | `instant` — после закрытия задачи; `after_due`; `never` | `instant` |
| `individual` | индивидуальные числа | нет |
| `kontrol` | контрольная: подсказок, «Запомни» и разобранного примера нет | нет |

Кому — классы и отдельные ученики (`homework2_targets`). При публикации
цели раскрываются в получателей: ученики классов, которых учитель ведёт
сейчас, и отмеченные ученики.

## Жизнь ДЗ

`draft` (черновик) → `published` (опубликовано; при `publish_at` в
будущем ученики увидят его в это время) → `closed` (учитель закрыл
приём). `template` — шаблон: не публикуется, копируется в черновик.

Статус ученика (`dz2_status`): `not_started`, `in_progress`,
`submitted`, `late` (сдано с опозданием), `missed` (дедлайн прошёл, не
сдано), `returned` (на доработке).

## Функции

| Функция | Кто | Что |
|---|---|---|
| `dz2_save(p)` | учитель | сохранить черновик или шаблон: настройки, цели, элементы, задачи и ключи (заменяются целиком) |
| `dz2_publish(id)` | учитель | опубликовать черновик: проверки, получатели, событие `published` |
| `dz2_copy(id, status)` | учитель | «Повторить ДЗ» / «ДЗ из шаблона» / «Сохранить как шаблон»: копия без целей и без индивидуальных задач |
| `dz2_edit(id, p)` | учитель | после выдачи: название, пояснение, дедлайн, правило после дедлайна, закрыть/открыть приём; событие `edited` ученикам |
| `dz2_delete(id)` | учитель | удалить черновик или шаблон (выданное — только закрыть) |
| `dz2_spisok()` | учитель | мои ДЗ: черновики, шаблоны, выданные со счётом «сдали N из M» |
| `dz2_itogi(id)` | учитель | ученики × элементы: статусы, прогресс, время |
| `dz2_otvety(id, ученик)` | учитель | задачи ученика: ответы как есть, верный ответ, попытки, подсказки, время |
| `dz2_vernut(id, ученик, комментарий)` | учитель | «Вернуть на доработку»: сдача снимается, событие `returned` |
| `dz2_comment(id, ученик, текст)` | учитель | комментарий ученику, событие `commented` |
| `dz2_moi()` | ученик | «Мои домашки» с прогрессом |
| `dz2_open(id)` | ученик | элементы, задачи без ключей, свой ход решения; решение — когда можно |
| `dz2_check(задача, ответ, секунды)` | ученик | проверка ответа: как у ДЗ №8 (неверная запись и дробь с верным значением попытку не тратят), попытки, решение; запись в журнал (этап 1) с `verified = true` |
| `dz2_hint(задача, шаг)` | ученик | шаг разбора как подсказка, если подсказки разрешены |
| `dz2_mark(элемент, сколько)` | ученик | карточки: сколько пройдено; теория: «прочитано» |
| `dz2_submit(id)` | ученик | «Сдать»; после дедлайна при `late_ok` — с опозданием, событие `submitted` учителю |

Ошибки — код в начале сообщения: `forbidden`, `dz2_off`, `not_draft`,
`not_published`, `bad_task_no`, `bad_answer`, `bad_variant`,
`bad_settings`, `bad_due`, `bad_goal`, `no_items`, `no_tasks`,
`no_recipients`, `chast2_not_ready`, `not_your_student`,
`not_your_homework`, `not_your_task`, `progress_not_allowed`,
`homework_closed`, `already_submitted`, `due_passed`, `not_allowed`,
`not_submitted`, `too_big`, `too_many_tasks`.

События (`homework2_events`) копятся для уведомлений этапа 3:
`published`, `edited`, `submitted`, `returned`, `commented`.

## Права

- Ученик не читает таблиц ДЗ: всё — функциями. Ключи и чужие задачи не
  уходят ему никогда; решение — только когда его можно показать.
- Учитель читает свои ДЗ, элементы и цели; задачи, ключи, ответы и
  получателей — функциями, и только своих ДЗ.
- Аноним не вызывает ничего.
- №6 и разделы вне флага в ДЗ не попадают.

Кнопка видна только учителю, при флаге `NEXT_PUBLIC_DZ2` и только в
разделах выдачи (сейчас №5 и №8). Кладёт элемент в корзину учителя

| Где | Что кладёт |

| блок опорных задач №8 | все задачи блока с ответами (генератор) и шагами разбора; задачи с выбором варианта ответа не идут — база сверяет число |
| блок опорных задач №5 | все задачи блока с ответами и шагами из закрытого разбора, картинка задачи |

`variant` в базе есть, кнопка появится отдельно.

### Мастер выдачи `/kabinet/dz2/vydat/`

- **Что задаём:** элементы корзины по порядку — выше, ниже, убрать. У
  тренажёра — запас задач (5–60) и цель: «решить все», «решить N»,
  «K верных подряд».
- **Название и пояснение** ученикам.
- **Кому:** классы и отдельные ученики.
- **Когда:** открыть ученикам сразу или в дату и время по Москве
  (отложенная публикация); дедлайн по Москве (в базе — UTC).
- **После дедлайна:** можно сдать «с опозданием» или ДЗ закрыто.
- **Правила:** контрольная (одна попытка, без подсказок, решения после
  дедлайна; «Запомни» и пример выключены), подсказки, индивидуальные
  числа, попытки 1/2/3/без ограничения, когда показывать решения.
- **Выдать**, **Сохранить черновик**, **Сохранить как шаблон.**

При выдаче браузер учителя собирает запас тренажёра тем же генератором,
что «Собрать вариант» (`lib/dz2/sborka.ts`): при индивидуальных числах —
свой набор каждому ученику (свой seed). Черновик и шаблон хранят рабочую
копию мастера (`homework2.chernovik`, миграция
`20261124120000_dz2_chernovik.sql`), поэтому их можно открыть и доделать.

### Мои ДЗ `/kabinet/dz2/`

Черновики, шаблоны, выданные: срок, «откроется …», «сдали N из M».
Действия: открыть черновик, «ДЗ из шаблона», «Повторить» (копия в
черновик — выдать другому классу), «В шаблоны», закрыть или открыть
приём, удалить черновик или шаблон. Вход — карточка «Домашние задания»
в кабинете учителя (при флаге).

## Ученик (PR 2в)

### «Мои домашки» `/kabinet/domashki/`

ДЗ новой выдачи (`dz2_moi`): статус, дедлайн по Москве, «выполнено N
из M», учитель. Сверху — «Нужно сделать» (на доработке — выше всех,
дальше по дедлайну, без дедлайна — в конце), ниже — сданные и закрытые.
В кабинете ученика при флаге — карточка «Мои домашки» с тремя ближайшими.

### Решение `/kabinet/domashki/reshat/?id=…`

ДЗ открывается функцией `dz2_open`: элементы по порядку, у каждого —
цель и прогресс (их считает база), открыт первый невыполненный.

| Элемент | Что делает ученик |
|---|---|
| опорные, тренажёр | решает задачи здесь же: лента номеров, условие (с картинкой у №5), поле ответа как в ДЗ №8, «Проверить» — `dz2_check`. Неверная запись и дробь с верным значением попытку не тратят. Попытки, вердикт и решение — по настройкам учителя |
| опорные | «Подсказка» — шаги разбора по одному (`dz2_hint`); шаги видит учитель. У тренажёра подсказок нет: его разбор одним куском показал бы всё решение. В контрольной подсказок нет |
| карточки | «Открыть карточки» ведёт на вкладку «Карточки» раздела; над ней плашка «засчитывается в ДЗ», каждая пройденная карточка — `dz2_mark` с числом разных пройденных (`lib/dz2/otmetka.ts`) |
| теория | «Открыть главу» (якорь главы) и «Прочитано» — `dz2_mark` |
| вариант, вторая часть | пока только пояснение (кнопок выдачи ещё нет) |

«Сдать ДЗ» — с подтверждением (сколько элементов не выполнено), после
дедлайна при «можно с опозданием» — отметка «с опозданием». После сдачи,
закрытия приёма или дедлайна с «закрыто» ДЗ только для просмотра.
Возврат на доработку и комментарий учителя — вверху ДЗ.

Ход решения хранится в базе после каждой проверки: ДЗ открывается с
того же места. Проверка в ДЗ пишется в журнал (этап 1) самой базой.

**Вёрстка задач.** Условия и разборы приходят из базы готовым HTML
(KaTeX набран в браузере учителя при выдаче) и перед показом
очищаются (`lib/dz/sanitize.ts`: только набор KaTeX и текст, плюс
списки шагов). Опорные №5 с PR 2в тоже набираются при выдаче: в банке у
них текст с `$…$` и TeX. Картинка условия — только своя, из `/images/`
(`risunokSrc`). Ученику — на «ты», без «мы».

## Итоги у учителя (PR 2г)

`/kabinet/dz2/itogi/?id=…` — из «Моих ДЗ» кнопкой «Итоги» у выданного
или закрытого ДЗ. Данные — `dz2_itogi` (только своё ДЗ: чужому учителю
и ученику база отвечает `forbidden`).

- **Таблица «ученики × элементы»:** статус ученика, в клетке — прогресс
  к цели («1/3», у теории — ✓) и цвет: выполнено, начато, не начато;
  время; строка «Выполнили» по каждому элементу. Порядок: сдавшие (их
  проверять), на доработке, в работе, не начавшие, не сдавшие. На
  телефоне строка — карточка ученика, на компьютере — таблица с
  закреплённым именем.
- **Ответы ученика** (имя в таблице) — `dz2_otvety`: по элементам и
  задачам — что ученик вводил (неверные зачёркнуты), верный ответ,
  попытки, шаги подсказки, время; условие раскрывается. Задачи, за
  которые ученик не брался, — одной строкой.
- **Комментарий ученику** — `dz2_comment`; ученик видит его вверху ДЗ.
- **«Вернуть на доработку»** — только сданное, с подтверждением и
  тем, что доделать (`dz2_vernut`): сдача снимается, ДЗ у ученика первым
  в «Моих домашках» со статусом «На доработке» и комментарием, решать и
  сдавать можно снова.
- События `commented` и `returned` копятся для уведомлений этапа 3.
- Проверка второй части с фото — с PR 1в (хранилище фото).

Статусы — без рода: «Сдано», «Не начато», «В работе».
