# Макеты экрана «Зачётная работа по заданию №12»

Нарисованы нейросетью: с них берутся раскладка и вид (шаги-вкладки, плитки
«Быстрый старт», строки типов со счётчиком «− N +», свёрнутые прототипы с
переключателями и «в банке: N», липкая сводка с превью, жёлтая плашка,
сегментированные переключатели, нижняя панель на телефоне).

Ошибки макетов, которые на сайте НЕ повторяются:

1. Левое меню — нынешнее меню сайта, а не нарисованное.
2. Состав типов — из данных сайта; «Скоро» только у типов без готового банка;
   по умолчанию включены все готовые типы.
3. Прототипы — из данных, формулы KaTeX; у показательной четыре разных.
4. Индикатор шагов показывает текущий шаг; заголовок без опечатки.
5. Цифры шаблонов: «Весь №12» — все типы по 2, «Короткая проверка» — по 1,
   тематические — по 3, «Как в прошлый раз» — из сохранённого набора.
6. Главная кнопка одна: «Собрать работу» → «Скачать для печати».
7. Превью — настоящая первая страница собранного варианта, до сборки — скелет.
8. На телефоне есть «Всем по 1 · Всем по 2 · Очистить».
