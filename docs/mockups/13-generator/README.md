# Макет генератора задания №13

Кликабельный макет без логики к этапу 2 (`docs/13-economics/02-design.md`, § 5).
Открыть: `index.html` в браузере. Кнопки переключают заранее подготовленные
состояния; числа в задачах настоящие и пересчитаны солвером, но новых задач
макет не генерирует. Внешние ресурсы: шрифты Google Fonts и библиотека
`qrcode-generator` с cdnjs (для QR комплекта).

| Снимок | Что показывает |
|---|---|
| `01-telefon-start.png` | телефон: пресеты, нижняя панель с главной кнопкой |
| `02-telefon-sostav.png` | телефон: шаг «Что», счётчики типов |
| `03-telefon-komplekt.png` | телефон: комплект после генерации — код, QR, листы |
| `04-telefon-list-uchenika.png` | телефон: лист ученика |
| `05-telefon-zachet.png` | телефон: пресет «Зачёт Н.В.», таблица баллов и шкала |
| `06-desktop-domashka.png` | десктоп: пресет «Домашка», три шага и предпросмотр |
| `07-desktop-list-uchitelya.png` | десктоп: лист учителя — сводка ответов и краткие решения |
| `08-desktop-zachet.png` | десктоп: пресет «Зачёт Н.В.» |

Что в макете условно и на сайте будет иначе:

1. Лента вкладок и шапка — упрощённые; на сайте — `RazdelTabs` и оболочка раздела.
2. Формулы набраны MathML; на сайте — KaTeX.
3. Предпросмотр показывает до шести задач; на сайте — настоящая первая страница листа после пагинации `lib/sheet/paginate.js`.
4. «↻ заменить» и «Перегенерировать» перебирают четыре готовых кода комплекта.
