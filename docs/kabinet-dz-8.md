# Кабинет репетитора и домашние задания №8 (этап 3)

Что делает этап 3 и как это устроено в базе. Схема одна — схема кабинета
(`supabase/migrations/20261015120000_kabinet.sql`); этап 3 расширяет её
миграцией `20261111120000_dz.sql`. Прежние таблицы ДЗ (`homework_items`,
`attempts`) остаются для пробного кабинета разработки и новым ДЗ не нужны.

## Классы и вступление по коду

| Что                                                                        | Где                                                                                                 |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Код класса: 6 знаков из `ABCDEFGHJKMNPQRSTUVWXYZ23456789` (без 0/O, 1/I/L) | `classes.join_code`, ставится триггером при создании                                                |
| Приём по коду можно выключить                                              | `classes.join_open` (репетитор меняет сам)                                                          |
| Новый код взамен старого                                                   | `rotate_class_code(class_id)` — только владелец класса                                              |
| Вступить по коду                                                           | `join_class(code)` — ученик; код без пробелов и дефисов, регистр не важен                           |
| Переименовать ученика для себя                                             | `tutor_students.alias` — пишет и видит только репетитор; читать — через представление `my_students` |
| Убрать ученика из класса                                                   | `delete from class_members` — уже разрешено владельцу класса                                        |

`join_class`:

- только роль `student` и только если ученику можно сохранять прогресс
  (`can_save_progress`: школьник до согласия родителя в класс не вступает);
- не больше 10 неудачных попыток за час (`class_join_tries`), дальше
  `too_many_tries`;
- код не найден, приём выключен или класс в архиве — ответ
  `{"error": "bad_code"}` (без подсказки, какой именно случай). Это данные,
  а не ошибка запроса: исключение откатило бы и запись о неудачной
  попытке, и предел в 10 попыток не работал бы. Остальные отказы
  (`forbidden`, `progress_not_allowed`, `too_many_tries`) — ошибки;
- связывает ученика с репетитором (`tutor_students`, снимает `ended_at`) и
  добавляет в класс; повторное вступление ничего не ломает;
- возвращает `{class_id, class_name, tutor_name}`.

Имя ученика для себя (`alias`) ученик не видит. Колонку от строки в
PostgreSQL не спрятать, поэтому `tutor_students` читается только по
колонкам `tutor_id, user_id, linked_at, ended_at` (`select *` не
работает), а репетитор читает имя через представление `my_students`
(`user_id, alias, linked_at, ended_at` — только свои ученики). Меняет
`alias` репетитор прямо в `tutor_students`. В выгрузку данных ученика
(`export_my_data`) `alias` не попадает.

## Домашнее задание

`homework` получает настройки:

| Колонка          | Значения                                                                 | По умолчанию   |
| ---------------- | ------------------------------------------------------------------------ | -------------- |
| `task_no`        | номер задания ЕГЭ (8)                                                    | —              |
| `attempts_limit` | `1`, `2` или `null` — без ограничения                                    | `null`         |
| `solutions_when` | `instant` (после ответа), `after_submit`, `after_due`                    | `after_submit` |
| `show_memo`      | показывать «Запомни»                                                     | `false`        |
| `show_example`   | показывать разобранный пример                                            | `false`        |
| `individual`     | у каждого ученика свои задачи                                            | `false`        |
| `origin`         | откуда выдано: `kabinet`, `generator`, `opornye`, `trenazher`, `oshibki` | `kabinet`      |
| `parent_id`      | «работа над ошибками» по какому ДЗ                                       | `null`         |

Задачи ДЗ хранятся готовыми — ничего не генерируется заново ни при решении,
ни при печати: лист ученика и лист учителя печатаются из тех же строк.

- `homework_tasks` — то, что видит ученик: `position`, `kind` (прототип
  «8.A»), `question_html` (условие, набранное KaTeX при выдаче), `comment`
  (комментарий репетитора к задаче), `student_id` (`null` — задача для всех,
  иначе — индивидуальная).
- `homework_keys` — то, что видит только репетитор: `ref`
  («прототип|seed|уровень»), `answer` (нормальная запись,
  `normalize_ege_answer`), `razbor` (решение по шагам, JSON `RazborHtml`),
  `source` («банк 8.A №3» / «новая»).
- `homework_answers` — ход решения ученика по задаче: `state`
  (`open` / `right` / `wrong` / `revealed`), `attempts`, `entries` (что вводил:
  `[{a, n, ok, at}]`), `seconds`.

Ученик пишет только через функции, репетитор меняет только текст:
`homework.note`, `homework.due_at`, `homework.closed_at`,
`homework_tasks.comment`.

| Функция                                 | Кто               | Что делает                                                           |
| --------------------------------------- | ----------------- | -------------------------------------------------------------------- |
| `issue_homework_tasks(p jsonb)`         | репетитор         | создаёт ДЗ, получателей, задачи и ключи одной транзакцией            |
| `homework_check(task, answer, seconds)` | ученик            | проверяет ответ на сервере, считает попытки                          |
| `homework_reveal(task)`                 | ученик            | «Показать решение» — только при `solutions_when = instant`           |
| `homework_solution(task)`               | ученик, репетитор | `{razbor, answer}`, если решение уже можно показать, иначе `not_yet` |
| `start_homework`, `submit_homework`     | ученик            | уже были в схеме кабинета                                            |

Ошибки — стабильный код в начале сообщения:

| Функция                | Коды                                                                                                                                                                                                                                                                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `rotate_class_code`    | `forbidden`                                                                                                                                                                                                                                                                                                                                |
| `join_class`           | `forbidden`, `progress_not_allowed`, `too_many_tries`; `bad_code` — данными, см. выше                                                                                                                                                                                                                                                      |
| `issue_homework_tasks` | `forbidden`, `not_your_student`, `not_in_class`, `no_recipients`, `bad_due` (срок прошёл; `after_due` без срока), `bad_task_no`, `bad_settings`, `bad_parent`, `no_tasks`, `too_many_tasks` (больше 60 на ученика), `bad_task_student`, `bad_kind` (нет прототипа в банке или он убран), `bad_answer` (не нормальная запись), `bad_razbor` |
| `homework_check`       | `not_your_task`, `progress_not_allowed`, `homework_closed`, `already_submitted`, `due_passed`                                                                                                                                                                                                                                              |
| `homework_reveal`      | `not_your_task`, `progress_not_allowed`, `due_passed`, `not_allowed`                                                                                                                                                                                                                                                                       |
| `homework_solution`    | `not_your_task`, `not_yet`                                                                                                                                                                                                                                                                                                                 |

`issue_homework_tasks`: ученики не указаны, а класс указан — ДЗ уходит
всем ученикам класса, которых репетитор ведёт сейчас.

### Проверка ответа (`homework_check`)

- Ответ — то, что ввёл ученик, как есть. Минусы всех видов и дробная черта
  «∕» распознаются так же, как в `lib/otvet`.
- Обыкновенная дробь `p/q`:
  - значение верное — `fractionRight`, попытка не тратится, в ответ
    возвращается десятичная запись (подсказка «Значение верное, но…»);
  - значение неверное — обычная неверная попытка;
  - `q = 0` — `format`.
- Прочая неверная запись (`normalize_ege_answer` = `null`) — `format`,
  попытка не тратится. Браузер ловит её раньше и подсказывает сам.
- Верно — задача закрыта (`right`). Неверно — попытка засчитана; попытки
  кончились — задача закрыта (`wrong`).
- Ответить нельзя, если задача закрыта (ответ `{kind: 'closed', state}`),
  ДЗ сдано (`already_submitted`) или закрыто репетитором (`homework_closed`).
- При `solutions_when = after_due` после срока отвечать нельзя
  (`due_passed`): решения уже открыты. «Показать решение» тогда тоже
  `due_passed`. В остальных ДЗ ответ после срока принимается — сдано с
  опозданием.
- Школьник до согласия родителя не отвечает (`progress_not_allowed`).
- Время по задаче (`seconds`) копится только с засчитанных попыток, не
  больше 3600 с за раз; в `entries` — первые 20 ответов.
- Ответ: `{kind: 'right' | 'wrong', state, attempts, left, solution}`;
  `left` — сколько попыток осталось (`null` — без ограничения),
  `solution` — разбор, если он уже доступен, иначе `null`.

### Когда ученик видит решение

| `solutions_when` | Решение доступно                                                |
| ---------------- | --------------------------------------------------------------- |
| `instant`        | задача закрыта: верно, попытки кончились или «Показать решение» |
| `after_submit`   | ДЗ сдано или репетитор закрыл ДЗ (`closed_at`)                  |
| `after_due`      | срок прошёл (отвечать тогда уже нельзя — `due_passed`)          |

Репетитор видит решения всегда.
