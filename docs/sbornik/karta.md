# Интерактивный сборник для поступающих в вузы — карта тем

Черновик структуры раздела «Сборник для вузов» (алгебра). Это шаг 1:
ждёт одобрения, кода ещё нет.

**Откуда карта.** Ориентир — классический сборник задач по алгебре для
поступающих в вузы. Его страницы разобраны вручную, по изображениям; сама
книга в репозитории не хранится. Отсюда взяты только **структура**: главы,
группы сложности и типы задач. Номера вида «1.001–1.124» — это диапазоны
задач в исходной книге. Они нужны, чтобы на каждую задачу книги сделать
свою задачу того же типа и уровня. Все описания типов и примеры ниже
написаны заново и с другими числами. На сайт номера книги не попадут.

**Уровни.** Внутри главы в книге три группы сложности: А, Б, В. У нас
это ★, ★★ и ★★★. Обязательный минимум — ★, уверенное знание
школьной программы — ★★, повышенная трудность — ★★★. В главах 10 и
11 групп нет, там уровень ставим сами.

доказал». В статистику верных ответов такие задачи не идут, только в
«решено».

## Движки: что уже есть на сайте и что нужно сделать

Есть: `lib/chast2/sravnenie.ts` и `lib/chast2/vyrazhenie.ts` — разбор
записи (обычный текст или LaTeX из MathLive), сравнение числа по
значению, выражения по точкам, корней без учёта порядка, промежутков по
концам и скобкам, серий на отрезке. Ещё есть общий движок банков и
генераторов (`lib/generator/obshchiy`), листы для печати (`lib/sheet`) и

**Клавиатура на телефоне** (MathLive уже подключён): кнопки √, ⁿ√, дробь,
степень, π, ∞, ∪, ;, |x|, ℤ, °, log, sin/cos/tg/ctg, arc.
Осторожно: в книге запись cos⁻¹x иногда значит 1/cos x. У нас всегда
пишем arccos x и 1/cos x, без этой записи.

**Подсказки и ошибка на шаге.** Решение каждой задачи хранится шагами.
У шага есть подпись, текст и KaTeX, а ещё необязательный «контрольный
ответ шага»: ОДЗ, корни после замены, корни до отбора. В тренажёре
ученик может ввести промежуточный результат. Тогда видно, на каком шаге
расхождение, — как в тренажёрах ЕГЭ.

## Как будет устроен раздел (предложение)

- **Адрес** `/sbornik/`, хвосты адресов — в `lib/paths.ts`. Главы
  `/sbornik/glava-1/` и т. д., вкладки внутри главы: `teoriya/`,
  `zadachi/` (по типам), `trenazher/`, `generator/`.
- **Данные** — `app/src/data/sbornik/glava-NN/*.json` + JSON-схема. У
  задачи: глава, тип, уровень (1–3), условие (KaTeX), ответ и его
  формат (код движка), шаги решения (подпись + текст + KaTeX +
  необязательный контрольный ответ шага), подсказки-вопросы.
- **Генераторы** — `tools/sbornik/` на Python + sympy, по генератору на
  тип. Генератор выдаёт задачу, ответ, считает его, проверяет
  подстановкой, отсеивает «плохие» числа и пишет JSON. Фиксированный
  банк на сайте — это отобранный и вычитанный выход генераторов, по
  одной задаче на каждую задачу книги. На сайте может быть ещё и
  клиентский генератор на TS — как в разделах ЕГЭ, для тренажёра и
  листов.
- **Самопроверка банка** — `tools/sbornik/check.py`: заново считает все
  ответы через sympy, ищет дубли (в том числе с точностью до
  переобозначения), проверяет «плохие» числа (ответ не «хороший»,
  совпадения с заезженными числами), прогоняет условия и шаги через
  KaTeX. В CI — отдельный шаг с Python. Плюс Node-тест: движок
  проверки на сайте принимает эталонный ответ каждой задачи и его
  эквивалентные записи.
- **Объём.** На каждую из 3620 задач книги — своя: это ≈3600 задач в
  банке. Пилот — глава 1 целиком (360 задач, 14 типов).
