# Где осталось слово «репетитор»

Места со словом „репетитор“, которые не менялись: вкладки „Для репетиторов“ в разделах и прочее, что не является ролью аккаунта.

Роль аккаунта в интерфейсе, кабинете, ДЗ, туре и «Как пользоваться» теперь называется «учитель». Внутренний ключ роли `tutor`, адреса `dlya-repetitorov/`, id `repetitory`/`repetitor`, имена файлов и классов CSS не менялись. Комментарии в коде в список не входят. Тариф «Учитель», оферта и подпись роли в форме регистрации переименованы в `main` отдельно (PR #455) и из списка убраны.
