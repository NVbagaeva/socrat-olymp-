# Часть 2 онлайн: ответы, фото решений, проверка учителем

Задания 14–20 в общем онлайн-модуле варианта — тот же экран решения,
что у «Собрать вариант» и «Вариантов повышенной сложности». Часть 2
появляется на ленте после 1–13, если у варианта есть её данные (сейчас —
версия 1.1 раздела повышенной сложности; у «Собрать вариант» генераторов
14–20 пока нет).

## Три режима

| Где открыт вариант | Часть 2 | Баллы |
| --- | --- | --- |
| Без входа или не из кабинета | самопроверка: «Сверить ответ», решение и критерии, свой балл | часть 1 — автоматически, часть 2 — самооценка, тестовый — ориентировочно |
| Работа из кабинета, «проверяю я» | ответы в полях + фото решений, отправка учителю | часть 1 сразу; 14–20 — учитель по критериям; тестовый — после проверки |
| Работа из кабинета, «самопроверка» | ответы + решение и критерии, свой балл | самооценка становится баллами при сдаче, работа сразу «проверена»; учитель может открыть и поправить |

Без входа ученик видит плашку «Войдите, чтобы отправить решение учителю».

## Ученик

- **Поля ответа** (`components/chast2/PoleOtveta.tsx`): формула (MathLive,
  экранная клавиатура на телефоне; шрифты — уже подключённые KaTeX, звуков
  нет, внешних запросов поле не делает), несколько корней, серии
  «x = … , n ∈ ℤ», конструктор промежутков (скобки нажатием, ±∞, точки),
  «да / нет». Нет MathLive — обычное поле, автопроверка понимает и запись
  «7pi/2».
- **Фото** (`FotoBlok`, `FotoRedaktor`, `lib/chast2/foto.ts`): камера или
  галерея, до 6 фото, порядок — перетаскиванием за ручку или «← →».
  Редактор: поворот на 90°, выпрямление ±15°, рамка обрезки, «как скан»,
  «Отменить всё». Поворот по EXIF, HEIC → JPEG (heic2any, грузится только
  для HEIC), сжатие до 2000 px и ~1 МБ, EXIF удаляется (новый JPEG из
  пикселей холста; сервер перекодирует ещё раз).
- **Очередь** (`lib/chast2/ochered.ts`): фото сначала в IndexedDB, потом
  на сервер по одному — прогресс, автоповтор (3 раза), «Повторить», без
  связи — «ждёт связи» и отправка при появлении. Переживает перезагрузку.
- Без фото — предупреждение «Без решения задание оценивается в 0 баллов,
  даже если ответ верный».
- **Сохранение ответов**: в кабинет через 0,6 с после правки
  (`lib/raboty/sinhron.ts`); на другом устройстве работа открывается с теми
  же ответами.
- **Перед отправкой** (`RabotaOtpravka`): сводка по 1–13, таблица 14–20
  (ответ, число фото), одна плашка о заданиях без фото, ожидание фото в
  пути; «Вернуться к работе» / «Отправить учителю».
- **После отправки** (`RabotaItog`): статус «На проверке» → «Проверено»
  (или «На доработке»), часть 1 окончательно, часть 2 «на проверке»,
  плашка «Полное количество баллов будет после проверки учителем». После
  проверки — таблица «№ — балл / максимум — строка критериев —
  комментарий», фото с пометками, эталонные решения, «Работа над
  ошибками» по части 1.

Автопроверка части 2 (`lib/chast2/sravnenie.ts`) сравнивает по значению:
числа с допуском, выражения по значениям в точках, корни без порядка,
промежутки по концам и скобкам, серии как множества. Не разобралось —
«ответ проверит учитель». Ученику до проверки показывается только
«совпадает / не совпадает»; это подсказка учителю, не балл.

## Учитель

Страницы кабинета (`page.dev.tsx`, пока у сайта нет сервера — только
`next dev` и сборка с `KABINET=1`):

- `/kabinet/vydat-variant/` — выдать вариант: версия, часть 2 (по фото или
  самопроверка), срок, класс или ученики.
- `/kabinet/raboty/` — «Работы на проверку» со счётчиком, фильтры (ждут /
  на доработке / проверенные / все, по работе, по ученику); выданные
  работы: статусы учеников, продление срока всем или одному, статистика по
  заданиям (средний балл, доля полных и нулей), выгрузка в Excel.
  Ученику — «Мои работы».
- `/kabinet/proverka/?id=…` — проверка: слева фото (листание, масштаб,
  поворот, во весь экран; пометки ручкой, ✓, ✗, текстом — отдельный слой,
  сохраняются сами), справа ответ ученика с автопроверкой, верный ответ,
  решение, кнопки 0…максимум и строки критериев, комментарий (сохраняется
  при уходе из поля), «Вернуть на доработку». Часть 1 — таблица с
  «Засчитать / Снять балл» (помечается «вручную»). Наверху — живой счётчик
  «Часть 1: X / 13 · Часть 2: Y / 20 · Итого: Z / 33 · Тестовый балл: N».
  «Завершить проверку» — только когда оценены все 14–20; задание без
  ответа и фото уже оценено «0 — не приступал». Проверенную работу можно
  открыть снова; история — кто, когда, было → стало.

Excel (`lib/raboty/xlsx.ts`) — свой генератор .xlsx без библиотек; файл
открывают Excel, LibreOffice, Google Таблицы (проверено openpyxl).

## Баллы и шкала

Максимумы — `content/variantOnline/bally.ts`: 1–13 по 1, 14 — 2, 15 — 3,
16 — 2, 17 — 2, 18 — 3, 19 — 4, 20 — 4; всего 13 + 20 = 33. Шкала 0…33 —
последняя шкала Рособрнадзора, равномерно растянутая
(`content/variantOnline/shkala.ts`), везде с пометкой «примерная».
Критерии — `content/variantOnline/kriterii.ts` (демоверсия ФИПИ 2027).

## Сервер

- Миграция `supabase/migrations/20261024120000_raboty_chast2.sql`: работы,
  ответы, фото, пометки, баллы (триггер «не больше максимума»), история
  (триггер), уведомления; RLS и функции `issue_variant_work`,
  `save_answer`, `submit_work`, `start_check`, `set_grade`,
  `override_part1`, `return_task`, `finish_check`, `save_photo_marks`.
  Тесты — `supabase/tests/raboty_chast2.test.sql` (`pnpm test:soglasiya-sql`).
  В `infra/lite/migrations.txt` миграция пока не внесена — вместе с
  миграцией кабинета, когда сервер будет готов.
- Ключи ответов — таблица `variant_keys`, пользователям недоступна.
  Собирает `pnpm build:variant-keys` в `app/pdf-private/` (в .gitignore);
  кнопка «Миграции» при `vars.CHAST2_ENABLED == '1'` собирает их в CI и
  применяет после миграций.
- Сервис загрузки `infra/lite/uploads` (профиль compose `chast2`):
  проверка по содержимому, перекодирование без EXIF, лимиты (6 фото к
  заданию, 3 МБ, частота), временные ссылки на 10 минут, чужое фото —
  404. Срок хранения — до 31 августа или `PHOTO_KEEP_DAYS` дней (не
  дольше); удаление — таймер `budetege-photos`. Бакет — Yandex Object
  Storage (закрытый, РФ). Тесты — `pnpm test:uploads`.
- В браузере до сервера — `lib/raboty/localApi.ts` с теми же правилами
  (`pnpm test:raboty`); с сервером меняется одна строка в
  `lib/raboty/client.ts`.

Политика: проект изменений — `docs/chast2-politika-proekt.md`.
