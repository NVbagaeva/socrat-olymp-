# Задание 5: «Домашняя работа», обновлённое ДЗ №9 и генератор по шаблонам

## Что сделано

1. **Обновлённое ДЗ №9.** 13 задач с новыми сюжетами и числами. Ход решения у каждой задачи тот же, что у задачи с тем же номером в исходном ДЗ.
2. **Вкладка «Домашняя работа»** в задании 5: `/zadaniya/5/domashnyaya-rabota/`.
   - Учитель нажимает «Выдать ДЗ» и выбирает источник задач:
     - готовое ДЗ — есть два набора, исходное и обновлённое ДЗ №9, задачи отмечаются галочками;
     - генератор — задаётся тип задачи и количество, кнопка «Сгенерировать заново» даёт новые задачи.
   - Выданное ДЗ открывается с шапкой «Домашнее задание · Задание 5 ЕГЭ · Теория вероятностей · дата». Под шапкой три отдельных листа: «Печать / PDF для учеников», «Ответы», «Решения».
   - Нумерация задач сквозная.
   - Пометка типа задачи видна только на экране учителя: на листы она не попадает, при печати экрана прячется.
   - Если отмечена задача «в условиях предыдущей задачи…», предыдущая задача добавляется сама, и экран об этом предупреждает.
   - Выданное ДЗ сохраняется в браузере и переживает перезагрузку страницы.
3. **Генератор задания 5 устроен как генератор графиков (№12).**
   - Тот же экран `GeneratorScreen`: вид работы и дата, карточки шаблонов с миниатюрами, параметры листа.
   - Тот же блок комплекта `KitBar`: код комплекта (seed), «Новый комплект», «Мои комплекты».
   - Листы ученика и учителя: `/zadaniya/5/shablony/pechat/` и `/zadaniya/5/shablony/pechat/otvety/`.
   - Прежний генератор по прототипам банка остался вторым режимом на той же вкладке.
4. **13 шаблонов** — по одному на каждый тип задачи из ДЗ №9.
   - У шаблона есть параметры с ограничениями и по 2–3 сюжета.
   - Ответ считается точно, в дробях на BigInt, и записывается по правилам ЕГЭ: конечная дробь не длиннее 4 знаков, иначе округление до сотых. Если ответ округляется, в условие сама добавляется фраза «Ответ округлите до сотых».
   - Генератор не выдаёт ответ, у которого до спорного значения «…5» остаётся меньше 0,1 шага округления.
5. **Автотест** `pnpm test:dz5` (`app/scripts/check-dz5.mjs`). Каждый шаблон генерируется 1000 раз, и проверяется:
   - ответ-вероятность лежит в (0; 1), ответ «во сколько раз» — в (0; 1000];
   - округление совпадает с независимым пересчётом;
   - в тексте нет пустых подстановок, «формул обычным текстом» и сырого TeX;
   - каждая формула разбирается KaTeX;
   - на диаграмме Эйлера столько точек, сколько сказано в условии;
   - одинаковый seed даёт одинаковую задачу;
   - выпадают все сюжеты шаблона;
   - ответы обоих наборов совпадают с ключом;
   - ДЗ из генератора собирается по плану типов.
