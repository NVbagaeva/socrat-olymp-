# Подписи точек и подробные решения — график корня (№12)

Скриншоты «до» и «после» лежат в `docs/audit/podpisi-i-resheniya-12/`
(`do-*` — `main`, `posle-*` — эта ветка; 390 и 1440 px).

## Баг 1. Подписи точек наезжают на кривую

**Что было на самом деле.** Чертежи, которые строит движок (условие, подсказка,
решение, лист учителя), подписи уже ставили без наездов. Наезды были на
рисунках теории: там подписи стояли по ручным смещениям `dx`/`dy`, а кегль на
телефоне не опускается ниже 11 px, поэтому рамка подписи в единицах чертежа
выходила больше, чем рассчитывал автор.

**Что сделано.**

- Новый общий модуль `src/lib/graph/labels.js`: автоматическое размещение
  подписи точки. Кандидаты: справа-снизу, слева-сверху, справа-сверху,
  слева-снизу, затем дальше (кольца 1 → 4,4 радиуса, плюс боковые положения).
  Для возрастающей выпуклой вверх кривой порядок «справа-снизу, слева-сверху,
  справа-сверху, слева-снизу», для убывающей — «справа-сверху, слева-снизу,
  справа-снизу, слева-сверху». Это порядок перебора; решает проверка.
  Берётся первое положение, у которого рамка не пересекает: кривую (точно, по
  отрезкам ломаной, а не по узлам), оси, подписи делений и названия осей,
  штриховые линии построений, чужие подписи, чужие точки и границу рисунка.
  Нет места рядом — подпись отодвигается и к точке идёт короткая выноска.
- Прежнее положение сохраняется, если оно уже удовлетворяет всем условиям
  (иначе менялись бы все PDF и привычные рисунки): новый перебор включается
  только при нарушении.
- `src/lib/graph/renderer.js` ставит подписи через этот модуль и рисует под
  текстом белую плашку с полями 2/1 px; выноска — тонкая линия от кружка
  точки к плашке.
- Рисунки теории: `src/lib/theoryLabels.ts` (раскладка на сборке) и
  `KatexFigure.tsx` (подписи по центру рамки, слой выносок). Подписи точек в
  `theoryFigures.ts` помечены `auto: true`; размер рамки берётся с запасом на
  минимальный кегль телефона. Окно рисунка «Начало графика» расширено, чтобы
  для `(x₀; y₀)` нашлось место.

**Автотест** `scripts/check-point-labels.mjs` (`pnpm test:point-labels`,
подключён в CI). Берёт все семейства и наборы из реестра прототипов
(`data/prototypes/*`, `data/prep/*`) × серии seed в режимах «сайт», «условие»,
«лист учителя», а также все рисунки теории. Независимый проверяющий код
(`scripts/lib/graph-label-checks.mjs`) смотрит наезды подписей на кривую
(выборка через 1 px), оси, штриховые построения, друг на друга и край.
Тест падает при любом наезде; в него встроена проверка на мутации (подпись
намеренно сдвигается на кривую — тест обязан это поймать). Результат на
стандартных seed: чертежей 62 580, рисунков теории 20, ошибок 0.
Для телефона отдельно работает DOM-тест `pnpm test:theory-labels` (живая
вёрстка KaTeX при 390 и 1440 px).

## Баг 2. Решение — подробно, словами

`src/lib/graph/solution-sqrt.js` (генерируемые решения: условие, тренажёр,
лист учителя) и `src/content/theoryIrrational.ts` (теория 4.1–4.3, примеры)
переписаны по шаблону:

1. (только у сдвинутого графика) «Находим начало графика (x₀; y₀)» и запись
   формулы после сдвига.
2. «Берём точку в узле сетки» — слова и точка.
3. «Находим k» — подстановка словами, перенос слагаемого, деление, затем
   «формула теперь выглядит так».
4. «Что нужно найти» — значение функции: подстановка, корень по шагам
   (6,76 = 676/100, 676 = 26², проверка умножением 26·26), умножение «умным»
   способом названо словами (на дробь 3/2: разделить пополам, потом ×3;
   целое на дробь — по частям), прибавление y₀; для обратной задачи —
   перенос, деление, возведение в квадрат. Каждая цепочка доведена до числа.
5. «Проверка на адекватность и ответ» (блок проверки не менялся).

Формулы теперь выводятся в строчном режиме KaTeX с `\displaystyle`:
выкладка переносится по знакам «=» и «·» на телефоне, а не обрезается.
Идентификаторы шагов (`start`, `point`, `k`, `asked`, `answer`) сохранены,
подсказки тренажёра работают как раньше. Для «корня и прямой» к шагам `k` и
`line` добавлены словесные пояснения и строка «формула теперь выглядит так».

Автоматические проверки (`scripts/lib/graph-sqrt-checks.mjs`,
`pnpm test:graph-sqrt`): шаг не начинается с формулы, нет двух формул подряд
без фразы, нет оборванных формул, после `k` есть фраза про вид формулы,
последняя формула шага «Что нужно найти» заканчивается числом из ответа.

## Проверка остальных разделов №12 (прямая, парабола, гипербола)

Разбор по всем наборам (шаги, формулы, оборванные формулы): ни одного шага,
начинающегося с формулы, ни одной оборванной формулы. Не по шаблону (не
менял: правка затрагивает три модуля и подсказки, объём большой):

- **Прямая** (`solution.js`): после «Находим k» нет строки «формула теперь
  выглядит так» — полная формула появляется только на шаге «Записываем
  формулу».
- **Парабола** (`solution-quadratic.js`): после `a`, `c`, `b` нет
  промежуточной записи `y = ax² + bx + c` с подставленными найденными
  значениями; в шаге 7 подстановка `(5 + 1)² − 1` показана как `(6)² − 1`.
- **Гипербола** (`solution-rational.js`): в шаге `k` «значит k = x·y» без
  объяснения (обе части `y = k/x` умножаем на `x`); «умножим на 2, чтобы
  избавиться от дробей» без показа, как именно меняются коэффициенты.
