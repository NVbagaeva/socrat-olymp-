# Задание №12: единые названия разделов

**Правило.** Заголовок раздела — название ФУНКЦИИ, подпись — название ГРАФИКА
в виде «График — …».

| Заголовок | Подпись |
|---|---|
| Линейная функция | График — прямая |
| Квадратичная функция | График — парабола |
| Дробно-линейная функция | График — гипербола |
| Иррациональная функция | График — ветвь параболы |
| Показательная функция | График — экспонента |
| Логарифмическая функция | График — логарифмическая кривая |
| Тригонометрические функции | Графики — синусоида, косинусоида, тангенсоида |

Порядок везде один, как в таблице. Адреса страниц и `id` разделов не менялись
(`rational` остаётся `rational`: адрес `/zadaniya/12/rational/` прежний).
Иконки не менялись.

## Где хранятся названия

В одном месте: `app/src/data/functionTypes.ts`. У каждого раздела три поля:

- `title` — название функции;
- `graphName` — название графика;
- `icon` — имя файлов иконки (было и раньше, но жило в отдельном объекте
  `razdel` рядом с дублями названий).

Убраны дубли названий:

- `razdel: { title, caption, icon }` — отдельные названия для меню;
- `shortTitle` — короткое название, нигде не использовалось;
- `sheetTitle` — название раздела для листа печати;
- `head: { subtitle }` в `content/quadratic.ts`, `content/rational.ts`,
  `content/irrational.ts`: теперь это признак `head: true`;
- `about.title` у этих трёх разделов: заголовок вкладки «О задании» берётся из
  `title`.

## Проверка

`pnpm test:razdely-names` (в CI, два шага):

- **`--src`, до сборки:**
  - список разделов дословно совпадает с таблицей и идёт в её порядке, `id`
    прежние;
  - название в `content/sheet12.js` равно названию линейной;
  - в исходниках нет строк, куда название раздела вписано руками мимо
    `data/functionTypes.ts` (комментарии и проза теории не считаются).
  - Проверено подложенным файлом: сканер его ловит.
- **`--site`, после сборки** (1504 проверки на страницах `/zadaniya/` и
  `/zadaniya/12/**`):
  - нигде нет прежних названий («Прямая и её наклон», «Иррациональная функция
    (график корня)», «График квадратного корня», «Линейные функции»,
    «Квадратичные функции», «Показательные функции», «Логарифмические функции»…);
  - подписи карточек не из таблицы или прежние («Обратная пропорциональность»,
    «Парабола», «Гипербола» как подпись) не встречаются;
  - в данных страниц 7 пар «название → подпись» идут в порядке таблицы;
  - в шапке стоит подпись графика, в крошках — название раздела;
  - `title`, `description`, `og:title`, `og:description` — из таблицы;
  - страница выбора разделов: все семь пар по порядку.
  - Проверено подложенной разметкой: прежнее название и прежняя подпись
    ловятся.

  видит.
