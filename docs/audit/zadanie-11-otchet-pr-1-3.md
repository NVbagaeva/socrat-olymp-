## PR 1. «О задании»

- Карточка раздела на карте **раскрывается во вступление** по единой схеме:
  что это → зачем и где на ЕГЭ → 3–4 главных пункта → «Теперь — задачи»
  с кнопками «Теория раздела», «Опорные задачи: N блоков», «Решать в
  тренажёре». Тексты девяти вступлений — из отчёта аудита
  (`VSTUPLENIYA_11` в `content/zadanie11.ts`).
- Под вступительным текстом **три кнопки маршрута**: «Начать с разминки»,
  «Проверить себя» (8 задач как вариант ЕГЭ, по одной из каждого раздела),
  «Я учитель» (генератор).
- «С чего начать» — шаги с кнопками «Начать» / «Прочитать»; список
  «Порядок изучения» убран (карта и есть порядок).
- На телефоне карточки карты — компактные строки: девять разделов
  помещаются на полтора экрана.
- Под кольцом прогресса — из чего складываются шаги (разделы теории ·
  опорные задачи · типы задач).
- Переходы работают по адресу: `opornye-zadachi/?razdel=SM` открывает
  список сразу на разделе, `trenazher/?tipy=…&n=8` отмечает типы и число
  задач.

## PR 2. Теория

- **Единая схема раздела** и одинаковые подпункты в содержании для всех
  девяти разделов: Что это и зачем → Формулы → Таблица → Лайфхаки → Ловушки
  → Типы задач → Теперь — задачи (опорные блоки раздела и кнопка в тренажёр).
  Вступление — то же, что в карточке на «О задании».
- Новый раздел **«Быстрый счёт»** (пункт 2 содержания): квадратные
  уравнения через вынесение множителя из-под корня и D/4, умножение на 11,
  квадрат числа на 5, сокращение вместо деления и признаки делимости.
  Каждый приём — правило → пример по шагам → «попробуй сам» (2–3 задания
  с проверкой на месте, после промаха можно открыть ответ).
- **«Прогрессии»**: что такое последовательность, что такое прогрессия и
  зачем, какие бывают (d и q), n-й член, сумма, как узнать задачу; три
  ловушки (номер и значение члена, дробные дни, член или сумма).
- **«Как устроено задание»**: три таблицы-образца (движение, работа,
  концентрация) вместо описания словами.
- Сводные «Лайфхаки» и «Ловушки» в конце — списки ссылок в разделы;
  карточка получает якорь по первому вхождению (ссылки из тренажёра
  работают).
- Плитки типов задач без кодов (код — во всплывающей подсказке).
- Самотест проверяет формулы приёмов и что ответы «попробуй сам» — числа.

## PR 3. Опорные задачи

- У каждого из 12 блоков — строка **«Зачем»** на карточке и под заголовком
  блока (`content/opornye11.ts`).
- В блоке под заголовком — сворачиваемая панель **«Теория к этому блоку»**:
  правило → пример; плашка «Запомни» переехала внутрь. Панель открывается
  кнопкой и сама после первой ошибки.
- При фильтре по разделу над списком — абзац **«что уметь до раздела и
  почему»**: «Перевод единиц» под «Окружностью» теперь объяснён.
- После 10/10 — **«Блок пройден»**: теория раздела, следующий блок, задачи
  ЕГЭ раздела в тренажёре.
- **Проценты по методике** в блоках 01 и 02: «за 100 % — то, с чем
  сравниваем (слово после „чем“)», краткая запись двумя строками

  В «Теории к блоку» — оба способа и для процента от числа, и для числа по
  проценту.
- Самотест проверяет новые тексты (KaTeX, без знака равносильности).
