# Задание 11 — проверки перед слиянием PR 4–12

Ветка `claude/task11-text-problems-5r1g7e`: коммиты PR 1–12 аудита, слияние
с `main` и правки по замечаниям. Отчёт по PR 4–12 —
`docs/audit/zadanie-11-otchet-pr-4-12.md`.

## 0. Слияние с main

Ветка аудита была начата до #116 (проценты: краткая запись → x →
пропорция → сокращение). При слиянии:

- проценты (`prototypes/pr.ts`, `prototypes/rz.ts`, разминка в
  `prep/bloki.ts`) — версия `main`;
- самотест процентов — `checkProcenty` из `main`;
- адреса страниц №11 — от `ZADANIYA` (у `tasksPage.href` теперь «/» на
  конце, иначе получалось `//`).

## 1. Проценты: строка «Иначе»

В ветке аудита строка «Иначе» была у ПР-01 и РЗ-11:

> **Иначе:** $0{,}87x=191\,400$, $x=191\,400:0{,}87=220\,000$.

У ПР-04 и РЗ-10 её не было. После слияния с #116 строки «Иначе» нет, но
оставались замечания «то же самое одним делением — $x=6630:0{,}85$» у
ПР-01, РЗ-10, РЗ-11 и у микрозадачи разминки. Они убраны: проценты
решаются только схемой сайта.

Самотест (`checkProcenty`) запрещает у задач на проценты строки
«Иначе», «другой способ», «Замечание», уравнение с десятичным множителем
($0{,}87x=\ldots$) и деление на десятичный множитель. Проверено, что
запрет срабатывает: если вернуть строку «Иначе» в ПР-01, самотест
сообщает о ней на задачах банка.

## 2. «Найди ошибку»: ошибка доведена до ответа

Было: ошибка меняла ровно одну строку нашего разбора, всё после неё
оставалось верным.

Стало: ошибка вносится в модель задачи. Подтип решает задачу так, как
решил бы ученик с этой ошибкой (`solve({ ...params, osh: id })`,
`Subtype.oshibki`). Таблица, уравнение, корни и ответ после ошибочной
строки посчитаны из неё, в строке «Ответ» — неверный ответ ученика. Из
работы ученика убраны пояснения методики: карточки правил, плашки, «почему
пропорция», лайфхаки, второй способ — в тетради их не бывает.

| Раздел | Подтипы | Ошибка |
|---|---|---|
| Проценты | ПР-01, ПР-04, РЗ-10, РЗ-11 | снижение записано как повышение: $100\%+p\%$ |
| Смеси | СМ-01 | вода не прибавлена к раствору |
| Смеси | СМ-04 | масса третьего сплава $2x$ вместо $2x+d$ |
| Вода | ВД-05 | стоянка не вычтена из времени |
| Протяжённые тела | ПТ-02 | скорости навстречу вычли; путь «мимо» без длины второго поезда |
| Окружность | ОК-01 | $40$ мин записали как $0{,}4$ ч |
| Прогрессии | ПГ-01 | в сумме потеряно деление на $2$ |
| Разные | ПР-04, СМ-04, ДП-07, ВД-05, ОК-01, РБ-01 | в ответ записана не та величина |

Если с числами задачи неверный ответ неправдоподобен (бесконечная дробь,
отрицательное число), лист берёт новую задачу того же типа. Ошибка в
модели выбирается раньше, чем «не та величина».

Ученик видит условие, таблицу и шаги работы ученика со строкой «Ответ».
Учитель видит то же и ниже: шаг с ошибкой, что не так, как написано и
как верно, ответ ученика и верный ответ. В таблице ответов —
«Шаг N; ответ …».

Самотест (`test:zadanie11`):

- в каждом разделе есть подтип с ошибками;
- каждая ошибка подтипа есть в словаре;
- на всех задачах банка и 20 новых каждого типа варианта ЕГЭ ошибка
  подбирается;
- для каждой подходящей ошибки ответ ученика ≠ верному;
- в строке «Ответ» — ответ ученика, верного ответа в работе нет;
- работа отличается от верной не одной строкой;
- формулы набираются.

Всего 265 работ, проблем нет.

## 3. Печать

`apt-get install apache2` в контейнере прошёл, `test:print-pages`
запущен как есть. В проверку добавлены три листа №11 в вариантах ученика
и учителя. Проверка колонтитулов теперь идёт по документам: домашняя
работа урока нумеруется отдельно, раньше скрипт смотрел только последний
колонтитул и падал зря.

Адреса листов (`/zadaniya/11/pechat/…`, у учителя `…/pechat/otvety/…`):

- Вариант ЕГЭ — `m=v&i=m&s=PR-04:1,SM-04:1,DP-07:1,PT-02:1,VD-05:1,OK-01:1,RB-01:1,PG-01:1&seed=print-check`
- Урок «Смеси», все блоки и место для решения — `m=o&i=m&s=SM-01:1,SM-02:1,SM-04:1,SM-06:1,SM-07:1,SM-08:1&seed=print-check&b=znat,primer,razminka,zadachi,oshibka,sam,dz&p=1`
- Отработка ДП-07 и РБ-01 по 4 задачи — `m=o&i=m&s=DP-07:4,RB-01:4&seed=print-check`

Результат — «страниц в PDF столько же, сколько в листе, пустых нет», сырого TeX нет:

| Вариант ЕГЭ | ученик | 2 | 2 / 2 / 2 | 2 листа A4 |
| Вариант ЕГЭ | учитель | 5 | 5 / 5 / 5 | 5 листов A4 |

Страница в WebKit везде $295$ мм. Листы №2, №4, №5, №8 и №12 тоже без

Числа страниц у учителя не совпадают с таблицей отчёта PR 12. Там

поле для решения и домашняя работа. Напрямую числа сравнивать нельзя.

Замечание без правки: в уроке у ученика блок «Найди ошибку» высокий и
переносится на следующую страницу целиком, поэтому на предыдущей
остаётся пустое место.

## 4. iPhone (WebKit)

`npx playwright install --with-deps webkit` поставился без ошибок
(WebKit 26.6).

- `test:sticky-tabs` в Chromium и WebKit (1280×800 и 390×844):
  72 проверки, ошибок нет. До правки была одна ошибка: в WebKit первый
  щелчок по пункту содержания теории №11 приходил раньше, чем страница
  оживала, и терялся. Теперь проверка повторяет щелчок до 3 с.
- Новый сценарий `test:trenazher11` (`scripts/check-trenazher11-webkit.mjs`):
  тренажёр №11 в WebKit, iPhone 13, 390×844, касания. 13 шагов, ошибок
  нет:
  - выбор типов;
  - липкая «Начать тренировку» над нижней навигацией;
  - после старта экран встаёт на условие, а не на шапку раздела;
  - неверный ответ подсвечивает карточку «Не получается?»;
  - верный ответ даёт «Верно!»;
  - на следующей задаче экран снова на условии;
  - горизонтальной прокрутки нет.

  Верный ответ сценарий берёт так же, как ученик: из «Показать решение»
  во втором проходе по тем же задачам. В браузер ответы уходят только
  отпечатками.
