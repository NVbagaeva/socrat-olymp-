# Раздел «Варианты повышенной сложности»

36 вариантов в формате ЕГЭ-2027 (часть 1 — задания 1–13; часть 2 — этап 2),
к каждому шесть версий: `k.1` — основная, `k.2…k.6` — параллельные с другими
числами. Всего 216 версий. Адрес раздела — `/povyshennye/`, вход с главной
(рядом с плашкой «Собрать вариант»), над банком заданий и из меню.

## Что откуда

| Что | Где |
|---|---|
| Данные версий: только шаблон и замороженные параметры, без ответов | `app/src/lib/povyshennye/dannye/vNN.ts` |
| Шаблоны: запись → задача онлайн-модуля (`VariantTask`) | `app/src/lib/povyshennye/shablony.ts` |
| Набор версий как партия «Собрать вариант» (`VariantSet`), код `PV-07` | `app/src/lib/povyshennye/set.ts`, `kod.ts` |
| Экран: сетка 36 карточек, статусы, фильтр, печать, статистика | `app/src/components/povyshennye/PovScreen.tsx` |
| Тексты | `app/src/content/povyshennye.ts` |

Шаблон задачи живёт в модуле своего раздела и строит условие, рисунок,
ответ, решение учителя, разбор и подсказки движками раздела:

| Задание | Шаблон в разделе |
|---|---|
| №1 | `lib/planimetriya/stseny/povyshennye.ts` + `reshenie/povyshennye.ts` (прототипы от 101; `prototip(id)` и `reshenie(id)` их находят, в реестр `PROTOTIPY` они не входят) |
| №2 | `lib/vektory/povyshennye.ts` |
| №3 | прототип раздела `P03-86` |
| №4, №5 | `lib/veroyatnost/povyshennye.ts` (прототипы вне `BANK_4`/`BANK_5`) |
| №6 | прототип раздела `P08` |
| №7 | `lib/zadanie7/prototypes/povyshennye.ts` (вне `PROTOTYPES`) |
| №8 | `lib/vychisleniya/povyshennye.ts` |
| №9 | `lib/proizvodnaya/povyshennye.ts`; запрос `max-na-otrezke` в `reshit.ts` |
| №10 | прототип раздела `P17`; коэффициент при $t^2$ — параметр `g2` (у банка 5) |

| №13 | `lib/zadanie13/proto/povyshennye.ts` + `generateFixed` в `generate.ts` |

В банки разделов, тренажёры и «Собрать вариант» шаблоны не входят.

## Онлайн-режим и листы

Отдельного решателя нет. Версия `k.v` — это вариант `v` набора с кодом
`PV-kk`: `loadSet` (lib/variant/online/work.ts) и лист печати
(`VariantPrint`) узнают код раздела и берут набор из `lib/povyshennye`.
Поэтому лента номеров, клавиатура, режимы «Тренировка» и «Как на ЕГЭ»,
пауза, итоги, код результата, шкала перевода, статистика и печать трёх
листов — те же, что у «Собрать вариант». «Работа над ошибками» берёт
аналог из соседней версии (то же задание, другие числа).

Печать версии: `/variant/pechat/?kod=PV-01&v=3&list=uchenik|uchitel|razbor`.

## Проверки

```
pnpm test:povyshennye                         # сборка всех версий, формат ответа, второй счёт, повторы
pnpm test:povyshennye --report                # таблица «вариант — задание — прототип — откуда»
node scripts/check-povyshennye.mjs --json /tmp/pv.json && python3 -I scripts/check_povyshennye.py /tmp/pv.json   # sympy
```

Каждая версия проверяется двумя независимыми способами: решатель шаблона
(движок раздела) и прямой пересчёт (перебор, подстановка корня,
численный счёт, бисекция по графику; отдельно — sympy). Внутри варианта
шесть версий различаются числами у каждого задания; одинаковых задач
среди всех версий нет.
