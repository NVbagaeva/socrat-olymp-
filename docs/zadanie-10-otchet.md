## PR1 — банк прототипов и галерея

### Что сделано

- `app/src/lib/zadanie10/` — модель раздела по образцу №11: прототип —
  одна функция `solve(params)`, она строит «Дано», подписанный разбор,
  панель «Считаем с умом» и подсказки-вопросы с кнопками. Те же функции
  решают задачи ФИПИ и аналоги.
- Разбор у всех задач — одинаковые подписанные этапы (алгоритм п. 3
  задания): **1) Что дано** (таблица величин с единицами) → **2) Что ищем
  и что подставляем** → **3) Решаем уравнение / неравенство** → **4)
  Выбираем корень по смыслу** (почему второй не подходит) → **5)
  Переводим единицы** (часы → минуты и т. п.) → **6) Проверка здравым
  смыслом**; последняя строка — ответ. Этапы 4–5 есть там, где они
  нужны по задаче.
- `app/src/data/zadanie10/fipi.json` — **160 задач ФИПИ** из стороннего
  задачника (Блок 1, задачи 1–160; в задачнике это «Задание 09», у нас
  №10). Условия — как в банке, формулы размечены `$…$` для KaTeX.
- `app/src/data/zadanie10/analogi.json` — **680 аналогов** (по 20 на
  каждый из 34 прототипов), подбор детерминированный:
  `pnpm build:bank-10` (`scripts/build-bank-10.mjs` →
  `lib/zadanie10/bank/analogi.ts`). Каждый аналог помечен «не из
  открытого банка»; 10 из 20 — современные сюжеты (дрон, электросамокат,
  смартфон, павербанк, спорт, космос, 3D-принтер…), формулы и физика те
  же.
- Галерея банка — **только разработка**: `/styleguide/zadanie-10/`
  (оглавление со статистикой) и `/styleguide/zadanie-10/П…/` (задачи,
  ответы, разборы, подсказки). Файлы `page.dev.tsx`: маршрутом они
  становятся только в `next dev` или со флагом `GALEREYA=1`
  (`GALEREYA_10=1`) в `next.config.ts`. В обычной сборке маршрута нет,
  адрес отдаёт **404** — `pnpm test:dev-pages` (шаг CI после сборки).
- `pnpm test:prikladnye` (`scripts/check-prikladnye.mjs`, шаг CI):
  - пересчёт ответов: ответ решателя = ответ в банке; для ФИПИ ответ в
    JSON посчитан **отдельной программой** (независимо от решателей) —
    две реализации сходятся на всех 160 задачах;
  - аналоги: ровно 20, из них 10 современных; файл совпадает с повторным
    подбором (иначе «файл устарел»);
  - распределение ответов: не меньше 12 разных из 20, ни один не чаще
    2 раз (исключения — ниже, с причиной);
  - отпечатки «прототип + числа условия» не повторяются во всём банке
    (в том числе аналог ≠ задача ФИПИ);
  - диапазоны величин (правдоподобность сюжета) для каждого аналога;
  - ответ ЕГЭ: положительный, целый или конечная дробь (≤ 3 знаков);
  - формулы условия, разбора, «Дано», подсказок и вычислений: KaTeX в
    строгом режиме; нет «1x», «+ −», «−(−», «− −», лишних скобок вокруг
    числа, двойных скобок, умножения на 1; нет NaN/undefined;
  - вне `$…$` нет формул обычным текстом и сырого TeX;
  - этапы подписаны «Шаг N. …», последняя строка — ответ; у подсказок
    варианты разные, верный есть.

### Исключения по ответам (прототип объективно не дотягивает)

| Прототип | Правило | Причина |
|----------|---------|---------|
| П-26 мяч под углом | 2 разных, повтор ≤ 10 | $\sin\alpha\ge\frac{tg}{2v_0}$ с рациональными данными: только $\frac12$ или $1$ → ответ $30^\circ$ или $90^\circ$ (синусы 45° и 60° иррациональны) |
| П-28 соударение | 4 разных, повтор ≤ 5 | $\sin^2\alpha=\frac{Q}{mv^2}$ — четыре табличных значения → $2\alpha=60^\circ, 90^\circ, 120^\circ, 180^\circ$ |
| П-29 мячик над стеной | 3 разных, повтор ≤ 8 | для острого угла $\cos2\alpha$ табличный: $\frac12, 0, -\frac12$ → $\alpha=30^\circ, 45^\circ, 60^\circ$ |
| П-33 дифракция | 10 разных, повтор ≤ 5 | в форме «наименьший угол» ответ только $30^\circ$/$90^\circ$; разнообразие дают задачи на наименьший период |

Остальные 30 прототипов выполняют правило «≥ 12 разных, повтор ≤ 2».
