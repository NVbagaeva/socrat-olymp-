# Иллюстрации к задачам по теории вероятности — партия 2

45 файлов PNG с прозрачным фоном. Стиль единый с первой партией (`prob-illustrations.zip`):
полупрозрачное синее стекло + тёплая оранжевая подсветка; оранжевый — только акцент
(благоприятный исход, выделенный объект, брак, нужная ветвь). Объекты, где важна
узнаваемость (люди, еда, техника), — реалистичные.

Это продолжение библиотеки, а не замена: файлы из первой партии не трогать.

- Все файлы — PNG, RGBA, настоящий альфа-канал (проверено), размеры от 1024 до 1774 px по длинной стороне.
- Дубли по сюжету с первой партией: `dice-two-1-6-grid.png` (у первой партии `dice-two-1-6.png` — без сетки),
  `shooter-four-targets-side.png` (первая партия — `shooter-four-targets.png`),
  `maze-spider-board.png` (первая партия — `maze-spider.png` / `.svg`; для тренажёра приоритет у SVG).
  Это разные картинки, не заменять одну другой.
