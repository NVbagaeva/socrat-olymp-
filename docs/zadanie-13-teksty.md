### Чем опасно

1. Пишут ответ не в тех единицах: считали в тысячах, а условие просит рубли, — это 0 баллов.
2. Считают проценты от суммы кредита, а не от долга на начало периода.
3. Путают сумму изменения долга и платёж: платёж = сумма изменения долга + переплата.
4. В «на сколько процентов больше» берут за $100\,\%$ не ту величину.
5. Во вкладе путают порядок: сначала начисление процентов или сначала пополнение.

## 4. «Что нужно знать»

Формула и маленький пример к ней. Формулы и примеры взяты из теории раздела; пример переплаты
($S = 1000$, $n = 3$, $r = 10$) посчитан заново — проверьте числа.

### Проценты и множитель

| Формула | Пример |
|---|---|
| $k = 1 + \frac{r}{100}$ | $r = 10:\ k = 1{,}1$ |
| $S\cdot k^n$ | $1000\cdot 1{,}1^2 = 1000\cdot 1{,}21 = 1210$ |

### Дифференцированный платёж

| Формула | Пример |
|---|---|
| $\text{платёж} = \text{сумма изменения долга} + \text{переплата}$ | $250 + 75 = 325$ |
| $S_{\text{перепл}} = S\cdot\frac{n+1}{2}\cdot\frac{r}{100}$ | $S = 1000,\ n = 3,\ r = 10:\ 1000\cdot 2\cdot 0{,}1 = 200$ |
| $S_{\text{общ}} = S + S_{\text{перепл}}$ | $1000 + 250 = 1250$ |

### «Поломанный» платёж

| Формула | Пример |
|---|---|
| $S_{\text{общ}} = S + \frac{r}{100}\,(D_0 + D_1 + \dots + D_{n-1})$ | $0{,}1\cdot(800 + 600) + 0{,}2\cdot(400 + 200) = 260$ |

### Аннуитет

| Формула | Пример |
|---|---|
| $Sk^n = x\,(k^{n-1} + k^{n-2} + \dots + k + 1)$ | $n = 3:\ x = \frac{Sk^3}{k^2 + k + 1}$ |
| $\text{долг на конец} = \text{долг}\cdot k - x$ | $2100\cdot 1{,}1 - 1210 = 1100$ |

### Вклад

| Формула | Пример |
|---|---|
| $\text{на конец} = \text{на начало}\cdot k \pm \text{пополнение или снятие}$ | $1\cdot 1{,}1 + 0{,}5 = 1{,}6$ |

### Единицы ответа

| Формула | Пример |
|---|---|
| $1\ \text{тыс.} = 1000\ \text{руб.}$ | $100\ \text{тыс.} = 100\,000\ \text{руб.}$ |
| $1\ \text{млн} = 1000\ \text{тыс.}$ | $1{,}25\ \text{млн} = 1\,250\,000\ \text{руб.}$ |
