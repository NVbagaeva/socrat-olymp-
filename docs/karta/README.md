# «Карта ЕГЭ»

Интерактивная карта заданий в кабинете ученика: `/karta/` (гостю — из
данных браузера) и главная вкладка `/kabinet/`.

## Как заменить фон

1. Положить новый файл как `app/public/images/karta/fon-ishodnik.jpg`.
2. `cd app && pnpm build:karta-fon` — WebP-версии и `fon.json`.
3. Если композиция та же (острова на тех же местах) — готово: контуры
   хранятся в долях от размера 1586 × 992 и растянутся вместе с фоном.
4. Если острова сдвинулись — поправить точки в `tools/karta/zerna.json`
   (по одной внутри каждого острова, в пикселях нового исходника, и его
   размер), запустить `python3 tools/karta/obvesti.py --snimok /tmp/k.png`
   и проверить контуры на сайте: `/karta/?debug=1`. Таблички частей и
   надпись пролива — `MESTA` в `lib/karta/geometriya.ts`.

## Формулы

- **Тип освоен** — в последних 5 попытках типа ≥ 3 верных («верно» — с
  первой попытки, без подсказки, решение не открывалось). Старые счётчики
  без порядка попыток занимают недостающие места в окне в той же доле
  верных, что и в счётчике.
- **Стоит повторить** — в последних 5 попытках типа ≥ 2 ошибок (ошибка
  или открытое решение) либо тип освоен, но не решался > 21 дня.
- **Область освоена** — освоено ≥ 80 % её типов (у №8 — 21 из 26).
  Иначе «в процессе» (есть попытки; процент = доля освоенных типов) или
  «не начато».
- **Рекомендуем следующей** — область «в процессе» с самой свежей попыткой;
  если таких нет — первая неначатая по номеру, сначала часть 1.
- **Путь** — освоенные области по номерам, затем рекомендованная.
- **Прогноз** — по каждому типу p = верных из последних 5 / 5 (недостающие
  попытки — неверные); по области — среднее p; первичный балл =
  Σ балл задания × p, округлён, переведён по шкале сайта на 33 первичных
  (`content/variantOnline/shkala.ts`). Показывается при ≥ 30 попытках в
  ≥ 3 областях.
- **Пролив** — «можно начинать вторую часть» при освоенных ≥ 10 из 13;
  связки в `content/karta/proliv.ts`.

Снимки трёх тестовых учеников — `snimki/`, запись сценария —
`scenariy-karta.webm` (делаются `pnpm test:karta-site --shots … --video …`).
