# Тренажёр с фильтрами · партия 1: №11, №1, №13

План — `01-plan.md`, п. 5. Пилот — `02-pilot-12.md`, генератор — `03-generator.md`.

## Что сделано

### Общее (для всех разделов)

- **Поля раздела** (`TrenazherConfig.dop`): не сужают список задач, а меняют, как задача решается. Показываются переключателями в панели, попадают в ссылку (`d=zadanie.tip`), в сводку и чипами активных фильтров с крестиком. Пригодятся №6 («Формулировка»).
- **Готовые наборы раздела** (`TrenazherConfig.nabory`) — рядом с «Быстрым стартом»: «Определи тип» №13.
- **Подсказка вопросами по шагам** — общий компонент `components/trenazher/ShagiVoprosy.tsx` со своими стилями: им пользуются №11, №1, №13.
- **Ответ после шагов** (`otvetPosleShagov`): у №11, №1, №13 шаги подсказки подводят к уравнению, а число ученик вводит сам. Поле ответа остаётся под подсказкой, верный ответ засчитывается «с подсказкой».
- **Составной ответ** (`gotov`): «Проверить» включается, когда заполнены все части ответа (таблица №13).
- **Ссылки:**
  - прежние `?tip=` и `?tipy=` открывают тренажёр с этими типами;
  - в `?t=` можно указать тему целиком (`?t=A` — все прототипы схемы A).
- **Исправлено:** на телефоне на короткой странице строка фильтров уходила под липкую «Начать тренировку» — отступ внизу теперь учитывает и навигацию сайта.

### №11

- Темы — разделы (проценты, смеси, движение…), чипы — 68 подтипов, ★–★★★.
- Источник:
  - открытый банк ФИПИ;
  - не из банка — разминка и аналоги.
- Список задач — 912: банк, разминка, по десять аналогов на подтип.
- «Похожая задача» — новая задача генератором подтипа.
- В карточке:
  - раздел;
  - условие;
  - лайфхак, теория, опорный блок;
  - подсказка вопросами, с каждым шагом открывается часть таблицы модели;
  - разбор по этапам.
- Незавершённая тренировка прежнего экрана открывается в новом (те же задачи, отметки на местах).

### №1

- Темы — блоки I–X, чипы — 75 прототипов (названия с формулами — KaTeX на сборке), ★–★★★.
- Источник: банк ФИПИ или аналоги (по двадцать на прототип). Список — 1714 задач.
- На каждом вопросе подсказки чертёж показывает слой этого шага.
- В решении — шаги, признаки делимости, сверка, чертёж построений.
- Пауза прежнего тренажёра (свой ключ в браузере) переносится в общую сессию один раз: на вкладке — плашка «Тренировка на паузе», «Продолжить» открывает ту же задачу.

### №13

- Темы — схемы A–D, чипы — 66 прототипов, ★ базовый / ★★ повышенный.
- Источник — у прототипа: из открытого банка ФИПИ или свой.
- Список — банк раздела, 660 задач.
- Поля раздела:
  - **«Задание»: Решить / Определить схему** — выбор схемы по условию; то же даёт набор «Определи тип»;
  - **«Ответ»: Только число / С оформлением** — плагин-таблица: схема, первая строка таблицы (клетки, которые считаются по условию) и число одним ответом. При ошибке подсвечено, что неверно; пояснение говорит, в чём ошибка.
- Ответ в чужих денежных единицах не засчитывается: «число верное, а единицы — нет».
- «Решать в тренажёре» у репетиторов — ссылка `?t=<схема урока>`.
- Незавершённая тренировка прежнего экрана переводится, режимы — в поля раздела.

- Настройки в sessionStorage.
- Планы тренировки (`planSessii`, `planTrenirovki13`).
- Неиспользуемые тексты.
