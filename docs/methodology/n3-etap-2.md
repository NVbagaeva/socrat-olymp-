# №3 · этап 2 · остальные главы теории

На этапе 1 по новой методике была написана глава 2 «Пространство → плоский треугольник». Этап 2 дописывает остальные главы теории №3 — 0, 1 и 3–10 — по новому оглавлению и в оформлении этапа 1: «Идея метода», определения, примеры с живым чертежом в две панели, рамки «Важно», «Лайфхак», «Ловушка» с задачей и ответом.

PR — поверх #236. Ветка: `claude/stereometry-etap-2`.

## Как устроено

Главы описаны данными, а не разметкой. Отображает их один общий компонент.

- `lib/stereo/glavy/tipy.ts` — схема данных главы:
  - разделы;
  - блоки: абзацы, идея, алгоритм, определение, карточка формул, список, формула, пример, «Важно», «Лайфхак», «Ловушка», ряд рисунков, типы задач, шпаргалки.
- `lib/stereo/glavy/glava*.ts` — по файлу на главу. Модели чертежей строятся из тел движка.
- `lib/stereo/glavy/schet.ts` — счёт по координатам для пересчёта ответов: длины, углы, площадь многоугольника и поверхности, объём многогранника и тетраэдра, площадь тела из кубиков.
- `components/stereo/glavy/GlavaMetodiki.tsx` — общий компонент главы. Он собран из блоков этапа 1 (`metodika/Bloki.tsx`): разделы со счётчиком и стрелками, две панели «объёмный чертёж → плоский треугольник», степпер решения, рамки.
- `TeoriyaStereo.tsx` берёт главы из `GLAVY_DANNYE_3`. Разделы главы становятся подпунктами в «Содержании».

Глава 2 осталась своим компонентом из этапа 1.

## Проверка (`pnpm test:stereo-metodika`, раздел 6)

- Ответ каждого примера и каждой задачи в рамке пересчитывается независимо от текста решения. Где есть чертёж, пересчёт идёт по координатам модели: длины, углы, площади граней и сечений, объёмы многогранников.
  - Если данные условия на модели не выполнены (например, ребро не той длины), пересчёт возвращает `NaN`, и проверка падает.
  - «Ответ: $…$.» совпадает с числом.
- Все строки и выкладки набираются KaTeX. В заголовках разделов и карточек формул формул нет: «Содержание» их не набирает.
- Каждый чертёж рисуется в обеих темах и на каждом шаге:
  - подписи не налезают;
  - прямой угол отмечен только там, где он действительно прямой;
  - число шагов модели совпадает с подписями шагов.
- id разделов и примеров не повторяются.

## Сознательные решения и ограничения

- **Часть тела по сектору (глава 5) — без чертежа.** В движке нет тела-сектора, а подставлять случайную картинку нельзя. Раздел объяснён формулой доли и задачами.
- **Ямка в кубе (ловушка главы 4) — без чертежа.** Движок рисует выпуклые тела и ступеньку, а тело с выемкой внутри грани — нет. Ответ $58$ пересчитывается по единичным кубикам.
- **Галерея ракурсов главы 1:**
  - неудачные виды — куб вдоль диагонали, тетраэдр сверху, цилиндр сбоку, пирамида почти сбоку;
  - удачные — те же тела в обычном ракурсе.
- **Плоские пирамиды главы 3 показаны ракурсом пониже.** Высота у них меньше основания, и при обычном ракурсе высота и апофема сливаются.
- **Примеры главы 9 — на чистый счёт, без чертежа**: «Задача → Решение → Ответ».

## Не входит в этап

- Опорные задачи по новым главам (блоки 1, 3–12).
- Упражнения внутри глав с проверкой ответа (как «нажми на чертеже» в блоке 2).
