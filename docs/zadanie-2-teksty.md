### Чем опасно

1. Путают конец и начало: координаты вектора — конец минус начало, иначе обе меняют знак.
2. По рисунку теряют знак: конец левее начала — $x$ отрицательный, ниже — $y$ отрицательный.
3. Считают длину суммы как сумму длин: $\left|\,\vphantom{\vec{b}}\vec{a}+\vec{b}\,\right|\ne\left|\,\vphantom{\vec{b}}\vec{a}\,\right|+\left|\,\vphantom{\vec{b}}\vec{b}\,\right|$.
4. Для косинуса останавливаются на скалярном произведении и не делят на произведение длин.

## 2. «Где теряют балл» — свой текст у каждого типа

Показывается под разобранным примером типа на «О задании».

### A. Длина вектора (значок $\left|\,\vphantom{\vec{b}}\vec{a}\,\right|$)

| Тип | Где теряют балл |
|---|---|
| Длина вектора по координатам | Забывают извлечь корень: $x^2+y^2$ — квадрат длины, а длина — $\sqrt{x^2+y^2}$. И теряют знак при возведении в квадрат: $(-15)^2=225$. |
| Длина суммы или разности | Складывают длины, а не координаты: $\left\|\,\vphantom{\vec{b}}\vec{a}+\vec{b}\,\right\|\ne\left\|\,\vphantom{\vec{b}}\vec{a}\,\right\|+\left\|\,\vphantom{\vec{b}}\vec{b}\,\right\|$. Сначала координаты суммы или разности, потом длина. |
| Длина с целыми коэффициентами | Умножают на коэффициент одну координату из двух или теряют знак: $-8\vec{b}$ — это обе координаты $\vec{b}$, умноженные на $-8$. |
| Длина с десятичными коэффициентами | Ошибаются в десятичных произведениях: $1{,}5\cdot 12=18$, $0{,}8\cdot 9=7{,}2$. Считай каждое произведение отдельно, а потом складывай. |
| Три вектора по координатам | Пропускают один из трёх векторов или знак перед ним: в $\vec{a}+\vec{b}-2\vec{c}$ координаты $\vec{c}$ умножают на $-2$. |
| Длина по рисунку: два вектора | Неверно читают координаты с рисунка: координаты вектора — конец минус начало, по клеткам и со знаком. Конец левее начала — $x$ отрицательный. |
| Длина по рисунку: три вектора | Берут координаты не того вектора или теряют знак у одного из трёх. Выпиши координаты каждого вектора, прежде чем считать комбинацию. |
| По рисунку, десятичные коэффициенты | Две ловушки сразу: знак при чтении координат с рисунка и десятичные произведения. Записывай каждое произведение отдельно. |

### B. Скалярное произведение (значок $\vec{a}\cdot\vec{b}$)

| Тип | Где теряют балл |
|---|---|
| Через длины и угол 60° | Забывают, что $\cos 60^\circ=\dfrac12$, или берут синус вместо косинуса. |
| Длины с корнями, 30° и 45° | Путают $\cos 30^\circ=\dfrac{\sqrt3}{2}$ и $\cos 45^\circ=\dfrac{\sqrt2}{2}$ или не сокращают корни: $\sqrt3\cdot\sqrt3=3$. |
| Скалярное произведение по координатам | Перемножают координаты крест-накрест: $\vec{a}\cdot\vec{b}=x_1x_2+y_1y_2$ — $x$ на $x$, $y$ на $y$. Минус на минус — плюс. |
| Скалярное произведение суммы | Раскрывают скобку не по правилу: сначала координаты $\vec{a}+\vec{b}$, потом скалярное произведение с $\vec{c}$ — или по свойству $\vec{a}\cdot\vec{c}+\vec{b}\cdot\vec{c}$. |
| По рисунку на сетке | Ошибаются в знаке координаты при чтении с рисунка — и скалярное произведение меняет знак. |
| Без сетки, из начала координат | Без сетки координаты читают по отметкам на осях. Векторы выходят из начала координат: координаты вектора равны координатам его конца. |
| Без сетки, не из начала координат | Векторы выходят не из начала координат: из координат конца вычитают координаты начала, а не берут конец как есть. |
| По рисунку: три вектора | Порядок: координаты с рисунка, затем вектор в скобке, затем произведение с $\vec{c}$. Знак в скобке читай внимательно — бывает и $+$, и $-$. |
| По рисунку: $2\vec{a}$ и $\vec{b}$ | Множитель $2$ ставят дважды — и к $\vec{a}$, и к $\vec{b}$. Он стоит только у одного вектора: $\vec{a}\cdot 2\vec{b}=2\left(\vec{a}\cdot\vec{b}\right)$. |

### C. Косинус угла (значок $\cos\alpha$)

| Тип | Где теряют балл |
|---|---|
| Косинус по координатам | Останавливаются на скалярном произведении, а нужен косинус: его ещё делят на произведение длин. Ответ всегда между $-1$ и $1$. |
| Косинус по рисунку | Те же три шага по рисунку: координаты, скалярное произведение, длины. Если косинус вышел больше $1$ по модулю — ошибка в координатах или длинах. |
