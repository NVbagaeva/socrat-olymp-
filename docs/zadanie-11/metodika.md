# Задание 11 «Текстовые задачи» — методика: обозначения, таблицы, ОДЗ

Единый свод правил раздела. Им пользуются движок решений и подсказок
(`app/src/lib/zadanie11`), генератор задач (`app/src/lib/zadanie11/gen`),
теория (`app/src/content/teoriya11.ts`), а в будущем — опорные задачи,
тренажёр, лист учителя и PDF. Нарушения ловит `pnpm test:zadanie11`.
Если где-то в другом месте написано иначе — верно то, что здесь.

## 1. Обозначения

- Неизвестная — всегда `x`, вторая — `y`, третья — `z`. Буквы `v`, `c`, `k`
  неизвестными не бывают (собственная скорость `x`, по течению `x + 2`,
  против течения `x − 2`).
- Сокращение при первом появлении на странице расшифровывается:
  «ОДЗ (область допустимых значений)», «m_в.в. — масса вещества»,
  «m_р-ра — масса раствора», «p % — концентрация». В таблице
  концентрации расшифровка стоит прямо в подписи строки.
- Вся математика — KaTeX (`$…$`).

## 2. Таблицы

| Тема | Столбцы | Строки |
|---|---|---|
| Движение | `S` (путь) · `v` (скорость) · `t` (время), `t = S / v` | участники или участки |
| Работа | `A` (работа) · `p` (производительность) · `t` (время), `t = A / p` | участники |
| Концентрация | участники смешивания | `m_в.в.` · `m_р-ра` · `p %` |

**Работа.** Если объём не дан — «Примем всю работу за 1», и это
пишется в решении.

**Концентрация** — развёрнутая таблица:

- строки сверху вниз: `m_в.в. — масса вещества`, `m_р-ра — масса
  раствора`, `p % — концентрация`; `m_в.в. = m_р-ра · p : 100`;
- столбцы — **римскими цифрами**: `I`, `II`, `III`, `I + II`, `вода`,
  `I + вода`, `I + II + вода`, `I + II + III`; при сушке — названия
  продуктов (`виноград`, `изюм`, `сухое пюре`, `пюре + вода`);
  арабских цифр в подписях столбцов нет;
- уравнение — по строке массы вещества: сумма по столбцам-слагаемым
  равна итоговому столбцу;
- **равные массы** — вторая таблица `I*`, `II*`, `I* + II*`: каждого
  раствора по `m`, итог `2m`, концентрации `x`, `y`, `z`; под таблицей
  полный ход: `(x/100)·m + (y/100)·m = (z/100)·2m`, делим на `m`
  (`m ≠ 0`), получаем `x + y = 2z`; в решении — строка
  «**Сокращаем на m**».

## 3. Дробно-рациональные уравнения

Если неизвестная стоит в знаменателе:

1. Сразу после уравнения — шаг **«ОДЗ»**: отдельной строкой «ОДЗ
   (область допустимых значений): x ≠ 0, x ≠ −3 — знаменатели не
   равны нулю» и отдельной строкой «По смыслу задачи: x > 0»
   (или `x > 3`, если есть скорость `x − 3`; `0 < x < v` для скорости
   течения).
2. Шаг **«Решение»**: «Умножим обе части на x(x + 3) ≠ 0 (по ОДЗ):».
   Знаки «⇔», «равносильно» при умножении на знаменатель запрещены;
   равносильность — только системой с ОДЗ.
3. Шаг **«Отбор корней»**: каждый корень сверяется с ОДЗ и с условием
   по смыслу, явно сказано, какой отброшен и почему.
4. Подбор корня (`x(x + d) = S`, делители числа) — только со строкой
   «Других подходящих корней нет» (второй корень по Виету отрицателен
   или левая часть возрастает при `x > 0`).
5. Подсказки: вопросы «Какие значения x недопустимы?» и «Какой корень
   подходит?» с кнопками.

То же правило действует в задании 12 (гипербола): шаги «ОДЗ» и «Отбор
корней» в решении и подсказке (`app/src/lib/graph/solution-rational.js`,
`hints-rational.js`).

## 4. Где это проверяется

`app/src/lib/zadanie11/selftest.ts`:

- `checkTablitsa` — порядок столбцов, строки концентрации с
  расшифровкой, римские цифры в столбцах;
- `checkMetodika` — вид таблицы по разделу, «примем всю работу за 1»,
  таблица `I*`, `II*`, `I* + II*` и сокращение на `m`;
- `checkOboznacheniya` — буквы `c`, `k`, `v` вместо `x` / `y`;
- `checkDrobnye` — шаги «ОДЗ» и «Отбор корней», строка «умножим …
  ≠ 0 (по ОДЗ)», вопросы подсказки, обоснование подбора, запрет
  знака равносильности.

Проверки идут по всем задачам банка, разминки и по 200 новым задачам
генератора на подтип; теория проверяется в `app/scripts/check-zadanie11.mjs`.
