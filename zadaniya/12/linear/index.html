Задание №12

Графики функций

В задании №12 вам могут предложить найти значение функции, аргумент или координаты точки пересечения графиков. Ниже — самые типичные формулировки этого задания.

Разные функции — разные истории, но одна идея: график всегда говорит правду.

Возможные формулировки

  • 01

    Найти значение функции

    Найти y, если известен x.

    f(x)=2x+3f(x) = 2x + 3f(x)=2x+3

    Найдите f(4).

  • 02

    Найти аргумент

    Найти x, если известно y.

    f(x)=2x+3f(x) = 2x + 3f(x)=2x+3

    Найдите x, если f(x) = 11.

  • 03

    Найти абсциссу точки пересечения

    Найти x точки пересечения графиков функций.

  • 04

    Найти ординату точки пересечения

    Найти y точки пересечения графиков функций.

Что нужно уметь для задания №12

  • Читать график функции
  • Находить значение функции по графику
  • Находить аргумент по заданному значению
  • Находить координаты точки пересечения графиков
  • Понимать основные виды функций
  • Определять свойства графика
