# Движок графиков, задание №12

Чистый JavaScript без сборки: модули работают и в Node (генерация,
проверка), и в браузере (страница сама загружает наборы и генерирует
по seed).

## Слои

| Файл | Что делает |
|---|---|
| `renderer.js` | чертёж: `renderGraph(scene) -> строка SVG`. Без зависимостей и предметной математики |
| `families/line.js` | семейство «прямая»: точные дроби, целые точки, окно, различимость наклонов |
| `triangle.js` | треугольник наклона: вершина прямого угла, катеты, дуга, зона подписи |
| `solution.js` | разбор из пяти шагов: структура шагов и блоков, без DOM |
| `animate.js` | показ разбора по шагам поверх готового SVG |
| `math.js` | набор формул: курсивные переменные, дроби, `data-tex` для KaTeX |
| `katex-boot.js` | подстановка вёрстки KaTeX вместо собственного набора |
| `generate.js` | сборка варианта: `generate(id, seed)`, `analysis(id, seed)` |
| `validate.js` | проверка всех правил; ненулевой код возврата валит сборку |
| `preview.html` | визуальный контроль: наборы, seed, разбор с эмуляцией попытки |

Данные — в `prep/12/` (подготовка) и `prototypes/12/` (прототипы ФИПИ).
Ответы — в `answers.json`, разделами, которые нигде не складываются.

## Команды

```bash
node graph/validate.js        # проверка; код возврата 1 при нарушении
node graph/generate.js build  # пересобрать answers.json
node graph/generate.js P12-1-03 [seed]
python3 -m http.server        # затем открыть /graph/preview.html
```

## KaTeX

Формулы набираются своими средствами и читаются без сторонних
библиотек, а KaTeX улучшает набор поверх: `katex-boot.js` заменяет
каждый `<span class="math" data-tex="…">` его вёрсткой.

**В приложении** (там, где есть сборка) KaTeX ставится обычной
зависимостью:

```bash
pnpm add katex
```

и подключается импортом:

```js
import katex from 'katex';
import 'katex/dist/katex.min.css';

window.katex = katex;          // либо GraphKatex.upgrade(root, katex)
GraphKatex.upgrade(document);
```

Копии библиотеки в репозитории нет и не нужно: `katex-boot.js` сам
видит уже подключённый экземпляр и ничего не загружает.

**В автономном `preview.html`**, который открывают без сборки, KaTeX
подключён с CDN прямо в разметке страницы — две строки в `<head>`.
Это единственное место, где используется CDN.
