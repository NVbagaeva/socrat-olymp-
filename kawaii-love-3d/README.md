# Спасибо, что ты рядом · 3D 🌙❤️

3D-мультфильм (~44 с, 1080×1920) на Three.js: два пушистика с мехом из оболочек (shell texturing),
глянцевая чёрная машинка с пластырем, луна с лицом, светлячки, сердечки, кинематографичная камера.

- `index.html` — вся анимация в одном файле. Three.js 0.186.1 подключается через importmap с jsdelivr.
- `render.py` — детерминированный покадровый рендер в MP4 (H.264, CRF 18, 30 fps) через Playwright + ffmpeg.

## Посмотреть в браузере

Откройте `index.html` в Chrome, Edge или Safari. Нужен интернет: Three.js и шрифт Nunito грузятся с CDN.
Сцена сама подстраивает разрешение под окно. После финала появляется кнопка «▶ Ещё раз».

Удобные параметры адреса:

- `index.html?t=17.5` — показать один кадр на 17.5 секунде;
- `index.html?from=26` — играть с 26-й секунды.

## Собрать MP4

Нужны Python 3.10+ и ffmpeg.

```bash
pip install playwright imageio-ffmpeg   # imageio-ffmpeg — запасной ffmpeg, если системного нет
python -m playwright install chromium

python render.py                         # весь мультик → out.mp4
python render.py --gpu                   # то же в окне браузера с видеокартой, намного быстрее
python render.py --start 8 --end 12 -o test.mp4   # быстрый кусок для проверки
```

Каждый кадр `k` рендерится вызовом `window.renderFrame(k / 30)`, поэтому видео не зависит от скорости
машины и кадры не пропускаются. Без видеокарты (программный WebGL) кадр занимает 3–7 секунд, весь мультик
около 1,5–2 часов. С `--gpu` это минуты.

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `-o` | `out.mp4` | итоговый файл |
| `--start`, `--end` | весь мультик | отрезок в секундах |
| `--fps` / `--crf` | `30` / `18` | частота кадров и качество H.264 |
| `--gpu` | выключено | рендер в видимом окне с аппаратным WebGL |
| `--workers` | `1` | несколько браузеров параллельно (помогает, только если у CPU много свободных ядер) |
| `--chromium`, `--ffmpeg` | из Playwright / PATH | свои пути к браузеру и ffmpeg |
| `--url` | — | открыть страницу по адресу, например с локального сервера |

## Озвучка

`voice.py` озвучивает реплики голосами RHVoice: Ната — голос «Арина» повыше и эмоциональнее, Оля — «Виктория»,
спокойнее и ниже. Тон, темп и громкость подстраиваются под настроение облачка (`sad`, `soft`), каждая фраза
начинается вместе с первой буквой в облачке. Ударения в трудных словах размечены в словаре `STRESS`.

```bash
sudo apt install rhvoice rhvoice-russian ffmpeg        # Linux или WSL на Windows
echo 'languages.Russian.stress_marker=+' | sudo tee -a /etc/RHVoice/RHVoice.conf
pip install numpy

python voice.py --update-html            # voice.wav + ротик в index.html следует за голосом
python render.py -o out.mp4              # видео (после --update-html — с синхронным ротиком)
python voice.py --video out.mp4 -o final.mp4   # наложить озвучку на видео
```

`--update-html` записывает в `index.html` огибающую громкости каждой фразы (блок `VOICE_ENV`),
и ротик открывается на гласных и закрывается в паузах. После правки реплик запустите эти три команды заново.

## Что поменять под себя

В начале `<script type="module">`:

- `LINES` — реплики, кто говорит, когда появляются (`at`) и настроение облачка (`sad`, `soft`);
- `T` — начала сцен и общая длительность `T.end`;
- `FINAL_TEXT` — финальная надпись;
- `TYPE_SPEED`, `HOLD_AFTER` — скорость печати и сколько реплика висит после допечатывания.

Позы героев лежат в `TRACKS`, планы камеры — в `CAM`, всё выражено через `T`, поэтому сдвиг сцены
в `T` сдвигает и всю анимацию внутри неё.
