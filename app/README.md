# Будет на ЕГЭ — приложение

Next.js 15 (App Router) + React 19 + TypeScript в строгом режиме + Tailwind CSS 4.
Сборка статическая (`output: 'export'`), деплой на обычный хостинг.
Существующий сайт в корне репозитория живёт отдельно и этой папкой не затрагивается.

## Запуск

```bash
cd app
pnpm install
pnpm dev
```

Откройте http://localhost:3000/styleguide — витрина дизайн-системы.

## Команды

| Команда | Что делает |
|---|---|
| `pnpm dev` | локальный сервер разработки |
| `pnpm build` | статическая сборка в `app/out/` |
| `pnpm lint` | ESLint |
| `pnpm typecheck` | `tsc --noEmit` |
| `pnpm format` | Prettier |

Готовую сборку можно посмотреть локально: `pnpm build && npx serve out`.

## Где что лежит

| Путь | Что это |
|---|---|
| `src/styles/tokens.css` | примитивы палитры и семантические токены в `@theme` |
| `src/styles/base.css` | сброс, типографика `t-*`, фокус, `prefers-reduced-motion` |
| `src/styles/components.css` | компонентный слой, перенос `design-reference/ui/components.css` |
| `src/components/ui/` | React-компоненты, по файлу на компонент |
| `src/app/styleguide/` | страница витрины и её собственное оформление |
| `src/fonts/` | Inter, по одному woff2 на начертание |

## Правила дизайн-системы

1. Компоненты используют **только семантические переменные** (`--color-primary`).
   Примитивы (`--blue-600`) и хексы (`#1F5FD0`) в компонентах запрещены.
2. Примитивы намеренно не выведены в `@theme`: утилиты вида `bg-blue-600`
   не существуют, как и `text-2xl` — размеры текста задают классы `t-*`.
3. Брейкпоинты ровно три: `md` 768, `lg` 1024, `xl` 1280.
4. Шаг сетки 4px: `p-1` = 4px, `p-4` = 16px, `p-6` = 24px.

## Шрифт

Inter берётся из пакета `@fontsource/inter`. Он поставляется отдельными файлами
на каждый юникод-поддиапазон, а `next/font/local` не умеет задавать `unicode-range`
для отдельного файла — поэтому latin, latin-ext, cyrillic и cyrillic-ext собраны
в один woff2 на начертание (`src/fonts/inter-400.woff2` и далее).
Пересобрать можно скриптом из истории коммита, если понадобится другой набор
начертаний. Лицензия — `src/fonts/LICENSE`.
