# Комплект №1 для учителей — самостоятельная по заданию 12

Бесплатный комплект по v0.1 §6: самостоятельная «Линейная функция» в
нескольких вариантах, лист учителя с ответами и краткими решениями,
последняя страница — «Частые ошибки» (текст автора, `chastye-oshibki.mjs`).

## Собрать одной командой

```
pnpm build:komplekt-12
```

Из папки `app`. Нужны зависимости проекта (`pnpm install`) и Chromium
Playwright (`pnpm exec playwright install chromium`; в песочнице путь
к готовому Chromium задаётся переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`).

Готовые файлы ложатся в `app/pdf-private/komplekt-12/`:

| Файл | Что внутри |
|---|---|
| `samostoyatelnaya-12-lineynaya-funkciya-cvet.pdf` | варианты для ученика, цвет; последняя страница — «Частые ошибки» |
| `samostoyatelnaya-12-lineynaya-funkciya-chb.pdf` | то же для чёрно-белой печати |
| `samostoyatelnaya-12-lineynaya-funkciya-otvety-uchitel.pdf` | таблица ответов «варианты × задачи» и краткие решения по вариантам |
| `sostav.json` | какие задачи, прямые и ответы вошли — для проверки |
| `html/` | промежуточный HTML каждого файла |

Папка `pdf-private` закрыта `.gitignore`: в комплекте есть ответы, а
репозиторий публичный. В `app/public` эти файлы не кладутся.

## Что можно менять

Переменными окружения, все необязательны:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `SOSTAV` | `12.A:2,12.B:2,12.C:2,12.D:2` | сколько задач из какого набора в варианте |
| `VARIANTS` | `4` | число вариантов |
| `LAYOUT` | `double-side` | раскладка листа ученика: `double-side` (две колонки, чертёж справа от условия), `double`, `single` |
| `CELL` | `3` | клетка чертежа в мм |
| `LEVEL` | `lucky` | уровень задач: `lucky` («Базовая», b читается с графика) или `unlucky` |
| `KOMPAKT` | `1` | без полос-заголовков блоков, «Вариант N» и строка для фамилии в одну строку: так восемь задач встают на одну страницу; `0` — полосы блоков и отдельная шапка варианта |
| `KRUPNYH` | `2` | сколько рядов с крупным чертежом допускается в варианте: ряд с окном ±8 (48 мм при клетке 3 мм) выше ряда с окном ±5 или ±6, и на странице A4 таких рядов помещается два |
| `KRUPNOE_OKNO` | `8` | с какого окна чертёж считается крупным |
| `KEGL` | `9.5pt` | кегль условия задачи (межстрочный 1,25): колонка текста рядом с чертежом узкая, и в кегле листа (10,5 pt) длинное условие 12.C/12.D делает ряд выше чертежа |
| `SEEDS` | `60` | на скольких seed набираются кандидаты каждого набора |
| `RAZNYE` | `1` | `0` снимает правило «прямые и ответы разные, кроме вынужденных повторов» вместе с охраной повторов — только для проб раскладки |
| `MAKS_POVTOR_OTVETOV` | `3` | сколько ответов может повториться между наборами; больше — сборка падает с перечнем |
| `MAKS_POVTOR_PRYAMYH` | `2` | сколько прямых может повториться половиной пары; больше — сборка падает с перечнем |
| `ZAPAS` | `3` | запас по высоте в мм, который должен оставаться на каждой странице листа ученика до потолка пагинатора; не хватает — у этого варианта лимит крупных рядов уменьшается на один (12.A/12.B берутся с окном ±5) и комплект подбирается заново, до трёх раз |
| `EXTRA_CSS` | — | добавочные правила стилей для проб раскладки |
| `NOMER` | `v-stroke` | номер задачи в первой строке условия, текст его обтекает: отдельный столбец отнимал у текста 9,5 мм, а рядом с чертежом ±8 тексту остаётся 26,8 мм; `v-tekste` — номер над условием; `stolbec` — отдельным столбцом слева, как на листе (тогда восемь задач на страницу не встают) |
| `ISKLYUCHIT` | `12.D-03,12.D-04` | задачи банка, которые в комплект не берутся: у 12.D-03/04 b = ±7 за рамкой окна ±5 и k = ±2,5 — по определению уровня «Базовая» это не она (в банке уровень не трогается) |
| `STOPKA8` | — | `1` — у карточек с окном ±8 условие над чертежом |

После печати каждого файла сборщик обмеряет готовую разметку в браузере.
По ширине: пагинатор шаблона следит только за высотой, а сетка в две
колонки растягивается под содержимое и может увести правую карточку
за поле; вышло за поле — сборка падает с перечнем задач и страниц,
выключить проверку нельзя. По высоте: на каждой странице листа ученика
до потолка пагинатора должно остаться не меньше `ZAPAS` мм, иначе
подбор повторяется с меньшим числом крупных рядов в этом варианте.
Запас по каждой странице печатается в отчёте сборки.


Пример: `SOSTAV=12.A:5,12.B:5 VARIANTS=4 pnpm build:komplekt-12`.

## Правило подбора

Прямые и ответы во всём комплекте разные, кроме вынужденных повторов
(у задач на пересечение прямые считаются каждая по отдельности).
Кандидаты — задачи нужного уровня на `SEEDS` разных seed;
из них перебором с возвратом набираются все варианты сразу, от тесных
наборов (12.C, 12.D) к просторным (12.A, 12.B). Крупные ряды считаются
там же: 12.C с окном ±8 занимает один из `KRUPNYH`, задачи 12.A/12.B
с окном ±8 берутся, только пока лимит не выбран.

Ответы: сначала ищется комплект, где ответ не повторяется нигде. Если
такого нет — у 12.C уровня «Базовая» разных ответов ровно восемь, и часть
из них (±7, ±13, ±14) есть и у 12.D, — действует запасное правило только
для тесных наборов: ответ не повторяется в своём наборе и в своём
варианте, а список повторов печатается в конце сборки.

Прямые: сначала без единого повтора. Если не собирается — у 12.D без
12.D-03/04 всего 26 разных прямых на восемь пар, и восемь пар с разными
ответами без повтора не набираются, — допускается повтор прямой
половиной другой пары в другом варианте: сначала один повтор, потом два,
до трёх. Целиком пара и одиночная прямая не повторяются никогда.
Повторы печатаются в конце сборки. Если и так не собирается — ошибка,
обходов нет.

### Вынужденные повторы (решение автора 01.10.2026)

Комплект по умолчанию (12.A:2, 12.B:2, 12.C:2, 12.D:2, «Базовая»)
собирается с повторами, и меньше при этом составе нельзя:

- у 12.C 8 разных ответов на 8 задач (±7, ±11, ±13, ±14), он берёт все;
- у 12.D 9 ответов, из них ±13 и ±14 совпадают с 12.C, свободных 5
  (±15, ±9,5, 12), а нужно 8 — значит, минимум 3 повтора ответа;
- восемь задач 12.D с разными прямыми и ответами не набираются вообще
  (точный перебор), поэтому прямая повторяется половиной пары.

Принятые повторы: ответы **14, −13, 13** (между наборами 12.C и 12.D;
в своём наборе и в своём варианте — нет); прямые **y = −x + 5**
(12.D-24, варианты 2 и 4) и **y = −2x + 5** (12.D-23, варианты 3 и 4).

Охрана: повторилось больше `MAKS_POVTOR_OTVETOV` ответов (по умолчанию 3)
или больше `MAKS_POVTOR_PRYAMYH` прямых (по умолчанию 2) — сборка падает
с перечнем повторов. Так правка банка не ухудшит комплект молча. Подбор
детерминирован (seed вида `komplekt:<набор>:<n>`), поэтому текущий
результат проходит.

Состав без повторов существует — 12.A:3, 12.B:2, 12.C:2, 12.D:1, но для
него нужен подбор, который берёт 12.D только с ответами, не занятыми
12.C. Не сделан, записан в `docs/tasks/12-lineynaya-pozzhe.md`.

Условия, чертежи, ответы и краткие решения приходят из движка `graph/`
и шаблона `lib/sheet/`; банк скрипт не меняет. Своего в скрипте:
подпись варианта, строка «Фамилия, имя, класс», подвал «Собрано
в „Будет на ЕГЭ“ · budetege.ru», таблица ответов и страница ошибок.
