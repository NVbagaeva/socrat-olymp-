# Комплект №1 для учителей — самостоятельная по заданию 12

Бесплатный комплект по v0.1 §6: самостоятельная «Линейная функция» в
нескольких вариантах, лист учителя с ответами и краткими решениями,
последняя страница — «Частые ошибки» (текст автора, `chastye-oshibki.mjs`).

## Собрать одной командой

```
pnpm build:komplekt-12
```

Из папки `app`. Нужны зависимости проекта (`pnpm install`) и Chromium
Playwright (`pnpm exec playwright install chromium`; в песочнице путь
к готовому Chromium задаётся переменной `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`).

Готовые файлы ложатся в `app/pdf-private/komplekt-12/`:

| Файл | Что внутри |
|---|---|
| `samostoyatelnaya-12-lineynaya-funkciya-cvet.pdf` | варианты для ученика, цвет; последняя страница — «Частые ошибки» |
| `samostoyatelnaya-12-lineynaya-funkciya-chb.pdf` | то же для чёрно-белой печати |
| `samostoyatelnaya-12-lineynaya-funkciya-otvety-uchitel.pdf` | таблица ответов «варианты × задачи» и краткие решения по вариантам |
| `sostav.json` | какие задачи, прямые и ответы вошли — для проверки |
| `html/` | промежуточный HTML каждого файла |

Папка `pdf-private` закрыта `.gitignore`: в комплекте есть ответы, а
репозиторий публичный. В `app/public` эти файлы не кладутся.

## Что можно менять

Переменными окружения, все необязательны:

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `SOSTAV` | `12.A:2,12.B:2,12.C:2,12.D:2` | сколько задач из какого набора в варианте |
| `VARIANTS` | `4` | число вариантов |
| `LAYOUT` | `double-side` | раскладка листа ученика: `double-side` (две колонки, чертёж справа от условия), `double`, `single` |
| `CELL` | `3` | клетка чертежа в мм |
| `LEVEL` | `lucky` | уровень задач: `lucky` («Базовая», b читается с графика) или `unlucky` |
| `KOMPAKT` | — | `1` — без полос-заголовков блоков, «Вариант N» и строка для фамилии в одну строку: так восемь задач встают на одну страницу |
| `OKNO` | — | `5` — брать только задачи с окном ±5 (10 клеток): при клетке 3 мм чертёж 30 мм, карточки ниже |
| `RAZNYE` | `1` | `0` снимает правило «все прямые и ответы разные» — только для проб раскладки |

Пример: `SOSTAV=12.A:5,12.B:5 VARIANTS=4 pnpm build:komplekt-12`.
Восемь задач на странице A4 при клетке 3 мм: `KOMPAKT=1 OKNO=5 pnpm build:komplekt-12`.

## Правило подбора

Во всём комплекте не повторяются ни прямая (у задач на пересечение —
пара прямых), ни ответ. Перебор идёт по задачам набора и по seed;
берётся первая задача, чьи прямая и ответ ещё не встречались. Если в
банке не хватает разных прямых или ответов, сборка останавливается
с сообщением, какой набор и вариант не добрались, — обходов нет.

Условия, чертежи, ответы и краткие решения приходят из движка `graph/`
и шаблона `lib/sheet/`; банк скрипт не меняет. Своего в скрипте:
подпись варианта, строка «Фамилия, имя, класс», подвал «Собрано
в „Будет на ЕГЭ“ · budetege.ru», таблица ответов и страница ошибок.
