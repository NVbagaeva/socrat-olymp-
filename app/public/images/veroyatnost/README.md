# Иллюстрации к заданиям №4 и №5 — теория вероятностей

| Файл                 | Размер    | Вес          | Для чего                                           |
| -------------------- | --------- | ------------ | -------------------------------------------------- |
| `labirint-glass.svg` | 908×688   | 14 КБ        | основной, для страницы                             |
| `labirint-glass.png` | 2724×2064 | 1,5 МБ       | вставка в Word и PowerPoint                        |
| `hleb-glass.webp`    | 482×448   | см. `ls -la` | иллюстрация к задаче про хлеб с макета карточки №4 |

Фон у обоих файлов прозрачный: подложка под картинкой не нужна и
только мешала бы — свечение стен уходит в прозрачность по краям.

## Картинка собирается, а не рисуется руками

Источник — `tools/gen_maze.py`: там лежат стены (`RECTS`), подписи
(`LABELS`), блёстки и паук. Стиль — в `tools/glass_style.py`.

```
python3 tools/gen_maze.py
```

Отсюда правило: **SVG нельзя править в редакторе.** Правка молча
разойдётся с генератором. Менять надо `tools/gen_maze.py` и
пересобирать.

Проверено: `kartinka(RECTS, LABELS, ...)` из `glass_style.py` даёт ровно
тот же файл, что был прислан, символ в символ.

### Метаданные C2PA убраны

В присланном SVG внутри тега `<svg>` лежал блок `<metadata>` с
манифестом C2PA — отметка о происхождении, которую проставляет сервис
при выгрузке. Она весила 7,8 КБ из 21 КБ, то есть треть файла, и
ездила к каждому посетителю страницы. Файл пересобран генератором:
21 КБ → 14 КБ, на вид не изменился ни в одной точке (сверено).

В `labirint-glass.png` такая же отметка лежит чанком `caBX` на
5,8 КБ. Из растра её не убирала: отдельной просьбы не было, а на фоне
1,5 МБ самого файла это доли процента.

## Шрифты

Русские слова в подписях — Inter, обозначения выходов `A`, `B`, `C`,
`D` — антиква курсивом, стек `Latin Modern Roman, Cambria Math, Times
New Roman, serif`. На сайте тот же стек лежит в токене `--font-math`
(`app/src/styles/tokens.css`).

Стек продублирован в `tools/glass_style.py` намеренно: SVG собирается
питоном, CSS-переменные проекта туда не доезжают.

**Отдельно про Inter.** В SVG гарнитура названа буквально:
`font-family="Inter, Segoe UI, Arial, Helvetica, sans-serif"`. На
сайте Inter подключён через `next/font/local`
(`app/src/lib/fonts.ts`), а он выдаёт шрифту служебное имя вида
`__inter_a1b2c3` и кладёт его в переменную `--font-inter`. Имени
`Inter` в документе нет. Отсюда два следствия:

- если вставлять картинку как `<img src=...>`, шрифты страницы до неё
  не дотянутся в принципе — внутри `<img>` SVG изолирован, и подписи
  наберутся системным гротеском (`Segoe UI`/`Arial`);
- если вставлять разметку SVG прямо в страницу, надо убрать жёсткий
  `font-family` с корневого тега и отдать его CSS — `var(--font-sans)`.
  Иначе результат тот же: `Inter` не найдётся, подставится `Segoe UI`.

Картинка выведена тегом `<img>`, то есть верен первый случай: подписи
на ней набраны не Inter, а `Segoe UI`/`Arial`. Иначе пришлось бы либо
вшивать Inter в сам SVG, либо втаскивать его разметку в бандл вторым
экземпляром — ради двух слов «Вход» и «Выход» это дорого. Обозначения
выходов от этого не страдают: они набраны антиквой, которая в стек
подставляется независимо.

## Где выводится

К задаче 33 подготовительных задач №5 (`/zadaniya/5`, вкладка
«Подготовительные задачи»). Разметку даёт `chertezhLabirinta()` из
`app/src/lib/veroyatnost/labirint.ts`, карточка ProblemCard ставит её
в колонку рисунка (поле `risunok`), стили — класс `.pc__chertezh` в
`app/src/components/tasks/card/problem-card.css`: до 600px на широком
экране, во всю ширину контейнера на узком.

Ответ задачи считается по тем же стенам, из которых нарисована
картинка. Правила и разбор — в
`content-source/veroyatnost-4-5/README.md`.

## Хлеб с макета карточки

`hleb-glass.webp` вырезан из присланного макета карточки задачи
(«Координатная прямая», хлеб из печи) и переведён в WebP. Задача с
макета — первый вариант прототипа p4-22 (`bank4/pryamaya.ts`), но к
нему картинка пока не подключена: у задач с моделью иллюстрация
берётся по соглашению о путях `zadanie-4/<id>.webp`, а этот файл
лежит отдельно. Подключить можно полем `illyustratsiya` прототипа
(`app/src/lib/veroyatnost/types.ts`) либо переименовав файл по
соглашению.
