# Портрет автора — облегчённые версии

Заменяет `app/public/images/author/nata-portrait.png`.
Кладётся в ту же папку, старый файл можно удалить.

| Файл | Размер | Вес | Для чего |
|---|---|---|---|
| `nata-portrait.webp` | 600×953 | 67 КБ | основной, обычные экраны |
| `nata-portrait@2x.webp` | 874×1388 | 81 КБ | экраны с высокой плотностью |
| `nata-portrait.png` | 600×953 | 698 КБ | запасной, только если WebP не отдаётся |

## Почему WebP, а не PNG

Портрет — фотография с прозрачным фоном. PNG такое сжимает плохо:
та же картинка весит 698 КБ против 67 КБ в WebP, при одинаковом
качестве. Разница в десять раз.

Проверяла ещё вариант с палитрой на 255 цветов — он даёт 109 КБ,
но на коже появляется заметная зернистость от дизеринга. Не годится
для портрета.

WebP с прозрачностью поддерживают все актуальные браузеры, включая
Яндекс Браузер. PNG в наборе оставлен только как страховка — в разметке
ссылаться надо на WebP.

## Как подключить

```html
<img
  src="/images/author/nata-portrait.webp"
  srcset="/images/author/nata-portrait.webp 1x,
          /images/author/nata-portrait@2x.webp 2x"
  width="600" height="953"
  alt="Наталия Багаева, учитель математики и автор платформы"
/>
```

`width` и `height` указывать обязательно — иначе при загрузке страница
дёргается, когда картинка встаёт на место.

`alt` осмысленный, не пустой: это не декор, а портрет человека.
