# Задание №1 «Планиметрия»: движок чертежей

Живёт в `app/src/lib/planimetriya/` — логика без React. Чертёж строится
из сцены: точки, построения, окружности и элементы по слоям. Своих SVG
в разделе нет — каждый рисунок (условие, подсказки, решение учителя,
теория, листы для печати) рисует этот движок.

## Сцена

```ts
const scena: Scena = {
  tochki: {
    ...ravnobedrennyy(180 - 2 * 37), // A, B, C — из чисел условия
    D: { seredina: ['A', 'B'] }, // построенная точка
    H: { osnovanie: ['C', 'A', 'B'] }, // основание перпендикуляра из C на AB
  },
  okruzhnosti: { w: { opisannaya: ['A', 'B', 'C'] } },
  elementy: [
    tri('A', 'B', 'C'),
    shtrih('A', 'C', 1), // штрихи равенства без второй линии
    ug('C', 'A', 'B', { vydelit: 'dano', znachenie: '37°' }),
    ug('A', 'C', 'B', { vydelit: 'iskomoe', znachenie: '106°', otvet: true }),
    ug('A', 'B', 'C', { sloy: 1 }), // слой «подсказка, шаг 1»
    otr('C', 'H', { sloy: 'reshenie', stil: 'punktir' }), // построение учителя
  ],
  proverki: [
    {
      ravny: [
        ['A', 'C'],
        ['B', 'C'],
      ],
    },
  ],
  otvet: '106°',
};
renderPlan(scena, { rezhim: { rezhim: 'podskazka', shag: 1 }, variant });
```

Построения точек: середина, основание перпендикуляра, конец биссектрисы,
пересечение прямых, прямая ∩ окружность, точка касания из внешней
точки, точка на касательной в точке окружности (`kasatelnayaV`),
точка на окружности по градусной мере, центры описанной и
вписанной окружностей, ортоцентр, точка на прямой, сумма векторов.
Окружности: центр и радиус, центр и точка, описанная, вписанная,
центр и касательная сторона.

Элементы: отрезок (штрихи 1–3, пунктир — только вне условия),
продолжение стороны (высота тупоугольного треугольника, внешний угол),
прямая (касательная), многоугольник, окружность, дуга, угол (1–3 дуги
или значок прямого угла), точка, заштрихованная область.

## Слои и режимы

- `uchenik` — лист ученика и «Задания для отработки»: только слой условия;
- `podskazka`, шаг N — условие и шаги 1…N, шаг N подсвечен (`pl-novoe`)
  и проявляется анимацией; элементы условия с `podsvetka: [N]` «загораются»;
- `uchitel` — все слои, включая `reshenie`.

Пунктир и вспомогательные окружности в слое условия — нарушение.

## Что гарантирует

- **Рисунок не спорит с условием.** Фигуры строятся из чисел условия
  (`figury.ts`), `proverki` сцены проверяются на точной геометрии:
  равные отрезки равны, угол с числом равен числу, тупой — тупой.
- **Схематичный режим.** Угол меньше порога (`POROG`, 12°) рисуется
  порогом, порядок точек сохраняется (`vidimyy`, `uglyTreugolnika`).
  Тогда сцена помечена `skhematichno`, числовые проверки углов
  выключены, топологические остаются.
- **Подписи.** Буквы — курсив KaTeX_Math, ставятся снаружи фигуры по
  биссектрисе внешнего угла; кандидаты — 24 направления и шесть
  отступов. Подпись не касается ни одной линии, дуги, окружности,
  засечки, точки и другой подписи (зазор `PL.gap`). Нет чистого места
  рядом — подпись уходит дальше и к ней ведёт короткая выноска; число,
  которое уехало от своего угла дальше 26 px, тоже получает выноску.
  Выноска не проходит через другие подписи и сама становится
  препятствием для следующих. Нет места и для выноски — нарушение в
  отчёте.
- **Живые чертежи.** Неподвижное окно сцены (`okno`): при
  перетаскивании масштаб не меняется; отчёт отдаёт преобразование
  экран ← сцена. Ограничения сцены (`zhivye.ts`) возвращают точку на
  окружность и отклоняют положения, где фигура выродилась бы.
- **Числа.** На листе ученика — только при `chisla: true` и только
  данные условия; искомое (`otvet: true`) — только на листе учителя.
  Если какое-то видимое значение (не из данных) совпадает с ответом —
  нарушение.
- **Вырожденность.** Подписанные точки не ближе 10 px, отрезки не
  короче 12 px, углы многоугольников не меньше 7°, отмеченные углы не
  меньше порога, значок прямого угла — только у прямого угла.
- **Печать.** Цвета — токены (`--graph-axis`, `--color-primary`,
  `--graph-accent`): в ч/б теме всё чернеет; искомое отличается
  толщиной и заливкой сектора, построения — пунктиром, площади —
  штриховкой.

## Проверка

```bash
pnpm test:planimetria [N]   # образцы всех прототипов во всех режимах, N случайных генераций (1000),
                            # живые чертежи, следы сторонних источников, файлы _sources/ в git
```

Стресс-тест берёт случайные числа прототипа, поворот, отражение и новые
буквы и проверяет каждый режим: нарушений движка нет, подписи заново
проверены по линиям отчёта, выноски не проходят через чужие подписи, в
SVG нет NaN, на листе ученика нет слоёв подсказок, пунктира и чисел,
переименование согласовано с условием.

Живые чертежи: 300 случайных перетаскиваний на сцену — каждое принятое
положение рисуется чисто, величины выполняют свойство карточки (сумма
углов 180°, суммы противоположных сторон равны…).

Раздел целиком: «О задании» — `/zadaniya/1/`, теория — `…/teoriya/`,
«Опорные задачи», «Тренажёр», «Генератор», «Для репетиторов».
Проверки: `pnpm test:planimetria` (движок, банк, теория, тренажёр и
листы), `pnpm test:seriya-1` (серия уроков по коду, байт в байт),
