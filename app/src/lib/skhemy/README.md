# Движок живых схем (`lib/skhemy`)

Интерактивные чертежи «Ключевых схем» №18 и, дальше, «Опорных задач» и
«Тренажёра» планиметрии части 2. Логика без React; компонент —
`components/skhemy/ChertezhSkhemy.tsx`.

| Файл            | Что делает                                                                                          |
| --------------- | --------------------------------------------------------------------------------------------------- |
| `tipy.ts`       | схема (`ZhivayaSkhema`), кадр, элементы, вид (поворот, отражение)                                   |
| `geometriya.ts` | геометрия движка №1 (`lib/planimetriya/geom.ts`) плюс вневписанная окружность, треугольник по углам |
| `dsl.ts`        | конструкторы элементов: `otr`, `okr`, `mnog`, `ug`, `tch`                                           |
| `ekran.ts`      | кадр → примитивы SVG в пикселях: рамка, масштаб, дуги углов, засечки, подписи                       |
| `podpisi.ts`    | места подписей: не касаются линий, окружностей, дуг, ручек и друг друга; в тесноте — выноска        |
| `svg.ts`        | неподвижный SVG схемы строкой — для карточек по теории, рисуется на сборке                          |

## Схема

Схема — функция от положений подвижных точек: `postroit(t)` отдаёт кадр.
У элемента есть **группы подсветки** (`gruppy`), **шаг построения**
(`shag`) и флаг `skrytyy` — виден только при подсветке своей группы
(вспомогательные окружности, заливки подобных треугольников, дуги
равных углов). Цвет подсветки — `a` (синий), `b` (терракота),
`c` (бирюзовый); словарь `{ группа: цвет }` — если у элемента в разных
группах разный цвет.

`ogranichit` отклоняет положения, где фигура выродится;
`sluchaynaya` даёт случайное невырожденное положение для карточек.

## Гарантии

- Всё считается в пикселях экрана: при повороте буквы стоят прямо, а
  кегль и дуги на телефоне те же, что на компьютере.
- Рамка подстраивается под видимое плавно и замирает, пока точку тянут.
- Кадр с NaN или бесконечностью (промежуточный кадр анимации) не
  рисует такие элементы.

Пример — `lib/zadanie18/skhemy/vysoty.ts`. Проверка схем — `pnpm test:skhemy-18`
(`scripts/verify_schemes/`): каждое следствие и шаг доказательства на
1000 случайных конфигурациях и экранная раскладка.

Чертежи опорных задач №18 — те же схемы: `lib/zadanie18/opornye/`
(сцена из короткого описания — `obshchee.ts`, `scena()`), исходное
положение — данные пункта б). Проверка — `pnpm test:opornye-18`
(`scripts/verify_opornye18/`).

Чертежи задач тренажёра №18 устроены так же: `lib/zadanie18/trenazher/`
(сцены через тот же `scena()`). Проверка — `pnpm test:trenazher-18`
(`scripts/verify_trenazher18/`).
