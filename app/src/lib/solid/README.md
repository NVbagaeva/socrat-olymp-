# Движок стереометрических чертежей, задание №3

Живёт в `app/src/lib/solid/` рядом с `graph/` и так же не знает о React:
модель → строка SVG. Компонент `components/solid/Solid.tsx` вставляет
эту строку на страницу.

## Слои

| Файл | Что делает |
|---|---|
| `vec.ts` | векторы в пространстве и на плоскости |
| `project.ts` | одна проекция на весь раздел и её константы |
| `model.ts` | типы модели: тела, пометки, описание; помощники для граней |
| `visibility.ts` | видимость: линия делится на видимые и скрытые куски по модели |
| `render.ts` | `renderSolid(model) -> SVG`; оформление в `THEME`, цвета только токенами |
| `figures.ts` | сборщики тел: призмы, пирамиды, параллелепипеды, усечённые тела |
| `catalog.ts` | 45 базовых фигур старого каталога, для витрины |

## Проекция

Ортогональная (параллельная) проекция: зритель спереди-справа
(поворот 28°) и сверху (подъём 25°). Сфера остаётся кругом,
горизонтальная окружность — эллипсом с горизонтальной большой осью
(отношение осей ≈ 0,42), вертикальные рёбра вертикальны, параллельность
и отношения отрезков на прямой сохраняются. Углы и ориентация
правильных многоугольников (`polygonStart`) подобраны так, чтобы ни одно
ребро основания не ложилось вдоль луча зрения, ни одна вершина не
вставала на ось чертежа (иначе высота пирамиды совпадёт с ребром)
и задние вертикальные рёбра не прятались за передними: самое
сокращённое ребро основания сохраняет не меньше 0,48 своей длины,
проекции соседних вертикалей расходятся не меньше чем на 14 % ширины.

## Видимость

Линия опрашивается в десятках точек; точка скрыта, если между ней
и зрителем лежит грань непрозрачного тела (проверка попадания
в проекцию грани и сравнение глубин) или поверхность шара. Границы
кусков уточняются делением пополам. Своё ребро своя грань не прячет.

Тела вращения для заслонения разбиты на 48 граней, а их собственные
контуры считаются точно: образующие конуса касаются эллипса основания
в точках, где `sin u = (r / h)·tg φ` (φ — подъём взгляда); у цилиндра
это крайние точки эллипса; невидимая половина нижнего основания —
дуга за точками касания.

В комбинациях внешнее тело помечается `glass: true`: сквозь него видно
всё, что внутри, но свои невидимые рёбра оно по-прежнему прячет само.
Внутреннее тело непрозрачно и прячет чужие линии, включая
вспомогательные внутри себя.

## Модель

```ts
const model: Model = {
  alt: 'Куб ABCDA₁B₁C₁D₁ с диагональю AC₁',
  bodies: [box(4, 4, 4)],
  lines: [{ a: A, b: C1 }],
  angles: [{ at: C, u: dir(C, A), v: dir(C, C1) }],
};
```

Тела: `polyhedron` (вершины, грани, имена), `cylinder`, `cone`
(в том числе усечённый и перевёрнутый сосуд), `sphere` (экватор,
сечения). Пометки: `marks` (точки с подписью), `lines`
(вспомогательные отрезки с подписью), `angles` (знак прямого угла),
`sections` (сечение с заливкой), `measures` (число у ребра).

## Оформление

Цвета в `THEME` только через переменные: `--solid-edge`, `--solid-face`,
`--solid-liquid` (объявлены в `styles/tokens.css`), `--graph-accent`
для вспомогательных построений, `--color-text` для подписей,
`--color-surface` для обводок. Невидимые рёбра — тот же цвет
с прозрачностью и штрихом. Шрифт подписей — `--font-sans` (Inter),
индексы — `tspan` меньшего кегля.

Подписи расставляются автоматически: у каждой перебираются
16 направлений на двух расстояниях, штрафуются пересечения с линиями,
точками и другими подписями, поощряется положение снаружи фигуры.
