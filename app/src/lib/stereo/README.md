# Общее ядро стереометрических чертежей (№3 и №15)

Чистый TypeScript: без React, без three.js, без DOM. Считается и
в браузере (на каждом повороте), и в node (сборка, листы, автотесты).
На нём работают интерактивный чертёж задания №15
(`components/zadanie15/chertezh/dvizhok.ts` через `lib/zadanie15/render`)
и чертежи задания №3 (`lib/chertezh3`).

| Файл | Что делает |
|---|---|
| `vec.ts` | плавающие векторы в пространстве и на экране |
| `telo.ts` | выпуклое тело гранями: грань, ребро, `teloIzGraney`, `teloIzIndeksov`, блок `blok` |
| `vidimost.ts` | камера (параллельная/центральная), видимость: правило граней для рёбер выпуклого тела, луч к зрителю для остальных линий |
| `tela.ts` | рисуемое тело — интерфейс сцены: выпуклые части для заслонения и свои линии при данной камере; `vypuklyy`, `izChastey` (невыпуклое тело) |
| `proekciya.ts` | базис экрана, ракурс (азимут и высота), поворот перетаскиванием, подписи текстом SVG |
| `metki.ts` | раскладка подписей: 16 направлений, кольца, запасные точки вдоль отрезка, штраф за подписи и линии, память направления |
| `vrashchenie.ts` | задел: интерфейс тел вращения, половины окружности основания |

## Видимость

- Ребро выпуклого тела невидимо, если обе его грани повёрнуты от
  зрителя — точное правило (так было и в №15).
- Любая другая линия (сторона сечения, высота, диагональ, ребро
  невыпуклого тела) делится на куски: точка закрыта, если луч от неё
  к зрителю входит внутрь какой-нибудь выпуклой части. Грубый шаг
  по отрезку, границы уточняются делением пополам.
- Невыпуклое тело (фигура из кубиков) держится набором выпуклых
  частей (блоков). Своё ребро на видимой грани свой блок не закрывает:
  луч от него сразу уходит наружу. Автотест сверяет правило граней
  с лучом на выпуклых телах при сотне ракурсов.

## Что перенесено из №15

`render/geom.ts`, `render/metki.ts` целиком, тело и грани из
`render/scena.ts`, правила видимости из `render/vidimost.ts`, базис и
подписи SVG из `render/eksport.ts`. Старые модули №15 реэкспортируют
ядро — импорты №15 не менялись, `pnpm test:zadanie15` зелёный.
