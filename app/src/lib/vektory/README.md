Живёт в `app/src/lib/vektory/` — логика без React. План раздела и
порядок этапов — в `docs/tasks/02-vektory-00-plan.md`.

## Чем рисует

Тема общая с чертежами №12: `THEME` из `lib/graph/renderer.js` даёт
клетку (34 px), поле, цвета-токены (`--graph-axis`, `--graph-grid`,
`--graph-accent`, `--color-surface`), толщины, кегли и стрелки осей.
Оттуда же четыре текстовых помощника: `esc`, `px`, `textWidth`,
`svgText` (гало под подписью). Своё здесь — векторы, подписи со
стрелкой, проекции и катеты.

В ч/б теме печати (`lib/sheet/theme.css`) те же токены дают чёрные оси
и векторы и серую сетку: отдельного «печатного» режима у движка нет.

## Конфиг

```ts
renderVectorPlane(
  {
    vectors: [{ name: 'a', from: [1, 1], to: [3, 5] }],
    window: { xmin: -1, xmax: 13, ymin: -2, ymax: 11 } | 'tight', // по умолчанию DEFAULT_WINDOW
    grid: true, // false — только оси, проекции концов и их числа (B6, B7)
    hints: false, // true — катеты Δx, Δy пунктиром с «+3», «−2»
    alt: '…', // без него рисунок — декор (aria-hidden)
  },
  report,
);
```

Окно расширяется под векторы так, чтобы до края оставалась клетка;
`'tight'` — окно только по векторам и началу координат.

## Что гарантирует

- Остриё наконечника стоит ровно в узле сетки конца вектора:
  наконечник — многоугольник от точки узла, стержень укорочен на длину
  наконечника без 1 px захода. Маркер `<marker>` не используется:
  положение острия с ним зависит от `refX`, и числом его не проверить.
- Подпись вектора — буква со стрелкой — не касается ни одного отрезка,
  оси, стрелки и другой подписи. Кандидаты: предпочтительная сторона
  (от начала координат) и другая, шесть смещений, семь сдвигов вдоль
  вектора; первый чистый и выигрывает. Нет чистого — лучший из плохих
  и запись в `report.problems`.
- Катеты рисуются только по явному `hints: true`; элементы помечены
  `data-hint`, по ним автотест проверяет их отсутствие на листах.
- В `report.problems` попадают и нарушения ограничений генератора:
  векторы пересекаются, ближе клетки, короче двух клеток, лежат на оси,
  закрывают подпись, числа на оси (без сетки) ближе 1. Генератор по
  пустому списку принимает расположение.

## Проверка

```bash
pnpm test:vektory [N]     # образцы витрины + N случайных рисунков (по умолчанию 300)
```

Самотест сверяет отчёт движка с разметкой SVG (остриё, начало и
укорочение стержня) и независимой геометрией проверяет, что подписи
ничего не касаются. Случайный рисунок берётся, только если движок
счёл его чистым; доля чистых не ниже половины — иначе движок слишком
строг для генератора.
