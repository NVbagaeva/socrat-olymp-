# Ядро сечений, задание №15

Чистый TypeScript без графики и React. Рендер (SVG со своей камерой,
`../scene`), инструменты ученика, обоснования и проверка заданий
строятся поверх ядра.

## Точность

Решения не сравнивают float «на глаз».

- `rational.ts` — дроби на BigInt, всегда несократимые; равенство
  точное.
- `surd.ts` — числа вида k√m (m без квадратов) и суммы таких
  слагаемых с приведением подобных; вывод в TeX и короткой строкой.
- `vec.ts` — векторы, прямые и плоскости с дробными координатами:
  «лежит в плоскости», «параллельны», «скрещиваются» решаются точно;
  `intersectPlanes` — прямая пересечения двух плоскостей (или ответ
  «параллельны» / «совпадают»).

Приближённые значения (`toNumber`, `toArray`) — только для рисования.

## Многогранник

`polyhedron.ts`: вершины с именами (TeX: `A_1`), грани списками
вершин, рёбра выводятся из граней (у каждого — две соседние грани).
Сборщики: `box(a, b, c)` — ABCDA₁B₁C₁D₁ с AB = a, AD = b, AA₁ = c;
`cube(a)`. Призма, пирамида, тетраэдр добавляются новым сборщиком —
ядро о форме тела ничего не знает.

## Сечение и расчёты

- `section.ts` — сечение плоскостью: упорядоченные вершины выпуклого
  многоугольника (обход по полуплоскостям, без atan2), у каждой —
  ребро и параметр или вершина и грани; случаи «совпадает с гранью»,
  «касание», «не пересекает»; `edgeCuts` — в каком отношении делятся
  рёбра; `polygonKind` — треугольник, трапеция, правильный
  шестиугольник…
- `measure.ts` — площадь, периметр, cos/sin/tg угла между плоскостями,
  расстояние от точки до плоскости — всё точно.

## Построение и происхождение

`construction.ts`: класс `Construction`. Каждый объект хранит
`origin` — операцию и аргументы:

| op          | что                                                | родители               |
| ----------- | -------------------------------------------------- | ---------------------- |
| `vertex`    | вершина многогранника                              | —                      |
| `onEdge`    | точка условия на ребре или продолжении, параметр t | —                      |
| `free`      | точка «на глаз» — не обоснована                    | —                      |
| `edgeLine`  | прямая ребра                                       | концы ребра            |
| `line`      | прямая через две точки одной плоскости             | две точки + плоскость  |
| `intersect` | точка пересечения прямых одной плоскости           | две прямые + плоскость |
| `parallel`  | прямая через точку параллельно данной + теорема    | прямая, точка          |
| `plane3`    | плоскость через три точки (с меткой α, β…)         | три точки              |
| `planeMeet` | прямая = α ∩ β, пересечение двух плоскостей        | две плоскости          |

Правила метода следов — внутри операций, нарушение возвращает отказ
с кодом и текстом для ученика:

- соединять можно только точки одной грани (или её продолжения):
  `not-coplanar` — «Эти точки не лежат в одной грани — так соединять
  нельзя»;
- пересекать — только прямые одной плоскости: `skew` — «Эти прямые
  скрещиваются — точки пересечения нет», `parallel`;
- линия пересечения есть только у непараллельных различных плоскостей:
  `parallel-planes` — «Плоскости параллельны — общей линии нет»,
  `same-plane`;
- имена точек: заглавная буква, индекс, штрихи; уникальны.

`chain(id)` — цепочка от точек условия к объекту, `grounded(id)` —
обоснована ли точка (в цепочке нет точек «на глаз»), `dependents` и
`remove` — удаление со всем зависимым.

Плоскость в операциях — `PlaneRef`: грань многогранника
(`{ kind: 'face', face }`) или построенная плоскость
(`{ kind: 'plane', id }`); `planeTex` даёт её имя для KaTeX —
`\alpha`, `(MNK)` или `(ABC)` по вершинам грани.

Вокруг линии пересечения:

- `planeMeet(a, b)` — прямая a ∩ b; если такая уже есть, возвращает её;
- `meetThrough(line)` — две общие точки плоскостей, уже лежащие на
  прямой (для обоснования «M ∈ α, M ∈ β; N ∈ α, N ∈ β ⇒ MN = α ∩ β»);
- `lineEdgeHits(line)` — где прямая пересекает рёбра и их продолжения:
  кандидаты в вершины сечения, с признаком «на самом ребре»;
- `describe(id)` — текст шага с обоснованием (TeX в `$…$`), `steps()` —
  порядок шагов построения без вершин тела;
- `setEdgeParam(id, t)` — сдвиг точки условия по ребру с пересчётом
  всего зависимого по графу происхождения (`recompute`); если какой-то
  объект при этом исчезает (прямые стали параллельны), сдвиг
  откатывается и возвращается отказ.
