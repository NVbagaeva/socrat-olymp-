# Сцена задания №15: SVG со своей камерой

Без three.js: ортографическая камера (поворот yaw/pitch, по умолчанию
28°/25° — как чертежи `lib/solid`), проекция на плоскость экрана и
сборка готовой 2D-сцены, которую React рисует в `<svg>`
(`components/tasks/zadanie15/StsenaSvg.tsx`).

- `camera.ts` — камера, базис, проекция, глубина; `facingPlane(n)` —
  камера, смотрящая на плоскость перпендикулярно (с ближней стороны);
  `lerpCamera` для плавного поворота; `orbit` для перетаскивания.
- `geom.ts` — float-геометрия для рисования: рамка (`frameOf`, ~1,5×
  тела), многоугольник «плоскость ∩ рамка», обрезка прямой рамкой,
  полуплоскости, видимость отрезка по выборке точек против передних
  граней (`segmentRuns` — куски «видно»/«скрыто»).
- `scene.ts` — `buildScene(construction, options)`: грани, рёбра,
  листы плоскостей (`sheets`, цвет из палитры `--color-plane-*`,
  плоскости граней — светлым), сечения, линии пересечения (`meet`),
  прямые построения (`aux`), продолжения рёбер (`ext`), точки,
  кандидаты в вершины, сообщение «плоскости параллельны». Режим
  `learn` показывает линии и кандидатов сам, `train` — только после
  `reveal`. `upTo` ограничивает число показанных шагов (пошаговый
  показ). Подписи раскладываются без наложений детерминированно
  (`spreadLabels`), поэтому не мигают при повороте.
- `scenarios.ts` — три сценария витрины `/styleguide/zadanie-15`.

Точность — в ядре (`../core`, дроби); здесь только числа для экрана.
