# Рисунок сечений, задание №15

Чистый TypeScript без three.js и React — считается в node и
проверяется `pnpm test:zadanie15`. Движок на three.js
(`components/zadanie15/chertezh/dvizhok.ts`) только вызывает эти
функции на каждом кадре.

- `scena.ts` — сцена из ядра: тело гранями (рёбра выводятся),
  сечение, вспомогательные отрезки, подписи; школьный ракурс, при
  котором сечение не смотрит ребром.
- `vidimost.ts` — видимость для параллельной и центральной проекции,
  аналитически (не буфером глубины WebGL). Ребро невидимо, если обе
  его грани повёрнуты от зрителя; сторона сечения — по грани, в
  которой лежит (на краю — видна). Любой другой отрезок (след,
  продолжение, контур секущей плоскости) разбивается точками, где в
  проекции он пересекает контуры лицевых граней и контур плоскости или
  протыкает грань; каждый кусок проверяется по середине — закрыт ли
  он лицевой гранью.
- `instrument.ts` — инструмент «Сечение по трём точкам»: выбор точек
  (вершина, точка на ребре или в грани с округлением до 1/12),
  счётчик, отмена, сброс, проверки с текстом для ученика; сцена с
  сечением и секущей плоскостью (параллелограмм с запасом вокруг
  сечения). Порядок рисования: плоскость → сечение → линии.
- `razrez.ts` — разрез тела плоскостью на две выпуклые части
  (анимация «разрезать»).
- `naturalnaya.ts` — сечение в натуральную величину.
- `metki.ts` — подписи: 16 направлений, штраф за наложение на
  подписи, линии и точки, скидка прежнему направлению (не прыгают).
- `eksport.ts` — SVG в параллельной проекции (экспорт PNG/SVG,
  натуральная величина).
- `primery.ts` — сцены витрины: сечения из тестов ядра, для
  пятиугольника — построение следами.

Витрина: `/zadaniya/15/vitrina/` (noindex, без ссылок).
Проверка на сайте: `pnpm test:zadanie15-vitrina`.
