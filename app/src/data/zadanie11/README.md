# Задание №11: открытый банк и разминка

- `bank.json` — задачи открытого банка ФИПИ (открытые данные).
- `razminka.json` — разминка (раздел РЗ): свои задачи, не банк и не ЕГЭ.

## Как добавить задачу

Одна задача — одна строка:

```json
{ "id": "DP-07", "params": { "form": "velo", "S": 156, "d": 1, "ask": "AB" }, "answer": 12 }
```

- `id` — код подтипа латиницей (`PR`, `SM`, `DP`, `PT`, `VD`, `OK`, `RB`, `PG`, `RZ` и номер).
- `params` — числа условия и выбор формы. Какие ключи нужны подтипу — смотрите
  первые строки его `solve` в `src/lib/zadanie11/prototypes/<раздел>.ts`
  (`num(p, 'S')` — число, `str(p, 'ask', [...])` — выбор из списка) или
  соседние строки того же подтипа в этом файле.
- `answer` — ответ, как в банке. Он контрольный: условие, решение и ответ
  строит функция подтипа, а автотест сверяет её ответ с этим числом.

Время в минутах там, где в условии «1 час 20 минут» (`"dt": 80`), часы по
циферблату — числом часов (`"t0": 10` — это 10:00).

После правки: `pnpm test:zadanie11` (из папки `app/`). Посмотреть задачу
текстом — `node scripts/print-zadanie11.mjs DP-07 3` (третья задача подтипа).

## Новые задачи

Генераторы — `src/lib/zadanie11/gen/`: сначала выбирается ответ и «внутренние»
величины, затем данные условия. Посмотреть новые задачи подтипа:
`node scripts/print-zadanie11.mjs --gen DP-07 5`.

## Пул аналогов (`analogs/<код>.json`)

По 10 вычитанных «новых» задач на прототип: та же модель и та же
функция `solve`, что у задачи банка, другие числа и сюжет. Запись:
`id` («ДП-07-a01»), `prototypeId`, `source: "analog"`, `level`,
`params` (модель + слова сюжета: `geroy`, `vv`, `tara` — словари в
`lib/zadanie11/prototypes/syuzhety.ts`; у разминки, процентов и смесей — свободные слова
вроде `tovar`, `mat`, `zan`, их читает `slovo()` из `kit.ts`, а без
них `solve` пишет слова задачи разминки), `text` (условие, написано
вручную), `ask`, `answer`, `plotTag`. Для разминки (РЗ) аналоги
сверяются с `razminka.json`, а не с открытым банком. Слово сюжета
нужно добавить в `SYUZHET` самотеста — тогда оно не участвует в
сравнении параметров. Подключение — строка в
`lib/zadanie11/analogi.ts`. В тренажёре и генераторе аналоги — это
«новые» задачи: в режимах «Банк + новые» и «Только новые» они идут
первыми, генератор — когда пул кончился. В браузер уходят без ответа.
Проверки — `lib/zadanie11/analogi-selftest.ts`; вычитка —
`/zadaniya/11/proverka-analogov/` (служебная, noindex).
